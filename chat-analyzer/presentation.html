01 — 初心

为什么需要 AI 来分析聊天？

在一段关系中，我们常常陷入主观判断——今天聊得好吗？Ta 对我有意思吗？ 这些问题没有标准答案，但数据可以提供一个参照系。

🎭

主观偏差

情绪好的时候觉得一切完美，
情绪低落时又过度悲观

📊

缺乏量化

每天聊几百条消息，
但无法客观评估互动质量

🔍

信息遗漏

对方透露的喜好、愿望、经历，
聊过就忘，缺乏系统记录

📈

趋势盲区

只看今天不知道走向，
关系是在升温还是降温？

核心洞察

聊天记录是一座未被开采的金矿。每一条消息都包含了互动的温度、节奏和深度—— 但人脑无法同时处理数千条消息的多维信息。LLM 恰好擅长这件事：在海量文本中发现模式、评估质量、提取关键信息。

02 — 想法

让 LLM 成为你的关系观察者

不是让 AI 告诉你"该怎么做"，而是提供一个客观、量化、可追溯的视角，帮助你更清醒地认识关系中的自己。

📝

每日日记生成

LLM 以第一人称视角将每天的聊天总结为 100-200 字的日记。不是冷冰冰的摘要，而是有情感、有反思的私密记录——就像你亲自写的一样。

📊

五维量化评分

从互动质量、对方投入度、自我暴露、节奏感、关系进展五个维度评分。每个维度都有客观数据锚点（消息数、回复间隔、主动发起次数等），避免 LLM 随意打分。

🎯

人物画像提取

自动从对话中提取对方透露的个人信息——爱好、背景、愿望、过去经历。持续更新、自动去重，帮你真正"了解"一个人。

🔔

信号与预警

每天输出一个正面信号和一个风险信号。连续低分自动预警，帮助你及时调整互动策略。

"我们需要的不只是一个聊天记录备份工具，而是一个能理解对话深度的分析系统。LLM 让这个想法从不可能变为可能。"

—— 项目核心理念
03 — 实现方法

技术架构与流水线

从原始微信导出到可视化报告，一条完整的 LLM 驱动分析流水线。

📱 微信聊天
→
📤 WeChatMsg 导出
→
🔧 Parser 解析
→
🤖 LLM 分析
→
📊 报告生成
→
🌐 HTML 看板
1

解析层 — ChatParser

解析 WeChatMsg 导出的 JSON/文本格式，统一时间戳、识别消息类型（文字/图片/表情/语音），支持凌晨 4 点日界线规则。

Python · JSON · 正则表达式
2

总结层 — Summarizer

调用 DeepSeek API，以第一人称视角生成日记式总结（100-200字）+ 次日行动计划。启用 thinking 模式进行深度推理。

DeepSeek API · Prompt Engineering · Temperature 0.7
3

评估层 — Evaluator

五维评分系统：互动质量(×1.5)、对方投入度(×2.0)、自我暴露(×1.5)、节奏感(×1.0)、关系进展(×1.0)。每个维度先用统计规则计算锚点分数，再交由 LLM 在锚点附近微调。评分时参考近 3 天历史分数做校准，确保趋势一致性。这是整个系统最核心的模块。

加权评分 · 统计锚点 · 历史校准 · Temperature 0.3
4

画像层 — PortraitUpdater

从对话中增量提取对方信息，按爱好/信息/愿望/过去四类归档。自动语义去重，避免信息冗余。严格过滤"我"的信息，防止污染。

增量更新 · 语义去重 · 身份过滤
5

报告层 — ReportGenerator + StageAnalyzer + Reporter

生成交互式 HTML 单页看板（含聊天查看器、评分趋势图、消息热力图、人物画像），阶段分析报告（整体评估+风险预警+下一阶段建议），趋势报告（维度变化方向+异常检测），以及 Markdown 文件树导出（适合归档到文档系统）。

HTML/CSS/JS · ECharts风格图表 · Markdown导出

05 — 总结

这个项目的意义

💡

技术验证

证明了 LLM 可以在高度主观的领域中提供有价值的量化分析。关键设计在于：用统计锚点约束 LLM 的评分范围，用历史校准保证趋势一致性，让 AI 的"主观"建立在"客观"之上。

🔧

工程实践

一套完整的 LLM 应用工程实践：Prompt 模板管理、API 调用优化（缓存/温度/thinking 模式按需开关）、增量处理、数据流水线设计、多格式输出（JSON/Markdown/HTML）。

🎯

个人价值

最重要的不是分数本身，而是"被看见"——看见自己的互动模式（话太多、节奏失衡），看见对方的付出（主动发起、深度分享），看见关系的走向。数据不会说谎，但需要你去解读。

"技术的终极目的不是替代人的判断，而是帮助人更清醒地做出判断。Chat Analyzer 不是告诉你好还是不好，而是给你一面镜子，让你看见关系中真实的自己。"
