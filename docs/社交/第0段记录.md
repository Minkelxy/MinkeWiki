# 第0段记录

人生得一知己足矣，斯世当以同怀视之。

## 日日记

### 前言
　　5月初开始主动进行社交，本质上应该是出于对未来的恐慌，一种来自未来的孤独感。我其实很少感受到孤独，只有回忆过去的时候，才会感到压抑。这两个月的社交发生了很多事情，但我的心情还是很平淡的，整个社交像是一场实验，事情没有超出我的预料。虽然我从一开始就不觉得执行这样的计划会有什么好结果，但做起来还是能让我安心一点。

　　但是这周，这两天，我真的完全沉迷进去了。偶然（也不太偶然）尝试了攀岩，觉得岩馆的大哥大姐挺好的，和他们聊天让我的压力缓解了很多，后来刻意的办了个聊天次卡，自然而然地加了他们的微信。这之后，岩馆就变成了我每次回来一定会去的地方，一开始还是匆匆来匆匆走，后面待的时间越来越长。因为回来的次数越多，越感到这座城市好像没有我的容身之所，他们是我少数能聊天的人了。

　　我没有刻意安排，但来到这里，至少不用在银川的街头乱撞。我会聊到自己生活和想法，咨询他们的建议，大哥的意见大多是狗屁，大姐的建议值得思考——她说我其实不知道自己在干什么，感情上也多少带点受虐倾向。

　　这周末我又来到这里，这次不知道是触发了怜悯机制还是保底机制，他们开始给我更多建议。姐姐给我介绍了她妹妹。我一开始其实是拒绝的，一是我已经开始放弃了，二是我怕得要死——毕竟这是真正的普通陌生人，不像网上认识的网友，没什么压力。

　　拿到微信后，我犹豫了好久才决定试试，毕竟这是第一个算是熟人介绍的人，如果不试试，完全是辜负了姐姐的好意。而且姐姐说得对：不要一上来就想着往对象的方向发展，应该先交朋友，压力没必要这么大。其实我还有疑问，我发现我既不知道自己为什么要找对象，也不知道为什么要交朋友。

第一天的聊天不温不火吧。我喜欢给人贴人类和非人类的标签，这次鬼使神差的贴了个好人标签。我罕见地很有分享欲，她也没有设立高高的社交围墙，我们聊了不少东西。我觉得对于孙楷亮的社交历史，这真的是一个伟大的胜利，但又开始考虑自己会不会表现得太过激动，要不要控制自己的表现，我把欲望又写在自己脸上了。

　　第二天我果然被这种顾虑束缚，选择不主动交流。其实我已经开始开心地和朋友分享这件事了，却还是觉得自己没办法往下推进交流。

　　快要离开银川了，才在晚上分享了一下这一天的经历，愈发感觉和她聊天很舒服，我不知道是因为她很会聊天，还是她的社交能力已经足以把我包围了。我迫切地想继续交流。她罕见地对智能体的使用有兴趣，不过想想也正常，学生有刚需，也容易接受新事物。和她聊聊这些话题也不错。她和我分享了看的话剧，对作品的鉴赏无疑是可以产生碰撞和共鸣。雷雨虽然忘得差不多了，但是还是可以找一些想法讨论，这个过程也不需要刻意，感受着她的情绪波动和多愁善感，愈发地察觉心在跳动。我其实突然想到一句话，仕宦当作执金吾，娶妻当得阴丽华。我开始胡思乱想了，开始考虑我不应该想的很多事情。

　　其实到这个时候我已经感受到了。我会和朋友说，我好像遇到了一个不一样的人。这个人健康、自信、积极向上，和她聊天的时候能感觉到心跳，上班时也会抽时间去聊，不聊天的时候也在想象和计划一些相关的事情。我意识到这种程度的刻意已经有点踩雷区了，必须控制这种不正常的情感。我分不清热情和冒犯的分界线，那就尽量不要胡乱扩展话题，不要老是往自己想的东西上聊。

　　我们继续聊着——其实也没聊多少，但她在我眼里愈发闪耀，我也愈发恐慌。我害怕她不属于我，不想被发好人卡，也不想当个陌生人。我应该去学习聊天和交往了。我真的反感天命说，但这个时刻，我有点迷信了：我感觉这就是我的命运。我不能再畏畏缩缩了，患得患失只会失去一切，想得越多越不能做自己。我应该做一些更有用的事情。

　　我做了一个梦，又是过去的事情，仿佛在提醒我还会重蹈覆辙。不过，我现在一个人活得很好了，这次我不会那么脆弱和敏感了，准备好面对这些自我怀疑。"死缠烂打"这个词不太好听，我以前从来没这么想过，但现在已经管不住自己的思绪了。思考走得太远，该做出行动了。

　　我是很容易想多的人。作为一个拖延症患者，是焦虑拖着我前进。考虑太多、想法太多，不一定是坏事，当然也不一定是好事：好处是我能考虑到不少实际情况，坏处是想了更多不切实际的事情。

　　这些不切实际的想象里，有感情迅速升温的画面，有一起生活的场景——这些想法对别人来说可能很雷吧。另一些想象则走向另一个极端：感情迅速破裂（甚至怀疑会不会先有感情）、互相欺骗，还有韩剧里那种狗血剧情。

　　这些想象的危害主要体现在对我行动的影响上，比如害怕见面，恐惧自己不熟悉的事情。说到底我根本没正常谈过恋爱，想象只能从有限的小说和影视剧里拼凑，拼凑出狗血也很正常。

　　纷乱的思考是灾难的开始，所以要限制这种想法。就用这个方式：记录和计划。所谓记录，除了实际发生的事情，还包括脑中所想，确保自己没有偏离；所谓计划，是约束自己的行为、预估自己的方向。这两者结合，才能表现得像个正常人。

　　既然是长期计划，就必须做好长期准备。目前看来，有必要记录自己——这是日后回忆的必要材料。

## 7-11
　　一个显然的事实是：AI的记录看上去客观，其实是盲人摸象。它能评估的是另一侧的反应和感受，却没办法反映我的想法。毕竟人是黑盒子，我投射出的那一点行为，只能勉强用来预测我的行动。

　　那我想记什么呢？我觉得是情绪。我的狗头军师比AI好就好在能感受我的情绪。今天mbf过生日，我很认真地再次表示，这次真的真的真的爱上一个人了。朋友吐槽我：人都没见到，爱什么呢。我说，这个人真的很好——认识她的第二天，我就和mbf说我恋爱了，那会儿连话都没聊几句呢。

　　为了向朋友证明这是个好人，我讲故事、亮证据。男生很容易就被我说服了，谷哥就麻烦一点。

　　她好像担心我遇人不淑，从前就会劝我不要回去。其实我也理解，作为北京土著，她很难理解我的心理，我是很懒的，脑子里想的总是怎么可以轻松一点，对我来说，留在哪个城市其实都过得下去，我也没什么好挑剔的，但总是会觉得自己让未来太忙碌了，我不想这样。听她说了半天，我才明白她是很反感那种不公平的恋爱关系，讨厌任何一方向下兼容。她举了党一凡的例子，认为他为了自己能指指点点，找了层次低于自己的人。谷哥很在意对等，好像笃定我回去就一定会谈不对等的感情一样。

　　不过前段时间确实有点这样。不知道从什么犄角旮旯翻出来的人，我都会凑过去交流，毫无底线。虽然有测试的原因，但这事确实发生过。不过一个多月过去，我的热情已经被消磨殆尽了。最近的生活又回归平静了。

　　谷哥说的有一部分对，我是有意识地在找和我不太匹配的人，不过原因没那么黑暗：我觉得自己还有很多问题，总是羞于启齿，总觉得说出来会破坏别人对我的印象，还有一种淡淡的自卑感。我不想压力那么大，所以避免接触优秀的人。这好像也是一种大男子主义的体现——为了让自己占据主导地位，会考虑降低自己的标准。

　　但我还是驳倒了谷哥，也不需要怎么论述，完全可以摆证据，证明自己是真的很喜欢对方，不然不会那么早就和他们说这件事，也不会久违地感到对见面的深度恐慌。很久没有这么急切地想要了解一个人了。也很久没有这么急切的想被对方了解。我过惯了随遇而安的生活，现在又开始对自己疑神疑鬼。对着聊天记录反思自己的问题，用自己的推理和信息搜集能力去侧写别人的生活，开始为自己说话不过脑子而后悔，在意自己的容貌和身材不好。

　　我感觉有的行为已经非常变态了：看照片认位置、推理行动轨迹，明明早就想办法获取到了抖音账号，还要假装不知道；面对很多聊天场景总自称为人机，遇到回答不了的问题就沉默不语；发散理解别人的简单问题。

　　诸如此类，有的是视奸行为，有的是撒谎，有的是不可名状的想法。朋友们说得很对，要降低思考热度，想得越多，越会恐慌。

　　但即使不去做这些事，仍然有一件事困扰着我：我从来没考虑过对方对我的感觉。我对着手机就陷入无脑恋爱状态，这终究不太正常。徐可说得对，一定要避免喜欢上想象中的人——但我其实不怕这个问题，我现在是能压抑住对别人的想象的。更严峻的问题是，如果喜欢的人不喜欢你，这时候怎么办？我倒也不是妄自菲薄，但我真的没底，我从来不相信"当朋友"这种话。我不知道，真不知道。

## 7-13
　　其实喜欢的理由真的很多，我和朋友说了半天，回来后又想起很多。她的性格太好了，我说她像太阳，其实也不确切。我是个疑神疑鬼的人，就好像曹操，但我和她相交完全不是负担，她就像郭嘉。我偶尔能意识到她在包容我，有时也能注意到她察觉了我的不安，会加以安慰。更多的时候，我感受到的是和她交流的舒适。我知道这个人完全可以信任，可以对她说一些真正的心里话，而不用总装傻或者装懂。

　　性格方面已经让我很激动了，但值得喜欢的地方远不止于此。这是个稳定的人，这一点很难得——不是说她的表现或生活有多稳定，而是一种内在的稳定性。认识这些天，能感觉到她的逻辑感很强，虽然她是个感性的人，却有一种超然的定力。写这些的过程中，她发来消息，我又想到另一件事，这个人是充实的。在我的想象里，她不会飞在高空，能感受到她的脚踏实地。

　　以前我总和朋友说，不管是交友还是恋爱，肯定要匹配三观。不过这次，这个条件被我抛在了脑后，我现在纯靠直觉去了解她。说到底，我觉得她是个善良的人，不会故意或主动伤害我，这就够了——我不相信一个善良的人内心会是破碎的。有那么多爱她的人，说明她值得被爱，多我一个也很正常吧。

　　不得不说，这周容貌焦虑有点严重了。看见她朋友圈，她小时候真的好可爱哈哈。其实从5月开始，我多多少少已经在管理自己的形象了：抛下早就习惯的运动鞋，降低运动服的出场，买了一些方便搭配的衣服，护肤防晒都搞了起来，减肥也很关键，见面总得看着像个人。

　　这两天焦虑就剧烈多了——某种角度这是一次奔现，见光死的概率我都不敢想，我势必要有所改善。更要紧的可能是防晒，我户外时间确实太长了，肤色已经黑得有点发亮了。穿搭也要提前规划，我觉得还是朴实些，黑白色就好，已经采购了一些方案，这周可以试试。

　　胡子还是别留了，虽然我很想留大胡子，但网上都说没有女性会喜欢胡子。肌肉不知道有没有用，关键也没办法速成——她很喜欢锻炼，我觉得她肯定偏爱有肌肉的类型，以后要好好练。

　　想起一个很有意思的回忆：就在上个月，大学同学和我讨论感情，说到底应该找爱你的还是你爱的。我说我不想追人，或许可以慢慢爱上爱我的人。但是到了现在，热烈的情绪充斥在大脑，愿意为一个想法付出时间和精力，愿意做出修改和退让。

　　网上听恋爱课的时候，经常出现两种观点：一种让你不要太热情，因为人多少都有点"来拒去留"的心理，你越热情，别人越疏远；另一种认为应该充分展现自己，随时准备表达更进一步的倾向。

　　我觉得这两种想法的核心差异，和个人魅力、自信程度、交友策略有关。网上普遍是广撒网的状态，这两种说法都没什么错。但具体到我个人，两种方法都是错误的：我是急着表达自己的感情，但大脑好像缺失这部分功能，能想到的表达总感觉会给对方很大压力。我还想写些什么，但感觉还是不要再发散了。

## 7-14
　　突然发现晚上的时间真的很短暂：稍微做些事情，发会儿呆，就到了上床的时间。想了想，其实哪有那么多事情要做，我只是又不想闲下来。我知道我的幽默很有限，有趣的事情也不是信手拈来，所以一直保持聊天的状态不一定是好事。我可以做很多事，却没办法变成一个有趣的人。

　　其实也不是没办法显得有趣，但这其实又是一种背叛——控制自己本质上是一种高级的不择手段。解决这个矛盾应该有更好的办法：有时候不是没有有趣的人和事，只是缺乏分享的意识。

　　仔细审视自己的生活，还是比较充实，健康的。未必要分享每一次日常，但我本来就会尝试一些新鲜事情，完全可以去交流感受。由此再想，无趣的人难道就没有有趣的地方吗？我觉得自己没什么趣味，但我有足够多的想法。有时候，想法本身也会成为一个人趣味的评价标准。

　　我可以发挥创造力，去弥补性格上的乏趣——新鲜的点子总是有趣的。还有许许多多的想法，把它们实现出来其实是能吸引人的，这一点我很清楚。所以应该有计划地去设计和实现一些有意思的东西。

　　还有一个问题：见面后的乐趣。我觉得到时候我会变成电线杆，需要好好想想怎么避免。我的社会化程度随着工作有所提升，但还是差点意思，得想想办法。

## 7-15
　　昨天我们聊得很少，有点多愁善感，今天就好得多了，我知道她不太会拒绝熟人，所以关系熟络起来后，我猜她为了维护一段关系会做出不顺自己心意的事情，甚至我怀疑我冒冒失失地去要求在一起，恐怕也不会被直接拒绝，她会考虑别人的感受的。这种邪恶的想法突然出现在我脑子里，像是恶魔的低语，在感到彷徨的时候就开始有这种思考。

　　今天会想起来这个，是因为她对我明确展现了这一点。如果说之前是猜测，现在我应该可以确信，死皮赖脸在她这里肯定是好使的。这倒不意外，很早的时候我就知道她是个善良的人，会在意哪怕陌生人的感受，毕竟w这种网友都能获得关心。只要稍稍强化我们的关系，只要持之以恒地追求，我觉得被接纳为朋友是很正常的。

　　但是我想要的自然不是朋友关系。这样的女孩，我看的所有教程都告诉我应该娶回家。这种情况下，利用我喜欢的人性格上的弱点，去获得一个人的爱，肯定是不好的。设身处地地想，如果我被人忽冷忽热，我自然会陷入到我的精神陷阱，陷入患得患失的深渊，这样的关系肯定是不健康的。总有其他办法的。

　　明明今天聊了这么多，明明知道她处于通勤聊天的状态，依然挡不住我对获得她分享的期待。这不太好。这其实涉及到一个问题——对关系的评价和期待不对等。虽然我很开心了，但一个很明显的事情摆在眼前：我并不是她的什么特殊的人，或许只是个网友。

　　虽然这两天想了很多不顾一切的爱恋，但我很清楚，没有人不期望自己喜欢的人喜欢自己。自然地追求自然的爱，艰难地追求艰难的爱。这些年过去，我总归是变得世俗化了一些，克制自己沉溺于幻想，克服自己去爱上不爱自己的人，克制自己做出自以为是的事情。

## 7-16
　　又看颜值提高的视频，又看情感节目，这两天是真的忙。我觉得还是学到了一些内容，稍作总结。

　　首先，要穿得像个人。这里的"像个人"，就是不要怎么方便怎么来——高亮度的运动背心、超短的运动短裤，绝对不能穿去约会。穿得像个正常人，一定要自然。自然应该是生活化的自然，不能为了穿衣过度装饰：帽子、领带这类，如果有用途就没问题，如果纯粹做装饰，就会显得矫揉造作。

　　对于我来说，下身一定要选择长裤，合适的长裤修饰腿的长度和形态。上半身两种选择：T恤和衬衫，两者通常来说一种更休闲，另一种更严肃。不过现在两者都有各式各样的变形款式，假两件也融合了两者。格子衫显然不应该出现在约会时。想了想，我应该尽量展现自己的青春活力，但恐怕驾驭不了太活力的类型。这样考虑的话，应该选择纯色的 T恤或者花哨些的衬衫。
