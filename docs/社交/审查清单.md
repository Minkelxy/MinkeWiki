# 日记审查清单

发布前逐项核查，每次写完后对照过一遍。

---

## 一、标点符号

- [ ] 全文无英文逗号 `,` → 中文逗号 `，`
- [ ] 全文无英文句号 `.` → 中文句号 `。`
- [ ] 列举项用顿号 `、` 而非逗号（如"蓝色、棕色和黑色"）
- [ ] 破折号统一用 `——`（两个 em-dash），不用 `--` 或 `—`
- [ ] 引号统一用 `""`（中文双引号），不用 `""`

## 二、的 / 地 / 得

- [ ] **的** + 名词：定语修饰（"不切实际的事情""性格上的弱点"）
- [ ] **地** + 动词：状语修饰（"冒冒失失地去""持之以恒地追求""设身处地地想"）
- [ ] **得** + 程度补语：动词/形容词后（"聊得很少""好得多了""自然得多"）

> 口诀：名词前面用"的"，动词前面用"地"，动词后面用"得"

## 三、高频错别字

| 错误 | 正确 | 场景 |
|------|------|------|
| 再（zài） | 在 | "死皮赖脸**在**她这里" |
| 到（dào） | 倒 | "这**倒**不意外" |
| 画妆 | 化妆 | "**化**点妆" |
| 来着 | 两者 | "**两者**通常来说" |

## 四、搭配与语病

- [ ] 无"想了更多不切实际的"类残缺 → 补全为"不切实际的事情"
- [ ] 无"对行为有约束"类不当 → 改为"约束行为"
- [ ] 无"消解殆尽"类重复 → 改为"消磨殆尽"
- [ ] 无"克制爱上幻想"类错配 → 改为"克制沉溺于幻想"
- [ ] 无"教程让我娶回家"类主谓不搭 → 改为"教程告诉我应该娶回家"
- [ ] 无三重"的"嵌套（如"喜欢的人的喜欢的性格的弱点"）→ 改为"喜欢的人性格上的弱点"

## 五、中英混杂

- [ ] 无不必要英文词（如 "ban了""OK"）→ 改为"排除""就好/没问题"
- [ ] 无网络口语（如 "hh"）→ 删除或用"（笑）"替代

## 六、人称一致

- [ ] 全文"她"无混入"他"（指代同一人时保持一致）
- [ ] 无"他"指代不明的情况

## 七、段落结构

- [ ] 无超过 200 字的段落（Markdown 中约 3-4 行为上限）
- [ ] 每个段落只讲一个主题，话题转换即分段
- [ ] 空行分隔所有段落（含不同小节之间）

## 八、标题检查

- [ ] 日期标题格式统一（`## 7-17` 而非 `## 7月17日`）
- [ ] 无重复标题（如两个 `## 7-15`）
- [ ] 标题后紧跟空行，再开始正文

---

> 前两次审校暴露的高频问题：的/地/得混用、英文标点、长段落碾压。这三项优先查。
