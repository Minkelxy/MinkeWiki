# 日记审查清单

发布前逐项核查，每次写完后对照过一遍。

---

## 一、标点符号

- [ ] 全文无英文逗号 `,` → 中文逗号 `，`
- [ ] 全文无英文句号 `.` → 中文句号 `。`
- [ ] 列举项用顿号 `、` 而非逗号（如"蓝色、棕色和黑色"）
- [ ] 破折号统一用 `——`（两个 em-dash），不用 `--` 或 `—`
- [ ] 引号统一用 `""`（中文双引号），不用 `""`
- [ ] 序号格式统一：`第一……第二……第三……`，不用 `一、二、三` 混 `第一，二，三`
- [ ] 书名、电影名加书名号 `《》`（如《白夜行》）

## 二、的 / 地 / 得

- [ ] **的** + 名词：定语修饰（"不切实际的事情""性格上的弱点"）
- [ ] **地** + 动词：状语修饰（"冒冒失失地去""持之以恒地追求""设身处地地想"）
- [ ] **得** + 程度补语：动词/形容词后（"聊得很少""好得多了""自然得多""激烈得多"）

> 口诀：名词前面用"的"，动词前面用"地"，动词后面用"得"

## 三、高频错别字

| 错误 | 正确 | 场景 |
|------|------|------|
| 再（zài） | 在 | "死皮赖脸**在**她这里" |
| 到（dào） | 倒 | "这**倒**不意外" |
| 画妆 | 化妆 | "**化**点妆" |
| 来着 | 两者 | "**两者**通常来说" |
| 这么 | 怎么 | "**怎么**就聊到" |
| 那会 | 那会儿 | "**那会儿**感情要激烈得多" |
| 显然易见 | 显而易见 | "**显而易见**的事实" |
| 拼音残留 | 对应汉字 | "**不会**"（非 `bu'hui`） |

## 四、搭配与语病

- [ ] 无"想了更多不切实际的"类残缺 → 补全中心语
- [ ] 无"对行为有约束"类不当 → 改为"约束行为"
- [ ] 无"消解殆尽"类重复 → 改为"消磨殆尽"
- [ ] 无"克制爱上幻想"类错配 → 改为"克制沉溺于幻想"
- [ ] 无"教程让我娶回家"类主谓不搭 → 改为"教程告诉我应该娶回家"
- [ ] 无三重"的"嵌套（如"喜欢的人的喜欢的性格的弱点"）→ 改为"喜欢的人性格上的弱点"
- [ ] 无重复疑问词（如"为什么会觉得自己为什么"）→ 删去多余
- [ ] 无句末赘余词（如"第一次语音交流**问题**"）→ 删去

## 五、中英混杂 & 残留

- [ ] 无不必要英文词（如 `ban`、`OK`、`xxx`）→ 改为中文或删除
- [ ] 无拼音残留（如 `bu'hui`）→ 这是 IME 切换失败的产物，必须查
- [ ] 无占位符残留（如 `x细节`、`xxx`）→ 补全或删除
- [ ] 无网络口语（如 `hh`）→ 删除或用"（笑）"替代

## 六、人称一致

- [ ] 全文"她"无混入"他"（这是最高频问题，流意识写作时极易出错）
- [ ] 无"他"指代不明的情况
- [ ] 同一段内人称前后统一（不出现第一句"她"第二句"他"）

## 七、段落结构

- [ ] 无超过 200 字的段落
- [ ] 每个段落只讲一个主题，话题转换即分段
- [ ] 空行分隔所有段落（含不同小节之间、标题前后）
- [ ] 无残缺结尾——段末不以逗号结束，句号收束

## 八、标题检查

- [ ] 日期标题格式统一（`## 7-17` 而非 `## 7月17日`）
- [ ] 无重复标题
- [ ] 标题前有空行（与上文分隔）
- [ ] 标题后紧跟空行，再开始正文

## 九、计划类内容（新增）

- [ ] 有时间预估（上午/中午/下午/晚上），不只是地点列表
- [ ] 有休息/喝东西的槽位（谷哥定律：不能只安排吃和动）
- [ ] 路线逻辑通顺（不反复跨区折返跑）
- [ ] 待定项明确标注，方便后续补充

---

> 最高频三类：的/地/得混用、她→他写错、长段落碾压。优先查。
