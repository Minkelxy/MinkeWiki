## 7-20
今天很离谱啊，我有点记不清楚怎么就聊到这种话题了，我去看看聊天记录，我在说什么啊哈哈哈。不过能阐述自己的观点是很好的。我总是试图分析别人，其实也渴望别人分析自己，自述的机会可不多。有深度的聊天机会就更少了。

其实很多事情还是说不出口，类似那天聊《白夜行》。我当然不能告诉她，自己一直都想成为亮司这样的人，对其行动甚至高度认可。当然，因为是高中看的书，那会儿感情要激烈得多，影响了我的记忆。我和她吐槽亮司不自爱，其实心里想的是另一个想法——佩服。

我读过顾城的一句诗："我不是五颜六色的打火机，我是盒子里的火柴，只能燃烧一次。"燃烧自己在所有影视作品里都是一种高尚品德。为什么为了大爱、为了公益就是高尚的，为了小爱、为了爱情就变得龌龊了？当然，这里一个极大争议的地方是违法犯罪行为，不过我觉得和这个没什么关系。

不过，确实有点吓人。和别人说自己是一个疯子、是一个恐怖分子，肯定会吓跑人。但我感觉她倒是不一定会跑，我感觉她甚至在等着我肯定亮司的一些行为。可惜我没什么勇气。

怎么能对一个人好，这也是值得研究的问题。总觉得很多情况下看上去就目的不纯——虽然本来目的也不纯，但真的没那么不纯。到底是什么目的呢，还真的没想过。除了纯粹的精神愉悦，总还是带着其他目的，表达爱意，增加自己的价值？还真不太好感受。
