## 日日记
人生得一知己足矣，斯世当以同怀视之。
### 前言
　　5月初开始主动进行社交，本质上应该是出于对未来的恐慌。我其实很少感受到孤独，只有回忆过去和展望未来的时候，才会感到压抑。这两个月发生了很多事情，但我的心情还是很平淡，事情没有超出我的预料。我从一开始就不觉得执行这样的计划会有什么好结果，但做起来还是能让我安心一点。

　　但是这周，这两天，我真的完全沉迷进去了。偶然（也不太偶然）尝试了攀岩，觉得岩馆的大哥大姐挺好的，和他们聊天让我的压力缓解了很多，后来自然而然地加了他们的微信。这之后，岩馆就变成了我每次回来一定会去的地方：一开始匆匆来匆匆走，后面待的时间越来越长。

　　我没有刻意安排，但来到这里，至少不用在银川的街头乱撞。我会聊到自己生活和想法的一些片段，大哥的建议毫无营养，大姐的建议值得思考——说我确实不知道自己在干什么，也多少带点受虐倾向。

　　这周末我又来到这里，这次不知道是触发了怜悯机制还是什么保底机制，他们开始给我更多建议。姐姐给我介绍了她妹妹。我一开始其实怕得要死——这是真正的陌生人，不像网上认识的那种没什么压力。

　　拿到微信后，我犹豫了好久才决定试试，毕竟这是第一个算是熟人介绍的人。而且姐姐说得没什么错：不要一上来就想着往对象的方向发展，应该先交朋友，不要把目的写在脸上。

　　但我其实还有疑问，我既不知道自己为什么要找对象，也不知道为什么要交朋友。第一天的聊天不温不火吧。我喜欢给人贴标签，这次手里的"人类"标签自然而然地贴了上去。我觉得这真的是一个伟大的胜利，但又开始考虑自己会不会表现得太过激进，要不要控制自己的表现。

　　第二天我果然被顾虑束缚，选择不主动交流。其实我已经开始开心地和朋友分享这件事了，却还是觉得自己没办法往下推进。晚上分享了一下这一天的经历，愈发感觉和她聊天很舒服，我不知道是因为她很会聊天，还是她的社交能力已经足以把我包围了。我迫切地想继续交流。她罕见地对AI兴趣很大，想想也是，在校的学生使用AI要比外面的人熟练得多。这正好是我的日常，在这上面扩展一些话题没什么困难，也不需要什么迎合。

　　其实到这个时候我已经感受到了。我会和朋友说，我好像遇到了一个不一样的人。这个人健康、自信、积极向上，和她聊天的时候能感觉到心跳，上班时也会抽时间去聊，不聊天的时候也在想象和计划一些相关的事情。我意识到这种程度的刻意已经有点踩雷区了，必须控制这种不正常的情感。我分不清热情和冒犯的分界线，那就尽量不要胡乱扩展话题。

　　我们继续聊着——其实也没聊多少，但她在我眼里愈发闪耀，我也愈发恐慌。我害怕她不属于我，不想被发好人卡，也不想当个陌生人。我应该去学习聊天和交往了。我真的反感天命说，但这个时刻，我有点迷信了：我感觉这就是我的天命。我不能再畏畏缩缩了，患得患失只会失去一切，想得越多越不能做自己。我应该想一些更有用的事情。

　　我做了一个梦，又是过去的事情，仿佛在提醒我还会重蹈覆辙。不过，这次我不会那么脆弱和敏感了，准备好面对这些自我怀疑。"死缠烂打"这个词不太好听，我以前从来没这么想过，但现在已经管不住自己的思绪了。思考走得太远，该做出行动了。

　　我是很容易想多的人。作为一个拖延症患者，是焦虑拖着我前进。考虑太多、想法太多，不一定是坏事，当然也不一定是好事：好处是我能考虑到不少实际情况，坏处是想了更多不切实际的事情。

　　这些不切实际的想象里，有感情迅速升温的画面，有一起生活的场景——这些想法对别人来说可能很雷吧。另一些想象则走向另一个极端：感情迅速破裂（甚至怀疑会不会先有感情）、互相欺骗，还有韩剧里那种狗血剧情。

　　这些想象的危害主要体现在对我行动的影响上，比如害怕见面，恐惧自己不熟悉的事情。说到底我根本没正常谈过恋爱，想象只能从有限的小说和影视剧里拼凑，拼凑出狗血也很正常。

　　纷乱的思考是灾难的开始，所以要限制这种想法。就用这个方式：记录和计划。所谓记录，除了实际发生的事情，还包括脑中所想，确保自己没有偏离；所谓计划，是约束自己的行为、预估自己的方向。这两者结合，才能表现得像个正常人。

　　既然是长期计划，就必须做好长期准备。目前看来，有必要记录自己——这是日后回忆的必要材料。
