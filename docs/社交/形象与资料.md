# 形象与资料

从穿搭到拍照到填写平台资料，一站式把自己包装好并上线。

---

## 一、外在形象

### 身材管理

| 项目 | 现状 | 目标 | 执行 |
|------|------|------|------|
| BMI | 24.5（轻微超重） | 18.5-24 | 饮食控制 + 规律运动 |
| 体脂率 | 约22% | 15-20% | 力量训练 + 有氧 |
| 运动频率 | 每周3-4次 | 保持 | 按 [健身计划](../健身/README.md) 执行 |
| 睡眠 | 约6-7小时 | 7-8小时 | 提前半小时睡 |

### 穿搭

| 场景 | 风格 | 要点 |
|------|------|------|
| 日常 | 简洁纯色T恤+修身裤 | 合身 > 品牌，基础款为主 |
| 约会 | 干净有品位 | 一套精心搭配，颜色不花哨 |

**核心原则**：告别格子衬衫+冲锋衣。日系/韩系基础款，同色系不超 3 色。定期断舍离。

### 仪表

| 项目 | 标准 |
|------|------|
| 发型 | 2-3周修剪一次 |
| 面部 | 洁面+保湿，无油光 |
| 口腔 | 定期洗牙，保持清新 |
| 手部 | 指甲修剪干净 |
| 体味 | 适度止汗，保持清爽 |

## 二、谈吐与展示

### 知识储备（可展示的话题）

技术/科技 ⭐⭐⭐⭐⭐ → 硬件创客 ⭐⭐⭐⭐⭐ → 音乐 ⭐⭐⭐ → 农业研究 ⭐⭐⭐⭐ → 运动 ⭐⭐⭐⭐

**原则**：不讲技术细节（"SPI时钟配错了"），用成果和类比（"做了个天气时钟""像给汽车大脑写程序"）。

### 朋友圈运营

| 内容 | 频率 | 展示什么 |
|------|------|----------|
| 生活记录 | 每周1-2条 | 北京日常、宁夏元素、美食 |
| 项目展示 | 每月1-2条 | 电子项目/硬件，拍出酷炫感 |
| 音乐/运动 | 每月1条 | 作品、运动打卡 |

**原则**：真实 > 包装，质量 > 数量。

## 三、照片清单

准备 6-8 张，按顺序：

| # | 类型 | 要求 | 状态 |
|---|------|------|------|
| 1 | **正面生活照**（首图） | 半身、自然光、微笑、背景干净 | ✅ |
| 2 | **全身照** | 休闲穿搭 | ⬜ |
| 3 | **北京场景照** | 咖啡馆/公司/街景 | ⬜ |
| 4 | **宁夏元素照** | 表明归属感 | ✅ |
| 5 | **项目/兴趣照** | 电子制作或弹琴或运动 | ⬜ |
| 6 | **社交照** | 和朋友的自然照 | ✅ |
| 7 | **旅行/户外照** | 展示活力 | ✅ |
| 8 | **宠物照**（可选） | 加分项 | ✅ |

> 📸 5/8 已有。需补：全身照、北京场景、项目/兴趣照。

**规则**：拒绝自拍镜/车内/浴室/对镜自拍 + 首图单人 + 至少 3 张近 6 个月。

## 四、平台资料模板

### 基本信息

```
昵称：[特征或兴趣取名，不暴露真名]
年龄：25    身高：181cm    学历：本科
职业：嵌入式软件工程师（轻松版："给汽车写程序的"）
所在地：宁夏银川（实际在北京工作）
收入：不填精确数字
```

### 自我介绍（三选一）

**短版**（探探/二狗）：

```
宁夏人在北京做嵌入式开发，计划1-2年回银川。
业余喜欢做电子项目、玩音乐。不烟，情绪稳定。
```

**标准版**（青藤之恋/她说）：

```
【关于我】
- 宁夏银川人，25岁，181cm，目前在北京做嵌入式开发
- 计划1-2年内回宁夏，每月能回1-2次见面
- 不烟，性格偏安静，熟了话多
- 业余做电子项目（天气时钟/游戏摇杆/电子琴等8个）、MIDI音乐改编、健身

【期待的你】
宁夏银川或周边，情绪稳定，善良真诚，有自己热爱的事情。
```

**详细版**（牵手/伊对）：

```
宁夏银川人，25岁，181cm。北京做嵌入式软件工程师（汽车电子方向）。
工作稳定有积蓄，计划1-2年内回宁夏发展。

业余是个"不无聊的技术宅"：做过8个硬件项目、会音乐制作、研究过宁夏农业、
健身跑步。不烟。

性格偏安静慢热，熟了靠谱。异地只是暂时的，每月能回宁夏见面。
照片真实，资料认真写的。
```

### 标签

| 类别 | 必选 | 可选 |
|------|------|------|
| 性格 | 慢热、靠谱、理性 | 细心 |
| 爱好 | 音乐、DIY、运动 | 科技、农业 |
| 生活 | 不吸烟、偶尔喝酒 | 会做饭 |

⚠️ 避免：重度游戏、宅、社恐、拖延症

## 五、上线检查清单

- [ ] 照片 ≥6 张，首图单人正面半身
- [ ] 资料明确提到"回宁夏/银川"

- [ ] 无错别字，无抱怨前任何/工作/生活
- [ ] 定位 = 宁夏银川
- [ ] 发给朋友帮忙看一遍
