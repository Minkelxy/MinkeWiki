# 沉默的大多数

## 从一篇杂文说起

提起「沉默的大多数」，很多人会想到王小波。他在后记里写过这个题目，说的是文革以后，那些不掌握话语权的人，那些被排除在公共表达之外的人。他不觉得这些人麻木，他觉得沉默本身是一种处境，也是一种选择。

我第一次读那篇杂文的时候还很年轻。最打动我的，是他写这件事的态度，不控诉、不煽情，用很平常的话讲一件很残酷的事。他写「沉默」，讲成了一种几乎人人都在其中的状态，但一点也不可怜。看完那篇，我明白了一件事，沉默不等于没有想法，摸不着把持话语的人，也未必就没有判断。

我喜欢这个说法。它给沉默的人留了位置。

## 沉默是什么处境

王小波说的沉默的大多数，是有特定背景的。那是一个话语被垄断、真话要付出代价的年代。你敢不敢说话，说的活不活得下去，是拿命在衡量的事。在那样的环境里，沉默是一种保护，也是一种智慧。不说话，至少不害人，不害自己。

可现在不一样了。现在谁都能说话，人人都能发声，声音大到比沉默更吵。沉默的大多数这个词，换了处境。

## 现在的沉默

现在的沉默，是另一种样子。话还是说的，只是话说出去没人接，接了也不确定要不要收回来。

你下班回家，想跟室友说说今天遇见的糟心事，室友低头刷手机，嗯了一声。你想在群聊里说一句跟大家都相关的话，发出去，半天没人回，你觉得自己像个傻子。你想在网上写点真诚的东西，写了一半，想起评论区什么都能吵起来，又删了。

这种沉默，怕的成分弱，累的成分多。怕的是麻烦，累的是说了也没人真听。

王小波那代人沉默，是因为说了真话会出事。我们这代沉默，常常是因为说了也没用，还得挨一顿骂。一群人抢着表达的时候，真正想说的那个人，反而把话咽了回去。沉默像个水湾，大家不知不觉就退到了那里。

## 无声的多数在想什么

沉默的人照样有想法。他们只是没学会说话，或者没找到说话的场合，或者觉得说了也白说。

可这不代表他们不懂。饭桌上那个不太吭声的长辈，可能对世道有很准的判断，只是他不习惯在你面前下结论。公司里那个总在会上沉默的同事，私下说的话往往比会上所有人加起来都实在。他们常常有声音，只不过声音留在了自己的小圈子里，没往公共场合去。

王小波说的好，沉默的大多数不掌握话语权，不等于没有尊严和判断。这话放到今天依然成立。热闹是那些爱说话的人制造的，可日子是沉默的人一天一天过出来的。

## 我为什么还是想写

写到这里，我也得承认，我写这篇东西，本身就有点讽刺。说沉默的大多数，可我正在用文字表达自己，对着可能没人看的方向。

但我见过一些真正安静的人。他们不写，也不说，可他们读，他们想，他们用行动做判断。我慢慢觉得，表达和沉默之间，该有一个分寸。有些话值得说，有些话留着更好。沉默里有被迫的，也有主动收着的。

王小波还写过一句话，大意是人得学会说话，也得学会什么时候不说。我记不全原话，但那个意思我记住了。说话是为了让人听，沉默是为了让自己想。两样都留着，才不至于被时代的喇叭声推着走。

## 结尾

「沉默的大多数」这个说法，我从王小波那里借来，又放进了现在的日子里。它提醒我，别被最大的声浪带走，也别以为不说话就是没想法。

这个世界永远有人在说，也永远有人沉默。说的人有说的理由，沉默的人有沉默的道理。我愿意做那个偶尔说说、但大多数时候认真听的人。
