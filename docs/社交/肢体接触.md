# 牵，还是不牵

第一次意识到自己在意握手这件事，是在和朋友告别的时候。他伸出手来，我握上去，三秒就松开，各自转身。这很正常，正常到我根本没想过它。可后来我在想，为什么我和有些人之间，这一步总要先在心里过一遍。

我不太会主动发起接触。小时候不是这样，那时候抱谁都不需要理由。长大以后碰出一套规矩来，身体贴着身体要有顺序，手搭上去要有由头，连开玩笑推你一下，都还要掂量熟不熟。这规矩我不是自己定的，是水涨船高养出来的，没有人说过，但你心里清楚，伸出去的手没落点，是很尴尬的一件事。

骑摩托那天，我难得没想那么多。她坐在后座，路有点颠，她抓了一下我腰侧的衣服，好几秒没松手。那一刻我说不出什么，就是觉得很近。我后来总想这件事。不是想那一下抓得有多重，是想那一瞬间我居然一点犹疑都没有。她靠过来，我往前骑，谁也不觉得这有什么好斟酌的。

当然不是每次都这样。有时候我的手在半空停了半秒，最后还是收回去。我不觉得这是什么退让，人本来就该有这半秒。要不要握住，永远不该是单方面笃定下来的。她愿意我才把手递过去，她松开我就该松手，这不是生分，是我想让她知道，这件事我永远给你留一个不答应的口子。

后来真牵上了，倒是比我想的平淡。没有心跳加速，也没有电影里那个慢镜头，就只是两只手就那么放着，她拇指动了一下，我也动了一下。那一刻我突然明白，我过去把这件事想得太重了。我以为会很难，其实难的从来不是出手那一下，是出手以前那些自己编出来的前因后果。

我更想要的是那种不用请示的靠近。她走累了往我肩上靠，我骑慢一点让她多吹会风，这些都不必讨论，身体自己就会答应。我承认我贪这种默契。

我唯一还惦记的，是她如果不愉快，一定要说出来。我可以学着怎么靠近，但我没办法替她判断她喜不喜欢。这话我认真说过一次，她没接话，只是把手又放回我手心里。我觉得那也算一种回答。

到今天我仍然不算一个擅长接触的人。多数时候我还是会先停半秒，在心里问一句行不行。但半秒以后，我比以前更愿意让这半秒有个答案了。
