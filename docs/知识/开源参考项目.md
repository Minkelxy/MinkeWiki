# 知识库开源参考

整理与[知识库](README.md)各分类对应的 GitHub 开源项目与学习资源，作为学习源码、动手实践和工具选型的起点。**Star 数为 2026-08-05 抓取时的真实数据**，点击项目名直达仓库。

---

## ⚡ 电机控制

| 开源项目 | Star | 技术栈 | 对应笔记 |
|---------|------|--------|---------|
| [simplefoc/Arduino-FOC](https://github.com/simplefoc/Arduino-FOC) | 2.9k | C++ | 最流行的开源 FOC 库，支持 BLDC 与步进电机，与[FOC学习笔记](电机控制/FOC学习笔记.md)配套实践 |
| [vedderb/bldc](https://github.com/vedderb/bldc) | 3.3k | C | VESC 电机控制固件，商业级 FOC 实现，硬件+软件全开源 |
| [simplefoc/Arduino-SimpleFOCShield](https://github.com/simplefoc/Arduino-SimpleFOCShield) | 610 | — | SimpleFOC 官方驱动 shield 硬件设计 |
| [xym-ee/motor-control](https://github.com/xym-ee/motor-control) | 57 | — | 中文电机原理/控制理论 + SimpleFOC 学习笔记，直接可对照阅读 |
| [dtltljb/FOC-MOTOR-CONTROLLER](https://github.com/dtltljb/FOC-MOTOR-CONTROLLER) | 118 | C | STM32 有感 BLDC 驱动，集成 CANopen 电机控制子集与 Modbus 协议 |
| [okhsunrog/oxifoc](https://github.com/okhsunrog/oxifoc) | 18 | Rust | Rust + Embassy 写的 STM32 FOC 固件，现代嵌入式新思路 |

**建议**：`FOC学习笔记.md` 偏理论，可配合 Arduino-FOC 把[电机霍尔驱动](电机控制/电机霍尔驱动.md)里的位置环/速度环在真机上调通；想深入工程化再看 vedderb/bldc。

## 🧠 RTOS

| 开源项目 | Star | 技术栈 | 说明 |
|---------|------|--------|------|
| [zephyrproject-rtos/zephyr](https://github.com/zephyrproject-rtos/zephyr) | 16.1k | C | Zephyr RTOS，新一代可扩展物联网操作系统 |
| [RT-Thread/rt-thread](https://github.com/RT-Thread/rt-thread) | 12.1k | C | 国产开源物联网 RTOS，中文生态好、文档全 |
| [FreeRTOS/FreeRTOS](https://github.com/FreeRTOS/FreeRTOS) | 7.7k | C | FreeRTOS 经典发行版（最广泛使用的 RTOS） |
| [FreeRTOS/FreeRTOS-Kernel](https://github.com/FreeRTOS/FreeRTOS-Kernel) | 4.4k | C | FreeRTOS 内核源码（独立仓库） |
| [apache/nuttx](https://github.com/apache/nuttx) | 4.0k | C | Apache NuttX，接近 POSIX 的嵌入式 RTOS，PX4 飞控用它 |
| [maksimdrachov/zephyr-rtos-tutorial](https://github.com/maksimdrachov/zephyr-rtos-tutorial) | 468 | C | Zephyr 入门教程（面向嵌入式初学者） |

**建议**：[自制RTOS](RTOS/自制RTOS.md) 是理解内核原理的好路径，对照 FreeRTOS-Kernel 源码（任务调度、队列、内存管理）可加深理解；想上生产项目优先看 Zephyr/RT-Thread。

## 🧪 软件测试（嵌入式）

| 开源项目 | Star | 技术栈 | 说明 |
|---------|------|--------|------|
| [ThrowTheSwitch/Unity](https://github.com/ThrowTheSwitch/Unity) | 5.3k | C | 轻量 C 单元测试框架，嵌入式 CI 常用，可与[单元测试学习](软件测试/单元测试学习.md)对照 |
