# LIN总线协议详解

LIN（Local Interconnect Network，局域互联网络）是用于汽车车身低速控制节点的低成本串行总线。与[CAN总线协议详解](CAN总线协议详解.md)相比，LIN 以更低成本换取更低速率，通常作为 CAN 网络的末端补充。本文对应[现场总线概述](README.md)中「LIN总线协议详解」条目。

---

## 一、概述

| 特性 | 说明 |
|------|------|
| 定位 | 低成本低速车身总线（门窗、座椅、后视镜、雨刷、车灯） |
| 速率 | 最高 **20 kbps**（LIN 2.x） |
| 拓扑 | 单主多从（1 主 + 最多 15 从） |
| 物理层 | **单线**（12V 电平），实现成本极低 |
| 底层 | 基于标准 UART/SCI，普通单片机即可实现 |
| 标准 | LIN 2.0/2.1/2.2（原 LIN Consortium），现为 ISO 17987 |

**核心优势**：一根线 + 现成 UART，比 CAN 便宜很多，适合对速率要求不高的开关/传感器节点。

---

## 二、物理层

### 单线电平

LIN 总线是**单线**，通过上拉电阻连接到电源（VBAT ≈ 12V）：

| 逻辑位 | 电平 | 说明 |
|--------|------|------|
| 显性（Dominant）= 0 | 接地（~0V） | 覆盖隐性位 |
| 隐性（Recessive）= 1 | 上拉到 VBAT（~12V） | 空闲状态 |

- 主节点和从节点各有一个**上拉电阻 + 二极管**（主 1kΩ，从 30kΩ）
- 不需要 CAN 那样的 120Ω 终端电阻
- 波特率容差：从节点需在 ±14% 内，通过同步场自动校正

### 一主多从

- **主节点**：负责调度、发帧头，也处理诊断请求
- **从节点**：被动监听，收到与自己 ID 匹配的帧才响应
- 从节点之间不直接通信，所有通信都经主节点调度 → **确定性**（无总线冲突）

---

## 三、帧结构

一个 LIN 帧 = **帧头（主节点发）** + **响应（主或从发）**：

```
帧头: [同步间隔][同步场 0x55][标识符场]  → 响应: [数据场 1-8字节][校验和]
```

### 帧头

| 字段 | 说明 |
|------|------|
| 同步间隔 | 连续 ≥13 位显性，用于识别帧起点（区别于普通数据） |
| 同步场 | 固定 `0x55`（10101010），从节点用它校准波特率 |
| 标识符场 | 6 位 ID + 2 位奇偶校验位 |

### 标识符

- ID 范围 0-63，决定由谁响应、数据长度
- 特殊 ID：
  - **ID=60**：主诊断请求帧
  - **ID=61**：从诊断响应帧
  - **ID=62**：保留
  - **ID=63**：保留

### 响应

- **数据场**：1-8 字节（由标识符确定长度）
- **校验和**：经典校验（仅数据）或增强校验（含 ID），区分版本

### 帧类型

| 类型 | 说明 |
|------|------|
| 无条件帧 | 主发帧头，指定从节点必响应 |
| 事件触发帧 | 多个从节点竞争，用于轮询节省带宽 |
| 偶发帧 | 有变化才发，减少总线负载 |
| 诊断帧 | ID=60/61，用于配置、故障诊断 |

---

## 四、调度表（Scheduling）

- **主节点**按预先定义的**调度表**周期性发送各帧的帧头
- 调度表保证每个从节点在固定周期内被轮询 → **确定的最大响应延迟**
- 这是 LIN 与 CAN 最大的区别：CAN 是事件驱动仲裁，LIN 是**时间驱动调度**，无冲突、可预测

---

## 五、LIN 与 CAN 的对比

| 维度 | CAN | LIN |
|------|-----|-----|
| 线数 | 双线差分 | 单线 |
| 速率 | 最高 1Mbps（CAN FD 更高） | 最高 20kbps |
| 成本 | 高 | 低 |
| 仲裁 | 多主非破坏性仲裁 | 主从调度、无冲突 |
| 同步 | 位填充+同步段 | 同步场校准 |
| 终端 | 120Ω×2 | 上拉电阻 |
| 典型应用 | 动力/底盘/诊断 | 车身开关/传感器 |

### 典型整车混用架构

```
CAN 主干（动力、底盘、仪表、OBD）
   │
   ├── LIN 总线1（车门：车窗/后视镜/门锁）
   ├── LIN 总线2（座椅调节/加热）
   └── LIN 总线3（雨刷/车灯）
```

**一句话**：CAN 做骨干，LIN 做末端的低成本支线——这就是大多数现代车身网络的形态。

---

## 六、开发实践

- LIN 从节点只需普通 MCU 的 UART + 一个晶体管电平转换（LIN 收发器如 TJA1020）
- 主节点用现成 LIN 收发器 + 调度表软件实现
- 涉及 AUTOSAR 时，LIN 由 LIN Driver / LIN Interface 模块管理（参考[AUTOSAR MCAL配置指南](../AUTOSAR/MCAL开发配置指南.md)）
