# CAN总线协议详解

Controller Area Network（控制器局域网），由博世（Bosch）于 1986 年提出，是汽车和工业领域最主流的现场总线之一。本文从物理层到数据链路层系统梳理 CAN 协议，并介绍 CAN FD 与常用高层协议。本文对应[现场总线概述](README.md)中「CAN总线协议详解」条目。

---

## 一、概述

CAN 是**多主**（multi-master）串行总线：总线上所有节点平等，均可主动发送。核心特性：

- **差分信号**，抗干扰能力强，适合车载/工业强电磁环境
- **非破坏性仲裁**，高优先级报文实时抢占，满足硬实时需求
- **完善的错误检测与隔离**，故障节点自动离线，不影响总线
- **成本低**，双线即可组网，最大节点数取决于收发器（常见 32-110 个）

标准：ISO 11898（CAN 2.0），其中 ISO 11898-1 定义数据链路层，ISO 11898-2 定义高速物理层。

---

## 二、物理层

### 差分信号

总线由两根双绞线组成：**CAN_H** 和 **CAN_L**。

| 逻辑位 | 电平 | 说明 |
|--------|------|------|
| 显性（Dominant）= 0 | CAN_H ≈ 3.5V，CAN_L ≈ 1.5V | **覆盖**隐性位 |
| 隐性（Recessive）= 1 | CAN_H ≈ 2.5V，CAN_L ≈ 2.5V | 差分电压为 0 |

- 显性位在仲裁中**优先**（0 优先于 1）
- 末端各接一个 **120Ω 终端电阻**，用于阻抗匹配、抑制反射

### 速率与拓扑

| 类型 | 标准 | 最高速率 | 特点 |
|------|------|---------|------|
| 高速 CAN | ISO 11898-2 | 1 Mbps | 汽车动力/底盘总线，总线长度 ≤ 40m（1Mbps 时） |
| 容错 CAN | ISO 11898-3 | 125 kbps | 单线失效仍可工作，多用于车身低速总线 |

速率与总线长度的折中：速率越高，允许的总线长度越短（1Mbps≈40m，125kbps≈500m）。

---

## 三、数据链路层：帧格式

### 帧类型

| 帧类型 | 用途 |
|--------|------|
| 数据帧 | 传输数据（最常用） |
| 远程帧 | 请求对方发送数据 |
| 错误帧 | 检测到错误时主动上报 |
| 过载帧 | 请求延迟后续帧 |

### 数据帧结构

**标准帧（CAN 2.0A，11 位标识符）**：

```
SOF | 仲裁场(11位ID + RTR) | 控制场(IDE/r0/DLC) | 数据场(0-8字节) | CRC场 | ACK场 | EOF
```

**扩展帧（CAN 2.0B，29 位标识符）**：在 11 位 ID 后通过 IDE=1 引入 SRR/IDE 位和额外 18 位 ID。

| 字段 | 说明 |
|------|------|
| SOF | 起始位（1 位显性） |
| ID | 报文标识符，用于仲裁与过滤 |
| DLC | 数据长度码（0-8 字节） |
| CRC | 15 位 CRC + 定界位，校验传输错误 |
| ACK | 接收节点应答 |
| EOF | 帧结束（7 位隐性） |

### 仲裁机制（非破坏性）

多个节点同时发送时，按位仲裁：
- ID 越小优先级越高（显性位覆盖隐性位）
- 发送中持续回读总线，一旦发现自己发送隐性但总线为显性，即**退出发送**，转为接收
- 仲裁过程不破坏高优先级报文，无时间损失 → 满足实时性

### 位填充

连续 5 个相同极性位后，自动插入 1 个相反位：
- 提供同步沿，保证接收端时钟同步
- 接收端检测到连续 6 个相同位 → 判定**位填充错误**

## 四、错误处理

### 5 类错误

| 错误类型 | 检测方式 |
|---------|---------|
| 位错误 | 发送的位与总线回读不一致 |
| 位填充错误 | 出现连续 6 个相同位 |
| CRC 错误 | 接收端 CRC 校验不符 |
| 形式错误 | 固定位（定界位/EOF）电平错误 |
| 应答错误 | 发送端未收到 ACK |

### 错误状态与隔离

节点维护两个错误计数器：**发送错误计数（TEC）** 和**接收错误计数（REC）**，按规则增减。

| 状态 | 条件 | 行为 |
|------|------|------|
| 主动错误（Error Active） | 计数 < 128 | 正常收发，主动发送错误帧 |
| 被动错误（Error Passive） | 计数 ≥ 128 | 受限，只发被动错误帧，发送前等待 |
| 总线关闭（Bus Off） | TEC > 255 | **完全断开总线**，等待恢复 |

> 这是 CAN 的关键优势：**故障节点自动隔离**，一个节点损坏不影响整条总线通信。

---

## 五、CAN FD

CAN FD（Flexible Data-rate，ISO 11898-1:2015）在 CAN 2.0 基础上改进：

- **数据场扩到 64 字节**（原来最多 8 字节）
- **双速率**：仲裁段保持原速率，数据段提速到 2-8 Mbps
- **CRC 增强**，降低漏检率

同一物理层可直接升级，兼容性好，是现代车载总线的主流演进方向（AUTOSAR 中也普遍使用 CAN FD）。

---

## 六、高层协议

CAN 只定义了物理/数据链路层，具体「谁发什么报文」由高层协议约定：

| 协议 | 应用领域 |
|------|---------|
| CANopen（CiA 301） | 工业设备、电机控制（如 STM32 FOC 项目中的 CANopen 电机控制子集） |
| J1939 | 重型车辆、工程机械 |
| OBD-II | 汽车诊断接口 |
| DeviceNet | 工业自动化 |

---

## 七、LIN 与 CAN 的关系（预告）

LIN（Local Interconnect Network）是 CAN 的**低成本补充**：单线、主从结构、最大 20 kbps，用于门窗、座椅、后视镜等低速车身控制。CAN 和 LIN 常混合使用——CAN 做主干，LIN 做末端低速节点。详见后续「LIN总线协议详解」。
