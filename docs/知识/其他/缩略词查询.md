常用嵌入式 / 汽车电子缩略词速查。

> AUTOSAR 官方提供了更完整的词汇表：[autosar.org](https://www.autosar.org/)

## 嵌入式基础

| 缩写 | 全称 | 说明 |
|------|------|------|
| MCU | Microcontroller Unit | 微控制器 |
| SoC | System on Chip | 片上系统 |
| GPIO | General Purpose Input/Output | 通用输入输出 |
| PWM | Pulse Width Modulation | 脉冲宽度调制 |
| ADC | Analog-to-Digital Converter | 模数转换器 |
| DAC | Digital-to-Analog Converter | 数模转换器 |
| DMA | Direct Memory Access | 直接内存访问 |
| ISR | Interrupt Service Routine | 中断服务程序 |
| RTOS | Real-Time Operating System | 实时操作系统 |

## 总线 / 通信

| 缩写 | 全称 | 说明 |
|------|------|------|
| UART | Universal Asynchronous Receiver/Transmitter | 通用异步收发 |
| SPI | Serial Peripheral Interface | 串行外设接口 |
| I2C | Inter-Integrated Circuit | 集成电路间总线 |
| CAN | Controller Area Network | 控制器局域网络 |
| CAN FD | CAN with Flexible Data-rate | 可变速率 CAN |
| LIN | Local Interconnect Network | 本地互联网络 |
| CRC | Cyclic Redundancy Check | 循环冗余校验 |

## 电机控制

| 缩写 | 全称 | 说明 |
|------|------|------|
| FOC | Field-Oriented Control | 磁场定向控制（矢量控制）|
| SVPWM | Space Vector PWM | 空间矢量 PWM |
| BLDC | Brushless DC | 无刷直流电机 |
| PID | Proportional-Integral-Derivative | 比例积分微分控制 |

## 汽车电子

| 缩写 | 全称 | 说明 |
|------|------|------|
| ECU | Electronic Control Unit | 电子控制单元 |
| AUTOSAR | AUTomotive Open System ARchitecture | 汽车开放系统架构 |
| MCAL | Microcontroller Abstraction Layer | 微控制器抽象层 |
| OTA | Over-The-Air | 空中升级 |
| BMS | Battery Management System | 电池管理系统 |
| SBC | System Basis Chip | 系统基础芯片 |
| PMIC | Power Management IC | 电源管理 IC |
| NVM | Non-Volatile Memory | 非易失存储器 |
| BIST | Built-In Self-Test | 内建自测试 |
| JTAG | Joint Test Action Group | 调试 / 烧录接口 |
| SWD | Serial Wire Debug | 串行调试接口 |
