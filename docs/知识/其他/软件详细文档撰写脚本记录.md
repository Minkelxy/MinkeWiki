从源代码快速生成软件详细文档的脚本技巧：**VSCode 正则匹配 → Word 文本转表格**。

## 准备

在 VSCode 中匹配并复制时，建议关闭高亮选择，避免带色复制（`设置 → 无高亮复制粘贴`）。

## VSCode 正则匹配常用模式

### 函数 / 变量定义

| 目标 | 正则 | 说明 |
|------|------|------|
| static 开头的行 | `^static .*` | 匹配静态函数 / 变量定义 |
| 非 static 开头的行 | `^(?!static\b).*$` | 负向前瞻，排除 static |
| 非 extern 开头的行 | `^(?!extern\b).*$` | 排除外部声明 |
| 某内容之后 | `100.*` | 从指定位置截取到行尾 |

### 括号 / 参数

| 目标 | 正则 |
|------|------|
| 括号之间的所有内容 | `\((.*?)\)` |
| 函数名（括号前） | `\w+\s*\(` |

### 清洗

| 目标 | 正则 |
|------|------|
| 行尾空格 | `[ ]+\n` |
| 空行 | `^\s*\n` |
| 行号前缀 | `^\d+\s+` |

## Word 文本转表格

用上面的正则把代码整理成 `名称<TAB>说明` 的文本行，然后在 Word 里 **插入 → 表格 → 文本转换成表格**（按制表符分隔），即可批量生成文档表格。

## 工作流

1. 在源码中用正则提取函数 / 变量定义
2. 用清洗正则去掉 static/extern 前缀、行尾空格、空行
3. 整理成 `名称<TAB>说明` 行
4. Word 文本转表格 → 得到规范的文档表格
