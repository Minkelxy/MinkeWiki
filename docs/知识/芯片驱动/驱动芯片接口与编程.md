# 驱动芯片接口与编程（主控 ↔ 驱动芯片怎么对话）

落地[芯片驱动学习路线](学习路线.md)的**第 2 步（接口）和第 4 步（保护联动）**。诊断文档讲"怎么判断坏了"，本文讲**"主控怎么用驱动芯片"**——SPI 配寄存器、PWM 控输出、使能/方向、FAULT 联动。

> 一句话：驱动芯片是"主控和电机之间的大管家"——SPI 告诉它怎么保护，PWM 告诉它出多大力，FAULT 告诉你它报警了。

---

## 一、接口全景

```
主控（SPI / PWM / GPIO）→ 驱动芯片（寄存器 / 输出级）→ 电机
```

| 接口 | 干什么 | 典型 |
|------|--------|------|
| **SPI** | 配寄存器（诊断 / 保护 / 模式） | DRV 系列 |
| **PWM** | 控输出占空比 / 频率 | 直流 / 步进 |
| **GPIO 使能 / 方向** | 启停 / 正反转 | 简单芯片 |
| **FAULT 输出** | 芯片报警（过流 / 过温） | 接主控中断 |

## 二、SPI 寄存器配置（现代驱动芯片核心）

1. **读数据手册的寄存器映射**：模式 / 死区 / 保护阈值 / 诊断使能
2. **写时序**：片选 → 地址 / 读写位 → 数据；**写后读回校验**
3. 例：DRV 系列配置过流阈值、死区时间、栅极驱动参数
4. **坑**：上电时序（先供电再配置）、寄存器默认值、写后确认——配置错一个位，电机行为就怪

## 三、PWM 控制

- **频率**：直流电机 10-20 kHz（避开可听声频）；BLDC 更高
- **占空比**：控电压 / 速度
- **死区（半桥关键）**：上下管**不能同时导通**（直通烧毁）——互补 PWM 必须带死区
- **由主控定时器产生**，别用软件延时（抖动 + 占 CPU）

## 四、使能与方向 + FAULT 联动（安全闭环）

- **使能（EN）**：低电平关断；**方向（DIR）**：正反转——简单接口
- **FAULT 接主控中断**：芯片报警 → 主控**立即停 PWM**——硬件级安全，别只靠轮询
- **故障处理流程**：检测到过流 / 过温 → 停 PWM → 读诊断寄存器确认 → 复位
- 参考 [SimpleFOC](https://github.com/simplefoc/Arduino-FOC) 的错误处理模式（异常即停 + 诊断上报）

## 五、与你的项目结合

- **网控车 / 电机控制器**：驱动芯片接口编程是核心
- 对照[电机驱动选型指南](../../制作/电机驱动选型指南.md)选芯片，然后按本文写驱动
- 诊断文档（[开路诊断](开路诊断.md) / [故障诊断](故障诊断.md)）与本文互补：**接口会用、诊断会查**

## 六、本轮项目推荐：做「驱动芯片最小驱动」

**推荐做什么**：选一款电机驱动芯片（如 DRV 系列或你手头的），用 SPI 配好寄存器 + PWM 控一个电机转起来 + **FAULT 接中断自动停转**，写成可复用驱动模块。

**为什么值得做**：
- 这是[学习路线](学习路线.md)第 2 步的**落地验收**——不写一遍，接口只是"看过"；
- **接口编程是"主控对话驱动芯片"的核心技能**，网控车 / 电机控制器都用；
- 做一次驱动模块，后续项目直接复用，也把"诊断"文档用起来（FAULT 联动）。

**具体怎么做**：
1. 读芯片数据手册，画主控 ↔ 芯片框图（SPI / PWM / EN / FAULT）
2. SPI 初始化 + 配寄存器（过流阈值 / 死区），PWM 启动电机
3. 接 FAULT 中断：模拟过流 → 自动停 PWM → 读诊断寄存器
4. 封装成 `init()` / `set_duty()` / `get_fault()` 驱动模块

**产出**：一个可复用的驱动芯片驱动模块 + 故障联动演示 → 进网控车 / 电机控制器，对应[学习路线](学习路线.md)第 2、4 步。
