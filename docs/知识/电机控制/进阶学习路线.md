## 二、推荐进阶顺序（6 步）

### 第 1 步：三环调试（电流 → 速度 → 位置）

- **学什么**：电流环（内环）、速度环、位置环（外环）的整定方法与 PI 参数关系
- **为什么**：FOC 的所有性能都靠三环，这是从「能转」到「转得好」的分水岭
- **怎么练**：用 [SimpleFOC](https://github.com/simplefoc/Arduino-FOC) + 开源电机板，先调电流环再看速度环；对照 [BLDC代码分析](BLDC代码分析.md) 里的 S32K 工程

### 第 2 步：无感 FOC（去掉霍尔）

- **学什么**：滑模观测器（SMO）、扩展反电动势估算转子位置与速度
- **为什么**：无感是工业主流（霍尔贵、会坏、有安装精度问题）
- **怎么练**：在 SimpleFOC 里切无感模式，对比有感/无感的波形差异；理解反电动势估算的零速难题

### 第 3 步：相电流采样方案

- **学什么**：单电阻、双电阻、三电阻采样；采样窗口与 PWM 死区的关系
- **为什么**：采样是 FOC 的「眼睛」，硬件关键，噪声直接毁性能
- **怎么练**：读你 S32K 工程的 ADC 配置，用[ADC Pro Toolkit](../../个人项目/adc2amp.md)练习换算

### 第 4 步：SVPWM 细节（死区补偿、过调制）

- **学什么**：死区造成电流畸变与补偿方法；过调制提升母线电压利用率
- **为什么**：细节决定效率与波形质量，是「工程 FOC」和「玩具 FOC」的区别

### 第 5 步：参数辨识

- **学什么**：离线辨识定子电阻 Rs、电感 Ls、反电动势常数 Ke
- **为什么**：控制器参数自适应是高性能/自适应控制的基础，也能解释「为什么参数一变就抖」

### 第 6 步：工程化（弱磁、高速、故障保护）

- **学什么**：弱磁控制扩展调速范围、过流/过温保护、安全冗余
- **为什么**：对应你[芯片驱动](../芯片驱动/README.md)、[故障诊断](../芯片驱动/故障诊断.md)的知识，往产品级收敛

## 三、实践推荐（别只看书）

1. **一块开发板 + 电机**：买一块 SimpleFOC 兼容板（ESP32 + 驱动），成本 ¥50-100
2. **调通三环**：按第 1 步把电流/速度环跑顺，这是最重要的里程碑
3. **复刻已有代码**：把 S32K 的 BLDC 工程换到更熟悉的板子/工具链上跑一遍
4. **写调试笔记**：每次调参的波形/现象记进[FOC学习笔记](FOC学习笔记.md)，形成你自己的踩坑库

---

## 四、学习建议总结

- **顺序**：三环 → 无感 → 采样 → SVPWM → 参数辨识 → 工程化
- **节奏**：每步「读 1 篇原理 + 调 1 次真机」，别连续啃理论
- **复利**：每一步都和已有笔记/项目挂钩，学得越深、复用得越多
