# RTOS 学习路线

基于[自制RTOS](自制RTOS.md)，推荐进阶学习顺序——从"写过内核"走向"懂工程级 RTOS"。每步给出「学什么、为什么、怎么练」。

## 二、推荐进阶顺序（6 步）

### 第 1 步：调度算法深入

- **学什么**：优先级抢占、时间片轮转、实时调度（速率单调 RMS / 最早截止期 EDF）的区别与适用
- **为什么**：调度是 RTOS 的心脏，决定实时性
- **怎么练**：对照你自制内核的调度器，改成支持优先级 + 时间片两种模式，对比行为

### 第 2 步：同步与 IPC

- **学什么**：信号量、互斥量、消息队列、事件组；互斥量如何解决**优先级反转**
- **为什么**：任务间通信是实际开发最常用的功能，几乎所有应用都用到
- **怎么练**：在自制内核上加一个**互斥量**，实现优先级继承；再对照 FreeRTOS 的实现

### 第 3 步：内存管理

- **学什么**：静态 vs 动态分配、内存池（块分配）机制、碎片问题
- **为什么**：嵌入式里动态 malloc 有碎片和不确定性问题，工程常用内存池
- **怎么练**：实现一个固定块大小的内存池，测分配/释放的确定性

### 第 4 步：中断与临界区

- **学什么**：中断嵌套、临界区（关中断/优先级）、中断延迟与任务切换的协同
- **为什么**：实时性的关键指标是**中断延迟**和**切换开销**
- **怎么练**：在自制内核里测量任务切换的时钟周期数，找出最耗时路径优化

### 第 5 步：主流 RTOS 对比与迁移

- **学什么**：FreeRTOS / Zephyr / RT-Thread 的架构差异与选型（见[知识库开源参考](../开源参考项目.md)）
- **为什么**：实际产品用成熟 RTOS，理解其设计再迁移就顺了
- **怎么练**：用 FreeRTOS 跑通「任务 + 队列 + 信号量」最小工程，再对照自制内核找差异

### 第 6 步：实时性分析

- **学什么**：最坏执行时间（WCET）、优先级反转、死锁检测、响应时间分析
- **为什么**：工程要证明"能按时响应"，是实时系统的硬要求
- **怎么练**：对你自制内核的一个任务集做响应时间分析，验证是否满足截止期

---

## 三、学习建议总结

- **顺序**：调度 → IPC → 内存 → 中断 → 主流 RTOS → 实时性分析
- **抓手**：每一步都在**自制内核上动手改一处**，再对照 FreeRTOS 实现——"写过 + 看过"记得最牢
- **复利**：第 5 步迁移到 FreeRTOS 后，后续产品开发直接用它
