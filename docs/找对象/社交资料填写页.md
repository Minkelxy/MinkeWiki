# 社交资料填写页

> 直接复制粘贴到交友平台。`[ ]` 中的内容替换为你的实际信息。

## 一、照片清单

准备 6-8 张，按以下顺序排列：

| # | 类型 | 要求 | 状态 |
|---|------|------|------|
| 1 | **正面生活照**（首图） | 半身、自然光、微笑、背景干净 | ⬜ |
| 2 | **全身照** | 展示身材比例，休闲穿搭 | ⬜ |
| 3 | **北京工作/生活照** | 咖啡馆、公司或街景，展示在京品质生活 | ⬜ |
| 4 | **宁夏元素照** | 回老家时拍，表明归属感 | ⬜ |
| 5 | **项目/兴趣照** | 做电子项目的侧面照、弹琴、运动（选1） | ⬜ |
| 6 | **社交照** | 和朋友在一起的自然照 | ⬜ |
| 7 | **旅行/户外照** | 展示视野和活力 | ⬜ |
| 8 | **宠物/趣味照**（可选） | 如果有宠物，加分项 | ⬜ |

**照片规则：**
- 拒绝自拍镜 + 车内 + 浴室 + 健身房对镜自拍
- 拒绝全身大logo、过度美颜
- 至少 3 张是近 6 个月内拍的
- 首图必须是单人照

## 三、自我介绍（选一个版本用）

### 短版（15-30字，适合探探/二狗简介）

```
宁夏人在北京做嵌入式开发，计划1-2年回银川。
业余喜欢做电子项目、玩音乐。不烟，情绪稳定。
```

### 标准版（适合青藤之恋/她说）

```
【关于我】
- 宁夏银川人，25岁，181cm，目前在北京做嵌入式软件开发
- 工作稳定，计划1-2年内回宁夏银川发展
- 不吸烟不酗酒，性格偏安静，熟了之后话多
- 业余喜欢捣鼓电子小项目，做过天气时钟、游戏摇杆、电子琴
- 也会MIDI音乐改编，偶尔跑步健身

【关于异地】
目前在北京工作但有明确回宁夏打算。
每月能回1-2次见面，可以接受短期异地。
希望找愿意在银川定居的你。

【期待的你】
- 宁夏银川或周边
- 情绪稳定、善良真诚
- 有自己热爱的事情
```

### 详细版（适合牵手/伊对）

```
宁夏银川人，25岁，181cm，本科。目前在北京做嵌入式软件工程师（汽车电子方向）。

简单说就是给汽车写底层程序，教芯片怎么跟各种传感器和外设说话。工作不加班，收入稳定有积蓄。

业余是个"不无聊的技术宅"：
- 自己动手做过8个电子硬件项目，从设计到焊接全流程
- 会音乐制作（MIDI），偶尔弹电子琴
- 对宁夏农业项目有研究（真的下去考察过）
- 保持健身跑步，不烟

关于性格：偏安静慢热，不是那种八面玲珑社交型。但熟了之后会很靠谱，朋友说我共情力还不错。

关于未来：计划1-2年内回宁夏银川发展。不是画饼，是真的在关注那边的机会——农业项目、本地技术圈都在看。

关于异地：异地只是暂时的，不是长期的。每月能回宁夏见面，保持视频沟通。希望你愿意一起规划未来。

照片都是真实的，资料也是认真写的。
```

## 五、各平台差异化策略

| 平台 | 重点展示 | 资料建议 |
|------|----------|----------|
| **青藤之恋** | 学历+职业+认真态度 | 用标准版介绍，头像正式 |
| **牵手** | 地域匹配+真诚 | 用详细版，强调宁夏规划 |
| **Soul** | 兴趣+瞬间动态 | 多发布项目/音乐瞬间 |
| **二狗** | 职业标签+简洁 | 用短版，照片质量第一 |
| **探探** | 照片颜值第一 | 首图最重要，文字精简 |
| **伊对** | 视频第一印象 | 准备30秒自我介绍视频 |
| **她说** | 女性主导匹配 | 资料要完整有深度 |

## 六、个人资料检查清单

填写完每个平台后自查：

- [ ] 照片至少 6 张，首图是清晰的正面半身照
- [ ] 资料中明确提到"计划回宁夏/银川"
- [ ] 职业描述普通人能看懂（不是纯技术术语）
- [ ] 没有错别字
- [ ] 没有"在吗""你好"之类的敷衍语录
- [ ] 没有抱怨前任/工作/生活
- [ ] 没有"试试看""随便"之类的不确定表述
- [ ] 至少提到 1-2 个具体兴趣（不是泛泛的"喜欢音乐"）
- [ ] 定位设置为宁夏银川
- [ ] 资料截图发给朋友帮忙看一遍
