# 三国群英传2Re 玩法与内容设计

复刻项目的**核心玩法与内容组织**——在[开发方案](三国群英传2Re开发方案.md)的 MVP 骨架上，把"能打"推进到"有内容、好玩"。

---

## 一、核心玩法循环（先定循环，再谈细节）

```
大地图：选择→移动→攻城
   ↓
战斗：实时指挥武将/兵
   ↓
结果：胜→招降/夺城 / 败→撤退
   ↓
扩军：招武将、募兵、整备
   ↓
再战（循环）
```

> **玩法循环是先于一切的**：循环通顺，游戏就成立；循环断了，再多内容也白搭。

## 二、MVP 玩法范围（控制在最小）

| 做 | 不做 |
|----|------|
| 1 张地图 + 3-5 座城 | 完整三国版图 |
| 10 名武将、4 兵种 | 全武将全兵种 |
| 攻防 + 招降基础 | 完整内政系统 |
| 单一剧本 | 多剧本/剧情 |

> MVP 目标不是"像三国"，是**先验证循环好玩**（见[开发方案](三国群英传2Re开发方案.md)）。

## 三、内容组织

### 剧本/关卡结构

```
一个剧本 = 起始局势（地图 + 势力 + 武将分布）
剧本表：名称、起始城、势力、武将、胜利条件
```

- 胜利条件简单起步：占领所有城 / 击败主要势力
- 数据放 JSON（见[数值设计](三国群英传2Re数值设计.md)），方便做多个剧本

### 地图与城池

- 城池：名称、位置、驻兵、武将
- 地图：城池间连线（移动路径），先做简单连通

## 四、玩家目标与反馈

| 项 | 建议 |
|----|------|
| 目标 | 清晰（"统一中原"或"占领 X 城"）——玩家随时知道该干嘛 |
| 反馈 | 战斗结果、武将成长、攻城进度——每一步都有可见反馈 |
| 成就感 | 招降一个名将、打赢一场以弱胜强，就是记忆点 |

> 反馈要**即时**：打赢一场立刻有奖励（兵力/武将/城），别让玩家"白赢"。

## 五、平衡与测试

- 数值平衡参考[数值设计](三国群英传2Re数值设计.md)：克制/数值差距在 JSON 里调
- **试玩测试**：自己打几局，找"太简单/太难/无脑重复"的点
- 每次改数值 → 试玩 → 记结论，迭代快（数据驱动调试）
