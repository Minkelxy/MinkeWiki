# 游戏逆向入门

分析游戏**内存 / 数据 / 存档**的基础方法——用于修改器开发、存档分析、游戏机制研究（仅限合规场景）。

---

## 一、逆向用来做什么

| 用途 | 说明 |
|------|------|
| 内存修改 | 改血量/金币/数值 |
| 存档分析 | 解析存档格式（对应[三国群英传2Re](三国群英传2Re.md)数据） |
| 机制研究 | 摸清游戏逻辑、为 Mod/复刻服务 |
| 协议分析 | 网络游戏通信（高风险，慎用） |

> 单机修改/存档研究相对安全；**联网游戏的内存/协议逆向触碰反作弊，务必只在合规环境**。

## 二、核心概念

| 概念 | 说明 |
|------|------|
| 进程内存 | 程序运行时占的内存，游戏数值存在这里 |
| 地址 | 一个数值在内存中的位置 |
| 偏移（Offset） | 从某个基址的相对位置 |
| 基址 | 常量的起始地址（如角色对象地址） |
| 指针链 | 从基址一路偏移到目标数值的路径 |

**关键思路**：搜数值（如血量 100）→ 改变它（受伤变 90）→ 再搜 90 → 缩小到唯一地址 → 找到指针链 → 写脚本/修改器。

## 三、工具

| 工具 | 用途 | 说明 |
|------|------|------|
| Cheat Engine | 内存搜索/修改 | 入门首选，可视化 |
| [Ghidra](https://github.com/NationalSecurityAgency/ghidra) | 反汇编/反编译 | NSA 开源框架，看代码逻辑 |
| [Frida](https://github.com/frida/frida) | 动态插桩 | 运行时 hook、追踪 |

> 也可参考[游戏自动化开源参考](游戏自动化开源参考.md)的逆向部分。

## 四、基本流程（以改数值为例）

1. **搜索**：用 Cheat Engine 搜初始值（如金币 1000）
2. **改变再搜**：在游戏里花掉金币（变 900），再搜 900——范围迅速缩小
3. **锁定地址**：搜到唯一地址后"锁定/冻结"测试
4. **追指针链**：找到该地址的指针，避免重启游戏后失效
5. **写修改器**：用脚本/Cheat Engine 表格固化

## 五、存档分析（对应三国群英传2Re）

- 存档是文件，比内存简单——**直接读文件结构**：
  - 备份 → 改动一个数值（如金币）→ 对比前后文件 → 定位字节偏移
- 参考[三国群英传2 存档修改器](https://github.com/lion23251002/Sango2_Save_Modifier)的字段反推
- 把解析出的结构写进[三国群英传2Re开发方案](三国群英传2Re开发方案.md)的数据设计，一举两得

## 六、合规提醒

- **单机修改/存档研究**：低风险，个人使用
- **联网游戏内存/协议**：高封号风险 + 可能违规，**不建议**
- 学习优先：先把 Cheat Engine 搜值流程练熟，再谈深入
