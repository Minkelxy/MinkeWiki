# 三国群英传2Re 技能系统设计（武将技）

[战斗系统设计](三国群英传2Re战斗系统设计.md)里"武将技能：二期再加"——本文把二期补齐。承接战斗系统 / [数值设计](三国群英传2Re数值设计.md) / [敌方AI设计](三国群英传2Re敌方AI设计.md)。

> 原版三国群英传2 的招牌就是**武将技**（武将喊招、放范围技）——复刻它=保留灵魂。但技能是"操作"不是"数值堆"：先做 3-5 个有区别的，别一上来做技能树。

---

## 一、技能系统的定位（先想清楚）

| 没有技能 | 有技能 |
|---------|--------|
| 战斗 = 拼兵力数字 | 有**操作感和翻盘点** |
| 胜负在开战前就定了 | 一个好技能能扭转战局 |

> 技能的价值不是"多一个伤害"，是**给玩家选择**：什么时候放、放给谁、留不留。这才是复刻的深度。

## 二、技能分类（起步够用）

| 类型 | 例子 | 设计点 |
|------|------|--------|
| **单体伤害** | 单挑将技 | 高伤害，但要有**前摇 / 命中判定** |
| **范围伤害** | 火计 / 落雷（打敌群） | 范围大、单伤低，**打聚堆的兵** |
| **增益 / 减益** | 士气提升 / 敌军混乱 | 改变战斗状态，影响走位 |
| **控制** | 定身 / 混乱 | 限制敌军，配合集火 |

> **MVP 建议**：每武将 **1 个标志技 + 1 个通用技**，别一上来做技能树——先把"放技能的感觉"做对。

## 三、触发与资源（怎么做"使用"）

- **资源**：**士气值 / 怒气条**（战斗中累积）——比魔法值更贴合策略感
- **触发**：玩家按键 → 蓄力 / 前摇 → 释放；AI 用类似规则（见[敌方AI设计](三国群英传2Re敌方AI设计.md)）
- **CD**：大招 CD 长（一场 1-2 次），小技 CD 短
- **取消机制**：移动 / 被打断可取消（防无脑站桩放）

> 士气条怎么涨、满条多久，是**战斗时长和节奏**的调节阀——值得在[数值设计](三国群英传2Re数值设计.md)里单独立一项。

## 四、技能与数值联动（关键）

- 伤害公式接[数值设计](三国群英传2Re数值设计.md)：`技能伤害 = 基础值 × 武力系数 × (1 + 等级加成)`
- **别让技能爆表**：技能是"有限次数的高峰"，平A 和兵力是基底——技能碾压平A = 战斗只剩放技能
- 克制关系：范围技克聚堆、单体技克大将、增益技克消耗战——让"用什么技能"有选择

## 五、AI 用技能（接 AI 设计）

- 敌方 AI 在**集火时放大招、兵力劣势时放增益**——让玩家感觉"被针对"但"能应对"
- **技能前摇必须给玩家反应时间**（红圈 / 预警 / 喊招）——否则不公平，AI 显得作弊

## 六、平衡与验收

- 每技能一页**技能卡**：类型 / 伤害 / 范围 / CD / 前摇 / 士气消耗 / 克制关系
- 验收标准：
  - 不同武将打法有区别（不换皮）
  - 技能不碾压平A（平A仍是基底）
  - AI 用技能有预警、可躲
  - 一场战斗能"放 2-3 次关键技能"（士气节奏合理）

## 七、本轮项目推荐：做「3 技能最小系统」

**推荐做什么**：给战斗系统加 **3 个有区别的武将技**——单体高伤 / 范围清兵 / 士气增益，配士气条 + CD + 前摇，玩家和 AI 各一套；统计每技能的使用频率和胜率影响，验证"有技能更好玩"。

**为什么值得做**：
- 战斗系统已有命令状态机 + AI，**技能是让战斗"有操作感和翻盘点"的下一步**；
- 3 个技能量级小，一周能跑通，正好当二期第一个里程碑；
- 直接验证原版三国群英传2 "武将技"的灵魂在不在——这是复刻区别于"数值对撞"的核心。

**具体怎么做**：
1. 选 3 个技能（单体 / 范围 / 增益），定伤害公式 + 士气消耗 + CD + 前摇（见第三、四节）
2. 战斗加**士气条**（累积机制）+ 技能释放命令（复用[战斗系统](三国群英传2Re战斗系统设计.md)的状态机）
3. 玩家按键触发 + AI 规则触发（接[AI设计](三国群英传2Re敌方AI设计.md)），带前摇预警
4. 跑对局统计：技能使用率 / 胜率 / 是否出现翻盘

**产出**：3 技能的战斗 Demo + 3 张技能卡 + 使用数据 → 进三国群英传2Re 战斗系统，验证"武将技"体验。
