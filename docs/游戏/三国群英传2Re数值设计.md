# 三国群英传2Re 数值与数据设计

复刻《三国群英传2》的**数据层设计**——武将、兵种、战斗数值怎么组织。承接[三国群英传2Re开发方案](三国群英传2Re开发方案.md)的"数据 JSON 化"。

---

## 一、数据架构原则

- **数据与逻辑分离**：武将/兵种/武器全放 JSON（或 CSV），代码只读不写死
- 好处：改平衡不用改代码、方便 Mod、方便[存档反推](../游戏/游戏逆向入门.md)的数据接入
- 目录建议：

```
data/
├── generals.json   # 武将
├── troop_types.json # 兵种
├── weapons.json    # 武器
└── balance.json    # 全局数值（伤害公式参数等）
```

## 二、武将属性设计

| 字段 | 说明 | 参考 |
|------|------|------|
| id / name | 标识 | 用原版武将名 |
| 武力 / 智力 / 统率 | 三维核心 | 数值范围 1-100 |
| 兵力 / 血量 / 攻防 | 战斗属性 | 由三维推导或独立 |
| 成长曲线 | 等级成长 | 线性或分段 |

> 先抄原版数值打底，再微调——**复刻的核心是还原手感，不是自创**。

## 三、兵种设计

| 兵种 | 定位 | 克制 |
|------|------|------|
| 步兵 | 均衡 | 克枪兵 |
| 枪兵 | 抗骑兵 | 克骑兵 |
| 骑兵 | 高速 | 克步兵（或被步兵克，按原版） |
| 弓兵 | 远程 | 脆但输出 |

- 克制关系先按原版来，后期再平衡
- 每兵种给**属性差异**（血/攻/速/射程），别都长一样

## 四、战斗数值（伤害公式）

建议简单起步，如：

```
伤害 = 攻击力 × 兵种克制系数 − 防御力（下限保底值）
```

- **克制系数**：如克制时 1.5、被克 0.7
- **保底伤害**：至少造成 1-5 点，避免"打不动"
- 先跑通，再调平衡——**别一开始追求完美公式**

### 平衡原则（MVP 够用）

1. 强将 > 强兵：武将三维差距要能体现
2. 高兵力 > 低兵力：数量要有意义
3. 克制 > 无脑数值：让"选兵种"有策略

## 五、复用存档/原版数据

- 用[游戏逆向入门](游戏逆向入门.md)的存档分析，反推原版武将数值作为初始表
- 参考[三国群英传2 存档修改器](https://github.com/lion23251002/Sango2_Save_Modifier)字段
- 一次导入成 JSON，后续所有平衡都在数据层调

## 六、落地建议（MVP 阶段）

1. 先写 `generals.json` + `troop_types.json` 两个 schema（10 名武将、4 兵种即可起步）
2. 伤害公式先用最简单的线性版
3. 平衡靠**测试**：跑几场战斗看数据，再调 JSON——数据驱动的调试是复刻的捷径
