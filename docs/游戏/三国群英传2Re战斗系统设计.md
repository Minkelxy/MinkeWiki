# 三国群英传2Re 战斗系统设计

复刻的核心战斗玩法——**实时指挥武将带兵**。承接[玩法设计](三国群英传2Re玩法设计.md)与[开发方案](三国群英传2Re开发方案.md)的 MVP 范围。

---

## 一、战斗核心（MVP 简化）

| 要素 | 说明 |
|------|------|
| 武将带兵 | 武将统率兵力，兵力决定强度 |
| 实时指挥 | 给武将下移动/攻击命令 |
| 简化战斗 | 自动攻击 + 手动走位，别做复杂微操 |

> MVP 目标：**能指挥、能分胜负**（见[开发方案](三国群英传2Re开发方案.md)的 M2 里程碑），不追求华丽。

## 二、战斗流程

```
开战 → 部署/移动 → 接敌 → 自动攻击 → 一方兵力归零 → 胜负
```

- 战斗开始：双方武将 + 兵力入场
- 移动：下达移动命令，士兵跟随武将
- 接敌：进入射程/接触后自动攻击（按[数值设计](三国群英传2Re数值设计.md)的伤害公式）

## 三、命令系统（用状态机管理）

| 命令 | 状态 | 行为 |
|------|------|------|
| 移动 | MOVING | 寻路到目标点 |
| 攻击 | ATTACKING | 追击/攻击范围内敌人 |
| 撤退 | RETREATING | 远离战场 |
| 待机 | IDLE | 站桩等待 |

> 用**状态机**管理战斗实体（见[开发方案](三国群英传2Re开发方案.md)），状态清晰可扩展——每武将/士兵组一个状态机实例。

## 四、士兵与武将

- **士兵**：跟武将移动，攻击由武将命令驱动（简化：士兵是武将的"数值池"）
- **阵型（可选）**：MVP 先不做，用"簇拥跟随"即可
- **武将技能**：二期再加（先让战斗能打起来）

## 五、胜负与奖励

- **胜负**：一方兵力归零即败
- **招降**：胜方对被击败武将可招降（进[玩法循环](三国群英传2Re玩法设计.md)）
- **经验/成长**：MVP 可先不做，或简单记录战果

> 反馈要即时（见[玩法设计](三国群英传2Re玩法设计.md)）：打赢立刻有"兵力/武将/城"的奖励。
