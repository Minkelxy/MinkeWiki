# 三国群英传2Re 内政系统设计

[玩法设计](三国群英传2Re玩法设计.md)把"完整内政系统"明确列为 **MVP 不做**——本文把它补成**下一阶段的设计**。承接玩法循环（大地图→战斗→招降→扩军→再战），内政是"打赢之后怎么发展"的深度层。

> 一句话：**别贪多**——先做三件事（招降 / 招募 / 发展），再做全。

---

## 一、内政系统的定位（MVP 后加）

| 没有内政 | 有内政 |
|---------|--------|
| 打赢→数据变强→再打，循环单薄 | 打赢→招降→发展→再打，有"经营感" |
| 全是战斗节奏 | 慢（内政）快（战斗）交替，给玩家呼吸 |

> 内政是**慢节奏的"经营"**，与战斗的快节奏交替——这是三国游戏"停不下来"的结构。

## 二、三大模块（起步）

| 模块 | 干什么 | 接哪 |
|------|--------|------|
| **招降** | 战败武将可招降（忠诚度 / 性格） | [战斗系统](三国群英传2Re战斗系统设计.md) |
| **招募** | 募兵（花资源换兵），养兵有成本 | [数值设计](三国群英传2Re数值设计.md) |
| **发展** | 城池经济（税收 / 粮），升级兵力上限 | [存档系统](三国群英传2Re存档系统设计.md) |

> 对应原版核心内政：**搜索人才 / 招降 / 建设城池**。

## 三、资源与经济（内政的地基）

- **资源**：金钱 + 粮（双资源，简单起步）
- **来源**：城池税收（按城 / 按武将）、战斗战利品
- **消耗**：募兵、养兵（月俸）、升级
- **数值接数值设计**：税收率 / 养兵成本在 JSON 调（见[数值设计](三国群英传2Re数值设计.md)）

## 四、招降机制（最有策略感的模块）

- **忠诚度**：招降成功概率 = 忠诚度 × 性格 × 关系
- **性格影响**：忠义型难降、野心型易降
- **招降后**：可**封赏**（忠诚上升）——内政和武将绑一起

> 招降是原版最有策略感的机制——"打赢名将能不能收服"是每次战斗的期待。

## 五、与战斗 / 大地图的衔接

- 战斗胜 → 可招降（接[战斗系统](三国群英传2Re战斗系统设计.md)）；招降 / 募兵 → 增强下次战斗（接[数值](三国群英传2Re数值设计.md)）
- 城池发展 → 兵力上限 / 税收 → 滚雪球
- 存档要**存内政状态**（接[存档系统](三国群英传2Re存档系统设计.md)）

---

## 六、本轮项目推荐：做「招降机制原型」

**推荐做什么**：在 MVP 打完仗后，加一个最简单的**招降流程**——战败武将可招降（忠诚度 + 性格判定），成功入队、失败跑路；配 3 个武将试招降体验。

**为什么值得做**：
- **招降是玩法循环"扩军"的核心**、原版最有策略感的机制；
- 一次做完验证"打赢 → 招降 → 变强 → 再打"的爽感；
- 是内政系统的**第一个落地模块**——先招降，再招募发展。

**具体怎么做**：
1. 定义忠诚度 / 性格字段（接[数值设计](三国群英传2Re数值设计.md) JSON）
2. 战斗胜 → 进入招降界面，判定成功概率
3. 成功入队（加武将） / 失败跑路
4. 试 3 个武将，调判定数值

**产出**：招降机制 Demo + 忠诚度 / 性格数值表 → 进三国群英传2Re，是内政系统第一个模块、玩法循环"扩军"的落地。
