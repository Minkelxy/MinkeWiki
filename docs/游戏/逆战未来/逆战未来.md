# 逆战未来硬件计划

## 项目概述

本项目是为《逆战：未来》游戏打造的完整硬件自动化解决方案，采用**三层架构设计**：

1. **Minke** - 硬件执行层（ESP32-S3）
2. **NZM_CMD** - 策略执行层（Rust）
3. **MINKE's Indexed NiZhan Keypoint Environment** - 数据生成层（Rust + egui）

通过硬件级隔离与计算机视觉相结合，实现安全、稳定、拟人化的游戏自动化体验。

## 核心组件

### 1. Minke - 硬件执行引擎

**定位**：基于 ESP32-S3 的微型自动化引擎

**核心特性**：
- 🛡️ **硬件级隐蔽性**：USB HID 协议伪装，目标电脑识别为标准键鼠设备
- 🤖 **极致拟人算法**：
  - 贝塞尔曲线鼠标轨迹
  - 基于菲茨定律的动态变速
  - 微观抖动与过冲修正
  - 高斯分布随机延迟
- 🖱️ **双模鼠标引擎**：
  - 相对模式：FPS 游戏视角控制
  - 绝对模式：MOBA/桌面自动化

**通信协议**（11字节定长帧）：

| 字节 | 含义 | 说明 |
|------|------|------|
| 0 | Header | 固定 0xAA |
| 1 | Type | 0x01=键盘, 0x02=相对鼠标, 0x03=绝对鼠标 |
| 2-7 | Args | 参数（键码、坐标、位移等） |
| 8-9 | Delay | 延迟时间（ms） |
| 10 | Tail | 固定 0x55 |

**输入事件结构**：

```c
typedef struct {
    uint16_t delay_ms;   // 与上一个事件的间隔（0～65535 ms，约18秒）
    uint8_t  type;       // 操作类型（见下表）
    uint8_t  code;       // 键码或鼠标按钮（如 VK_A=0x41, MOUSE_LEFT=0x01）
    int16_t  dx;         // 鼠标X相对位移（-128～127）
    int16_t  dy;         // 鼠标Y相对位移
} InputEvent;
```

**操作类型定义**：

| Type | 说明 | Code 含义 |
|------|------|-----------|
| 0x01 | 键盘按下 | 虚拟键码（VK_A=0x41） |
| 0x02 | 键盘释放 | 虚拟键码 |
| 0x03 | 鼠标按下 | MOUSE_LEFT=0x01, RIGHT=0x02, MIDDLE=0x04 |
| 0x04 | 鼠标释放 | 按钮代码 |
| 0x05 | 鼠标移动 | dx/dy 为相对位移 |
| 0x06 | 鼠标滚轮 | dx 为滚轮值 |

### 2. NZM_CMD - 策略执行框架

**定位**：《逆战：未来》自动化执行终端与辅助框架

**核心特性**：
- ⚙️ **双模驱动架构**：支持硬件串口与软件模拟热切换
- 🧠 **计算机视觉**：基于 Windows OCR 的场景识别与状态判断
- 🗺️ **智能导航**：NavEngine 基于 TOML 配置的动态路由分发
- 🏰 **塔防业务**：JSON 定义建造/升级/拆除序列，坐标自动修正
- 📅 **日活业务**：每日任务自动识别、刷新、领奖及弹窗跳过

**已完成功能**：

| 智能导航 | NavEngine、OCR 识别、动态路由 | 2026-02-07 |

### 3. MINKE's Indexed NiZhan Keypoint Environment - 地图数据化引擎

**定位**：次世代地图数据化工具，将游戏截图转化为机器可读的纯数字环境数据

**核心特性**：
- 🗺️ **图物分离架构**：静态地形与动态建筑解耦
- 🎯 **浮点数级校准**：Float32 精度，根除分辨率变化误差
- 🔍 **无限工作台**：平滑拖拽、无损缩放（10% - 1000%）
- ⛰️ **高度映射笔刷**：五色笔刷绘制三维地形信息

**地形颜色编码**：

| 颜色 | ID | 含义 | 用途 |
|------|----|----|------|
| 🔴 红色 | -1 | 障碍物 | 寻路强制避开 |
| 🟢 绿色 | 0 | 基础平地 | 默认可放置陷阱 |
| 🟡 黄色 | 1 | 一级高台 | 矮墙/低高台 |
| 🔵 蓝色 | 2 | 二级高台 | 标准墙面/中等高度 |
| 🟣 紫色 | 3 | 三级高台 | 天花板/防空位置 |

**输出数据格式**：

```json
{
  "map_name": "Ni-Zhan_Exported_Map",
  "meta": {
    "grid_pixel_size": 32.5,
    "offset_x": 12.0,
    "offset_y": 5.0
  },
  "layers": [
    {
      "major_z": 0,
      "name": "Major_Layer_0",
      "elevation_grid": [
        [0, 0, -1, -1],
        [0, 1,  1, -1]
      ]
    }
  ]
}
```

## 工作流程

### 标准自动化流程

```
1. 数据准备阶段
   └─> 在 MINKE Keypoint Environment 中
       └─> 加载游戏截图 (1.png)
       └─> 网格校准（Grid Size、Origin、Rows/Cols）
       └─> 地形绘制（五色笔刷标记）
       └─> 导出 minke_map_data.json

2. 策略配置阶段
   └─> 在 MINKE 中
       └─> 加载地图数据
       └─> 绘制陷阱布局
       └─> 定义建造/升级/拆除序列
       └─> 导出 strategy.json

3. 执行运行阶段
   └─> 将 JSON 文件放入 NZM_CMD 目录
   └─> 连接 Minke 硬件（USB OTG + UART）
   └─> 启动 NZM_CMD
       └─> OCR 识别游戏状态
       └─> 生成拟人化操作序列
       └─> 通过 UART 发送给 Minke
       └─> Minke 执行物理键鼠操作
```

## 快速开始

### 硬件准备

1. **ESP32-S3 开发板**（必须支持 USB OTG）
2. **两条 USB 线**：
   - USB OTG 口：连接受控电脑（模拟键鼠）
   - UART/Debug 口：连接控制电脑（发送指令）

### 环境配置

```bash
# 1. 安装 Rust 工具链
# 访问 https://rustup.rs/

# 2. 安装 Python 3.8+
pip install pyserial pyautogui pynput

# 3. 安装 ESP-IDF v5.0+
# 访问 https://docs.espressif.com/projects/esp-idf/
```

### 烧录 Minke 固件

```bash
cd Minke
idf.py set-target esp32s3
idf.py build flash -p COM3 monitor
```

### 编译 NZM_CMD

```bash
cd NZM_CMD
cargo build --release
```

### 运行地图编辑器

```bash
cd MINKE-s-Indexed-NiZhan-Keypoint-Environment
cargo run --release
```
