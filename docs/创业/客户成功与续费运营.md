# 客户成功与续费运营

你的成交前链路已齐（获客 / 报价 / 合同 / 政采 / 品牌），本文补**成交之后**——订阅制业务的利润中心在续费。[财务与定价模型](财务与定价模型.md)讲了"续费是核心现金流"，本文讲**怎么让客户愿意续费**。

> 一句话：**卖出去只是开始，客户用起来、续起来，才有利润**。续费靠的不是合同，是客户成功。

---

## 一、为什么续费是利润中心

| 事实 | 含义 |
|------|------|
| 订阅毛利 90%+（无硬件成本） | 一个客户续费 N 年 = 纯利润 |
| 留住老客户比拉新便宜 5-10 倍 | 老客户是最好的"新客户" |
| 续费率 = 业务健康度核心指标 | 续费好，业务才敢加投入 |

> 财务上：**N 个客户 × 年续费率 × 年订阅额** = 你的稳定收入公式（见[财务与定价模型](财务与定价模型.md)）。

## 二、续费漏斗（从成交那一刻开始设计）

```
成交 → 上线启用 → 首月价值 → 季度回访 → 续费窗口
```

- 每个环节都是"续费"的伏笔：**启用是否顺、数据是否真的在看、是否感受到价值**
- 别等到续费窗口才联系——那时候客户已经忘了几年前为什么买你

## 三、客户成功的三个动作（落地）

1. **上线启用做扎实**：交付不是终点是起点——上线当天教会客户看数据（见[LoRa监测产品化路线](LoRa监测产品化路线.md)的交付 SOP）
2. **主动回访节奏**：
   - 首月回访：问"用得顺不顺、哪里看不懂"
   - 季度回访：顺带卖增值（加传感器）
   - 续费前回访：确认价值，处理疑虑
3. **流失预警**：客户不再看数据 / 停更数据 / 电话不接 → **提前介入**，别等续费时才慌

## 四、让客户"感受到价值"（续费的本质）

- 农业客户续费的理由不是"合同"，是**"数据帮过忙"**：报警救了番茄、报表应付了检查
- 把价值**显性化**：月报自动发、年度对比、"避免了什么损失"写出来
- 用案例强化：你其他客户的效果说话（见[品牌与宣传](品牌与宣传.md)的案例集）

> 记住：**客户续费 = 他觉得你值**。他觉得不值，降价也没用。

## 五、增值续订（续费时卖更多）

- 加传感器 = 加订阅额（土壤 / 水势 / 更多节点）
- 年度报告 / 定制看板 = 增值服务
- **续费窗口 = 顺带提增值**，别只续原有——续费是最自然的增销时机

## 六、续费相关的财务操作（对齐财务定价模型）

- **提前 30 天提醒续费**；按年收、别月付（现金流好，见[财务与定价模型](财务与定价模型.md)）
- **流失记录原因**（价格 / 没用起来 / 倒闭），反哺产品与获客
- 续费目标：第一年 70%+，之后 80%+；**农业有季节波动，别只看单季**

## 七、本轮项目推荐：建一个「客户回访与续费日历」

**推荐做什么**：做一个简单的**客户成功表**（表格 / 飞书 / 自建均可）：每个客户一行——上线日期、首月回访日、季度回访日、续费到期日、当前状态；配一个**"到期前 30 天"提醒**。

**为什么值得做**：
- 订阅制最怕"**卖完就忘**"——一个日历让回访、续费不靠记性；
- 续费是利润中心，一个动作（**按时回访**）就能显著拉高续费率；
- 和[财务与定价模型](财务与定价模型.md)的"续费率检查"形成闭环，是订阅制生意的**利润守护表**。

**具体怎么做**：
1. 列客户清单：上线日期 / 合同额 / 订阅到期日
2. 设回访节奏：首月 / 季度 / 续费前（见第三节）
3. 到期前 30 天提醒 → 续费沟通
4. 流失客户记录原因（反哺产品）

**产出**：一个客户成功日历 + 回访模板（3 句话版）→ 与合同交付 / 财务定价闭环，直接守护你的订阅利润。
