### 2. 灯光系统布光方案

#### 2.1 基础三点布光法
```
        [主光灯] 45°
             \
              \  主播
               /
              /
        [辅光灯]    [轮廓灯/发丝灯]
```

**各灯作用：**
- **主光灯（Key Light）**：主要光源，亮度最高，放置在主播前方45°
- **辅光灯（Fill Light）**：填充阴影，亮度为主光的50-70%，对称放置
- **轮廓灯（Back Light）**：从后方打亮轮廓，分离背景，增加立体感

| 环形灯 | 神牛 LR180 | 可调色温 | ¥600-800 | 双色温，可调节 |
| 柔光箱 | 神牛 SL60W + 柔光箱 | 60W | ¥800-1200 | 光线柔和，阴影少 |

#### 2.4 灯光调节参数参考
- **主光与辅光比例**：2:1 到 4:1（主光更亮）
- **灯光高度**：略高于主播眼睛水平线，向下15-30°
- **距离**：主光距主播1-1.5米，避免过近刺眼
- **色温统一**：所有灯光色温保持一致或有意创造对比

## 二、软件工具详解

### 1. 美颜软件深度设置

#### 1.1 抖音自带美颜参数推荐
| 参数 | 建议值 | 说明 |
|------|--------|------|
| 磨皮 | 40-60% | 过高会失真，过低瑕疵明显 |
| 瘦脸 | 30-50% | 自然为主，避免蛇精脸 |
| 大眼 | 20-40% | 轻微放大，保持真实 |
| 瘦鼻 | 20-30% | 适度即可 |
| 美白 | 30-50% | 配合灯光色温调整 |
| 锐化 | 20-30% | 增加清晰度 |
| 清晰 | 40-60% | 提升整体画质 |
| 风格妆 | 淡妆/裸妆 | 避免浓妆艳抹 |

**设置原则：**
- 美颜参数宁低勿高，保持个人特色
- 不同光线环境参数需微调
- 定期让粉丝提意见，调整过度美颜

#### 1.2 无他相机参数详解
- **肤质选择**：根据肤质选择「自然」「水光」「磨皮」
- **五官微调**：
  - 下巴：轻微收尖，避免过尖
  - 额头：适当饱满
  - 颧骨：适度调整，保持轮廓
  - 嘴巴：大小和厚度微调
- **滤镜选择**：「自然」「清新」类更适合颜值主播

#### 1.3 OBS 美颜插件设置
```
插件：FaceRig / Snap Camera / 美颜摄像头插件

推荐设置：
- 磨皮：中等强度
- 美白：低强度
- 大眼：关闭或极低（避免不自然）
- 滤镜：LUT 调色提升质感
```

### 2. 直播推流软件详解

#### 2.1 抖音直播伴侣
**功能特点：**
- 官方推流，稳定性最好
- 内置美颜和滤镜
- 支持多场景切换
- 礼物特效显示

**设置建议：**
- 分辨率：1920×1080（电脑配置好）或 1280×720
- 码率：4000-6000 kbps
- 帧率：30fps（舞蹈类建议 60fps）
- 编码器：NVENC（N卡）或 x264（CPU强）

#### 2.2 OBS Studio 高级设置
**场景设置：**
```
场景1：开场画面（暖场音乐+封面图）
场景2：正常直播（摄像头+背景）
场景3：PK 场景（放大+特效）
场景4：感谢场景（礼物特效展示）
场景5：结束画面（关注引导）
```

**插件推荐：**
- **Move Transition**：平滑场景切换
- **Spectralizer**：音频可视化
- **Advanced Scene Switcher**：自动场景切换
- **StreamFX**：高级滤镜效果

#### 2.3 多平台推流
如需同时推流多个平台：
- **Restream**：云端多平台推流
- **OBS + 多路推流插件**：本地多平台
- **手机直播**：一机多平台需多个手机

## 四、妆容穿搭上镜指南

### 1. 上镜妆容详解

#### 1.1 底妆
- **粉底**：比日常深半个色号（吃光）
- **遮瑕**：重点遮黑眼圈、痘印、法令纹
- **定妆**：哑光散粉，避免反光
- **修容**：比平时重一点，增强立体感

#### 1.2 眼妆（重点）
- **眼线**：内眼线+微微上扬外眼线，放大眼睛
- **睫毛**：假睫毛或浓密睫毛膏，增加眼神光
- **眼影**：大地色系百搭，闪片点缀卧蚕
- **美瞳**：自然款，直径 14.0-14.2mm

#### 1.3 眉妆
- 根据脸型选择眉形
- 颜色与发色统一
- 眉毛轮廓清晰，有毛流感

#### 1.4 唇妆
- 选择显气色的颜色（豆沙、珊瑚、水红）
- 唇峰明显，增加精致感
- 直播时随时准备补妆

#### 1.5 高光与腮红
- 高光：鼻梁、眉骨、颧骨、下巴
- 腮红：斜向扫，有瘦脸效果
- 避免大珠光，会显毛孔

---

### 2. 穿搭上镜技巧

#### 2.1 颜色选择
| 肤色 | 适合颜色 | 避免颜色 |
|------|----------|----------|
| 白皙 | 粉色、浅蓝、白色、 pastel 色 | 过于暗沉的颜色 |
| 偏黄 | 宝蓝、酒红、墨绿、白色 | 土黄、橙色 |
| 偏黑 | 白色、亮黄、橙色、正红 | 深褐、深紫 |

#### 2.2 款式选择
- **上镜显瘦**：V领、露肩、收腰设计
- **避免**：横条纹、oversize、高领（显脸大）
- **小心机**：露锁骨、露手腕、露脚踝
- **换装**：准备2-3套衣服，直播中换装增加新鲜感

#### 2.3 配饰搭配
- **耳环**：长款显脸瘦，珍珠显气质
- **项链**：V型拉长颈部线条
- **发饰**：与衣服风格统一
- **避免**：过于夸张的配饰（抢镜）

## 五、直播间布置方案

### 1. 背景设计方案

#### 1.1 纯色背景
- **白色/米色**：干净、百搭
- **粉色**：甜美、少女心
- **灰色**：高级、简约
- **注意**：纯色需均匀打光，避免阴影

#### 1.2 实景背景
- **书架背景**：知性、文艺
- **窗帘背景**：温馨、居家
- **床/沙发**：生活化、亲切
- **注意**：背景要整洁，避免杂乱

#### 1.3 虚拟背景（绿幕）
- 可切换多种场景
- 适合打造特定人设（海边、咖啡厅等）

## 八、常见问题与解决方案

### 1. 画面问题
| 问题 | 原因 | 解决 |
|------|------|------|
| 画面模糊 | 对焦不准/码率低 | 检查对焦，提高码率 |
| 肤色发黄 | 白平衡不准 | 手动白平衡或调色 |
| 背景过曝 | 背景光太强 | 降低背景光或调整曝光 |
| 眼睛无神 | 没有眼神光 | 环形灯调整位置 |
| 有噪点 | 光线不足/ISO高 | 增加灯光，降低ISO |

### 2. 音频问题
| 问题 | 原因 | 解决 |
|------|------|------|
| 声音小 | 增益太低 | 调高麦克风增益 |
| 有回声 | 监听外放 | 戴监听耳机 |
| 有电流声 | 接地不良 | 检查线路，使用隔离器 |
| 爆音 | 麦克风太近/增益高 | 拉远距离，降低增益 |
| 杂音多 | 环境噪音 | 开启降噪，关闭门窗 |

### 3. 直播卡顿
| 原因 | 解决 |
|------|------|
| 网络带宽不足 | 升级宽带，关闭其他设备 |
| 电脑配置低 | 降低分辨率/码率 |
| 软件冲突 | 关闭不必要的软件 |
| 手机过热 | 使用散热背夹 |
