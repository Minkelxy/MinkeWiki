# 个人抖音直播辅助网站方案

## 一、网站核心定位

**目标用户**：个人颜值主播（单兵作战）
**核心目标**：一台电脑/平板搞定所有直播辅助需求
**使用场景**：直播时放在副屏或iPad上随时查看操作

---

## 二、核心功能模块设计

### 模块1：直播中控台 🎛️
**功能**：一站式控制直播节奏

| 功能项 | 说明 |
|--------|------|
| 直播计时器 | 显示已直播时长，设置目标时长倒计时 |
| 环节提醒 | 预设环节时间点自动提醒（如"该PK了"、"该感谢了"） |
| 在线人数监控 | 手动记录峰值人数（或对接API） |
| 音浪计算器 | 实时计算本场收入、目标完成进度 |
| 快捷操作按钮 | 一键复制话术、播放音效、切换场景提示 |

**界面示意**：
```
┌─────────────────────────────────┐
│ ⏱️ 直播时长: 01:23:45            │
│ 👥 在线: 156  |  峰值: 289       │
│ 💰 音浪: 12.5k  |  目标: 50%     │
│                                 │
│ [PK提醒] [感谢时间] [下播提醒]   │
│ [喝水提醒] [休息提醒] [换装提醒] │
└─────────────────────────────────┘
```

---

### 模块2：智能话术库 💬
**功能**：告别冷场，快速调用话术

#### 2.1 话术分类管理
```
📁 话术库
├── 🎯 开场话术（5条）
├── 👋 欢迎话术（按等级：路人/粉丝/守护）
├── 💝 感谢话术（按礼物等级）
├── ⚔️ PK话术（拉票/求守护/感谢）
├── 🎮 互动话术（游戏/问答/投票）
├── 🌙 深夜话术（情感/陪伴向）
└── 👋 下播话术（5条）
```

#### 2.2 快捷发送
- 点击话术 → 自动复制到剪贴板 → 直接粘贴到抖音
- 支持快捷键（如按数字1-9快速发送）
- 搜索功能：输入关键词快速找到话术

#### 2.3 智能推荐
- 根据直播时长推荐话术（开场30分钟用开场话术）
- 根据在线人数推荐（人多时推荐PK话术）
- 根据时间段推荐（深夜推荐情感话题）

---

### 模块3：音效音乐控制台 🎵
**功能**：网页版音效板，告别手机找音乐的尴尬

#### 3.1 音效分类
| 分类 | 示例音效 | 快捷键 |
|------|----------|--------|
| 欢迎类 | 门铃、欢呼声、掌声 | F1-F4 |
| 感谢类 | 金币声、礼花、魔法音 | F5-F8 |
| PK类 | 战鼓、倒计时、警报 | Q-W-E-R |
| 搞笑类 | 乌鸦叫、尴尬、打脸 | A-S-D-F |
| 氛围类 | 暧昧、悬疑、温馨 | Z-X-C-V |

#### 3.2 音乐播放列表
- BGM列表：开场音乐、暖场音乐、PK音乐、下播音乐
- 支持网易云/QQ音乐链接嵌入
- 音量独立控制

#### 3.3 特效音联动
- 可设置「收到火箭」自动播放特定音效
- 可设置「进入直播间」播放欢迎音

---

### 模块4：弹幕助手 📱
**功能**：更方便的弹幕管理

#### 4.1 弹幕展示
- 弹幕滚动显示（比手机更大更清晰）
- 高亮显示：
  - 高等级用户弹幕
  - 包含关键词的弹幕（如"守护"、"加油"）
  - 送礼弹幕特殊标记

#### 4.2 弹幕统计
- 今日弹幕总数
- 活跃粉丝排行（发言最多的人）
- 关键词云（粉丝最关注什么）

#### 4.3 快捷回复
- 点击弹幕 → 快速生成回复话术
- 支持@用户快捷回复

---

### 模块5：直播日程规划 📅
**功能**：提前规划，直播不慌乱

#### 5.1 直播计划表
```
📅 今日直播计划（19:00-23:00）
├── 19:00-19:30  开场暖场 + 今日主题介绍
├── 19:30-20:00  聊天互动 + 问答环节
├── 20:00-20:30  🎯 PK环节（目标：赢2场）
├── 20:30-21:00  才艺展示（今天跳舞）
├── 21:00-21:30  🎯 PK环节
├── 21:30-22:30  深度聊天 + 粉丝连麦
├── 22:30-23:00  感谢环节 + 下播预告
└── 23:00        准时下播
```

#### 5.2 内容准备清单
- 今日话题（提前准备3-5个）
- 今日服装/妆容准备
- 需要准备的道具
- PK对手名单（提前约好）

#### 5.3 直播目标设定
- 时长目标：4小时
- 音浪目标：50000
- 粉丝增长目标：100人
- PK胜率目标：60%

### 模块6：粉丝管理系统 👥
**功能**：记住每一个重要的人

#### 6.1 粉丝档案
| 信息项 | 说明 |
|--------|------|
| 昵称 | 抖音昵称 |
| 等级 | 粉丝团等级/亲密度 |
| 标签 | 大哥/活跃粉/潜水粉/黑粉 |
| 喜好 | 喜欢的话题/歌曲/互动方式 |
| 历史 | 第一次来的时间、送过什么礼物 |
| 备注 | 私人备注（如"喜欢被叫哥哥"） |
| 上次互动 | 上次聊天内容 |

#### 6.2 自动提醒
- 「XX已经3天没来了」提醒维护
- 「XX今天生日」提醒送祝福
- 「新守护加入」特别提醒感谢

#### 6.3 粉丝数据分析
- 贡献榜（本周/本月）
- 活跃时段分析（粉丝什么时候来看）
- 流失预警（谁好久没来了）

## 三、技术实现建议

### 3.1 技术选型
| 层级 | 推荐技术 | 说明 |
|------|----------|------|
| 前端 | React/Vue + TailwindCSS | 响应式，支持手机/平板/电脑 |
| 后端 | Node.js/Python Flask | 轻量级，个人使用 |
| 数据库 | SQLite/MongoDB | 数据量不大，够用 |
| 部署 | Vercel/腾讯云开发 | 免费或低成本 |

### 3.2 数据同步
- 本地存储：IndexedDB 离线可用
- 云端同步：可选，多设备同步数据
- 导出导入：JSON格式备份

### 3.3 抖音API对接（可选进阶）
- 如果有开发能力，可对接抖音开放平台
- 实现自动获取直播数据
- 自动弹幕获取和回复

## 五、界面设计建议

### 5.1 整体风格
- **深色模式**：直播环境通常较暗，深色护眼
- **大字体**：远距离也能看清
- **高对比度**：关键信息突出
- **极简设计**：直播时操作要快速

### 5.2 布局建议（电脑副屏）
```
┌─────────────────────────────────────────────────┐
```

## 七、使用流程示例

### 直播前（准备阶段）
1. 打开网站，查看今日直播计划
2. 准备话术：检查今日话题对应的话术是否齐全
3. 音效测试：测试今日要用的音效是否正常
4. 目标设定：设置今日音浪和时长目标

### 直播中（执行阶段）
1. 点击「开始直播」，计时器启动
2. 话术库悬浮窗放在抖音旁边，随时复制
3. 按环节提醒切换话术和话题
4. 记录重要粉丝信息和互动

### 直播后（复盘阶段）
1. 填写本场数据（音浪、时长、粉丝增长）
2. 记录本场表现（哪里好、哪里差）
3. 更新粉丝档案（新守护、重要互动）
4. 查看数据统计，对比目标完成情况
