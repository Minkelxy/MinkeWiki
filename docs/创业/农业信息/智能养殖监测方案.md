# 智能养殖监测方案

把 LoRa 监测技术用到**养殖业**——对应[养殖业分析](养殖业.md)的技术落地。是你 LoRa 产品化的第二个行业场景。

---

## 一、养殖监测的核心需求

| 需求 | 说明 | 对应传感器 |
|------|------|-----------|
| 环境 | 温湿度（猪/禽舍很重要） | BME280 |
| 气体 | **氨气/硫化氢**（呼吸道疾病主因） | 气体传感器 |
| 通风 | 风机联动 | 控制节点 |
| 饮水/饲料 | 用量监测（进阶） | 计量传感器 |

> 养殖卖点比种植更"硬"：**环境差 → 死亡率高 → 直接亏钱**——监测能降死亡率，客户更容易买单。

## 二、方案（复用 LoRa 技术栈）

```
LoRa 节点（温湿 + 气体）→ 网关 → ThingsBoard 看板 + 报警
```

- 节点：复用[LoRa组网实践指南](../../制作/LoRa组网实践指南.md)与[低功耗设计指南](../../制作/低功耗设计指南.md)技术
- 报警：温湿度超限、氨气超标 → 看板/短信推送（区别于种植，养殖报警更紧急）

## 三、与种植监测的差异

| 维度 | 种植 | 养殖 |
|------|------|------|
| 核心传感器 | 土壤/气象 | 温湿/氨气 |
| 卖点 | 长势/节水 | **降死亡率/防病** |
| 报警 | 预警为主 | **紧急报警** |
| 客户 | 大棚/农场 | 养殖场/合作社 |

## 四、定价与客户（参照商业方案）

- 套餐/定价参照[LoRa监测产品商业方案](../LoRa监测产品商业方案.md)：硬件 + 平台订阅 + 服务
- 客户：中大型养殖场（能报销、有痛点）、示范户
- 获客走[农业获客与销售](../农业获客与销售.md)的渠道（协会/农技站）

## 五、落地步骤

1. 先做**环境监测**（温湿 + 氨气）——需求最硬、最易切入
2. 试点 1 家养殖场，拿"氨气超标报警"的真实案例
3. 再扩展通风联动/饮水计量（进阶）

> 里程碑：1 家养殖场试点 + 一个"报警救了一棚"的案例，就是最好的销售材料。
