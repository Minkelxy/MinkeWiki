# 智能大棚监测方案

把 LoRa 监测技术用到大棚/温室——对应[大棚分析](大棚.md)与[温室监测项目](../../制作/温室监测.md)。是你 LoRa 产品化的另一个核心场景。

---

## 一、大棚监测需求

| 需求 | 说明 | 对应传感器 |
|------|------|-----------|
| 温湿度 | 大棚核心（作物生长/病害） | BME280 |
| CO2 | 光合作用关键 | MH-Z19 |
| 光照 | 补光决策 | 光照传感器 |
| 土壤 | 湿度/EC（灌溉决策） | 土壤传感器 |
| 控制 | 通风/卷帘/滴灌联动 | 控制节点 |

> 大棚是"环境敏感"场景——**温湿度一失控就减产**，监测价值直接、客户易理解。

## 二、方案（复用温室监测项目）

- 直接复用[温室监测](../../制作/温室监测.md)项目的技术栈：LoRa 节点 → 网关 → 看板
- 加**控制联动**（通风/卷帘）：阈值触发，自动开风机/卷帘（见[制作温室监测](../../制作/温室监测.md)控制节点）
- 报警：温湿度/CO2 超限 → 看板 + 推送（大棚报警比预警更紧急）

## 三、与大棚分析关联（卖点）

| 大棚场景 | 监测价值 |
|---------|---------|
| 反季节蔬菜 | 控温控湿保产量 |
| 育苗 | 精确环境减少死苗 |
| 花卉 | 光照/温控提质 |

> 结合[大棚分析](大棚.md)：银川设施农业是大场景，监测是"降本增效"的刚需。

## 四、定价与客户（参照商业方案）

- 套餐/定价参照[LoRa商业方案](../LoRa监测产品商业方案.md)：硬件 + 平台订阅 + 服务
- 客户：大棚种植户、合作社、园区（能报销、有痛点）
- 获客走[农业获客与销售](../农业获客与销售.md)

## 五、落地步骤

1. 先做**环境监测**（温湿 + CO2 + 光照），需求最硬
2. 试点 1 个大棚，拿"温湿度失控报警 + 挽回损失"的案例
3. 再加控制联动（通风/卷帘）——进阶卖点

> 里程碑：1 个大棚试点 + 一个"报警避免损失"的案例，就是最好的销售材料。
