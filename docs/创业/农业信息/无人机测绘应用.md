# 无人机测绘在农业的应用

用消费级无人机 + 全开源软件做农田数字化：测绘地块、评估长势、辅助灌溉与灾害判断。这是[创业工具与开源参考](../工具与开源参考.md)中无人机测绘方向的落地展开，可作为银川农业/设施农业的服务切入点。

---

## 一、能解决什么

| 应用 | 说明 |
|------|------|
| 地块数字化 | 正射影像、地块边界、面积测量 |
| 长势评估 | 多光谱/NDVI 判断作物健康，发现病害/缺水区域 |
| 灌溉规划 | 地形 DEM 结合土壤水分数据优化灌溉 |
| 灾害评估 | 冰雹/霜冻/涝灾后快速盘点损失 |
| 产量预估 | 结合生长模型做收获前预测 |

## 二、完整工作流

```
采集（无人机航拍）
   ↓
处理（OpenDroneMap → 正射影像/DSM/DEM）
   ↓
分析（QGIS 计算 NDVI、裁剪、制图）
   ↓
决策（结合 IoT 土壤/气象数据 → 农业建议）
   ↓
交付（报告/地图/数据平台）
```

## 三、工具链（全部开源）

| 环节 | 开源项目 | Star | 说明 |
|------|---------|------|------|
| 航拍处理 | [OpenDroneMap/ODM](https://github.com/OpenDroneMap/ODM) | 6.3k | 无人机影像生成正射影像/点云/3D 模型/DEM |
| 地理分析 | [qgis/QGIS](https://github.com/qgis/QGIS) | 14.2k | 免费 GIS：裁剪、量测、栅格计算（NDVI）、出图 |
| 数据平台 | [thingsboard/thingsboard](https://github.com/thingsboard/thingsboard) | 22.2k | IoT 数据后台，汇合土壤/气象/测绘数据 |

### NDVI 简介

归一化植被指数（Normalized Difference Vegetation Index）：

```
NDVI = (NIR - Red) / (NIR + Red)
```

- 需要**近红外 + 红光**两个波段（消费级多光谱相机或改装相机）
- 范围 -1 ~ 1：健康植被 0.5+，稀疏植被 ~0.2，水体/裸地 < 0

## 四、设备与成本

| 项目 | 方案 | 成本 |
|------|------|------|
| 无人机 | 消费级（DJI Mini 等）+ 相机 | ¥3000-8000 |
| 多光谱 | 消费级多光谱相机（红边/近红外） | ¥5000-15000 |
| 软件 | ODM + QGIS（免费） | ¥0 |
| 云服务器 | 处理大项目时可租 GPU 云 | 按需 |

> 入门：普通可见光相机先跑通 ODM → QGIS 出图，再上多光谱做 NDVI。

## 五、服务清单（银川落地）

面向设施农业/大棚/农场，可打包为服务：

1. **测绘服务**：地块边界、面积、正射图 → 按亩收费
2. **长势报告**：NDVI 分级图 + 问题区域标注 → 按季订阅
3. **灾情评估**：灾害后快速出图定损
4. **数据平台**：测绘 + IoT（LoRa 土壤/气象）汇总到 ThingsBoard，给客户看板

**差异化**：与[LoRa气象监测](../../制作/LoRa气象监测/目录.md)产品组合——「天上测绘 + 地面监测」一套智慧农业方案，正是[宁夏银川农业项目考察与分析](宁夏银川农业项目考察与分析.md)里强调的科技应用方向。

---

## ⚠️ 合规与注意

- 无人机飞行需遵守当地空域法规（禁飞区、限高、实名登记）
- 测绘成果涉及地块隐私，服务协议中明确数据使用边界
- 多光谱 NDVI 需按作物校准，别只看单张绝对值，要看**相对变化**
