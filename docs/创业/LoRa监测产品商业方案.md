# LoRa 监测产品商业方案

承接[落地优先级推荐](落地优先级推荐.md)的第一优先项，把 LoRa 气象监测从"技术方案"变成**可卖的产品**：定价、套餐、交付、获客一整套。

---

## 一、产品形态：三块收入

| 收入 | 内容 | 特点 |
|------|------|------|
| 硬件 | 节点 + 网关（卖设备） | 走量、门槛低 |
| 平台 | ThingsBoard 看板 + 数据存储（订阅） | **持续性收入**，核心 |
| 服务 | 勘测/安装/运维（按次） | 利润最高、建立关系 |

> 一句话模式：**硬件平价引流，平台订阅养家，服务赚利润。**

## 二、成本基准（来自现有预算）

- 单节点硬件 ≈ **265 元**（含传感器/控制器/LoRa/供电）
- 10 节点 + 1 网关整套 ≈ **22,150 元**（示例规模）

> 定价时把「单节点 265」当硬件成本底，加上平台/服务分摊，就是你套餐的下限。

## 三、套餐设计（推荐 3 档）

| 套餐 | 内容 | 定价思路 |
|------|------|---------|
| **基础版** | 2-3 节点 + 基础看板 + 1 年平台 | 平价引流，验证需求 |
| **标准版（主力）** | 10 节点 + 网关 + 安装 + 2 年平台订阅 | 对标 22k 成本，加利润 |
| **旗舰版** | 多节点 + 无人机测绘 + 数据平台定制 | 高端农户/园区，利润最高 |

**平台订阅**：按「节点数 + 年」计费（如 10 节点每年 ¥3000-5000），这是持续现金流。

## 四、定价原则

1. **硬件平价**：不靠硬件赚大钱，用它敲门
2. **平台订阅是主收入**：一次卖出设备，年年收订阅
3. **服务单独收费**：安装/勘测/培训按次，别打包送
4. **留降价空间**：报价先留 10-15% 折扣位，方便谈

## 五、交付流程（标准化）

```
勘测（地块/点位）→ 部署（节点+网关）→ 上线（平台看板）→ 培训 → 运维（季度巡检）
```

> 每跑完一单，把流程沉淀成模板——下一单更快、成本更低。

## 六、获客与试点

1. **先做 1-2 家种子客户**（合作社/大棚）：成本价或折扣做一单，换真实反馈和案例
2. **借力银川渠道**：农业协会、农技站、园区招商
3. **打包卖**：LoRa 监测 + 无人机测绘一起推「天上 + 地面」方案（见[无人机测绘应用](农业信息/无人机测绘应用.md)）

## 七、里程碑

| 里程碑 | 内容 |
|--------|------|
| M1（2-3 周） | 做出**可演示的 Demo**（节点 + 网关 + ThingsBoard 看板） |
| M2（1-2 月） | 接 1-2 家试点，跑通交付流程 |
| M3（3 月） | 沉淀标准套餐 + 报价单，可对外报价 |
