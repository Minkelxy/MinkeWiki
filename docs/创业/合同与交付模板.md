# 合同与交付模板

签单和交付的**标准化模板**——每单都按流程走，别靠口头约定。承接[农业获客与销售](农业获客与销售.md)的销售流程。

---

## 一、合同要点清单（别只有口头）

| 项 | 必须写清 |
|----|---------|
| 服务范围 | 含哪些硬件、平台订阅几年、含不含测绘 |
| 费用 | 总价、付款节点（定金/验收/质保金） |
| 工期 | 交付时间、延期责任 |
| 质保 | 硬件质保期、平台服务期 |
| 违约 | 双方违约怎么处理 |

> 原则：**先小人后君子**——把最坏情况写进合同，双方都安心。

## 二、报价单模板

| 项目 | 说明 | 数量 | 单价 | 小计 |
|------|------|------|------|------|
| LoRa 监测节点 | 硬件+传感器 | 10 | ¥265 | ¥2650 |
| 网关 | 含软件配置 | 1 | ¥1500 | ¥1500 |
| 平台订阅 | 年费 | 2 年 | ¥4000 | ¥8000 |
| 安装调试 | 一次性 | 1 | ¥2000 | ¥2000 |
| **合计** | | | | ¥14150 |
| 折扣 | -10% | | | -¥1415 |
| **应收** | | | | ¥12735 |

> 分项列清，客户看得明白，你也有调整空间（见[财务与定价模型](财务与定价模型.md)的折扣位）。

## 三、交付验收清单（交付时逐项打勾签字）

- [ ] 硬件：节点/网关安装到位、通电正常
- [ ] 平台：看板可见数据、告警生效
- [ ] 培训：客户会用 App/看板
- [ ] 文档：交付说明（IP/账号/使用）
- [ ] 验收签字（客户确认）

> **验收签字是关键**——没签字别算交付完，后面扯皮有依据。

## 四、售后与回访

- 交付后 1 周回访一次（确认正常）
- **季度回访**：顺带卖运维/升级/续约（见[财务](财务与定价模型.md)的续费率）
- 客户报修有记录（微信群/工单），别口头

## 五、合规注意

- **发票**：能开票更专业（个体户/公司资质），提前问清客户要什么票
- 合同留档（纸质/电子都行），别事后找不到
- 涉及地块数据的使用边界在合同里写清（见[无人机测绘服务方案](无人机测绘服务方案.md)合规）
