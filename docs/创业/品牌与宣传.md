# 品牌与宣传

创业怎么"被看见"——命名、宣传材料、线上线下渠道。承接[农业获客与销售](农业获客与销售.md)与[合同与交付模板](合同与交付模板.md)。

---

## 一、品牌基础（别过度包装）

| 项 | 建议 |
|----|------|
| 命名 | 简单好记、跟行业沾边（如"XX智慧农业"），别起太玄的名字 |
| 一句话介绍 | **10 秒讲清**："我们做农业环境监测，帮大棚降损增产" |
| Logo/视觉 | 能省就省，先别花大钱设计——**案例和口碑 > Logo** |

> 创业初期品牌 = **能讲清楚你干什么 + 有案例**，不是包装。

## 二、宣传材料（准备一套）

- **一页简介**：服务内容 + 三档套餐 + 联系方式（见[商业方案](LoRa监测产品商业方案.md)）
- **案例集**：每个试点做一页"背景-方案-效果"（**案例是最强广告**）
- 微信/名片：随时能发的电子版一页简介

## 三、线上渠道

| 渠道 | 用法 |
|------|------|
| 公众号/视频号 | 定期发案例、监测小知识，攒信任 |
| 抖音/B站 | 发大棚/养殖监测实拍，比文字直观 |
| 农业群/朋友圈 | 本地农业社群，案例直接发 |

> 内容原则：**发客户看得懂的价值**（"这个大棚报警救了番茄"），别发技术自嗨。

## 四、线下渠道

- 农业展会/交流会：一次见多个潜在客户
- 农技站/协会：借渠道背书（见[农业获客与销售](农业获客与销售.md)）
- 熟人转介绍：满意客户是最大渠道

## 五、冷启动宣传

1. **案例先行**：先做 1-2 个试点，把案例材料做出来再谈宣传
2. **定期更新**：每周发 1 条内容（案例/知识），别断更
3. **本地聚焦**：先在银川本地圈子打响，别一开始就铺全国
