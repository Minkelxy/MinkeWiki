# 财务与定价模型

把[LoRa商业方案](LoRa监测产品商业方案.md)和[测绘服务方案](无人机测绘服务方案.md)的定价落到**具体数字**：成本结构、毛利、回本周期。核心逻辑：**硬件平价引流，订阅养家，服务赚利润。**

---

## 一、成本结构

| 成本项 | 参考 | 来源 |
|--------|------|------|
| 硬件成本 | 单节点 ≈ 265 元、10 节点+网关 ≈ 22k | LoRa 项目预算 |
| 平台/服务器 | 自建（NAS 已有）≈ 低；云平台另算 | [网络与存储规划](../小屋装修/网络与存储规划.md) |
| 人工/交付 | 勘测、安装、培训按次算 | [交付流程](LoRa监测产品商业方案.md) |

> 创业初期最大成本是**自己的时间**——平台自建、软件免费，能把启动成本压到最低。

## 二、定价与毛利（三档套餐估算）

| 套餐 | 定价参考 | 直接成本占比 | 毛利 |
|------|---------|------------|------|
| 基础版（2-3 节点） | ¥2000-3000 | 硬件 265×3 ≈ 800 | 60-70% |
| 标准版（10 节点） | ¥25000-30000 | 硬件 22k | 20-30%（硬件占大头） |
| 旗舰版（+测绘定制） | ¥50000+ | 硬件 + 服务 | 30-40% |

> 标准版毛利看着低，但**卖点是平台订阅和服务**——把后续收入算进去就高了（见下）。

## 三、订阅收入模型（核心）

| 项 | 说明 |
|----|------|
| 平台订阅 | 10 节点每年 ¥3000-5000，**持续现金流** |
| 客户生命周期价值 | 硬件一次性 + 订阅多年：一个客户 3 年 = 硬件 + ¥9k-15k 订阅 |
| 毛利率 | 订阅基本无成本，毛利 90%+——**这才是真正赚钱的部分** |

> 一句话：**硬件单子赚不赚不关键，关键是签下来的订阅**。N 个客户 × 年订阅 = 稳定收入。

## 四、回本周期

```
投入（硬件 + 启动成本）÷ 月订阅收入 = 回本月数
```

示例：自建平台 + 10 节点样板（22k），谈下 2 个标准版客户（各 2.5 万）：
- 首单收入 5 万 > 样板投入 2.2 万 → **一个订单回本 + 余钱**
- 之后每单毛利 + 订阅都是净增长

> 农业项目回款慢，**先收硬件定金、订阅按年付**，别做纯垫资生意。

## 五、财务检查清单（每季度过一遍）

- [ ] 每单：直接成本 < 收入的 60%？（硬件单）或更低
- [ ] 订阅续费率如何？客户第二年还续吗
- [ ] 回款周期是否太长（>3 个月就要收紧付款条款）
- [ ] 硬件压货了多少资金？够现金流吗
- [ ] 时间成本：花的时间能不能覆盖收入（别做"倒贴时间"的单）
