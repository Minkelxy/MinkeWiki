# 农业获客与销售

银川农业市场的**客户怎么找、单怎么签**。承接[落地优先级推荐](落地优先级推荐.md)与两个商业方案（[LoRa](LoRa监测产品商业方案.md)、[测绘](无人机测绘服务方案.md)），本文讲销售端怎么落地。

---

## 一、目标客户画像

| 客户 | 痛点 | 我们能给 |
|------|------|---------|
| 大棚/温室农场 | 看不到棚内环境、靠经验 | LoRa 监测 + 看板 |
| 合作社/农业园区 | 地块多、管理粗 | 测绘 + 数据平台 |
| 农技站/示范户 | 要做示范、报数据 | 免费试点 + 案例 |

> 一句话：**卖给"能报销、能示范、有痛点"的人**——优先合作社、园区、示范户，别啃散户。

## 二、获客渠道（按有效度排序）

1. **熟人/协会介绍**：银川农业圈小，一个案例能传开（成本最低、信任最高）
2. **农技站/政府对接**：示范项目常走农技站，挂了名就有后续
3. **农业展会/交流**：一次性见多个潜在客户
4. **试点换案例**：免费/低价做 1-2 单，拿到案例和照片再去谈下一单

## 三、销售流程（先给价值，再谈钱）

```
需求挖掘 → 现场看 → 给方案/报价 → 小试点 → 正式签约
```

- **需求挖掘**：先问客户"现在怎么管、最烦什么"，别急着报方案
- **现场看**：实地看地块/棚，方案才靠谱（也建立信任）
- **小试点**：先上 1-2 个节点跑一周，客户看见数据比说一万句有用
- 签约时把**服务边界写清**（含不含测绘、几年订阅）

## 四、报价与谈判

- 用[商业方案](LoRa监测产品商业方案.md)的 3 档套餐，**先报标准版、留旗舰版升级空间**
- 报价留 10-15% 折扣位（客户砍价时退）
- **别一上来就降价**：先加服务（送一次测绘报告），再谈价

## 五、交付闭环（让客户转介绍）

- 交付后**主动要案例授权**（拍照/数据做宣传材料）
- 季度回访（顺带卖运维/升级）
- 满意客户是**最大的渠道**——农业圈子转介绍率极高
