# 农业信息化项目的政府采购与招投标入门

承接[农业获客与销售](农业获客与销售.md)里"农技站/政府对接"这一步——你的目标客户（合作社、农业园区、农技站、示范户）**大量用财政性资金**（农业补贴、示范项目、园区基建），用财政资金采购就要走政府采购程序。本文讲清：**采购怎么发生、你作为小供应商怎么参与、报价怎么定、红线别踩什么**。

> 核心判断：**先问清资金来源**——财政补助走政采流程，合作社自筹可以直接谈。别一上来就以为都要投标。

---

## 一、先判断：这是"政府采购"吗

| 资金来源 | 是否政府采购 | 流程 |
|---------|-------------|------|
| 财政性资金（补贴/示范/园区基建） | **是**，按金额和品类走对应方式 | 公告→响应→评审→签约 |
| 合作社/民营园区自筹 | 一般不是 | 直接谈合同（见[合同与交付模板](合同与交付模板.md)） |
| 财政补贴 + 自筹混合 | 视补贴占比/用途 | 通常仍要走程序，问清楚 |

> 一个单子省不了多少流程成本，**报错流程才是大坑**（该走政采没走，后期验收/审计可能被卡）。

## 二、采购方式（知道够用即可，不用精通）

| 方式 | 适用情况 | 你的角色 |
|------|---------|---------|
| **公开招标** | 金额较大（限额以当地/当年财政规定为准） | 投标准备重，大单才碰 |
| **竞争性谈判** | 金额中等、技术需求明确、符合 74 号令情形 | ⭐ 常遇到，谈价格谈方案 |
| **询价** | 金额小、货物标准化（设备类） | ⭐ 最常遇到，报一次价 |
| **竞争性磋商** | 服务类/方案类（测绘、平台建设） | ⭐ 你的测绘/平台业务多走这个 |
| 单一来源 | 只有一家能做 / 紧急 | 少见，别指望 |

> 小供应商**最常碰的是询价、竞争性谈判、竞争性磋商**——公开招标门槛高，先不深耕。

## 三、你作为供应商怎么参与（流程六步）

1. **看公告**：[中国政府采购网](https://www.ccgp.gov.cn/)（ccgp.gov.cn，官方）及**宁夏分网**/本地媒体，搜关键词"农业 + 监测 / 测绘 / 信息化"
2. **自查资格**：营业执照经营范围、纳税/社保记录、信用记录（无失信）、近年同类业绩
3. **报名获取采购文件**：按公告要求提交报名材料，拿到技术参数/评分办法
4. **写响应文件**：商务 + 技术 + 报价三部分，**逐条响应技术参数**（不响应=废标）
5. **评审**：公开招标公开开标；谈判/磋商有谈判过程（可谈价格和方案）
6. **成交 → 签约 → 履约 → 验收付款**：走[合同与交付模板](合同与交付模板.md)，验收单留痕

> 政采项目常见要求**同类业绩**——这就是你的[品牌与宣传](品牌与宣传.md)案例集派上用场的地方。

## 四、报价注意（别报亏，也别报飞）

- **评标不只看最低价**：综合评分 = 技术分 + 商务分 + 价格分，价格分通常占 **30%-50%**
- 报价覆盖：**设备 + 安装 + 培训 + 一年运维**分列；订阅类（平台）单独写周期，别一次性贱卖
- 留意**履约保证金**（中标后交，通常 ≤ 合同额 10%）和**付款节点**（验收后付，账期可能长——结合[财务与定价模型](财务与定价模型.md)的现金流注意）
- 留**报价弹性**：谈判/磋商可以再谈价，首轮报价别把底价亮光

## 五、资质与材料（提前备好，别临阵找）

- 营业执照、开户、税务信息（一般纳税人/小规模）
- 信用报告：信用中国、政府采购严重违法失信名单自查
- **同类业绩合同 1-2 份**（案例页即可）
- 加分项：软件著作权/专利、产品检测报告（如有）

> 材料平时整理成一套，公告出来 3 天内能投——**错过公告期 = 白准备**。

## 六、合规红线（小供应商最容易踩）

- ❌ 围标/串标（找朋友陪标）——政采打击重点，查出来记入黑名单
- ❌ 挂靠资质、响应文件造假
- ❌ 保证金/款项走私人账户
- ✅ 合同、交付、验收**全程留痕**（见[合同与交付模板](合同与交付模板.md)）

## 七、本轮项目推荐：做一份「政府采购应答包」

**推荐做什么**：把 LoRa 监测 + 无人机测绘服务整理成一份**可复用的政采应答包**——一页技术方案（产品参数表）、商务响应模板、报价结构表（设备/安装/运维分列）、业绩案例页。公告一出现，改改报价就能投。

**为什么值得做**：
- 你的目标客户大量用财政资金，**政采是绕不开的渠道**——不备好材料，公告来了也赶不上；
- 这是对你现有[商业方案](LoRa监测产品商业方案.md)、[产品化路线](LoRa监测产品化路线.md)、[案例集](品牌与宣传.md)的**"投标版"整合**，一次整理、反复复用；
- 和[农业获客与销售](农业获客与销售.md)形成"**直接谈 + 投标**"两条腿，冷启动更快。

**具体怎么做**：
1. 从商业方案抽产品参数 → 做一页技术响应表（逐条对应常见采购参数）
2. 报价结构：设备/安装/培训/运维分列，留 2-3 档金额位
3. 业绩页：用案例集模板整理 1-2 个案例（含数据/照片）
4. 订阅宁夏政采分网/关键词提醒（农业+监测/测绘）

**产出**：一份可复用的「政采应答包」（4 份文档）+ 采购公告订阅提醒 → 下次公告直接套用，也是向机构客户展示专业度的敲门砖。
