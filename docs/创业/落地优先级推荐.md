## 二、推荐优先级（分 3 档）

### 🥇 第一优先级：LoRa 监测产品化（硬件 + 平台）

**为什么排第一**：
- 技术最成熟——方案、选型、成本都齐了
- 差异化最强——本地硬件 + 数据平台，竞争对手少
- 银川农业场景直接对口（大棚/温室/果园）

**怎么落地**：
1. 硬件：LoRa 节点 + 网关（现有方案）
2. 平台：接 ThingsBoard 做设备管理 + 数据看板（见[工具与开源参考](工具与开源参考.md)）
3. 收入：**硬件 + 平台订阅 + 安装服务**三块

**目标客户**：银川农业合作社、大棚农场、农业园区。

### 🥈 第二优先级：无人机测绘服务

**为什么排第二**：
- 成本低——消费级无人机 + 免费软件即可开工
- 一次投入可**反复卖**（测绘/长势/灾损服务）

**怎么落地**：测绘 → NDVI 报告 → 数据平台（可与 LoRa 监测打包卖「天上 + 地面」方案）。

### 🥉 第三优先级：直播辅助工具

**为什么排第三**：
- 面向主播、市场大但**竞争激烈**
- 建议**先自用打磨**，验证有需求后再产品化，别一上来就做面向大众的产品

---

## 三、冷启动建议（先验证再投入）

1. **接 1-2 个种子客户**：免费/低价先做一单监测或测绘，验证付费意愿，拿到真实反馈
2. **借力银川圈子**：农业协会、合作社、农技站是现成渠道
3. **先做「服务」再上「产品」**：测绘/安装这种服务启动快，跑通了再沉淀成标准化产品
4. **基建同步**：NAS/服务器搭好后，数据平台才有家（见[网络与存储规划](../小屋装修/网络与存储规划.md)）

## 四、风险与前提（提前想清楚）

| 项 | 说明 |
|----|------|
| 场地 | 需要放服务器/NAS 的地方（装修清单已排） |
| 测绘合规 | 无人机空域、实名登记、测绘数据使用边界 |
| 客户周期 | 农业项目回款慢，先做现金流的轻服务 |
| 精力 | 建议主攻一条，别三条同时铺 |
