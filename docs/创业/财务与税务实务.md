# 小生意财务与税务实务（个人创业的账和税）

[财务与定价模型](财务与定价模型.md)讲"定价和毛利"，本文讲**"开张做生意的现实"**——注册形式、记账、开票、报税、现金流。核心一句：**别把生意做成"账一团糟 + 税没报"**，早期用最简办法合规。

> 你卖的是硬件 + 订阅 + 服务，不是自己一个"技术人员接单"——**越早把账和税理清，后面做大越顺**。

---

## 一、先定注册形式（个体户 vs 公司）

| 形式 | 特点 | 适用 |
|------|------|------|
| **个体工商户** | 注册简单、成本低、无限责任 | 起步 / 试水 |
| **有限责任公司** | 有限责任、规范、可开专票 | 有企业客户合同 / 想做大 |

> 判断：**先个体户起步**，接公司客户要开专票、或开始签政采合同时再升级公司（见[政府采购与招投标入门](政府采购与招投标入门.md)）。别一上来就注册公司。

## 二、记账（最简方案）

- 小生意记账**三件**：收入、支出、应收应付（谁欠我 / 我欠谁）
- 一张表格 / 记账 App 就够，**别上 ERP**
- 关键：**每笔都记、按月对账**，别攒半年再补
- 每月看一眼**现金流**（结合[财务与定价模型](财务与定价模型.md)的回款注意）

## 三、开票与税务（别踩雷）

- 小规模纳税人开票 / 税率简化；接企业客户常要**普票 / 专票**
- 报税周期：**以当年政策为准**，小规模多为按季申报——**逾期有罚款，别漏**
- 免税 / 优惠政策会变，**别听口口相传**，按当年规定办
- 个体户报**经营所得**个税；公司报增值税 + 所得税
- 早期建议：用**代账**（几百元/月）省心，或学自助申报

> ⚠️ 本文只讲"该管哪些事"的方向，**具体税率 / 免税额度 / 申报期限以税务机关当年度规定为准**——动手前查最新政策。

## 四、工商与合规底线

- **注册**：营业执照（市场监督管理局），核名、定经营范围
- **年度报告（年报）**：每年报一次，**逾期进异常名录**（影响后续贷款 / 投标）
- 用[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)（官方）自查信用状态
- 合同 / 交付**留痕**（见[合同与交付模板](合同与交付模板.md)），验收单签字

## 五、现金流（小生意的生死线）

- 政采 / 农业项目账期长 → **别接纯垫资单**（见[财务与定价模型](财务与定价模型.md)）
- **先收定金、按节点收款、订阅按年付**（见[客户成功与续费运营](客户成功与续费运营.md)）
- 预留 **3-6 个月运营现金**，别把流水当利润

---

## 六、本轮项目推荐：做「开店账本 + 合规日历」

**推荐做什么**：建一个最简单的**生意账本**（收入 / 支出 / 应收应付三列 + 每月对账），配一张**"合规日历"**（报税、年报、客户续费提醒）——一张表管账，一张日历管合规和现金流。

**为什么值得做**：
- 个体户起步最容易"账乱税漏"——**记账 + 合规日历是最低合规成本**；
- 和[客户成功续费日历](客户成功与续费运营.md)合并成一张**经营日历**，账期 / 续费 / 报税一眼看清；
- **账清楚了，[财务定价模型](财务与定价模型.md)的检查清单才有数据可查**。

**具体怎么做**：
1. 建账本表：日期 / 收入 / 支出 / 类型 / 应收应付
2. 每月末对账一次，对现金流
3. 做合规日历：报税（按季）、年报（每年）、客户续费（提前 30 天）

**产出**：一个生意账本 + 一张合规现金流日历 → 与财务定价模型 / 客户成功日历配套，是个体户的"**经营底盘**"。
