# LoRa气象监测节点供电方案分析

## 方案概述

### 供电方案组合
采用 **太阳能板 + 锂亚电池(ER) + 超级电容(SPC)** 的混合供电方案，充分发挥各组件优势，实现高效、稳定、长期的供电保障。

### 方案优势
- **太阳能板**：持续能源输入，可再生能源
- **锂亚电池(ER)**：超高能量密度，长寿命，宽温域
- **超级电容(SPC)**：高功率密度，瞬时大电流放电，长循环寿命

### 应用场景
- 户外气象监测节点
- 无人值守长期运行
- 恶劣环境（高温、低温）
- 低功耗间歇工作模式

### 工作模式

#### 1. 太阳能充足模式（白天）
- 太阳能板产生电能
- 通过MPPT充电管理给超级电容充电
- 超级电容电压上升至5.5V
- 超级电容通过LDO稳压给节点供电
- 锂亚电池处于备用状态

#### 2. 太阳能不足模式（阴天/夜晚）
- 太阳能板输出不足
- 超级电容放电给节点供电
- 当超级电容电压降至3.6V时
- 锂亚电池开始工作，通过LDO稳压给节点供电

#### 3. 瞬时大电流模式（LoRa发送）
- 节点需要瞬时大电流（100-200mA）
- 超级电容提供瞬时大电流
- 锂亚电池提供持续小电流
- 确保LoRa模块稳定发送

#### 4. 长期无光照模式（连续阴雨天）
- 太阳能板无输出
- 超级电容电量耗尽
- 锂亚电池单独供电
- 可持续供电30-60天（取决于容量）

## 充放电管理

### 充电管理芯片选择

#### 方案一：BQ25504（推荐）
- **特点**：超低功耗，MPPT充电，冷启动
- **输入电压**：0.1V - 5.5V
- **输出电压**：可调（2.5V - 5.3V）
- **静态电流**：330nA
- **充电效率**：>90%
- **价格**：约15元

#### 方案二：LTC3105
- **特点**：低电压启动，高效率
- **输入电压**：0.225V - 5V
- **输出电压**：可调（1.8V - 5V）
- **静态电流**：6µA
- **充电效率**：>85%
- **价格**：约20元

#### 方案三：CN3791
- **特点**：太阳能专用，MPPT追踪
- **输入电压**：6V - 26V
- **输出电压**：可调（4.2V - 8.4V）
- **充电电流**：2A
- **充电效率**：>95%
- **价格**：约8元

### 充电策略

#### 1. MPPT最大功率点追踪
- 实时追踪太阳能板最大功率点
- 提高太阳能利用率15-20%
- 适应光照强度变化

#### 2. 分阶段充电
- **恒流充电**：快速充电阶段
- **恒压充电**：电压稳定阶段
- **浮充充电**：维持电压阶段

#### 3. 过压保护
- 超级电容电压上限：5.5V
- 超过5.5V自动停止充电
- 防止电容过压损坏

#### 4. 欠压保护
- 超级电容电压下限：3.0V
- 低于3.0V切换至锂亚电池供电
- 防止电容深度放电

### 放电管理

#### 1. 电源切换逻辑
```c
if (solar_cap_voltage > 3.6V) {
    // 超级电容供电
    use_solar_cap();
} else if (lithium_er_voltage > 2.0V) {
    // 锂亚电池供电
    use_lithium_er();
} else {
    // 低电量告警
    low_battery_alert();
}
```

#### 2. 瞬时大电流管理
- LoRa发送前：预充电超级电容
- LoRa发送中：超级电容+锂亚电池并联供电
- LoRa发送后：超级电容快速充电

#### 3. 低功耗策略
- 休眠时：仅锂亚电池供电，超级电容待机
- 唤醒时：超级电容+锂亚电池并联供电
- 采集时：超级电容提供瞬时大电流

## 优缺点分析

### 优点

#### 1. 超长续航
- 锂亚电池寿命10-15年
- 超级电容寿命100万次
- 整体系统免维护

#### 2. 宽温域工作
- 锂亚电池：-55℃ ~ +85℃
- 超级电容：-40℃ ~ +70℃
- 适合恶劣环境

#### 3. 高可靠性
- 锂亚电池安全稳定
- 超级电容无记忆效应
- 系统冗余设计

#### 4. 瞬时大电流
- 超级电容提供瞬时大电流
- 支持LoRa模块稳定发送
- 避免电压跌落

#### 5. 高效率
- MPPT充电管理
- 超级电容充放电效率>95%
- 太阳能利用率高

### 缺点

#### 1. 成本较高
- 锂亚电池价格较高
- 超级电容价格较高
- 整体成本比传统方案高75%

#### 2. 体积较大
- 锂亚电池体积较大
- 超级电容体积较大
- 需要更大的安装空间

#### 3. 设计复杂
- 需要充放电管理电路
- 需要电源切换逻辑
- 需要保护电路

#### 4. 锂亚电池不可充电
- 锂亚电池为一次电池
- 不能重复充电使用
- 需要定期更换（10-15年）

### 软件设计

#### 电源管理算法
```c
void power_management_task() {
    // 读取电压
    float solar_cap_voltage = read_solar_cap_voltage();
    float lithium_er_voltage = read_lithium_er_voltage();
    
    // 电源切换逻辑
    if (solar_cap_voltage > 3.6V) {
        // 超级电容供电
        switch_to_solar_cap();
        log_power_source("Solar Cap");
    } else if (lithium_er_voltage > 2.0V) {
        // 锂亚电池供电
        switch_to_lithium_er();
        log_power_source("Lithium ER");
    } else {
        // 低电量告警
        low_battery_alert();
        enter_deep_sleep();
    }
    
    // LoRa发送前预充电
    if (lora_send_pending) {
        precharge_solar_cap();
    }
}
```

#### 低功耗策略
1. **休眠策略**：深度休眠，定时唤醒
2. **任务调度**：合并任务，减少唤醒次数
3. **传感器管理**：按需供电传感器
4. **LoRa优化**：合并数据包，减少发送次数

- **高温测试**：+85℃连续运行24小时
