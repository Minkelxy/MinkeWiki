# 无人机测绘服务方案

把无人机测绘（[技术路线见这里](农业信息/无人机测绘应用.md)）做成**可售的服务**：服务包、定价、交付一整套。对应[落地优先级推荐](落地优先级推荐.md)的第二优先项。

---

## 一、服务形态（三块）

| 服务 | 内容 | 特点 |
|------|------|------|
| 测绘出图 | 地块正射图、边界、面积 | 单次、引流、好理解 |
| 长势监测 | NDVI 分级图 + 问题区域标注 | **订阅制**，持续现金流 |
| 灾损评估 | 灾害后快速出图定损 | 应急、按次、可高价 |

> 模式：**单次测绘敲门，长势监测订阅养家，灾损评估应急赚钱。**

## 二、服务包设计（推荐 3 档）

| 服务包 | 内容 | 定价思路 |
|--------|------|---------|
| **单次测绘** | 1 次航拍 + 正射图 + 面积/边界 | 平价引流（按亩） |
| **长势监测季包** | 一季 3-4 次 NDVI 报告 + 问题标注 | **主力**，按季订阅 |
| **灾损应急** | 灾害后 48h 内出图定损 | 按次高价 |

## 三、定价原则

- **按亩 + 按次 + 按季** 组合，别一口价
- 成本参考：无人机折旧 + 自己工时（软件 ODM/QGIS 免费，见[工具参考](工具与开源参考.md)）
- 单次测绘价格压住做引流，利润靠季包和应急

## 四、交付流程（标准化）

```
需求确认 → 飞行计划（合规检查）→ 航拍采集
→ ODM 处理 → QGIS/NDVI 分析 → 报告交付 → 回访续约
```

> 每跑一单沉淀一个模板（飞行航线、报告格式），下一单更快、成本更低。

## 五、合规要点（必看）

- **空域**：禁飞区/限高/实名登记，飞行前查当地规定
- **数据隐私**：地块影像涉及农户信息，服务协议写明用途边界（见[无人机测绘应用](农业信息/无人机测绘应用.md)）
- 建议先用**自己/熟人地块**试飞积累案例，再对外

## 六、与 LoRa 联动：打包卖「天上 + 地面」

| 方案 | 内容 |
|------|------|
| 测绘 + 监测打包 | 无人机测长势 + LoRa 节点测土壤/气象，一套看板 |
| 对农户 | "您地块长势哪弱、土壤怎么样" 一份报告说清 |
| 差异化 | 竞争对手要么只有测绘、要么只有传感器，你俩都有 |

> 打包是**差异化**的关键——见[LoRa监测产品商业方案](LoRa监测产品商业方案.md)的旗舰版。

## 七、里程碑

| 里程碑 | 内容 |
|--------|------|
| M1（1-2 周） | 自己/熟人地块试飞，跑通 ODM+QGIS 出图 |
| M2（1 月） | 接 1-2 单免费/低价测绘，换案例与反馈 |
| M3（2-3 月） | 沉淀服务包 + 报价单，配合 LoRa 打包对外 |
