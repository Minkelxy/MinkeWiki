# 负载率监测软件

系统负载率实时监测工具（CPU / 内存 / 磁盘 / 网络），对应[项目排期建议](项目排期建议.md)里推荐的「本月可开工」项目。

---

## 📋 项目概述

### 项目目标
- 实时监测系统负载率（CPU、内存、磁盘、网络）并可视化
- 历史数据留存，支持回看与趋势
- 阈值告警（可选）
- 自用为主，后期可挂到[网络与存储规划](../小屋装修/网络与存储规划.md)的服务器/NAS 上

### 为什么推荐做这个
1. **零硬件成本**，纯软件，随时能开工
2. **练 Rust 系统编程**——读 `/proc`、文件系统、多线程，正好接上 NZM_CMD 的 Rust 功底
3. **有真实用途**：你装修后要跑 NAS/服务器，这个工具就是它们的"体检表"

---

## 🔧 技术方案

### 语言选型

| 选项 | 优点 | 缺点 |
|------|------|------|
| **Rust（推荐）** | 贴合你的功底、性能好、可编译单文件 | 开发稍慢 |
| Python | 快、生态好 | 要装解释器、占用略高 |

> 推荐 **Rust**：正好练习系统编程，产出单二进制直接部署。

### 数据采集（Linux）

| 指标 | 数据来源 | 说明 |
|------|---------|------|
| CPU 负载 | `/proc/stat` | 差分计算各核占用率 |
| 内存 | `/proc/meminfo` | 总量/可用/缓存 |
| 磁盘 | `/sys/block/*` 或 df | 使用率、IO |
| 网络 | `/proc/net/dev` | 收发速率 |

### 展示与存储

| 模块 | 方案 |
|------|------|
| 终端展示 | TUI（ratatui）实时刷新，轻量 |
| Web 面板（可选） | 简单 HTTP + 图表，浏览器看 |
| 历史存储 | JSON 落盘（或 SQLite），保留 N 天 |

### 功能清单

- ✅ 实时负载率（多核 CPU、内存、磁盘、网络速率）
- ✅ 进程 Top（按 CPU/内存排序）
- ✅ 历史曲线（当天/7 天）
- ✅ 阈值告警（如 CPU > 90% 持续 5 分钟，终端/日志提示）
- ☐ Web 面板（二期）

---

## 📅 落地步骤（约 2-3 周）

| 阶段 | 内容 |
|------|------|
| 第1周 | 读 `/proc` 采集 CPU/内存，终端打印基本数据 |
| 第2周 | 加磁盘/网络，做差分与历史存储 |
| 第3周 | 加 TUI 展示 + 告警，打包单文件 |

> 里程碑：第 2 周末能连续跑一天不崩、数据可回看，就算达标。

---

## ⚠️ 注意事项

- 采集频率别太密（1-5 秒足够），避免监测工具自己占资源
- `/proc` 字段随内核版本有差异，做好兼容处理
- 告警阈值先给默认值，允许命令行参数覆盖
