# 电子卡祖笛方案

电子乐器卡祖笛——**音乐 + 硬件的小项目**，排期建议里的兴趣向项目，也是能快速出成品的练习。

---

## 📋 项目概述

- **卡祖笛原理**：人声哼鸣 → 膜振动 → 类似鼻音的音色（不会真乐器也能玩）
- **电子版**：麦克风拾音 → 检测音高 → 合成/放大音色 → 喇叭输出
- 定位：**快速成品 + 练音高检测**，配合[MIDI音源方案](MIDI音源方案.md)复用音源技术

## 🔧 方案

```
麦克风 → ESP32（音高检测 + 音色合成）→ 功放 → 喇叭
```

| 模块 | 选型 |
|------|------|
| 拾音 | 驻极体麦克风（模块） |
| 主控 | ESP32 |
| 输出 | I2S DAC + 功放（MAX98357）+ 小喇叭 |
| 供电 | 18650 或 USB |

## 💻 实现路线（三步）

### 1. 音高检测
- **过零率/自相关**：检测哼鸣的基频 → 得到音高
- 简单起步：自相关法（时域），测准 C3-C6 就够用
- 注意：环境噪声要滤（高通/降噪）

### 2. 音色合成
- 用检测到的音高驱动**合成器引擎**（参考 [esp32_basic_synth](https://github.com/marcel-licence/esp32_basic_synth)）
- 或采样回放（见[MIDI音源方案](MIDI音源方案.md)的音色路线）

### 3. 输出
- 合成结果 I2S → DAC → 功放 → 喇叭
- 可加**效果**（混响/颤音）提升趣味

## 🔗 与 MIDI 音源的关系

- 音高检测 + 音色引擎和[MIDI音源方案](MIDI音源方案.md)是**同一套引擎**——做完卡祖笛，MIDI 音源就剩"把检测换成 MIDI 输入"
- **复用最大化**：先做卡祖笛验证音源引擎，再做 MIDI 音源省一半力

## 💰 成本与步骤

| 项 | 参考 |
|----|------|
| 成本 | ESP32 + 麦克风 + DAC/功放 + 喇叭 ≈ **¥50-80** |
| 工期 | 2-3 周业余时间 |

| 阶段 | 内容 |
|------|------|
| 第1周 | 麦克风拾音 + 音高检测（串口打印音高验证） |
| 第2周 | 音色合成 + 输出，吹出第一声 |
| 第3周 | 打磨（滤波/效果/外壳） |

> 里程碑：**第 2 周吹出能"跟调"的音**，就算成功——卡祖笛是能随身带出去的成品。

## ⚠️ 注意事项

- 音高检测对**环境噪声敏感**：在安静环境试，或加简单降噪
- 哼鸣音域窄，检测范围别设太宽（C3-C6 够）
- 喇叭音量别太猛，先小功率测试
