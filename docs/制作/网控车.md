# 网控车

网络远程控制的小车，支持网页/手机实时遥控 + 摄像头 FPV 画面。计划中的「网控车」项目的完整方案。

---

## 📋 项目概述

### 项目目标
- 通过网页/手机远程遥控小车前进、后退、转向
- 摄像头实时回传画面（FPV）
- 基于 Wi-Fi，局域网内低延迟控制
- 低成本、易复刻，为后续加传感器（GPS/避障）留扩展

### 应用场景
- 家庭娱乐、远程巡查
- 结合[定时拍照装置](定时拍照装置.md)做移动记录
- 宠物互动、农业地块巡检（后续扩展）

## 🔧 硬件方案

### 主控与摄像头

| 组件 | 选型 | 说明 |
|------|------|------|
| 主控 | ESP32（开发板） | Wi-Fi 控制核心 |
| 摄像头 | ESP32-CAM（OV2640） | 实时图传，也可直接做主控 |
| 电机驱动 | L298N / TB6612 | 双电机驱动，TB6612 效率更高、体积小 |
| 电机 | 双直流电机 + 车轮 | 两驱车架（四驱可选） |
| 供电 | 18650×2 / 锂电池 | 电机与逻辑分压 |

> 简化版：直接 **ESP32-CAM 单板** + 电机驱动 + 车架，省一块主控。

### 车架与布局

```
[ESP32-CAM] → [电机驱动 TB6612] → 左右电机
    │                │
 [电池 7.4V] ←—— 电源管理 ——→ ESP32 供电
```

## 💻 软件方案（基于开源参考）

| 开源项目 | Star | 借鉴点 |
|---------|------|--------|
| [Ezward/Esp32CameraRover2](https://github.com/Ezward/Esp32CameraRover2) | 46 | 完整的 ESP32 摄像头小车框架（遥控 + 视频 + 驱动抽象） |
| [ArminJo/ESP32-Cam-Sewer-inspection-car](https://github.com/ArminJo/ESP32-Cam-Sewer-inspection-car) | 12 | ESP32-CAM 小车 + 舵机云台，图传/遥控参考 |

### 核心功能

1. **遥控**：网页（局域网 IP）或手机，WASD/方向键 → WebSocket 指令 → 电机
2. **图传**：ESP32-CAM 输出 MJPEG 视频流，网页 `<img>` 直接显示
3. **PWM 调速**：PWM 控制电机速度（转向差速），左右轮速度差实现转弯
4. **回传状态**：电池电压、连接状态显示在网页

### 协议（简）

```
浏览器 → WebSocket JSON {cmd:"forward", speed:80} → 小车解析 → PWM 输出
浏览器 ← MJPEG 视频流（HTTP）   ← 摄像头
```

## 📅 实施计划

1. **硬件组装（1-2天）**：车架 + 电机 + 驱动 + ESP32-CAM 接线
2. **电机控制（1天）**：PWM 驱动双电机跑通前后左右
3. **图传（1-2天）**：跑通 MJPEG 视频流到网页
4. **网页遥控（2天）**：WebSocket 遥控 + 状态回显
5. **扩展（可选）**：舵机云台、避障、路径记录

---

## ⚠️ 注意事项

- 电池电压与电机驱动/逻辑电压要匹配，别让 ESP32 直接吃 7.4V
- Wi-Fi 距离有限，室内几十米内没问题；远程控制可后续接 4G/内网穿透
- MJPEG 流量较大，局域网内流畅，公网需降低分辨率/帧率
- 电机驱动要加续流二极管/电容，避免干扰 ESP32 复位
