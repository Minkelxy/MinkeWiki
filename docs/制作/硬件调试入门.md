# 硬件调试入门

电路搭好不工作怎么办——**系统排查方法**。服务你的所有硬件项目（定时拍照、网控车、MIDI 音源等）。

---

## 一、调试工具（按优先级）

| 工具 | 查什么 | 必备度 |
|------|--------|--------|
| **万用表** | 电压、通断、电流 | ⭐⭐⭐ 必须有 |
| 示波器 | 波形、时序、PWM | ⭐⭐ 有最好 |
| 逻辑分析仪 | 数字信号、协议（串口/I2C/SPI） | ⭐⭐ 调试通信 |

> **万用表**是地基——大部分硬件问题第一步都是"量电压"。

## 二、排查顺序（别乱试）

```
1. 供电 → 2. 复位/时钟 → 3. 信号 → 4. 分模块隔离
```

1. **供电**：先量各电源点电压对不对（3.3V/5V/电池），虚接/短路最常见
2. **复位/时钟**：MCU 没跑？查复位脚、时钟是否起振
3. **信号**：串口打印/示波器看关键信号，确认"跑了没"
4. **分模块隔离**：拔掉外围只留最小系统，一个个加回来——**定位到"是哪个模块"**

> 黄金法则：**一次只改一个变量**。同时动好几处，出问题没法定位。

## 三、常见问题清单

| 现象 | 可能原因 |
|------|---------|
| 完全没反应 | 供电没到 / 短路 / 方向接反 |
| 偶尔死机 | 电源纹波 / 电机干扰（缺电容） |
| 串口乱码 | 波特率不对 / 共地问题 |
| 传感器读数怪 | 电源不稳 / I2C 地址冲突 / 接线虚 |

## 四、分模块调试（先最小系统）

1. **最小系统**：MCU + 电源 + 复位，先确认能跑（LED 闪/串口打印）
2. 加一个外设测一个：电源、信号、数据逐一验证
3. 每个模块**独立测过**再联调——联调出问题，责任就清晰了

## 五、排障记录（比你想的更有用）

- 每次排障记 3 行：**现象 / 原因 / 解决**
- 三个月后你会攒出一本"自己项目的踩坑库"——比任何教程都值钱
- 也能反哺[知识库](../知识/README.md)和[项目排期建议](项目排期建议.md)的决策
