# 电源设计指南（电池供电设备的供电系统）

[低功耗设计指南](低功耗设计指南.md)讲"**怎么省电**"，本文讲"**供电系统怎么搭**"——电池 / 太阳能进来，怎么变成稳定的 3.3V / 5V 给主控和外设。跨项目通用（LoRa监测 / 移动气象站 / 定时拍照 / 网控车都是电池供电）。

> 一句话：**电源选错，后面全错**——该用 DC-DC 用了 LDO 会发热、纹波大、续航差。

---

## 一、先定供电架构

```
电池 / 太阳能 → 稳压（LDO / DC-DC）→ 3.3V 主控 + 5V 外设
```

- **输入源**：锂电池（3.7V）、太阳能 + 电池（见[LoRa供电方案分析](LoRa气象监测/供电方案分析.md)）
- **输出电压**：主控 3.3V、外设 5V（显示屏 / 舵机）
- **核心决策**：用 LDO 还是 DC-DC（第二节）

## 二、LDO vs DC-DC（核心选型）

| 项 | LDO | DC-DC |
|----|-----|-------|
| **效率** | 低压差时高（输入接近输出） | 高（尤其压差大时） |
| **纹波** | 低（干净） | 有开关噪声 |
| **成本 / 面积** | 小 | 大（电感 / 电容） |
| **适用** | 压差小、小电流（3.7→3.3） | 压差大、大电流（电池→5V / 大负载） |

> **经验**：3.7V→3.3V 小电流用 LDO；5V 供电 / 大电流用 DC-DC（升压或降压）。

## 三、布局与纹波（稳压的工程细节）

- **去耦电容**：芯片电源脚**就近放** 100nF + 10µF（见[PCB设计入门](PCB设计入门.md)）
- **DC-DC 布局**：电感 / 反馈走线短，开关节点远离敏感信号
- **纹波超标会**：ADC 读数不稳、无线模块误码（尤其 LoRa / BLE）
- **测试**：万用表量电压，示波器看纹波（见[硬件调试入门](硬件调试入门.md)）

## 四、充电与电池管理

- **锂电池充电**：充电 IC（如 TP4054），注意充电电流 / 保护
- **电池保护**：过放保护（**别放到 3.0V 以下**）、BMS
- **太阳能**：MPPT / 充电管理（见[LoRa供电方案分析](LoRa气象监测/供电方案分析.md)的组合方案）
- **电池选型**：容量 vs 尺寸（用[低功耗设计指南](低功耗设计指南.md)的续航公式算）

## 五、与低功耗 / 项目的配合

- **供电方案决定低功耗能做多好**：DC-DC 静态电流 vs LDO
- **深度睡眠时，稳压器静态电流是主要耗电**——选低静态电流的
- 对照：LoRa供电方案（太阳能 + 电池 + 超级电容）、定时拍照（18650）

---

## 六、本轮项目推荐：做「电源选型速查卡」

**推荐做什么**：做一张 **1 页「电源选型速查卡」**：LDO vs DC-DC 对比、常用芯片、去耦布局要点、电池充电 / 保护清单——每个电池项目立项先查它。

**为什么值得做**：
- **供电系统是每个电池项目的第一步**，选错（该 DC-DC 用 LDO）会发热 / 纹波 / 续航差；
- 一张卡避免反复踩坑；
- 和[无线选型速查卡](无线通信选型指南.md)、[低功耗指南](低功耗设计指南.md)配套，是"**电源三件套**"。

**具体怎么做**：
1. 填 LDO / DC-DC 对比表 + 常用芯片（3.3V LDO、升压 / 降压 DC-DC）
2. 记布局要点（去耦 / 开关节点）
3. 电池充电 / 保护清单

**产出**：1 页电源选型速查卡 → 进制作目录，每个电池项目立项第一步。
