# MIDI 音源方案

把 MIDI 指令变成**声音**的硬件音源模块，对应[项目排期建议](项目排期建议.md)的 3-4 月槽位。完成后与 `midi键盘转换`、`可扩展电子琴` 组成一条音乐硬件链。

---

## 📋 项目概述

### 项目目标
- 接收 MIDI 信号 → 解析 → 合成/回放 → 输出声音
- 先做**单音源单复音**，再扩展复音与音色
- 与[音乐栏目 MIDI 基础](../音乐/MIDI基础与电子音乐.md)衔接：理解 Note On/Off、CC、通道

### 为什么现在做
- 排期建议的 3-4 月项目（定时拍照、网控车、负载率已排完）
- 音乐链的**核心**：做完它，键盘/电子琴都能挂上发声

## 🔧 技术方案

### 架构

```
MIDI 输入（USB-MIDI / 5针DIN） → ESP32 解析
   → 音源引擎（合成或采样）
   → I2S → 功放 → 喇叭
```

### 关键选型

| 模块 | 选型 | 说明 |
|------|------|------|
| 主控 | ESP32 | 现成、性能够、Wi-Fi 可留升级 |
| MIDI 输入 | USB-MIDI 或 5针 DIN → 串口 | 参考 [esp32_usb_midi](https://github.com/marcel-licence/esp32_usb_midi) |
| 音频输出 | I2S DAC + 功放（如 MAX98357） | 一路 I2S 即出声音 |
| 音源引擎 | 采样回放 或 合成 | 见下 |

### 音色实现路线（先易后难）

| 路线 | 做法 | 难度 | 效果 |
|------|------|------|------|
| ① 采样回放 | 把音色录成 WAV，按键触发播放 | 低 | 真实、无实时合成 |
| ② 合成器 | 减法/FM 合成，实时生成 | 中 | 可编程、可做音色 |

> 推荐：**先做①采样回放**（几天就能响），再上②合成（参考 [esp32_basic_synth](https://github.com/marcel-licence/esp32_basic_synth) ★309）。

### 复音规划

- **单复音起步**：同一时刻只响一个音，最简单
- 复音 = 多个声音叠加（如 4 复音），需要分配器管理音槽——二期再做

## 📅 落地步骤（约 3-4 周）

| 阶段 | 内容 |
|------|------|
| 第1周 | ESP32 + DAC + 喇叭出声（播一段 WAV） |
| 第2周 | 接 MIDI 输入，Note On 触发对应音（单音源） |
| 第3周 | 加力度/延音，做几个采样音色 |
| 第4周 | 整合成模块，接线固定，写说明 |

> 里程碑：第 2 周末，**键盘按下去能出对应的音**，就是关键胜利。

---

## ⚠️ 注意事项

- **延迟**：USB-MIDI 走 HID 延迟低；蓝牙 MIDI 延迟高，初版别用
- **音量**：DAC 直推喇叭声音小，务必过功放
- **供电**：功放工作电流大，5V 供电要足（别和 ESP32 挤一个弱 USB 口）
- **采样格式**：WAV 16bit 44.1kHz，先录短音色（<1 秒）
