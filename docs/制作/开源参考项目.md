## 📦 环境监测类（温室监测 / 农田土壤监测 / LoRa气象监测）

### LoRa 网络与网关后端

| 开源项目 | Star | 技术栈 | 与我的项目关系 |
|---------|------|--------|--------------|
| [brocaar/chirpstack-network-server](https://github.com/brocaar/chirpstack-network-server) | 1.5k | Go | LoRaWAN 网络服务器，温室/气象监测网关的数据汇聚后端 |
| [TheThingsNetwork/lorawan-stack](https://github.com/TheThingsNetwork/lorawan-stack) | 1.2k | Go | The Things Stack，完整的开源 LoRaWAN 网络服务器（含控制台、MQTT 集成） |
| [chirpstack/chirpstack](https://github.com/chirpstack/chirpstack) | 1.1k | Rust | ChirpStack 新一代版本 |
| [gotthardp/lorawan-server](https://github.com/gotthardp/lorawan-server) | 1.0k | Erlang | 面向私有 LoRaWAN 网络的精简服务器，适合自建不依赖云 |

**借鉴点**：温室监测文档中「网关节点 → 服务器/云端」一段，可直接落地为 `LoRa网关 + ChirpStack/TheThingsStack`，Web 界面用现成控制台，省去自研协议栈。
