# 显示与UI设计指南

调试 / PCB / 低功耗 / 电机 / LoRa / 按键 / 无线选型都齐了，补**显示**这一环——你的天气时钟、定时拍照装置、网控车、可扩展电子琴都要显示，选对屏 + 驱动 + UI 一次搞定。

> 一句话：**先按需求选屏，别默认 OLED**——简单状态用 OLED/段码，复杂 UI 才上彩色 TFT。

---

## 一、先选屏（按需求）

| 屏 | 特点 | 适用 |
|----|------|------|
| **段码 LCD** | 省电、便宜、只显数字/图标 | 时钟、仪表 |
| **单色 OLED**（SSD1306） | 简单、显字符/图形、视角好 | 状态显示、菜单 |
| **单色 LCD**（1602 等） | 便宜、字符型 | 简单文本 |
| **彩色 TFT / IPS** | 色彩、可触摸 | 复杂 UI、图片 |

> 决策：**要不要彩色 / 触摸？** 简单状态 → OLED / 段码；复杂 UI → TFT。别为"好看"上彩色屏，费电又费代码。

## 二、驱动库选择（省心）

| 库 | 特点 | 适用 |
|----|------|------|
| [olikraus/u8g2](https://github.com/olikraus/u8g2) | **单色、一库支持几十种屏**、中文字体支持 | 大部分单色屏首选 |
| [adafruit/Adafruit_SSD1306](https://github.com/adafruit/Adafruit_SSD1306) | 简单上手 | SSD1306 OLED 专用 |
| [lvgl/lvgl](https://github.com/lvgl/lvgl) | **全功能 UI 控件**（按钮/列表/动画/触摸） | 彩色 / 触摸复杂 UI |

## 三、接线与通信

- **I2C**（OLED / 部分 LCD）：2 线（SDA/SCL）省引脚，注意地址（0x3C / 0x3D）
- **SPI**（TFT / LCD）：快，但引脚多（CS / DC / RES / MOSI / SCK）
- **段码屏**：串行驱动（如 HT1621），引脚最少
- **供电**：背光 / 大屏注意电流，**TFT 可能需独立电源**（见[低功耗设计指南](低功耗设计指南.md)）

## 四、中文与字体（中文项目必踩的坑）

- 单色库：中文字库占 Flash——**选小字号子集，别全量加载**
- LVGL 有字体转换工具，按需生成
- 简单 UI 建议：**图标 + 短文本**为主，少用长中文（省字库 + 排版省心）

## 五、UI 简单框架（够用）

- **状态屏**：一屏一个状态（温度 / 在线 / 错误），定时轮询切换
- **菜单屏**：上下选择 + 确认——配合按键 / 编码器（见[按键输入设计指南](按键输入设计指南.md)）
- **低功耗配合**：显示完**熄屏 / 降刷新率**，别让屏常亮（见[低功耗设计指南](低功耗设计指南.md)）

---

## 六、本轮项目推荐：做「通用显示模块」

**推荐做什么**：做一个 **ESP32 + 1.3 寸 OLED**（或小 TFT）的通用显示模块，用 U8g2 跑通中文 / 图标 / 简单菜单，输出一个可复用的**显示骨架**（初始化 / 画状态页 / 翻菜单），供定时拍照 / 网控车 / 可扩展电子琴直接套用。

**为什么值得做**：
- 你的**多个项目都要显示**（定时拍照 / 网控车 / 电子琴），做一次通用骨架 = 全部复用；
- **中文 / 菜单 / 低功耗这些坑先踩平**，项目里就不会卡显示；
- 和[按键输入测试台](按键输入设计指南.md)是一对——**输入 + 显示 = 完整交互**。

**具体怎么做**：
1. 选屏（OLED 起步）+ U8g2 驱动跑通
2. 写三个函数：初始化、画状态页（温度 / 电量）、翻菜单（配合按键）
3. 加中文字体子集 + 低功耗（空闲熄屏）

**产出**：一个可复用的显示模块 Demo + 显示骨架代码 → 直接喂定时拍照 / 网控车 / 可扩展电子琴。
