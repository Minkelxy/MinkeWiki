# LoRa气象监测项目

## 项目概述

### 项目背景
随着智慧农业的发展，对农田、温室等农业环境的实时监测需求日益增长。传统有线监测系统布线复杂、成本高、维护困难，而LoRa（Long Range）无线通信技术具有远距离、低功耗、抗干扰等优势，非常适合农业场景的大范围环境监测。

### 项目目标
- 构建基于LoRa技术的农业气象监测系统
- 实现温湿度、风速、光照、土壤等多参数实时监测
- 支持太阳能供电，实现无人值守长期运行
- 提供远程数据监控和预警功能
- 降低部署和维护成本

### 应用场景
- 农田气象监测：大范围农田的气象数据采集
- 温室环境监测：温室大棚内的环境参数监测
- 果园气象站：果园区域的微气候监测
- 畜牧环境监测：养殖场的环境质量监测
- 水利监测：灌溉区域的水位、水质监测

## 技术方案

### 通信技术
- **LoRa调制**：采用Semtech LoRa调制技术
- **频段**：470MHz（中国民用频段）
- **通信距离**：视距可达10km以上
- **数据速率**：0.3kbps - 50kbps
- **网络拓扑**：星型网络（节点-网关）

### 数据采集
- **采集频率**：可配置（5分钟-1小时）
- **数据精度**：温度±0.5℃，湿度±3%RH
- **数据存储**：本地缓存+云端存储
- **数据传输**：LoRa无线传输

### 供电方案
- **主电源**：太阳能电池板
- **储能**：锂电池（18650/26650）
- **功耗管理**：低功耗设计，休眠唤醒机制
- **续航时间**：连续阴雨天7-15天

## 硬件选型

### 监测节点硬件

#### 主控制器
- **方案一**：STM32L系列（低功耗MCU）
  - 型号：STM32L431C8T6
  - 特点：超低功耗、丰富外设、成本低
  - 功耗：运行模式100µA/MHz，休眠模式0.4µA

- **方案二**：ESP32系列（Wi-Fi+蓝牙+LoRa）
  - 型号：ESP32-S3
  - 特点：集成Wi-Fi、支持OTA升级
  - 功耗：运行模式80-240mA，休眠模式10µA

#### LoRa模块
- **方案一**：SX1278
  - 频段：410-525MHz
  - 发射功率：+20dBm
  - 接收灵敏度：-148dBm
  - 成本：约15元

- **方案二**：SX1262
  - 频段：150-960MHz
  - 发射功率：+22dBm
  - 接收灵敏度：-148dBm
  - 成本：约25元

#### 传感器模块

##### 气象传感器
- **温湿度传感器**：SHT31/SHT40
  - 温度范围：-40~125℃
  - 湿度范围：0-100%RH
  - 精度：温度±0.2℃，湿度±2%RH
  - 成本：约10元

- **风速传感器**：三杯式风速仪
  - 测量范围：0-70m/s
  - 精度：±0.3m/s
  - 成本：约50元

- **风向传感器**：风向标
  - 测量范围：0-360°
  - 精度：±3°
  - 成本：约60元

- **光照传感器**：BH1750
  - 测量范围：1-65535lx
  - 精度：±20%
  - 成本：约5元

- **雨量传感器**：翻斗式雨量计
  - 分辨率：0.2mm
  - 成本：约80元

##### 土壤传感器
- **土壤温湿度传感器**：SHT10土壤传感器
  - 温度范围：-40~80℃
  - 湿度范围：0-100%
  - 成本：约30元

- **土壤EC传感器**：电阻式EC传感器
  - 测量范围：0-10mS/cm
  - 成本：约40元

- **土壤pH传感器**：pH电极
  - 测量范围：0-14pH
  - 成本：约50元

##### 其他传感器
- **CO2传感器**：MH-Z19B
  - 测量范围：0-5000ppm
  - 精度：±50ppm
  - 成本：约40元

- **PM2.5传感器**：PMS5003
  - 测量范围：0-500µg/m³
  - 精度：±10µg/m³
  - 成本：约30元

#### 供电系统
- **太阳能电池板**：5V/2W 或 6V/5W
  - 尺寸：150mm×150mm 或 200mm×150mm
  - 成本：约20-40元

- **锂电池**：18650（3.7V/2500mAh）或 26650（3.2V/5000mAh）
  - 容量：2500mAh-5000mAh
  - 成本：约15-30元

- **充电管理**：TP4056或CN3791
  - 功能：太阳能充电、过充保护
  - 成本：约5元

- **电源管理**：LDO稳压、DC-DC转换
  - 成本：约5元

### LoRa网关硬件

#### 方案一：Raspberry Pi网关
- **主控**：Raspberry Pi 4B
- **LoRa模块**：SX1301集中器
- **天线**：470MHz高增益天线
- **外壳**：防水IP65外壳
- **成本**：约500元

#### 方案二：ESP32网关
- **主控**：ESP32-S3
- **LoRa模块**：SX1262
- **天线**：470MHz高增益天线
- **外壳**：防水IP65外壳
- **成本**：约150元

## LoRa组网方案

### 网络拓扑
```
         云端平台
             │
         网关服务器
             │
    ┌────────┴────────┐
    │   LoRa网关1     │
    │   (覆盖范围5km)  │
    └────────┬────────┘
             │
    ┌────────┼────────┐
    │        │        │
 节点1    节点2    节点3
(农田)   (温室)   (果园)
```

### 通信协议
- **LoRaWAN**：标准LoRaWAN协议
- **自定义协议**：轻量级自定义协议
- **数据格式**：JSON / 二进制
- **加密方式**：AES-128

### 网络参数
- **扩频因子**：SF7-SF12（可配置）
- **带宽**：125kHz / 250kHz
- **编码率**：4/5, 4/6, 4/7, 4/8
- **发射功率**：+14dBm ~ +20dBm

### 节点管理
- **节点注册**：节点ID、类型、位置
- **状态监控**：在线状态、信号强度、电量
- **远程配置**：采集频率、发送间隔
- **OTA升级**：固件远程升级

## 供电方案设计

### 太阳能供电系统
```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│  太阳能板   │───→│  充电管理   │───→│   锂电池     │
│  5V/2W      │    │  TP4056     │    │  3.7V/2500mAh│
└─────────────┘    └─────────────┘    └─────────────┘
                                            │
                                            ↓
                                    ┌─────────────┐
                                    │  电源管理   │
                                    │  LDO/DC-DC  │
                                    └─────────────┘
                                            │
                                            ↓
                                    ┌─────────────┐
                                    │  监测节点   │
                                    └─────────────┘
```

### 功耗分析
- **工作功耗**：50-100mA（采集+发送）
- **休眠功耗**：10-50µA
- **日均功耗**：约50mAh
- **电池容量**：2500mAh
- **理论续航**：50天（无充电）

### 低功耗策略
1. **休眠唤醒**：定时休眠，唤醒采集
2. **数据压缩**：减少传输数据量
3. **发送优化**：合并数据包发送
4. **电源管理**：按需供电传感器

## 项目优势

### 技术优势
1. **远距离通信**：LoRa技术支持10km以上通信距离
2. **低功耗设计**：太阳能供电，长期无人值守运行
3. **多节点组网**：支持数百个节点同时在线
4. **高可靠性**：抗干扰能力强，数据传输稳定
5. **灵活扩展**：可根据需求增加传感器和节点

### 成本优势
1. **部署成本低**：无需布线，安装简便
2. **维护成本低**：远程监控，减少人工巡检
3. **运营成本低**：太阳能供电，无需外接电源
4. **扩展成本低**：模块化设计，易于扩展

### 应用优势
1. **适用范围广**：农田、温室、果园等多种场景
2. **实时监测**：数据实时采集和传输
3. **智能预警**：异常数据自动告警
4. **数据分析**：历史数据分析和趋势预测
