# 低功耗设计指南

电池供电设备的低功耗方法，**跨项目通用**——定时拍照装置、移动气象站、LoRa 节点都要靠它把续航从"天"做到"月"。

---

## 一、为什么低功耗重要

你的多个项目都是电池供电、无人值守：
- [定时拍照装置](定时拍照装置.md)（太阳能/18650）
- LoRa 气象监测节点（[供电方案](../制作/LoRa气象监测/供电方案分析.md)）
- 移动气象站（便携）

> 续航不是"电池够大"，而是"**平均功耗够低**"——这是无人值守设备的核心指标。

## 二、功耗分解：先懂公式

```
平均功耗 = 工作电流 × 工作占比 + 休眠电流 × 休眠占比
```

- 工作状态电流大，但**占比小**；休眠电流小，但**占比大**
- 想省电，**两头都要压**：缩短工作时间 + 压低休眠电流

## 三、四条低功耗策略（按收益排序）

### 1. 睡眠模式（收益最大）
- 主控支持 deep sleep（如 ESP32 deep sleep 电流 10-100μA）
- 定时唤醒采集一次 → 立刻再睡

### 2. 占空比控制
- 采集频率是最大的能耗开关：5 分钟一次 vs 60 分钟一次，能耗差 12 倍
- 能降频就降频（气象监测 15-60 分钟一次足够）

### 3. 外设电源控制
- **传感器/无线模块用开关管单独供电**，不用时断电
- 很多传感器的"待机"电流也不小，物理断电最省

### 4. 电压与效率
- 3.3V 主控 + LDO 直供比升压电路省（升压有转换损耗）
- 大电流模块（LoRa 发射、相机）避开峰值叠加

## 四、具体数字示例（ESP32 类）

| 状态 | 电流 | 说明 |
|------|------|------|
| 工作（采集+发送） | 100-200mA | 每秒毫秒级 |
| 轻睡 | 1-5mA | 保留部分外设 |
| **Deep Sleep** | 10-100μA | 定时唤醒 |

**续航估算**（以 2000mAh 电池为例，每天采集 24 次、每次工作 5 秒）：

```
日耗 = 150mA × (5s × 24) + 50μA × 剩余时间 ≈ 5mAh
续航 ≈ 2000mAh / 5mAh ≈ 400 天
```

> 这是理想值，实际打 5 折也有**几个月**——远优于不休眠的几天。

## 五、实测与工具

- **万用表（μA 档）**测休眠电流、mA 档测工作电流
- **功率分析仪/电源分析工具**（有就更好，没有万用表足够）
- 分模块测：主控、传感器、无线分开测，找出"漏电大户"
- 用示波器看工作电流波形，确认没在"该睡时醒着"

## 六、注意事项

- **别只信手册电流**：实测为主（尤其劣质模组待机电流虚标）
- **唤醒后先别发数据**：等工作稳定、传感器就绪再采集，避免峰值叠加
- **低功耗 ≠ 低性能**：休眠期间要能按时唤醒（RTC 时钟校准）
- 电池电压监测 + 低电告警，别让电池过放（见[定时拍照装置](定时拍照装置.md)注意事项）
