# 按键输入设计指南

横跨你多个硬件项目的通用输入设计——hitbox、midi电子琴、摇杆控制器、midi键盘转换、可扩展电子琴、switch2模拟手柄都会用到。按键不是"接个引脚"那么简单：**怎么省引脚、怎么防误触、怎么多键不冲突**，决定项目能不能稳定跑。

> 一句话：**单按键看消抖，多按键看矩阵，旋转看编码器，省引脚看 ADC/触摸。**

---

## 一、单按键基础（先记三件事）

| 事 | 说明 |
|----|------|
| **上拉电阻** | 按键默认接 `INPUT_PULLUP`（内部上拉），按下拉低——**少焊一个电阻** |
| **消抖必做** | 机械按键按下有 **5-20ms 抖动**，不消抖会误触发（连发/跳变） |
| **读法选择** | 中断（响应快、引脚独用）vs 扫描轮询（省引脚、费一点 CPU） |

**软件消抖两招**：
- 简单：按下后 `delay(10-20ms)` 再确认——适合低频按键
- 稳健：连续 N 次采样一致才认定（不阻塞，适合游戏/乐器）

> 游戏手柄、乐器这类"手速快 + 要多键同时按"的场景，消抖更要稳，否则打游戏串键。

## 二、按键矩阵（省引脚的关键，hitbox / 电子琴必用）

**原理**：M×N 矩阵只用 **M+N 个引脚**。例如 4×4=16 键只需 8 引脚；hitbox/电子琴几十个键，矩阵是唯一现实方案。

```
逐行扫描：拉低某一行 → 逐列读 → 行列交叉即定位按键 → 下一行
```

**关键问题：按键冲突（鬼键/幽灵键）**
- 当 3 个键形成"行列矩形"同时按下，第 4 个角会被误判为按下
- 游戏/乐器要**多键同时按**（和弦、组合键），冲突必须解决

**解决**：每个键**串联二极管**（1N4148），阻止电流回流——标准做法；或改进扫描算法（做不到 100% 防）。键盘固件参考 [qmk/qmk_firmware](https://github.com/qmk/qmk_firmware)（开源键盘固件，矩阵扫描 + NKRO 多键无冲突的成熟实现）。

**实践要点**：
- 行列都接内部上拉，扫描周期 5-10ms 足够（64 键也就 16 引脚）
- 二极管方向一致（行→列），焊接时注意别混
- 矩阵 + 消抖一起做：扫描时每个键先采样确认再上报

## 三、旋转编码器（摇杆 / 音量 / 菜单选择）

**原理**：A/B 两相**正交信号**，相位差判断正反转，带定位（detent）的选菜单、无定位的调音量。

| 用途 | 建议 |
|------|------|
| 菜单/数值选择 | 带定位编码器（一格一格有手感） |
| 音量/无极调节 | 无定位编码器（连续转） |
| 确认键 | 编码器自带的下按开关（复用一路） |

**接法**：A/B 接**支持中断的引脚**，用中断读（编码器变化很快，轮询会丢步）；库用现成的：[mathertel/RotaryEncoder](https://github.com/mathertel/RotaryEncoder)（Arduino）、[LennartHennigs/ESPRotary](https://github.com/LennartHennigs/ESPRotary)（ESP32）。

## 四、ADC 按键（一根引脚读多个键）

**原理**：多个按键接不同分压电阻到**一个 ADC 引脚**，读电压值判断按了哪个。

| 优点 | 缺点 |
|------|------|
| 超省引脚（1 个 ADC 读 4-8 键） | **不能同时按**（只能单键） |
| 适合面板菜单键 | 分压精度受电阻误差影响，阈值要实测 |

> **不适合游戏/乐器**（需要同时按）——只适合"偶尔按一下"的功能键（菜单、设置）。

## 五、触摸按键（ESP32 自带，无实体键）

- ESP32 有 **电容触摸引脚**（T0-T9），手碰即触发，无需机械按键
- 适合：侦探徽章、大师剑这种"道具感"项目（没实体按键也好看）
- 注意：触摸受湿度/手指接触面积影响，**阈值要实测校准**，别用默认值

## 六、选型建议（对照你的项目）

| 项目 | 推荐输入方案 |
|------|-------------|
| hitbox / 游戏手柄 | **按键矩阵 + 二极管**（NKRO），参考 QMK |
| midi键盘转换 / 可扩展电子琴 | 按键矩阵（**多键同时按必须防冲突**），力度可后续加 |
| 摇杆控制器 | 旋转编码器，或霍尔摇杆（模拟量） |
| 侦探徽章 / 大师剑 | 触摸按键 + 轻触开关（无实体键需求） |
| switch2模拟手柄 | 按键矩阵 + 方向（见[现有方案](switch2模拟手柄方案.md)） |

## 七、本轮项目推荐：做「迷你输入测试台」

**推荐做什么**：用 ESP32 把**三类输入**——4×4 按键矩阵（带二极管防冲突）、旋转编码器、触摸按键——做到一块测试板上，配 OLED/串口实时显示输入事件，做成你的**可复用输入骨架**。

**为什么值得做**：
- 你的 hitbox、midi键盘转换、可扩展电子琴、switch2模拟手柄、侦探徽章**反复用到这三类输入**——做一次，后面所有项目直接套用；
- 顺带把**消抖阈值、扫描周期、防冲突有效性**实测出来，形成一份"输入设计参数卡"；
- 这是纯软件+简单硬件，一晚上能跑通，是投入产出比最高的通用件。

**具体怎么做**：
1. 硬件：ESP32 + 4×4 矩阵（每键串 1N4148）+ 旋转编码器 + 2 个触摸引脚
2. 固件：矩阵扫描（消抖 + 防冲突）、编码器中断读、触摸校准——统一输出一个 `InputEvent` 结构体（键值/编码器方向/触摸状态 + 时间戳）
3. 显示：OLED 或串口打印事件流
4. 实测记录：各输入延时、消抖参数、三键同按是否误触

**产出**：一个输入测试台 Demo + 一份「输入设计参数卡」（实测的消抖/扫描/防冲突数值）→ 直接喂给你的新输入类项目，也是[硬件调试入门](硬件调试入门.md)的活教材。
