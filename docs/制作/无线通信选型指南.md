# 无线通信选型指南

承接[电机驱动选型指南](电机驱动选型指南.md)的"选型"系列——你的联网项目（网控车 / switch2手柄 / 宠物直播 / LoRa监测 / 移动气象站 / 可扩展电子琴）每个都要选无线，本文给一张**按需求选型**的表。核心一句话：**别一上来就默认 Wi-Fi**——距离、速率、功耗三者不可兼得，先想清楚你要哪个。

> 通信方案决定硬件、固件、功耗全链——**选错了，等于整个架构返工**。立项第一件事就是选它。

---

## 一、先问四个问题（选型前必答）

1. **距离**：室内同屋 / 室内跨房 / 室外百米级 / 千米级？
2. **速率**：几字节状态 / 几 KB 音频 / 几 MB 视频？
3. **功耗**：电池年续航 / 几天一充 / 常供电？
4. **环境**：空旷 / 有墙有金属（穿墙）？

## 二、主流方案速查表

| 方案 | 频段 | 距离 | 速率 | 功耗 | 适合 |
|------|------|------|------|------|------|
| **Wi-Fi** | 2.4/5 GHz | 室内 50-100m | 高（几十 Mbps） | 高 | 网控车 / 摄像头 / 视频 |
| **BLE** | 2.4 GHz | 10-30m | 中（几百 Kbps） | **低** | 手柄 / 键盘 / 接手机 |
| **ESP-NOW** | 2.4 GHz | 200m+ 视距 | 中 | 低 | 点对点私有遥控 |
| **LoRa** | Sub-GHz | **1-10km** | 低（几十 Kbps） | **极低** | 农业监测 / 电池野外 |
| **4G/5G** | 蜂窝 | 广域 | 高 | 高（有资费） | 移动气象站远程 |

> 权衡铁律：**距离 ↑ / 速率 ↑ / 功耗低，三者最多取其二**。要远又要低功耗 → 牺牲速率（LoRa）；要快又要远 → 牺牲功耗（Wi-Fi/4G）。

## 三、按你的项目选（对照表）

| 项目 | 需求 | 推荐 | 理由 |
|------|------|------|------|
| 网控车 | 室内 + 控制/视频 | **Wi-Fi** | 需要速率和 IP 网络 |
| switch2模拟手柄 | 近距 + 低延迟 | **BLE** | 手柄协议标准就是 BLE |
| 宠物第一人称直播 | 视频 + 移动 | **Wi-Fi**（图传） | 速率优先 |
| LoRa气象监测 / 温室 | 室外远距 + 电池 | **LoRa** | 距离 + 低功耗（见[LoRa组网实践指南](LoRa组网实践指南.md)） |
| 移动气象站 | 户外远距 + 偶尔上报 | LoRa / 4G | 视现场覆盖，有人值守 LoRa，无覆盖 4G |
| 可扩展电子琴（MIDI） | 近距 + 低延迟 | **BLE MIDI** | 标准协议，接手机/DAW |
| 定时拍照装置 | 室内近距 | Wi-Fi / 本地存储 | 就近即可，别过度设计 |

## 四、同距离下怎么再选

| 纠结 | 决策 |
|------|------|
| **Wi-Fi vs ESP-NOW** | 要上网/连路由器 → Wi-Fi；纯设备间点对点低延迟 → ESP-NOW |
| **BLE vs 私有 2.4G** | 要接手机 / 用标准协议 → BLE；纯设备间私有 → 可自研 |
| **LoRa vs 4G** | 自己搭网关 → LoRa；要运营商覆盖 → 4G |
| **Wi-Fi 常开 vs 深度睡眠** | 电池供电 → 深度睡眠 + 定时唤醒上报，别常连 |

## 五、实操要点（各方案的坑）

- **Wi-Fi**：功耗大，电池设备别保持常连接——深度睡眠 + 定时唤醒（见[低功耗设计指南](低功耗设计指南.md)）
- **BLE**：注意广播/连接两种模式；休眠靠广播唤醒，兼容性先测
- **LoRa**：速率低只能传小数据；扩频因子 SF 越大越远但越慢——权衡见[LoRa组网实践指南](LoRa组网实践指南.md)
- **天线别忽略**：PCB 天线 vs 外置天线，**差天线毁掉整个链路预算**——选型定了也要留天线位

## 六、本轮项目推荐：做一张「无线选型速查卡」

**推荐做什么**：把第二节速查表 + 第三节项目对照整理成**一页「无线选型速查卡」**（含四个必答问题勾选模板 + 方案表 + 项目对照），放进制作目录——以后每个联网项目立项先查它，**5 分钟定方案**。

**为什么值得做**：
- 你的联网项目多且通信需求各异，一张卡避免"默认 Wi-Fi"的惯性，也避免项目做一半才换通信；
- 通信方案决定硬件/固件/功耗全链，**选型先行省整个架构返工**；
- 是[电机驱动选型指南](电机驱动选型指南.md)的姊妹篇，补全"选型"系列——一张表管所有联网项目。

**具体怎么做**：
1. 做四个问题（距离/速率/功耗/环境）的勾选模板
2. 填方案速查表 + 项目对照行（按第三节）
3. 立项时先查卡定方案，再进[项目排期建议](项目排期建议.md)

**产出**：一页「无线选型速查卡」→ 进制作目录，成为你每个联网项目的立项第一步。
