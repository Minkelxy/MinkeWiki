# PCB 设计入门

把面包板电路做成**正式 PCB** 的基础流程——稳定、小巧、可复用，服务你的硬件项目进入"成品"阶段。

---

## 一、为什么做 PCB

| 面包板 | PCB |
|--------|-----|
| 只适合原型 | **稳定可靠**（接触不良是面包板最大的坑） |
| 占空间 | 小巧、可装壳 |
| 难复用 | 可复制、可送样 |

> 判断标准：项目要**长期用 / 重复做 / 装进壳里**，就值得上 PCB。

## 二、设计流程（5 步）

```
1. 原理图 → 2. 布局 → 3. 布线 → 4. 检查 → 5. 出 Gerber 打样
```

- **原理图**：画电路逻辑（管脚、连接、电源）
- **布局**：把元件摆到板上（先想好接口/螺丝孔位置）
- **布线**：连走线
- **检查**：DRC（设计规则检查）、封装核对
- **出 Gerber**：交给工厂生产

## 三、工具（开源首选）

| 工具 | 用途 | 说明 |
|------|------|------|
| **KiCad** | 原理图 + PCB 一体 | 免费开源，教程多 |
| EasyEDA/立创EDA | 在线画 + 直接下单 | 国内方便（嘉立创） |

> 国内打样常用**嘉立创**（便宜、快），用立创EDA画图可无缝下单；KiCad 更通用。

## 四、布局布线要点（新手最容易错）

| 项 | 要点 |
|----|------|
| 电源/地 | **先走电源和地**（大面积铺地），再走信号 |
| 去耦电容 | 每个 IC 电源脚旁放 0.1µF（抑制噪声） |
| 走线宽度 | 电流越大线越宽：1A ≈ 0.5mm+（参考[电机驱动选型](电机驱动选型指南.md)） |
| 间距 | 线距别太近（能力不够先放宽），别走直角 |
| 外壳 | 螺丝孔、接插件位置先定（见[硬件调试](硬件调试入门.md)装机） |

## 五、打样

- 嘉立创等：小批量 5 片约 **¥20-50，3-5 天**（2 层板）
- 首次打样**先验证再量产**：先做 5 片测试，没问题再批量
- 记得要**钢网/贴片**选项（做 SMD 的话）

## 六、常见错误清单

| 错误 | 后果 |
|------|------|
| 封装选错（如直插 vs 贴片） | 焊不上/装不进 |
| 元件方向反 | 烧件 |
| 电源/地接反 | 短路烧板 |
| 走线太细过流 | 发热/烧线 |
| 忘放去耦电容 | 系统不稳定（偶发重启） |

> **打样前 DRC 检查 + 人眼核对封装**，能挡掉 80% 的坑。
