# 定时拍照装置

定时拍摄照片的自动化装置（time-lapse / 定时相机），用于延时摄影、植物生长记录、健身成果记录等场景。

---

## 📋 项目概述

### 项目目标
- 定时（如每 5/15/30 分钟）自动拍摄照片
- 支持延时摄影、运动触发两种模式
- 照片存储到 SD 卡，可无线上传（FTP/Web）
- 低成本、低功耗，可长时间无人值守

### 应用场景
- 健身成果照片（配合[健身栏目](../健身/README.md)的每月对比）
- 植物/温室生长记录（配合温室监测）
- 延时摄影、日出日落
- 简易安防（运动触发拍照）

---

## 🔧 硬件方案

### 主控：ESP32-CAM（¥25-35）

| 组件 | 规格 | 说明 |
|------|------|------|
| 摄像头 | OV2640，200万像素 | 标配，1600x1200 够用 |
| 存储 | microSD 卡槽 | 照片直接存卡 |
| 无线 | Wi-Fi（2.4G） | 上传照片、远程配置 |
| 闪光灯 | 板载白灯/红灯 | 夜间补光 |

### 供电

| 场景 | 方案 |
|------|------|
| 室内（健身/延时） | USB 5V 电源，可长期运行 |
| 室外（植物/温室） | 太阳能板 + 18650 锂电池 + 低功耗休眠（参考温室监测供电方案） |

| 开源项目 | Star | 借鉴点 |
|---------|------|--------|
| [robotzero1/esp32cam-timelapse](https://github.com/robotzero1/esp32cam-timelapse) | 65 | 现成的时间间隔拍摄实现（定时拍、存卡、可选上传） |
| [playfultechnology/esp32-cam](https://github.com/playfultechnology/esp32-cam) | 28 | 可定制的拍摄控制（定时/闪光/触发） |
| [pilotak/esp32-camera-ftp](https://github.com/pilotak/esp32-camera-ftp) | 21 | 拍照后 FTP 上传，适合集中归档 |

| [SciCraft9/DIY-Security-CAM](https://github.com/SciCraft9/DIY-Security-CAM) | 20 | PIR + ESP32-CAM 安防抓拍 |

**推荐起步**：直接拿 `esp32cam-timelapse` 改——它已覆盖「定时拍摄 → 存卡」核心链路，加个 FTP 上传（`esp32-camera-ftp`）就能自动归档。

### 三种工作模式

1. **定时模式**：固定间隔拍一张，适合延时摄影/植物记录
2. **运动触发**：PIR 或光流检测到变化才拍，省电省空间（安防/健身打卡）
3. **远程控制**：连 Web 页面手动拍照，或接 HA（参考[小屋装修智能家居](../小屋装修/智能家居开源参考.md)）

## 📅 实施计划

1. **硬件搭建（1-2天）**：ESP32-CAM 接 USB 供电 + 烧录 SDK
2. **核心功能（2-3天）**：跑通 `esp32cam-timelapse` 定时拍照，验证照片质量
3. **上传功能（2天）**：加 FTP 上传，自动按日期归档到服务器/NAS
4. **触发模式（2天）**：加 PIR 运动触发（可选）
5. **长期运行（1周）**：室外版加太阳能供电，压测稳定性

---

## ⚠️ 注意事项

- ESP32-CAM 功耗较高（工作 ~180mA），室外长期运行务必做休眠，否则电池撑不住
- 拍照间隔建议 ≥5 分钟，避免过热和卡写坏
- 照片按 `YYYY-MM-DD_时间.jpg` 命名，便于和健身照片索引规范统一
- 摄像头镜头可调焦，安装后先对焦再固定
