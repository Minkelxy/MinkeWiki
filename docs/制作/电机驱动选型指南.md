# 电机驱动选型指南

不同电机、不同场景怎么选驱动——**跨项目通用**，服务[网控车](网控车.md)、旋钮电机控制器、BLDC 等项目。

---

## 一、先分清电机类型

| 电机类型 | 特点 | 典型用途 |
|---------|------|---------|
| 直流有刷 | 便宜、控制简单 | 玩具车、风扇 |
| 无刷 BLDC | 效率高、需三相驱动 | 电机项目、FOC |
| 步进 | 定位准、低速有力 | 3D 打印、云台 |
| 舵机 | 角度控制 | 云台、机械臂 |

> 选驱动**先分清电机**：直流有刷用 H 桥、BLDC 用三相桥、步进用细分驱动、舵机直接 PWM。

## 二、驱动方案对应表

| 电机 | 驱动方案 | 常用芯片/模块 |
|------|---------|--------------|
| 直流有刷（小型） | H 桥 / PWM | L298N、**TB6612**（推荐小电流） |
| 直流有刷（大电流） | 大功率 H 桥 | BTN7971、DRV8871 |
| BLDC 无刷 | 三相桥 + 换相 | ESC、DRV8301 等（配合 FOC） |
| 步进 | 细分驱动器 | A4988、DRV8825、TMC2208 |
| 舵机 | 直接 PWM | 无专门驱动，接 PWM 即可 |

## 三、关键参数（选驱动必看）

1. **电压**：驱动耐压 ≥ 电机工作电压（留 20% 余量）
2. **电流**：驱动额定电流 ≥ 电机峰值电流（**建议 2-3 倍余量**——启动/堵转电流大）
3. **散热**：持续大电流要散热片/风扇，别裸奔
4. **接口**：PWM / 方向 / 使能引脚与主控匹配

## 四、场景选型示例

### 网控车（你的项目）
- 直流电机 + **TB6612**（双通道、体积小、效率高，比 L298N 更适合小电流）
- 参考[网控车方案](网控车.md)的 PWM 调速

### 旋钮电机控制器 / 电机项目
- 若用无刷：走**三相桥 + FOC**，参考[电机控制进阶路线](../知识/电机控制/进阶学习路线.md)

## 五、注意事项（电路必看）

- **续流二极管**：直流电机必须加续流（防反电动势打坏驱动）
- **滤波电容**：电源端加电解电容，吸收电机启停的电压尖峰
- **电源分开**：电机大电流与主控电源分开（或加隔离），避免电机干扰主控复位
- **先小后大**：先用小电机/低速验证接线，再上大电流
