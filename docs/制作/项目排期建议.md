# 制作项目排期建议

分析[制作目录](README.md)里 **19 个计划中项目**，按「投入产出比 + 技能串联 + 场地依赖」推荐优先级。原则：**先做有方案、能复用、成本低的**。

---

## 一、分组与推荐理由

### 🥇 第一梯队：已有方案、性价比高（本月可开工）

| 项目 | 推荐理由 |
|------|---------|
| 定时拍照装置 | 已有[完整方案](定时拍照装置.md)，能服务健身照片 + 植物/温室记录 |
| 网控车 | 已有[完整方案](网控车.md)，练 WebSocket + 图传 + 电机控制 |
| 负载率监测软件 | 纯软件零硬件成本，练系统监控（对应你熟悉的负载率方向） |

### 🥈 第二梯队：技能串联、值得做（1-2 个月）

| 项目 | 推荐理由 |
|------|---------|
| MIDI音源 → midi键盘转换 → 可扩展电子琴 | **一条音乐硬件链**：做完一个下一个省一半力，MIDI 技能互通 |
| switch2模拟手柄 | GP2040-CE 固件成熟（见[开源参考](开源参考项目.md)），硬件做好键位映射即可 |
| 移动气象站 | 复用 LoRa 气象监测全部技术，只是做小做便携 |

### 🥉 第三梯队：依赖场地/硬件投入（等条件成熟）

| 项目 | 依赖 |
|------|------|
| 温室监测 / 农田土壤监测 | 需实地部署场地（可等银川房子/农场定） |
| 宠物第一人称直播 | 硬件成本较高、要宠物配合 |
| 激光靶 | 需射击场地/空间 |

### 🎨 兴趣向：按心情做

- 侦探徽章 / 大师剑（道具制作，随缘）
- 电子卡祖笛（娱乐向）
- Windows Hello 设备（安全方向，需要指纹/摄像头模块）

### 🎮 跟随逆战项目

- 逆战地图编辑器 / 逆战CMD / 硬件宏 → 与[逆战未来](../游戏/逆战未来/逆战未来.md)项目绑定推进，别单独排期

---

## 二、推荐排期表（近 6 个月）

| 月份 | 项目 | 说明 |
|------|------|------|
| 本月 | 定时拍照装置、负载率监测软件 | 先出两个成品找手感 |
| 第2月 | 网控车 | 练遥控 + 图传 |
| 第3-4月 | MIDI 音源 → midi键盘转换 | 打通音乐硬件链 |
| 第5月 | switch2模拟手柄 | 复用手柄经验 |
| 第6月 | 移动气象站 | 复用 LoRa 技术做便携版 |

> 温室监测、宠物直播、激光靶等项目**挂起**，等银川场地/装修定了再接（见[装修执行清单](../小屋装修/装修执行清单.md)）。

---

## 三、决策原则（以后遇到新想法也用这套）

1. **有方案优先**：已有完整方案的项目排前面（方案≈一半工作量）
2. **能复用优先**：技术能复用到其他项目（LoRa、MIDI、电机控制）的优先
3. **成组做**：相关项目一起推进，技能/物料复用，避免重复踩坑
4. **硬件/场地依赖**：依赖场地或大额硬件投入的，等条件成熟再启动
