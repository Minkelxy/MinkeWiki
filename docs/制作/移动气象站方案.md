# 移动气象站方案

便携式气象监测站，对应[项目排期建议](项目排期建议.md)第 6 月槽位——**复用 LoRa 气象监测的全部技术，只是做小、做便携**。

---

## 📋 项目概述

### 项目目标
- 便携设备，采集温/湿/气压/风速并 LoRa 上报
- 可在不同地块/地点移动测量（临时部署）
- 与固定站互补：固定站长期监测，移动站灵活补点

### 为什么现在做
- 排期建议第 6 月槽位（前序：定时拍照、网控车、负载率、MIDI 音源、手柄已排）
- **技术全是现成的**：LoRa 组网 + 低功耗设计 + BME280 传感器，主要工作是"做小"

---

## 🔧 硬件方案

| 模块 | 选型 | 说明 |
|------|------|------|
| 主控 + LoRa | ESP32 + SX1278/SX1262 | 复用 LoRa 监测方案 |
| 温湿压 | BME280 | 一个芯片全搞定，低功耗 |
| 风速 | 三杯式风速计（可选） | 增加风速则加风叶+霍尔 |
| 供电 | 18650×1 或 5W 太阳能 | 见[低功耗设计指南](低功耗设计指南.md) |
| 外壳 | 防雨小盒 + 支架 | 便携、可架三脚架 |

> 传感器全用 LoRa 监测已验证的型号，**不引入新硬件风险**。

## 💻 软件方案

- 采集 → LoRa 上报 → 网关（复用 LoRa 网关/云端链路）
- **低功耗**：占空比采集（15-60 分钟一次）+ deep sleep，参考[低功耗设计指南](低功耗设计指南.md)
- 校准：气压海拔换算、风速计脉冲计数

## 📊 对比固定站（移动站的定位）

| 维度 | 固定站 | 移动站 |
|------|--------|--------|
| 部署 | 长期固定 | 临时、可迁移 |
| 场景 | 温室/地块长期监测 | 测多点、示范、临时应急 |
| 价值 | 连续数据 | **灵活补点 + 移动测量** |

> 亮点：给客户演示时，移动站可以"现场测给你看"——是很好的销售道具（配合[农业获客与销售](../创业/农业获客与销售.md)）。

## 💰 成本预算

| 配置 | 组件 | 参考价 |
|------|------|--------|
| 基础版 | ESP32-LoRa + BME280 + 18650 | ¥80-120 |
| 完整版 | 加风速计 + 太阳能 + 便携盒 | ¥150-200 |

## 📅 落地步骤（约 3-4 周）

| 阶段 | 内容 |
|------|------|
| 第1周 | BME280 采集 + 屏幕/串口显示 |
| 第2周 | LoRa 上报到现有网关，数据入库 |
| 第3周 | 低功耗：deep sleep + 占空比，续航实测 |
| 第4周 | 外壳 + 支架，野外试运行 |

> 里程碑：第 2 周末**移动站数据进到现有看板**，就是复用成功的证明。

## ⚠️ 注意事项

- 户外外壳**防水 + 通风**：传感器要通风、电路要防水（分室设计）
- 太阳能 + 低功耗配合，别做一半功耗超标（参考[低功耗设计指南](低功耗设计指南.md)实测方法）
- 移动站便携是卖点，重量控制在 1kg 内更好
