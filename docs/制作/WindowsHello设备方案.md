# Windows Hello 设备方案

兼容 Windows Hello 的**认证设备**——计划中项目，先做 USB 安全密钥（FIDO2），进阶再做生物识别。

---

## 📋 项目概述

- **Windows Hello**：微软生物识别/安全密钥登录
- **本项目方向**：USB 安全密钥（FIDO2/WebAuthn），插上即可解锁
- 进阶：加指纹/摄像头做生物识别

## 🔐 FIDO2 基础（先懂协议）

| 概念 | 说明 |
|------|------|
| WebAuthn | 网页身份认证标准 |
| FIDO2 | 安全密钥协议（含 CTAP2） |
| 注册 | 设备生成密钥对，公钥给服务端 |
| 断言 | 登录时设备签名验证 |

> 本质：**密钥对存在设备里**，登录用私钥签名——比密码安全（不怕泄露）。

## 🔧 硬件方案

| 模块 | 选型 |
|------|------|
| 主控 | ESP32-S3（原生 USB，可做 HID） |
| USB | HID 模式（CTAP 走 HID） |
| 安全存储 | 密钥存 MCU 安全区（或加安全芯片） |
| 按键 | 确认键（按一下才签名） |
| 可选 | 指纹模块（进阶） |

> 参考：FIDO2 安全密钥是成熟品类，协议有标准实现可参考（开源 CTAP 库）。

## 💻 实现路线

1. **HID 枚举**：ESP32-S3 枚举成 FIDO HID 设备（参考[硬件宏设计](../游戏/硬件宏设计.md)的 HID 思路）
2. **CTAP 协议**：实现注册/断言流程（开源 CTAP 库起步）
3. **密钥管理**：生成/存/读密钥对
4. **登录打通**：Windows Hello 认到设备，按一下解锁

## 📅 落地步骤（约 3-4 周）

| 阶段 | 内容 |
|------|------|
| 第1周 | 熟悉 FIDO2/WebAuthn + 开源实现 |
| 第2周 | ESP32-S3 枚举 HID + CTAP 注册流程 |
| 第3周 | 断言/登录打通 |
| 第4周 | 加确认键 + 稳定性测试 |

> 里程碑：**Windows 能认到设备、按一下能解锁**，就是成功。

## ⚠️ 注意事项

- **安全是重点**：密钥私钥别明文存，用 MCU 安全存储；确认键必做（防静默签名）
- 先做注册/登录通，再谈指纹等生物识别
- 协议成熟，**优先复用开源实现**，别从零造协议
