# LoRa 组网实践指南

LoRa **节点 → 网关**组网的实操要点，跨项目通用（移动气象站、温室监测、LoRa 气象监测都用）。配套[LoRa气象监测](../制作/LoRa气象监测/目录.md)的组网方案。

---

## 一、组网基本概念

| 概念 | 说明 |
|------|------|
| 拓扑 | **星型**：节点直连网关（最常见），中继扩展距离 |
| 频段 | 中国民用 470-510MHz；模块如 SX1278/SX1262 |
| 扩频因子 SF | SF7-SF12：SF 越大距离越远、速率越低 |
| 带宽/编码率 | 影响速率与抗干扰，一般默认即可 |

> 组网三要素：**频段对上、SF 匹配、信道不撞**——全配对才能通。

## 二、节点配置（发送侧）

- **发送频率/周期**：占空比采集（见[低功耗设计指南](低功耗设计指南.md)），别高频狂发
- **发射功率**：默认最大（如 +20dBm），距离不够再调
- **入网/鉴权**：私有协议可做简单地址+密钥，防串扰
- **失败重传**：发送失败缓存本地，下次补发（见[低功耗](低功耗设计指南.md)与温室监测的数据缓存）

## 三、网关与后端

- **网关选型**：复用 LoRa 监测方案（ESP32 + LoRa + WiFi/以太网）
- **数据链路**：网关收节点数据 → 转 TCP/MQTT → 服务器（可接 ThingsBoard，见[工具参考](../创业/工具与开源参考.md)）
- 网关本身要**稳定 + 断电自启**（无人值守）

## 四、距离与干扰

| 项 | 要点 |
|----|------|
| 距离估算 | 开阔地 2-5km；**有墙体/植被打 3-5 折** |
| 天线 | 天线位置越高越好，别贴着金属/地面 |
| 干扰 | 同频段设备会抢信道；**换信道/SF** 是首选 |
| 丢包排查 | 先看 RSSI/SNR（信号强度），再看发送是否撞信道 |

## 五、测试方法（场测步骤）

1. **点对点先通**：1 个节点 + 网关，近距离（10m）确认收发
2. **逐步拉远**：50m → 500m → 2km，记录每段 RSSI
3. **加干扰测试**：打开别的设备，确认不会掉线
4. **连续跑 24-48h**：确认不重启、不丢包（见[低功耗](低功耗设计指南.md)实测）

> 里程碑：**1 节点 2km 场测稳定 + 24h 不掉线**，才算组网过关。
