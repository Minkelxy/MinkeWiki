# 农田土壤监测气象站

基于太阳能供电的农田环境监测系统，实时采集温度、湿度、风速等农业气象数据。

---

## 项目概述

本项目旨在为农田提供一个低功耗、免维护的环境监测解决方案，通过太阳能供电实现长期无人值守运行，帮助农户实时掌握农田环境状况，为科学种植提供数据支持。

## 核心功能

### 🌡️ 环境监测

| 传感器类型 | 型号推荐 | 监测参数 | 采样频率 |
|-----------|----------|----------|----------|
| 空气温度 | DHT22 | -40°C ~ +80°C | 每10秒 |
| 空气湿度 | DHT22 | 0% ~ 100% RH | 每10秒 |
| 土壤湿度 | Capacitive Soil Sensor | 0% ~ 100% | 每30秒 |
| 土壤温度 | DS18B20 | -55°C ~ +125°C | 每30秒 |
| 风速 | Anemometer | 0 ~ 30 m/s | 每5秒 |
| 风向 | Wind Vane | 0° ~ 360° | 每5秒 |
| 光照强度 | BH1750 | 0 ~ 65535 lx | 每60秒 |
| 降雨量 | Rain Gauge | 0 ~ 999.9 mm | 实时 |

### 🔋 电源管理

**太阳能供电系统**：

| 组件 | 规格 | 说明 |
|------|------|------|
| 太阳能板 | 10W ~ 20W 单晶硅 | 户外防水，IP65等级 |
| 锂电池 | 18650 × 4 (并联) | 12V 10000mAh |
| 充电管理 | TP4056 + 保护板 | 过充过放保护 |
| DC-DC转换器 | LM2596 | 5V/3.3V稳压输出 |
| 低功耗模式 | 深度睡眠 | 待机电流 < 10μA |

**供电策略**：
- 白天：太阳能板供电 + 电池充电
- 夜间：电池供电
- 低电量：进入低功耗模式，降低采样频率
- 极低电量：仅保留RTC，系统休眠

### 📡 数据通信

**通信方案**：

| 方案 | 优势 | 适用场景 |
|------|------|----------|
| WiFi | 传输快、成本低 | 有网络覆盖区域 |
| LoRa | 远距离、低功耗 | 无网络覆盖、偏远农田 |
| NB-IoT | 广覆盖、低功耗 | 农村地区 |
| 4G Cat.1 | 高可靠性 | 商业化部署 |

**数据传输**：
- MQTT 协议上报数据
- 本地SD卡备份（断网保护）
- 数据压缩传输（节省流量）
- 断点续传机制

### 🖥️ 数据平台

**云端服务**：
- 实时数据可视化仪表盘
- 历史数据查询与导出
- 异常告警推送（微信/短信）
- 数据分析与预测

**本地显示**：
- OLED 0.96寸显示屏
- 实时显示当前环境参数
- 电池电量指示
- WiFi连接状态

## 软件设计

### 主控程序架构

```c
├── main.c                 // 主程序入口
├── sensors/
│   ├── dht22.c           // 温湿度传感器
│   ├── soil_sensor.c      // 土壤传感器
│   ├── wind_speed.c       // 风速传感器
│   └── bh1750.c          // 光照传感器
├── power/
│   ├── solar_monitor.c    // 太阳能监控
│   ├── battery_check.c    // 电池检测
│   └── power_save.c       // 低功耗管理
├── communication/
│   ├── wifi_manager.c     // WiFi连接管理
│   ├── mqtt_client.c      // MQTT客户端
│   └── lora_driver.c     // LoRa驱动
├── storage/
│   ├── sd_card.c         // SD卡读写
│   └── data_buffer.c     // 数据缓存
└── ui/
    ├── oled_display.c     // OLED显示
    └── button_handler.c   // 按键处理
```

### 工作流程

```
1. 系统启动
   └─> 初始化硬件
   └─> 连接WiFi/LoRa
   └─> 显示欢迎界面

2. 主循环
   └─> 读取传感器数据
   └─> 数据处理与校准
   └─> 本地存储（SD卡）
   └─> 远程上传（MQTT）
   └─> 更新显示
   └─> 检测电池电量
   └─> 低功耗决策

3. 异常处理
   └─> 传感器故障告警
   └─> 通信中断重连
   └─> 低电量保护
```

### 低功耗策略

| 场景 | 动作 | 电流消耗 |
|------|------|----------|
| 正常工作 | 全传感器采样 + WiFi上传 | ~150mA |
| 夜间模式 | 降低采样频率 | ~80mA |
| 低电量 | 仅保留RTC | ~10μA |
| 深度休眠 | 完全休眠 | ~5μA |

## 安装部署

### 站点选择

- 地势平坦，无遮挡
- 太阳能板朝南，倾斜角30°~45°
- 避开高大建筑物和树木
- 传感器安装高度：温湿度1.5m，风速3m

### 防护措施

- IP65防水外壳
- 传感器防雷击保护
- 电池过充过放保护
- 定期清洁太阳能板
