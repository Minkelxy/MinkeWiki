## 🎞️ 如何新增视频（本站约定）

1. 在 B 站上传后拿到 **BV 号**（如 `BV1xx411c7mD`）
2. 在本文件对应分类下加一行
3. 需要在文档里**内嵌播放**时，用以下 HTML 模板（MkDocs 已开启 `md_in_html`，可直接渲染）：

```html
<iframe src="https://player.bilibili.com/player.html?bvid=BV号&page=1&high_quality=1"
        scrolling="no" border="0" frameborder="no" framespacing="0"
        allowfullscreen="true" style="width:100%;aspect-ratio:16/9"></iframe>
```

> 想让某篇文档里直接出现播放器，把这段 `<iframe>` 粘进对应文档即可。
