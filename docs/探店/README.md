# 探店与游玩记录

记录去过的景点、游乐项目和店铺，把当时的体验、花费与值得注意的细节留下来，方便以后回看，也方便规划下一次出行。

## 使用方式

- 每个地点单独记录，按实际体验补充内容。
- 建议至少填写体验日期、同行人员、花费和一句话印象。
- 照片可以放在对应文档的「照片记录」部分，或补充图片说明。
- 新地点直接沿用现有模板，并在 `mkdocs.yml` 的「探店与游玩」栏目登记。
