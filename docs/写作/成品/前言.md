# 前言

　　5月初开始主动社交，说到底是对未来的恐慌。我其实很少感到孤独，只有回忆过去和展望未来的时候才会压抑。两个月下来，事情没超出预料。我一开始就不觉得这类计划会有什么好结果——但做起来，多少能安心一点。

　　然后这周，这两天，完全陷进去了。

　　偶然（也不太偶然）尝试了攀岩。岩馆的大哥大姐人挺好，聊天让压力缓解了很多，后来自然而然地加了微信。这之后，岩馆成了每次回来必去的地方：一开始匆匆来匆匆走，后面待的时间越来越长。我没有刻意安排，但至少不用在银川的街头乱撞了。大哥的建议毫无营养，大姐的倒是值得思考——说我确实不知道自己在干什么，也多少带点受虐倾向。

　　周末再去，不知道触发了什么机制，他们开始给我更多建议。姐姐介绍了她妹妹。我怕得要死——这是真正的陌生人，不像网上认识的那种没什么压力。拿到微信后犹豫了很久才决定试试。毕竟是第一个熟人介绍的人。姐姐说得没错：不要一上来就往对象方向想，先交朋友，别把目的写在脸上。

　　但我其实还有疑问——我既不知道自己为什么要找对象，也不知道为什么要交朋友。

　　第一天的聊天不温不火。我喜欢给人贴标签，这次手里的"人类"标签自然而然地贴了上去。我觉得这是一个伟大的胜利，但紧接着开始担忧：会不会太激进了？要不要收着点？

　　第二天果然被顾虑束缚，选择了不主动。但我已经在开心地和朋友分享这件事了。晚上整理这一天的感受，愈发觉得和她聊天舒服——我不确定是她在向下兼容，还是她的社交能力已经足以把我包围。她罕见地对 AI 兴趣很大，想也是，在校生用 AI 比外面的人熟练得多。这正好是我的日常，扩展话题没什么困难，也不需要迎合。

　　其实到这个时候我已经感觉到了——遇到了一个不一样的人。我说她健康、自信、积极向上，聊天的时候能感觉到心跳。上班时也抽空聊，不聊的时候在想象和计划。后来我意识到，这种程度的刻意已经在踩雷区了。分不清热情和冒犯的边界，那就尽量别胡乱扩展话题。

　　我们继续聊着。其实也没聊多少，但她在我眼里愈发闪耀，我也愈发恐慌。怕她不属于我，怕收好人卡，怕当个陌生人。我反感天命论，但这个时刻有点迷信了：感觉这就是我的天命。不能再畏畏缩缩了，患得患失只会失去一切，想得越多越不能做自己。

　　然后做了一个梦。

　　又是过去的事，像在提醒我还会重蹈覆辙。不过这次，我不会那么脆弱和敏感了。"死缠烂打"不太中听，我以前从没这么想过，现在已经管不住这念头了。思考走得太远，该行动了。

　　想太多不一定是坏事，当然也不一定是好事。好处是能考虑到实际情况，坏处是想更多不切实际的——感情迅速升温的画面，一起生活的场景，对别人来说可能很雷吧。另一些走向相反的极端：感情迅速破裂，互相欺骗，还有韩剧里那种狗血剧情。说到底我根本没正常谈过恋爱，想象只能从有限的小说和影视剧里拼凑，拼凑出狗血也正常。

　　纷乱的思考是灾难的开始。限制它的办法就一个：记录和计划。记录，是写下实际发生的事，也包括脑中所想，确保自己不偏离；计划，是约束行为、预估方向。两件事绑在一起，才能表现得像个正常人。

　　既然是长期的事，就必须做好长期准备。记录自己，是为了日后回忆有材料。
