# MkDocs 技术文档库建设

把之前散落在 Word、PDF、Confluence 里的技术文档整理到了一个 MkDocs 站点里。

## 为什么要做

之前的技术笔记要么在 Confluence 上（离职就没了），要么在聊天记录里（找起来费劲），要么在脑子里（最不可靠）。用 Markdown + Git 管理之后：

- 版本可控，修改有记录
- 本地离线可查
- GitHub Pages 一键部署
- Markdown 写起来比 Word 快

## 当前规模

接近 90 篇文档，覆盖：

- **制作项目**（28 个硬件/软件项目）
- **知识库**（AUTOSAR / 电机控制 / 芯片驱动 / RTOS / 软件测试等）
- **创业研究**（宁夏农业信息、抖音直播）
- **健身**（训练计划、数据追踪）
- **社交**（工程化社交管理）

## 后续计划

- 持续把 Confluence 上的旧文档迁移过来
- 用 mkdocs 的 blog 插件记录项目和生活
- 探索自动化部署 CI
