# FOC 矢量控制学习之路：从六步换相到磁场定向

电机控制是嵌入式领域里软硬结合最紧密的方向之一。接手电控项目时我也是从零开始啃，这篇记录 FOC（Field-Oriented Control，磁场定向控制）的学习路径。

## 为什么需要 FOC

传统的六步换相控制（方波驱动）够简单，但存在明显问题：

- 转矩脉动大（每 60° 电角度换相一次，电流不连续）
- 低速时噪声明显
- 效率不是最优

FOC 通过坐标变换把三相交流电机等效为直流电机来控制，可以独立调节励磁电流和转矩电流。结果就是：更平滑的转矩输出、更高的效率、更好的动态响应。

## 学习路径

### 第一站：理解 BLDC 和 PMSM 的区别

很多人以为 BLDC 和 PMSM 是一回事，但严格来说：

| | BLDC | PMSM |
|------|------|------|
| 反电动势波形 | 梯形波 | 正弦波 |
| 驱动方式 | 方波（六步换相） | 正弦波（FOC/SVPWM） |
| 转矩脉动 | 较大 | 较小 |
| 控制精度 | 中等 | 高 |

实际项目中这两个概念经常混用——硬件叫 BLDC，控制却用 FOC。工程上不必太纠结名词，关键看你的电机反电动势是什么波形。

### 第二站：Clarke 和 Park 变换

这是 FOC 的数学核心。一句话概括：

- **Clarke 变换**：三相静止坐标系（a-b-c）→ 两相静止坐标系（α-β）
- **Park 变换**：两相静止坐标系（α-β）→ 两相旋转坐标系（d-q）

变换完的结果：d 轴电流对应励磁分量，q 轴电流对应转矩分量。现在你可以像控制直流电机一样单独控制这两个量了。

### 第三站：电流环、速度环、位置环

FOC 通常采用级联 PI 控制：

```
位置环（外环）→ 速度环（中环）→ 电流环（内环）
    ↓                ↓               ↓
  位置给定        速度给定       Id/Iq 电流给定
```

电流环最快（通常在 PWM 周期里执行），速度环次之，位置环最外层。

### 第四站：SVPWM

有了 d-q 轴的电压给定后，经过 Park 逆变换回到 α-β，再通过 SVPWM（空间矢量 PWM）生成六路 PWM 信号驱动逆变桥。SVPWM 比 SPWM 的母线电压利用率高约 15%。

### 第五站：弱磁控制

电机转速超过基速后，反电动势接近母线电压，没法继续升压。这时候需要加负的 d 轴电流来削弱永磁体磁场——这就是弱磁控制。代价是效率下降。

## 调试经验

1. **电流采样是基础**：采样电阻值、运放增益、ADC 参考电压一定要算准，否则后面全是错的
2. **PI 参数整定**：先调电流环（内环），再调速度环（外环）。电流环要快，速度环要稳
3. **角度估算**：无感 FOC 的角度估算（如滑模观测器、龙伯格观测器）是最大的难点，低速和高负载下的角度估算精度直接影响控制效果
