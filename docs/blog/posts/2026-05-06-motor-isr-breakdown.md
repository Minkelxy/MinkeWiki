# S32K 电机控制代码拆解：ISR 是怎样驱动电机的

之前分析了 FOC 的理论（[FOC 学习之路](./2026-05-06-foc-learning-path.md)），这篇拆一段实际代码——基于 S32K 的无感 BLDC 六步换相控制，看看各个 ISR 是怎么协同工作的。

## 整体架构

这段代码的核心是一个中断驱动的控制循环：

```
硬件事件 → ISR → 读取传感器/状态 → 计算 → 更新输出 → 等待下一个事件
```

所有控制逻辑都在中断里跑，main 函数只负责初始化然后睡觉。

## 各个 ISR 的职责

### LPIT0_Ch0：速度和电流控制回路（最核心）

这是执行频率最高的中断。每次触发做三件事：

1. **计算速度**：统计最近 6 次过零事件的 FTM0 计数器周期 → 算出当前电转速
2. **齿轮状态机**：调用 `Gear_EngageControl()` 根据当前位置和 PWM 命令决定电机状态（初始/脱开/啮合/运行/制动/自由）
3. **PI 调节**：速度 PI 控制器计算新的 PWM 占空比

理解了这个 ISR，就理解了控制的核心循环。

### LPIT0_Ch1：PWM 命令解析

读取外部 PWM 信号的高低电平持续时间，计算出 PWM 命令值。用于响应外部控制器的速度指令。

### ADC1：数据采集

每次 ADC 转换完成后触发。采集三项关键数据：
- 断开相的反电动势（BEMF）——用于过零检测
- 直流母线电流——用于电流环和过流保护
- 直流母线电压——用于电压前馈

采集完后会做低通滤波。

### FTM0 溢出/重载：换相时机

**这是六步换相的心脏。** 每次 FTM0 计数器溢出时：
1. 检测过零事件
2. 计算两次换相之间的时间 → 用于估算速度
3. 更新换相扇区（0→1→2→3→4→5→0...）
4. 更新 PWM 输出（哪相导通、哪相关断）

### PORTE：故障检测

监听 MC34GD3000 驱动芯片的故障引脚。硬件故障（短路、过流、过温）会触发此中断。

## 辅助函数链

ISR 里调用的辅助函数构成了一条处理管道：

```
速度估算 → PI 调节器 → 占空比更新
     ↓
换相执行 → BEMF 检测 → 过零判断 → 速度更新
     ↓
ADC 触发 → 采样 → 滤波 → 控制回路使用
```

几个关键函数：

- **`assignNextADCtrigger()`**：根据当前占空比计算下次 ADC 触发的延迟，确保在 PWM 脉冲中间采样（电流纹波最小）
- **`filterDCbusCur()`**：移动平均滤波直流母线电流。低占空比时忽略（噪声大），高占空比时取平均
- **`estimateSpeed()`**：基于过零检测计算转速，含插值补偿提高精度
- **`speedPIregulator()`**：速度环 PI，考虑了最大扭矩限制和电压前馈

## 无感六步换相的时序

无感 BLDC 的关键难点是过零检测的时序。电机转动的每个电周期（360°）分成 6 个扇区，每个扇区 60°。换相发生在过零事件之后的 30° 电角度——即"检测到过零 → 等待 30° → 换相 → 等 60° → 下一次过零"。
