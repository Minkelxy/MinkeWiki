# 卡牌设计器 card-designer

一个用于设计和打印自定义卡牌的 **Web 应用**。

- **仓库**：[github.com/Minkelxy/card-designer](https://github.com/Minkelxy/card-designer)
- **语言**：JavaScript（ES Modules）
- **形式**：纯前端 Web 应用，无需后端

---

## 功能特性

- **卡牌设计**：支持添加图片、文字、矩形等元素
- **卡组管理**：创建、编辑、导入、导出卡组
- **打印排版**：自动排版打印，支持 A4/A3 等多种纸张
- **导出功能**：导出为 PNG 图片或 PDF 文档
- **撤销/重做**：支持操作历史记录
- **快捷键**：丰富的快捷键支持

## 快速开始

由于使用 ES Modules，需要通过 HTTP 服务器运行：

```bash
# 方式一：Python
python -m http.server 8080

# 方式二：Node
npx serve .

# 方式三：装依赖开发
npm install
npm run dev
```

然后访问 http://localhost:8080

## 用途

- 自印桌游/卡牌
- 名卡、祝福卡、收藏卡
- 剧本杀角色卡、游戏道具卡（可与[剧本创作](../剧本/恒润疗养院.md)、[制作项目](../制作/README.md)结合）
