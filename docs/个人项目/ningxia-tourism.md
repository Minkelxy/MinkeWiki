# 宁夏旅游地图 ningxia-tourism

一款专注于宁夏回族自治区旅游景点的**交互式地图网站**——塞上江南·神奇宁夏。融合现代设计美学与地域文化特色，为游客提供直观、便捷的旅游目的地探索体验。

- **仓库**：[github.com/Minkelxy/ningxia-tourism](https://github.com/Minkelxy/ningxia-tourism)
- **语言**：TypeScript
- **文档**：项目含 PRD 与技术架构文档（`.trae/documents/` 下）

---

## 核心特性

- **交互式 SVG 地图**：基于宁夏行政区划的矢量地图，支持缩放、平移、区域高亮
- **景点标记系统**：动态图标展示景点位置，悬停放大、点击导航
- **触摸手势**：移动端双指缩放，优化触控体验
- **动态视图框**：根据缩放级别自动调整地图视野
- **多层级导航**：省 / 市 / 区县三级地图导航
- **景点详情页**：高清图库、文字介绍、实用信息、周边推荐
- **响应式设计**：桌面 / 平板 / 移动端适配

## 页面模块

| 页面 | 路由 | 功能 |
|------|------|------|
| 首页地图 | `/` | 全屏交互式地图为主体 |
| 景点详情 | `/attraction/:id` | 景点图片、介绍、实用信息 |

## 地图功能明细

| 功能 | 描述 |
|------|------|
| 省份视图 | 宁夏五个地级市全貌，省会/市政府标记 |
| 城市视图 | 放大查看单个城市，景点标记（评分 ≥4.5） |
| 区县视图 | 深入区县级行政区划 |
| 景点标记 | 动态图标 + 悬停预览 |
| 政府标记 | 省会和市政府所在地 |
| 触摸缩放 | 双指捏合缩放 |
