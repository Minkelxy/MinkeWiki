# ADC Pro Toolkit adc2amp

一个专为嵌入式系统开发者设计的 **ADC 计算工具集**，提供电流、电压和温度的快速换算功能。

- **仓库**：[github.com/Minkelxy/adc2amp](https://github.com/Minkelxy/adc2amp)
- **语言**：Rust（Edition 2021）
- **GUI**：eframe/egui 0.26

---

## 功能特性

| 功能 | 说明 |
|------|------|
| ⚡ 电流计算 | 运放电流采样换算，支持采样电阻、放大增益、偏置电压配置 |
| 🔌 电压计算 | 电阻分压网络换算，支持任意分压比配置 |
| 🔬 NTC 温度计算 | 基于 B 值法的 NTC 热敏电阻温度测量计算 |
| 双向换算 | 寄存器值与物理值相互转换 |
| 实时计算 | 输入即时显示结果，无需点击计算按钮 |
| 溢出检测 | 自动检测 ADC 饱和和溢出情况 |

## 技术栈

- **语言**：Rust (Edition 2021)
- **GUI 框架**：eframe/egui 0.26
- **图标处理**：image 0.24、winres 0.1

## 编译运行

```bash
# 前置：安装 Rust；Windows 系统（图标功能需要）
cargo build --release
cargo run
```

或直接运行编译后的可执行文件。

## 应用场景

嵌入式开发中 ADC 采样 → 物理量的换算（电流/电压/温度）是高频需求，本工具把常用换算做成桌面工具，适合配合[芯片驱动](../知识/芯片驱动/README.md)、[电机控制](../知识/电机控制/README.md)等知识库内容使用。
