# 作品发布与分享

从混音完成到**正式发布**的流程——把[编曲 Demo](音乐创作推荐路线.md) 变成能分享的成品。

---

## 一、发布前检查（混音之后）

| 项 | 检查 |
|----|------|
| 混音 | 走完[混音基础](混音基础入门.md)四步 + 单声道/手机检查 |
| 响度 | 别爆音、别太小声（参考 -14 LUFS） |
| 唱词 | 对照[词谱](词谱/传达不到的爱恋改编.md)核对歌词 |
| 信息 | 歌名、作者、封面（一张图胜过千言） |

> 发布前的"最终检查"和剧本的"修改打磨"同理——**别让明显问题暴露给听众**。

## 二、发布渠道（按目的选）

| 渠道 | 特点 | 适合 |
|------|------|------|
| 音乐平台（网易云/QQ） | 正式、可收藏 | 认真发布的成品 |
| 短视频（抖音/B站） | 流量大、反馈快 | 推广/试水 |
| 私发/朋友 | 最直接反馈 | 先给朋友听 |

> **先发朋友/小范围试水**，收到反馈再正式发布——比直接上平台更稳。

## 三、音质与格式

- **保留无损 WAV**（源文件，永远别删）
- 发布用 320kbps MP3 或平台要求的格式
- 不同平台对响度有归一化，别过度压缩

## 四、分享技巧（让作品被听完）

1. **前奏抓耳**：前 3 秒决定听众留不留——开头别太温
2. **副歌前置**：短视频/B站 先放最抓耳的副歌片段
3. **封面/标题**：一张好封面 + 简短标题，比内容更容易被点开
4. 标注"改编自《传达不到的爱恋》"（见下版权）

## 五、版权注意（改编作品尤其重要）

- **改编作品**要标注原曲信息（歌名/原唱/曲作者）——尊重原作者
- 改编的**歌词部分**是你的原创，可主张；旋律版权仍属原曲
- 商业使用（接广告/上架变现）前，确认改编授权要求
