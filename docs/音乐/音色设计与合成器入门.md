# 音色设计与合成器入门

编曲的最后一个"维度"——**音色**。[配器实战](配器实战入门.md)解决"哪一层由谁演奏"，本文解决"演奏出来像什么"。同样一段 MIDI，换一个音色就是换一种感觉，音色是电子音乐"好不好听"的大头。

> 本文是纯原理 + LMMS 实操，不依赖任何付费音源；看懂「合成器四大件」，任何合成器（软件或硬件）你都能上手。

---

## 一、先记住：合成器四大件

所有合成器（LMMS 的 tripleOscillator / ZynAddSubFX、Surge XT、甚至你硬件项目里的 esp32 synth）都是这四件组合出来的：

| 部件 | 干什么 | 比喻 | 关键参数 |
|------|--------|------|---------|
| **振荡器 Osc** | 产生原始波形（音源） | 琴弦本身 | 波形（锯齿/方波/正弦/三角）、音高、多个振荡器叠加（detune 变厚） |
| **滤波器 Filter** | 切掉部分频率 | 蒙在琴弦上的布 | 类型（低通/高通/带通）、截止频率 cutoff、共鸣 resonance |
| **包络 Envelope** | 控制每个音符的"起-落" | 弹奏的方式 | ADSR：Attack（起音）/Decay/ Sustain/ Release |
| **LFO** | 低频自动调制 | 自动晃琴的手 | 速率、目标（音高/滤波/音量）、深度 |

> 一句话记忆：**振荡器决定"什么音"，滤波器决定"亮还是闷"，包络决定"脆还是绵"，LFO 决定"会不会动"。**

## 二、ADSR：决定音色"性格"的包络

一个音符从按下到松开，音量/音色随时间变化，由 ADSR 包络控制：

```
音量
 │    A（起音）   D（衰减）      S（持续）        R（释音）
 │      /‾‾‾‾‾‾‾‾‾‾‾‾‾‾
 │     /              ‾‾‾‾‾‾‾
 │    /                        \
 │   /                          \___  ← 松键后滑落
 └──┴─────────────────────────────── 时间
```

| 参数 | 含义 | 短（快）→ 长（慢）听感 |
|------|------|----------------------|
| A（Attack） | 按下到峰值的时间 | 快速=清脆打击；慢速=软绵绵推上来 |
| D（Decay） | 峰值到持续电平的时间 | 弹一下就掉的"哒"感 |
| S（Sustain） | 按住时的电平 | 高=持续响亮；低=像拨弦 |
| R（Release） | 松键后的滑落时间 | 短=干脆；长=拖尾、氛围感 |

**经验对照**：鼓=全短；贝斯=A短+S长+R短；弦乐Pad=A和R都很长；主奏Lead=A短+R中等。

## 三、减法合成思路：从"满"到"合身"

最常用的合成法叫**减法合成**：从一个频率很丰富的波形（锯齿/方波）出发，用滤波器"减"掉不需要的部分，得到目标音色。步骤固定：

```
选波形 → 多个振荡器叠加（detune）→ 低通滤波（cutoff）→ 包络塑形 → 加LFO/效果
```

「听觉问题 → 调哪个参数」对照表：

| 你觉得… | 去调 |
|---------|------|
| 音色太刺耳 | 降低通 cutoff，或减少高次谐波（换三角波） |
| 音色太单薄 | 加第二个振荡器并 detune（稍微失谐），或升 resonance |
| 音头太硬 | 拉长 Attack，或开一点低通让"推起来" |
| 音色死板 | 加 LFO 颤音（调音高）或滤波扫频 |
| 太散、糊 | 收紧 cutoff、缩短 Release |

## 四、四个基础音色配方（LMMS 实操）

用 LMMS 的 **tripleOscillator**（三个振荡器 + 滤波 + 包络）就能调出来。以下数值是起点，按听感微调：

### 1. 贝斯 Bass（低沉、有弹性）
| 参数 | 值 |
|------|-----|
| 波形 | 锯齿波（单振荡器即可） |
| 低通 cutoff | 200-400 Hz |
| ADSR | A 快 / R 快 |
| 技巧 | 每小节跟和弦根音，别和底鼓抢 1、3 拍 |

### 2. 弦乐 Pad（绵、铺底）
| 参数 | 值 |
|------|-----|
| 波形 | 2-3 个锯齿波，互相 detune（±几个音分） |
| 低通 cutoff | 800-1200 Hz（糊就降） |
| ADSR | A 和 R 都慢（1-2 秒） |
| LFO | 给滤波 cutoff 加慢扫频，让"呼吸" |

### 3. 主奏 Lead（亮、突出）
| 参数 | 值 |
|------|-----|
| 波形 | 方波或锯齿，detune 加厚一点 |
| 低通 cutoff | 开大（3000+ Hz）保持亮度 |
| ADSR | A 快 / R 中等 |
| 技巧 | 加一个简单延迟（Delay）让它有空间感，别和旋律抢 |

### 4. 鼓点 HiHat（碎、快）
| 参数 | 值 |
|------|-----|
| 波形 | **噪声（Noise）**，不是乐音 |
| 高通滤波 | 切掉低频，只留"沙沙" |
| ADSR | 全部极短（< 50ms） |
| 技巧 | 音高略随机一点更像真踩镲 |

> 调音色的心法：**一次只动一个参数，边动边听**，别一次调三个。听不出差别就回到"听觉→参数"对照表。

## 五、合成器原理 = 你的硬件项目

制作目录的 `esp32_basic_synth` 音源，实现的就是「振荡器 → 包络 → 输出」这条链（见[MIDI基础与电子音乐](MIDI基础与电子音乐.md)）。理解四大件之后，你就能：
- 改波形表（换一种振荡器音色）
- 加一段简单的低通滤波（让音色变柔和）
- 用包络控制音量（做鼓/拨弦质感）

**软件音色调明白 = 硬件音源方案有了音色参照**，两边互相反哺。

## 六、本轮项目推荐：做「音色配方卡」小项目

**推荐做什么**：在 LMMS 里调出上述 **4 个基础音色（贝斯/Pad/Lead/HiHat）**，每个写一张**配方卡**（波形/滤波/ADSR/LFO 数值表 + 想改亮/厚/短怎么调的提示），沉淀成一个可复用的**音色库**。

**为什么值得做**：
- 音色是电子音乐"好不好听"的 60%+，而你现在缺的正是这一维——调音色的手感是练出来的，不是看会的；
- 四个基础音色是**所有编曲的起点**（[配器实战](配器实战入门.md)的四层正好每层一个），一次沉淀、永久复用；
- 直接喂给你的两个真实项目：《传达不到的爱恋》编曲 Demo（[推荐路线](音乐创作推荐路线.md)项目一）和 esp32 音源硬件方案（项目二）。

**具体怎么做**：
1. LMMS → 新建 tripleOscillator 乐器 → 按第四节配方逐项调（一次动一个参数）
2. 调好一个，**保存为音色预设**（LMMS 支持保存乐器预设）
3. 写配方卡：表格记录波形/滤波/ADSR/LFO 数值 + 一句"想更X就调Y"
4. 全部调完，录一段 4 个音色依次演奏的对比音频（每个音色弹同一小段和弦）

**产出**：4 张配方卡 + 4 个音色预设文件 + 一段 4 音色试听对比音频 → 进《传达不到的爱恋》编曲工程直接选用，也是 esp32 音源方案的音色参考清单。
