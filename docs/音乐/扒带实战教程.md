# 扒带实战教程

扒带 = 把一首歌"拆开"：听出结构、速度、调性、和弦和各声部，为[编曲 Demo](音乐创作推荐路线.md) 打底。本教程用开源工具（demucs + basic-pitch）把流程做成**可操作步骤**。

---

## 一、扒带要扒出什么

| 要素 | 用途 |
|------|------|
| 结构（主歌/副歌/桥段） | 编曲分段依据 |
| 速度 BPM、拍号 | DAW 建工程 |
| 调性（大小调） | 决定和弦走向 |
| 旋律 | 转 MIDI 后直接复用/改编 |
| 和弦走向 | 编曲和声层的基础 |

## 二、工具准备

| 工具 | 用途 | 说明 |
|------|------|------|
| [demucs](https://github.com/facebookresearch/demucs) | 分离人声/鼓/贝斯/其他 | 把混音拆成音轨 |
| [basic-pitch](https://github.com/spotify/basic-pitch) | 音频转 MIDI | 旋律/和弦转可编辑音符 |
| 播放器 + 变速/循环 | 听细节 | 慢放听低音/和弦 |

## 三、步骤

### 第 1 步：定结构与速度

- 先听全曲，记结构（Intro → 主歌 → 副歌 → 桥段 → 尾奏）
- 用节拍器对 BPM；常见流行 70-130

### 第 2 步：分离音轨

```bash
# 安装并分离
pip install demucs
demucs 原曲.mp3        # 输出 stems/原曲/{vocals,drums,bass,other}.wav
```

- 用分离出的 **drums** 对鼓点、**bass** 听低音/根音，比混在一起容易得多

### 第 3 步：定调性

- 听**最后结束的和弦/音**通常落主音；配合旋律音判断大小调
- 不确定就先用 basic-pitch 把旋律转 MIDI，数主音频次

### 第 4 步：旋律转 MIDI

```bash
pip install basic-pitch
basic-pitch 原曲.mp3 输出目录     # 生成 MIDI + 音符事件
```

- 生成的 MIDI 可能带杂音，在 DAW 里逐句清理、改错音

### 第 5 步：推和弦走向

- 听 bass 轨，根音即和弦根音；再从旋律音推大小调性质（三音是判断关键）
- 每小节记一个和弦，写成 `C - G - Am - F` 这样一张走向表

### 第 6 步：记录成果

- 把结构 + BPM + 调性 + 走向存成一页「扒带笔记」，编曲时对照

## 四、常见问题

| 问题 | 处理 |
|------|------|
| 分离效果一般 | 换 demucs 更大的模型（`-n htdemucs`）；别用太差的音源 |
| 听不清低音 | 变速到 0.5x 循环，用耳机；bass 轨单听 |
| MIDI 太多杂音 | 清掉低置信度音符，只留主旋律 |
| 和弦推不出 | 先只记**根音走向**（bass 最准），三音后补 |

## 五、推荐节奏

- 一首歌扒带 **1-2 晚**够用（不用 100% 准确）
- 重点是**结构和根音走向**——这两样够编曲起步，细节后面再补
