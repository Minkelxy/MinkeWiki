# 音乐创作推荐路线

结合你现有的基础（改编词谱《传达不到的爱恋》+ 制作栏目的 MIDI 硬件项目），推荐 **3 个值得做的项目**，按优先级排序。每个都给出：**推荐原因、目标产出、具体执行路线**。

---

## ⭐ 项目一：完成《传达不到的爱恋》完整编曲 Demo（推荐先做）

### 推荐原因
1. 你**已有改编词谱**——歌词端就绪，只差音乐端
2. 扒带→编曲工具链已成熟且**全开源免费**（见下方路线）
3. 做完得到一首可分享的成品，同时练就 MIDI/编曲技能，**反哺**制作栏目的 MIDI 硬件项目

### 目标产出
- 一首约 3 分钟的完整翻唱编曲（伴奏 + 旋律 + 基础混音），导出 WAV/MP3
- 一份可复用的词谱 PDF

### 执行路线（6 步，每步约 1-2 个晚上）

| 步骤 | 做什么 | 关键点 | 支撑工具 |
|------|--------|--------|---------|
| 1. 扒带 | 听原曲记结构（主歌/副歌/桥段）、速度 BPM、调性 | 用分离功能把伴奏和人声分开听 | [demucs](https://github.com/facebookresearch/demucs) |
| 2. 旋律转 MIDI | 把主旋律转成 MIDI，改错音、定调式 | 生成的 MIDI 在 DAW 里逐句核对 | [basic-pitch](https://github.com/spotify/basic-pitch) |
| 3. 定和弦走向 | 找每个段落的和弦进行（如 C-G-Am-F） | 从低音/根音推算，先求顺耳不求复杂 | 上一步 MIDI |
| 4. 编曲 | 按和弦搭鼓、贝斯、和弦层 | 旋律先用 MIDI 占位 | [LMMS](https://github.com/LMMS/lmms) |
| 5. 人声 | 自己录，或用合成器音色当旋律 | 录不好就用 MIDI 旋律顶替 | LMMS + 音源 |
| 6. 混音出谱 | 音量/声像/简单压缩 → 导出；同时排词谱 | 别追求完美，先出成品 | LMMS + [MuseScore](https://github.com/musescore/MuseScore) |

### 需要哪些技能（及捷径）
- **不用会弹琴**：basic-pitch 转 MIDI 就能"获得"旋律
- **和弦不懂**：用同调性常用进行起步，先求顺耳
- 乐理够用即可：音名/半音、大小调、常用和弦、BPM/拍号

## 项目二：为「MIDI音源 / 电子琴」硬件项目立技术方案

### 推荐原因
制作目录里 `midi键盘转换`、`可扩展电子琴`、`MIDI音源` 都是**计划中**，且硬件路线已在[制作项目开源参考](../制作/开源参考项目.md)验证过。先立方案，避免开工后返工。

### 推荐路线
1. **先定音源形态**：软件音源（手机/电脑 VST，零硬件成本）vs 硬件音源（ESP32 + I2S 音频 + 功放，可独立出声）。建议**先软件验证、后硬件落地**
2. **硬件参考**：用 `esp32_basic_synth`（合成器引擎）+ `esp32_usb_midi`（USB MIDI 接入）两个已验证项目组合，即可打通"MIDI 进 → 声音出"
3. **定接口与复音**：USB-MIDI 或 5 针 DIN；单复音起步，先做简单音色

### 产出
- 一份「音源模块方案」文档（输入 → 处理 → 输出），能进制作目录立项

## 项目三：沉淀「扒带-改编」方法论

### 推荐原因
项目一的流程若固化成文档，**下次改编任何歌都能直接套用**，也能分享。

### 做法
把 6 步路线 + 工具命令整理成一页「扒带改编 Checklist」，放到音乐栏目，以后每次改编按清单执行。
