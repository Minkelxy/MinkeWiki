# 混音进阶实战

[混音基础入门](混音基础入门.md)是"够用版四步"（音量/声像/EQ/压缩），本文补**实战深化**：**场景化修音、空间效果、总线处理、母带入门**——从"能听"到"能发"。承接混音基础，为[编曲 Demo](音乐创作推荐路线.md) 收尾。

> 一句话：混音基础教你"四步走"，本文教你"**听到问题 → 知道调哪里**"。

---

## 一、场景化修音（听到问题 → 调哪里）

| 症状 | 排查 / 修法 |
|------|------------|
| **人声不突出** | 中高频 2-4 kHz 轻微提升；**先查别的声部是否挤占**（让位而非硬提） |
| **底鼓没劲** | 低频 60-100 Hz 提升 + 压缩让冲击一致；检查与贝斯频段错开 |
| **整体糊** | 高通清理 40 Hz 以下无用低频；查多个声部是否挤同一频段 |
| **刺耳** | 齿音 / 高频 6-8 kHz 衰减；加一点低通让高频顺滑 |
| **响度忽大忽小** | 单轨压缩不够、或多个压缩打架 → 统一到总线压缩 |

> 原则：**先让位，再提升**——大部分问题是"挤"，不是"弱"。

## 二、空间效果（让声音有"房间"）

- **混响 Reverb**：给主旋律 / 人声加空间感（小房间 / 大厅）；别加太多变糊
- **延迟 Delay**：单音点缀 / 回声，用**节奏型延迟**（与 BPM 同步）
- **用 send（发送）轨道**：一个混响发给多个声部共用，比每个 insert 好控制
- **前后景**：混响让声部"退后"，不用混响的在前——用混响控制层次

## 三、总线处理（让整首歌"粘"起来）

- **Bus / Group**：鼓组、和声组、乐器组各归一条 bus，**先组内平衡再整体**
- **总线压缩**：整首歌挂一个轻压缩（2:1 左右），让响度起伏更一致——"粘合"的关键
- **立体声宽度**：铺底声部略窄 / 居中，点缀靠两边；**别整首太宽**（单声道兼容问题）

## 四、母带入门（发布前最后一关）

- **目的**：让整首歌响度统一、达到平台标准——**不是"再混一遍"**
- **响度**：流行歌约 **-14 LUFS**（流媒体标准），用响度表看，别到 -6 爆音
- **步骤**：总线压缩 → 立体声增强（可选）→ **限幅器（Limiter）**压到目标响度
- 导出前检查：单声道 / 手机外放 / 无削波（见[混音基础](混音基础入门.md)）

## 五、一首歌的收尾清单（实操顺序）

1. 场景化修音：逐声部"让位 + 补足"（对照第一节表格）
2. 加空间：主旋律 / 人声 send 混响，鼓加一点 room
3. 归 bus：鼓 / 和声 / 乐器分 bus，组内平衡
4. 总线压缩 + 响度到 -14 LUFS
5. 三设备检查（耳机 / 音箱 / 手机）

---

## 六、本轮项目推荐：给编曲 Demo 做「混音进阶版」

**推荐做什么**：用混音基础的四步 + 本文的进阶手法，给《传达不到的爱恋》编曲 Demo 做一版**进阶混音**——场景化修音 + send 混响 + 总线压缩 + 响度到 -14 LUFS，记录每步前后对比。

**为什么值得做**：
- 混音是[编曲 Demo](音乐创作推荐路线.md)项目一的最后一步，进阶混音让它从"能听"到"**能发**"；
- **场景化修音（听到问题→调哪里）是通用技能**，以后每首歌都用得上；
- 前后对比音频能直观看到进步，也是[作品发布与分享](作品发布与分享.md)的成品基础。

**具体怎么做**：
1. 对照第一节，修 3 个最明显的"症状"
2. 主旋律加 send 混响，鼓加一点 room
3. 归 bus + 总线轻压缩
4. 响度到 -14 LUFS，导出**基础版 vs 进阶版**对比

**产出**：进阶混音版 Demo + 前后对比音频 → 直接进作品发布，也是你混音能力的第一个完整成果。
