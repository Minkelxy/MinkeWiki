# 音阶与调式入门

**音阶**是旋律与和弦的"原料库"——懂了音阶，写旋律和配和弦都有据可依。承接[和弦理论与编配](和弦理论与编配.md)。

---

## 一、音阶是什么

- 音阶 = 一组按音高顺序排列的音
- **调** = 以哪个音为主音 + 用哪个音阶
- 流行/中国风最常用：大调、小调、五声音阶

## 二、大调音阶（最常用）

**结构：全全半全全全半**

```
C 大调：C - D - E - F - G - A - B - C
       全  全  半  全  全  全  半
```

- 大调听感：明亮、欢快、稳定
- 主音（I 级）是"家"，旋律常从/回到主音

## 三、自然小调

**结构：全半全全半全全**

```
A 小调：A - B - C - D - E - F - G - A
       全  半  全  全  半  全  全
```

- 小调听感：忧伤、内敛
- 对比：同样的音，主音不同 → 情绪完全不同

## 四、关系大小调（重要技巧）

| 关系 | 说明 |
|------|------|
| C 大调 ↔ A 小调 | **音相同**（都是 C D E F G A B），只是主音不同（C vs A） |
| 用法 | 写歌时可在大调/小调间切，音阶不用换 |

> 关系大小调 = 同一组音，换主音就换情绪——这是"大调歌突然变暗"的底层原理。

## 五、五声音阶（中国风/好写）

```
宫 商 角 徵 羽（C 大调五声）：C D E G A（去掉 F、B）
```

- 只有 5 个音，**怎么走都好听**（没有半音冲突）
- 中国风、民谣、流行旋律大量使用
- **新手写旋律首选**：用 C 大调五声，基本不会难听

## 六、怎么用（落到创作）

1. **写旋律**：主要用调内音（大调用 C D E F G A B），落点在主音
2. **配和弦**：从音阶里取和弦（见[和弦理论](和弦理论与编配.md)的级数表）
3. **换调**：把整首歌移调（如 C 大调 → G 大调），旋律级数不变
4. 五声起步：先只用 C D E G A 写，顺耳后再加半音
