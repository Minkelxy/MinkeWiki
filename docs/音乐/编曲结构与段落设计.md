# 编曲结构与段落设计（整首歌怎么排）

[配器实战入门](配器实战入门.md)讲"一个段落内怎么分层"，本文讲**"一首歌怎么排段落、能量怎么起伏"**——把流行歌的结构模板落到你的编曲 Demo。核心一句话：**结构是能量的剧本**——该松的地方松、该燃的地方燃，听着才不累。

> 常见病：四和弦循环铺满整首，听 30 秒就腻。段落结构就是治这个病的药。

---

## 一、为什么结构决定"好不好听"

| 只有配器，没有结构 | 配器 + 结构 |
|-------------------|------------|
| 一段好听，全程一个密度 | 前奏精简 → 副歌全上 → 桥回落 → 副歌再冲 |
| 30 秒后疲劳 | 每个段落"不一样"，重复也不腻 |

> 副歌配器 > 主歌配器（密度/音色/和声全拉开）——**这是"重复也不腻"的秘诀**。

## 二、流行歌标准段落模板（够用的骨架）

| 段落 | 作用 | 能量 | 配器/音色怎么变 |
|------|------|------|----------------|
| **前奏 Intro** | 定调性/氛围 | 低 | 精简，鼓晚进（如第 8 小节进） |
| **主歌 Verse** | 叙事/铺垫 | 低-中 | 分解和弦、留空隙，旋律中低音区 |
| **预副歌 Pre-Chorus** | 拉高期待 | 中 | 加节奏（踩镲/军鼓更密）、和弦收窄 |
| **副歌 Chorus** | 情绪顶点 | 高 | 全配器、柱式和弦、旋律上移高音区 |
| **间奏 Interlude** | 呼吸 | 中 | 简化，给耳朵休息 |
| **桥 Bridge** | 对比/转折 | 变化 | **换和声进行 / 换音色**，不重复前面积累 |
| **尾奏 Outro** | 收束 | 低 | 回落、减少层次、淡出 |

> 副歌前常用 **"留白一拍"**（预副歌最后）制造期待——最便宜的推进感。

## 三、能量曲线（先画出来，再写）

```
能量
 10│                          ★副歌3
   │                ★副歌1    ★副歌2
   │     ★预副歌   ↗       ↗
  5│ ★主歌   ↗            ↘ ★桥(转折)
   │★Intro     ↘ ★间奏
  0└──────────────────────────────→ 时间
```

- **画法**：每 4 小节给能量打分（1-10），把整首歌连成曲线
- **原则**：前奏低 → 副歌 1 高 → 回落 → 副歌 2 更高 → **桥最低（转折）** → 副歌 3 顶峰
- **变化不是加音量**，而是：加层数 / 加音色 / 换和声 / 旋律上移——四选一，段段不同

> 验收：闭眼听，能不能感觉到"段落边界"和"能量起伏"。感觉不到 = 结构没立起来。

## 四、段落之间的过渡（最暴露"业余"的地方）

- **鼓过门（fill）**：段尾加一小节军鼓滚奏，提示"要换了"
- 低音延迟一拍 / 和声在段末收窄（只留根音）
- 桥进副歌：换一下和声（如 `vi → IV → I → V`）再猛进副歌，反差更大
- **别每段之间都停**：间奏和桥是不同的，桥一般不停顿、直接接

## 五、套用到扒带（结构也是扒出来的）

- 扒带不只记旋律和弦，还记**段落结构 + 每段配器密度**（见[扒带实战教程](扒带实战教程.md)）
- 把你听的歌画成能量曲线，**原曲怎么排，你就怎么排**——先模仿再创新

## 六、LMMS 落地建议

- 用 **标记/颜色区分段落**（或每段一个 pattern/track），别全挤在一个 pattern 里
- 先排**骨架**（每段 4-8 小节），再填配器——骨架定结构，配器定质感
- 常见起步长度：主歌 8 小节、副歌 8 小节、前奏 4-8 小节

---

## 七、本轮项目推荐：给《传达不到的爱恋》排一张「结构×能量」图

**推荐做什么**：先扒这首歌的**段落结构**（前奏/主歌/副歌/桥/尾奏 + 每段配器密度），画成一张「结构×能量」表；再照着为你的[编曲 Demo](音乐创作推荐路线.md)排段落骨架；最后对比原曲与你的能量曲线。

**为什么值得做**：
- 编曲 Demo 最怕"四和弦循环一整首"，**段落结构是让它"像一首歌"的关键**；
- 扒结构比扒旋律简单得多（听段落边界即可），一次做两张图（原曲 + 你的）直接当编曲**施工图**；
- 是对[配器实战](配器实战入门.md)（段落内）+ [扒带](扒带实战教程.md)（听原曲）的**进阶配套**，正好补上"整首"这一层。

**具体怎么做**：
1. 听原曲，画段落表：时间戳 + 段落名 + 配器密度（几层）
2. 每 4 小节给能量打分，画能量曲线
3. 排你的编曲骨架：每段 4-8 小节 + 标配器层数
4. 在 LMMS 里按骨架填配器，段间加过渡（鼓过门/留白）

**产出**：一张「原曲结构×能量」图 + 你的编曲段落骨架 → 直接进编曲 Demo 当施工图，也是配器实战的进阶配套。
