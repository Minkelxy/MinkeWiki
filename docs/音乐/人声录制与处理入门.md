# 人声录制与处理入门

录人声 + 简单处理（修音/压缩/混响）——对应[音乐创作推荐路线](音乐创作推荐路线.md)项目一的第 5 步（可选自己录音）。

---

## 一、录音环境（先别花钱买设备）

- **安静 + 少反射**：选卧室/衣柜旁等安静点；铺毯子/挂衣服吸反射，别在空房间录
- 手机也能起步：别对着空旷房间，离麦克风 15-25cm
- **防喷**：喷麦声（p/b 音）用防喷罩或手挡，最便宜的解决是"斜对麦克风唱"

## 二、设备选择

| 麦克风 | 特点 | 适合 |
|--------|------|------|
| 动圈（如 SM58 类） | 拾取范围小、抗噪 | 家庭环境（**推荐起步**） |
| 电容（如 AT2020 类） | 细腻、但拾取环境音 | 安静声学处理过的房间 |

> 家庭录音**动圈优先**——它不收音环境杂音，比贵的电容在差环境更实用。

## 三、录音设置（录好比修好重要）

- **电平别爆**：峰值留 -6dB 以上余量，爆音修不回来
- 采样率：48kHz 够用
- **录多几遍**：同一段录 2-3 遍，选最好的一遍（或用 comping 拼）
- 开头留 2 秒空白（方便对拍）

## 四、人声处理链（按顺序）

| 步骤 | 做什么 | 别过头 |
|------|--------|--------|
| 1. 修音 | 音准不对的音拉正（DAW 自带修音） | 修太多出"电音" |
| 2. 压缩 | 音量忽大忽小拉平（2-3:1） | 压死没动态 |
| 3. EQ | 去 200-400Hz 的"闷"、给 4-8kHz 加"亮" | 过度刺耳 |
| 4. 混响/延迟 | 加空间感 | 混响太大会糊 |

> 顺序别乱：修音 → 压缩 → EQ → 混响。混响放最后，别先加再压缩（会把混响也压扁）。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 喷麦/口水声 | 防喷罩、斜对麦、后期用 EQ 削低频喷声 |
| 齿音（s 刺耳） | 用 de-esser 或 EQ 削 6-8kHz 齿音频段 |
| 音准飘 | 修音 + 录多遍挑好的 |
| 太干/太近 | 加一点混响 + 延迟，别全程干声 |

## 六、练习推荐

1. 先录一段清唱，走完四步处理链，对比"处理前/后"
2. 给[编曲 Demo](音乐创作推荐路线.md) 录一段副歌，检验在伴奏里的融合度
3. 录 3 遍挑最好，学会"选素材"比"硬修"更省力
