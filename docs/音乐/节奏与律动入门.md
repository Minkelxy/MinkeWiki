# 节奏与律动入门

从"有拍子"到"有律动"——节奏是音乐的骨架，配合[旋律写作](旋律写作入门.md)与[配器实战](配器实战入门.md)的节奏层。

---

## 一、拍号与速度

| 概念 | 说明 |
|------|------|
| 拍号 | 每小节几拍（**4/4 最常见**：每小节 4 拍，四分音符为一拍） |
| BPM | 每分钟几拍，决定快慢（70=慢、120=中快） |
| 强弱规律 | 4/4 拍通常是"强-弱-次强-弱" |

> 先定 BPM 和拍号，节奏才有"坐标系"。

## 二、音符时值（长短关系）

| 音符 | 时值（4/4 拍） | 记法感觉 |
|------|--------------|---------|
| 全音符 | 4 拍 | 长长长 |
| 二分音符 | 2 拍 | 长长 |
| 四分音符 | 1 拍 | 长 |
| 八分音符 | 半拍 | 快 |
| 十六分音符 | 1/4 拍 | 快快快 |

> 练法：打拍子（脚/手）数"1-2-3-4"，把音符时长"数"出来。

## 三、律动 ≠ 节奏（关键区别）

| 概念 | 含义 |
|------|------|
| 节奏 | 时值组合（什么时候响、响多久） |
| **律动** | **强弱 + 切分的流动感**（响得有没有"劲/摇摆"） |

> 同样的节奏型，强弱处理不同，律动天差地别——**律动是音乐"活起来"的关键**。

## 四、切分与反拍（律动的核心技巧）

- **反拍（off-beat）**：重音落在"2、4"拍或拍与拍之间——流行乐常用，立刻有"往前推"的感觉
- **切分音**：重音落在弱拍/弱位，制造"意料之外"的推进感
- 例子：底鼓踩 1、3，军鼓压 2、4，踩镲走反拍——就是最基础的"律动架子"（见[配器实战](配器实战入门.md)）

## 五、节奏型练习（手打拍子就够）

1. **四分拍**：手打"1-2-3-4"，脚打同拍
2. **八分拍**：手"1-&2-&3-&4-&"，脚保持四分
3. **切分**：手打"1（停）2-&3（停）4-&"，体会重音错位
4. 打开任何歌，跟拍打拍子，再听它"重音在哪"

## 六、练习推荐

1. 用[扒带实战教程](扒带实战教程.md)扒一首歌的鼓，记下节奏型 + 重音位置
2. 在 LMMS 里写一个 4 小节节奏（底鼓/军鼓/踩镲），改强弱和反拍，对比听感
3. 给[编曲 Demo](音乐创作推荐路线.md)的节奏层加"反拍踩镲"，听律动变化
