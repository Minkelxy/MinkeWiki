# 旋律写作入门

怎么写出一段**能记住**的旋律。承接[和弦理论](和弦理论与编配.md)（和声是伴奏的地基），本文讲旋律本身怎么写。

---

## 一、好旋律的三个特点

| 特点 | 说明 |
|------|------|
| 可哼唱 | 不用看谱就能哼出来（音程不太跳、节奏不太乱） |
| 有重复 | 有动机重复，人才记得住 |
| 有落点 | 段落在稳定音（主音/属音）上收，有"回家感" |

> 检验：哼一遍你的旋律，能记住吗？记不住 = 没有重复，或太散。

## 二、三种素材（来回用）

1. **重复（动机）**：同一个短句重复，制造记忆点（如副歌第一句）
2. **模进（序列）**：把旋律搬到高/低一度再唱一遍——**最省力又出效果**
3. **对比（新素材）**：重复几遍后给个新片段，打破单调

> 好的结构：**重复 + 变化 + 对比**。全是重复=单调，全是新=记不住。

## 三、走向与音程

- **级进为主**：相邻音（C-D-E）占多数，顺耳好唱
- **跳进点缀**：三度/五度跳进制造起伏，别全程跳（难唱）
- **落点**：句尾回到稳定音（和弦根音/主音）——"悬着"的句子要配着解决

## 四、节奏（旋律的骨架）

- **动机节奏**：先定一个节奏型（如 嗒-嗒-嗒嗒-嗒），重复它，旋律就成形
- **留空隙**：别每个拍都填满音——有停才有呼吸，也才好唱

## 五、实用方法（从零起稿）

1. **从和弦音出发**：跟着伴奏的和弦，先用根音/三音/五音搭骨架
2. **顺着情绪走**：先哼一段（不管对错），把"感觉对"的录下来再整理
3. **用工具试**：把哼的音录下来，用 [basic-pitch](音乐创作工具参考.md) 转 MIDI 修音准（见[扒带实战教程](扒带实战教程.md)反向用）

## 六、练习推荐

1. **写 4 小节动机**：定一个节奏型，用级进 + 一次模进写 4 小节
2. **给编曲 Demo 写主旋律**：在和弦进行上写一段旋律，检验"能哼出来"
3. **对照扒带**：把你扒到的副歌旋律拆开，看它是"重复 + 模进 + 对比"怎么用的
