# LMMS 编曲实操技巧（从零到成品工程）

[音乐创作工具参考](音乐创作工具参考.md)只列了 LMMS 链接，本文把 **LMMS 的实操操作**讲透——配器 / 结构 / 音色 / 混音的文档都有了，这篇是"**在 LMMS 里怎么把它们做出来**"。

> 一句话：LMMS 最强的武器是 **pattern 复用**——段落差异、编曲结构全靠它。

---

## 一、工程结构（先搭骨架）

- **Song Editor（总谱）** vs **B+B Editor（节拍编辑器）**：编曲在 Song Editor 排 pattern
- **一个 pattern 一段**（主歌 / 副歌分开），方便重排——对应[编曲结构与段落设计](编曲结构与段落设计.md)
- 常用面板：**钢琴卷帘**（写旋律 / 和弦）、**B+B**（写鼓）、**调音台**（混音）

## 二、写鼓（B+B Editor）

- 每轨一个鼓件（底鼓 / 军鼓 / 踩镲），画在时间格上
- **用 pattern 复用**：一套鼓 loop 反复用，副歌只改踩镲密度
- 力度：踩镲偶尔轻重变化，比全一样自然

## 三、写旋律与和弦（钢琴卷帘）

- 钢琴卷帘画音符，拖长度 / 音高
- 和弦：柱式 / 分解都在这画（对照[配器实战](配器实战入门.md) / [和弦理论](和弦理论与编配.md)）
- **量化（Grid）开**，节奏才不会飘
- 复制粘贴**模进**（[旋律写作](旋律写作入门.md)的手法）

## 四、音色与音源（乐器轨）

- 选乐器：tripleOscillator / ZynAddSubFX（见[音色设计](音色设计与合成器入门.md)）、采样器（SF2）
- **每层一个乐器轨**，别全部挤一轨——方便混音调音量 / 声像
- 音色预设：调好**存成 preset 复用**（见音色配方卡）

## 五、自动化与效果（让编曲"动"起来）

- **自动化曲线**：音量 / 滤波器 / 声像随时间变化——"副歌前滤波扫频"就用这个
- 效果器：混响 / 延迟 / 压缩加在乐器轨或调音台 send
- **别加太多**：每个效果先问"这首需要吗"

## 六、混音与导出（对齐混音文档）

- 调音台：每乐器轨一路，音量 / 声像 / EQ / 压缩（见[混音基础](混音基础入门.md) / [进阶](混音进阶实战.md)）
- 响度到 **-14 LUFS**，导出 WAV
- **工程管理**：工程文件按项目存（带版本号），配器 / 混音版本分开存

---

## 七、本轮项目推荐：用 LMMS 做「一个 pattern 变四个段落」

**推荐做什么**：拿编曲 Demo 的一个主歌 pattern，**复制 4 次**，分别改造成——主歌（精简）/ 预副歌（加节奏）/ 副歌（全配器）/ 间奏（简化）——一次练会 **pattern 复用 + 自动化 + 段落差异**。

**为什么值得做**：
- LMMS 最强的就是 **pattern 复用**，段落差异全靠它；
- 把[编曲结构](编曲结构与段落设计.md)的骨架在 LMMS 里**真做一遍**，比看十篇教程有用；
- 直接衔接你的编曲 Demo，是"结构 → 工程"的落地验收。

**具体怎么做**：
1. 写一个 8 小节主歌 pattern（鼓 + 贝斯 + 和弦 + 旋律）
2. 复制成 4 份，按主歌 / 预副歌 / 副歌 / 间奏分别改（加层 / 减层 / 加自动化）
3. 在 Song Editor 排成整首，加过渡（鼓过门 / 留白）

**产出**：一个"四段落变奏"的 LMMS 工程 + 段落对比音频 → 直接进编曲 Demo，验证结构设计落地。
