# 练耳与听力训练

训练"听得准"——扒带和创作的**底层能力**。承接[扒带实战教程](扒带实战教程.md)：扒带慢，往往不是工具问题，是耳朵还没练出来。

---

## 一、为什么练耳

| 用途 | 说明 |
|------|------|
| 扒带 | 听出旋律/和弦/节奏——扒带的核心是耳朵 |
| 创作 | 脑子里的旋律能"想象出声音" |
| 即兴/合奏 | 跟着听就能反应 |

> 工具（basic-pitch 等）能辅助，但**耳朵是上限**——听得出才能写得出、改得准。

## 二、练什么（四个层次）

| 层次 | 内容 | 例子 |
|------|------|------|
| 1. 音程 | 听出两个音的距离 | "这俩音隔了个五度" |
| 2. 和弦 | 听出色彩（大小/七/挂留） | "这是大三还是小三" |
| 3. 节奏 | 听出节奏型 | "反拍还是正拍" |
| 4. 调性/主音 | 听出"家"在哪 | "这首歌是 C 还是 G" |

> 按顺序来：**先音程 → 再和弦**。音程听不准，和弦一定听不准。

## 三、怎么练（最重要是"跟唱"）

1. **跟唱**（最关键）：听一段旋律，**哼唱出来**——能唱准，才算真听懂
2. **扒带即练耳**：每次[扒带](扒带实战教程.md)都是一次练耳，别跳过"听"直接转 MIDI
3. 工具辅助：练耳 APP/网站（音程/和弦听辨练习），每天几分钟

> 口诀：**先唱后记**——先用嘴跟唱旋律，再试着写/对谱。

## 四、日常练习安排（每天 10 分钟）

| 分钟 | 内容 |
|------|------|
| 0-3 | 音程听辨：先唱"标准音"，再辨大二度/小三度等 |
| 3-6 | 和弦听辨：大三 vs 小三 vs 七和弦 |
| 6-10 | 跟唱一段歌的旋律（用[扒带](扒带实战教程.md)的素材） |

> 每天 10 分钟，比周末两小时有效——耳朵是"肌肉记忆"。
