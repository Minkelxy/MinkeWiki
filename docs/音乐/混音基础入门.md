# 混音基础入门

把编好的曲子"调好听"——只讲**够用版**的四步：音量、声像、均衡、压缩。对应[音乐创作推荐路线](音乐创作推荐路线.md)项目一的最后一步。

---

## 一、混音是什么

混音 = 平衡各音轨，让它像一首歌，而不是一堆声音叠在一起。**核心不是"加效果"，而是"让每个音轨各占其位"。**

> 记住：好的混音是**做减法**——该让位的让位，不是把所有都调大。

## 二、四步流程（按顺序）

1. 音量平衡（推子）
2. 声像（Pan）
3. 均衡 EQ（频率避让）
4. 压缩（动态控制）

**别跳步**：前两步没做好，后面 EQ/压缩是救不回来的。

## 三、每步怎么做

### 1. 音量平衡

- 先把所有推子归零，**从鼓开始**，再依次加贝斯、和声、旋律
- 参考你扒带听的歌：主旋律要比伴奏响、但别盖过鼓
- 边放边调，别盯表

### 2. 声像（Pan）

| 音轨 | 位置 |
|------|------|
| 底鼓/军鼓/贝斯/主旋律/人声 | 中间（居中） |
| 和声/节奏吉他 | 左右各分一点 |
| 点缀音色 | 更靠两边 |

> 居中留给"地基和主角"，两侧留给配角——听感立刻开阔。

### 3. 均衡 EQ（频率避让）

| 冲突 | 处理 |
|------|------|
| 底鼓（低）+ 贝斯（低） | 底鼓砍一点 60Hz 以下、贝斯留 80-120Hz，或反过来错开 |
| 人声（中高）+ 旋律 | 给主角留频段，配角让位 |
| 嗡嗡的低频噪音 | 全轨高通（去掉 40-60Hz 以下） |

> 原则：**两个都挤在同一频段 = 糊**；错开频段 = 清晰。

### 4. 压缩（动态控制）

- **人声**：轻压（3:1 左右），让忽大忽小更稳
- **鼓**：可稍重压让冲击力一致
- **别过度**：压狠了声音发死，失真

## 四、响度与导出

- 参考响度：流行歌约 **-14 LUFS**（DAW 里有响度表），别到 -6 爆音
- 导出前检查**没有削波**（红色爆表）
- 导出 WAV 无损，发布再压 MP3

## 五、常用检查（导出前必做）

1. **单声道检查**：切单声道听一遍——手机外放/蓝牙音箱是单声道，立体声相位问题在这现形
2. **三种设备听**：耳机（细节）+ 音箱（低音/空间）+ 手机（真实场景）
3. **对照参考曲**：和你喜欢的歌 AB 对比响度与清晰度

## 六、推荐练习

1. 给[编曲 Demo](音乐创作推荐路线.md)做一版混音，走完四步
2. 导出前做**单声道 + 手机外放**检查，记下问题再调
3. 别追求完美——第一版混音能"听着顺、不刺耳"就合格
