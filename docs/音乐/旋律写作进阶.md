# 旋律写作进阶：动机发展与主题贯穿

[旋律写作入门](旋律写作入门.md)讲"写出一句能记住的"，本文深一层——**怎么把一句发展成整首歌**：动机发展、主题贯穿、旋律与和声结合、高潮设计。

> 一句话：旋律写作最卡的地方是"**写一句会，写一首不会**"——动机发展就是解药。

---

## 一、动机发展（一句变八句）

| 技法 | 说明 | 例（C-D-E 动机） |
|------|------|-----------------|
| **重复** | 原样再来 | C-D-E / C-D-E |
| **模进** | 搬到高 / 低一度 | C-D-E / D-E-F |
| **倒影** | 上下反转 | C-D-E / C-B-A |
| **逆行** | 倒着走 | E-D-C |
| **增值 / 减值** | 时值拉长 / 缩短 | 慢一倍 / 快一倍 |
| **组合** | 拆开重组、变奏 | 取片段改节奏 |

> 一个 3 音动机能发展出 8 小节——**别老写新句，发展旧句**。

## 二、主题贯穿（让全曲像一首歌）

- **副歌动机在段落间"回响"**：主歌用变奏、桥用倒影
- **首尾呼应**：尾奏回主歌开头动机
- **检验**：删掉其他声部，光旋律也能听出"这是同一首"

## 三、旋律与和声结合（别音对不上和弦）

- **强拍放和声内音**（根音 / 三音 / 五音），弱拍可放经过音 / 邻音
- **和弦外音要解决**：经过音（音阶内上下经过）、邻音（绕回本音）
- 目的：旋律"**踩在和弦上**"，听感才顺

## 四、高潮与音区设计

- **高潮**：最高音 / 最强时值放副歌第二遍或桥后
- **音区**：主歌中低、副歌上移（呼应[编曲结构](编曲结构与段落设计.md)）
- **留白**：高潮前给个小停顿，效果更响

---

## 五、练习推荐

1. 拿你编曲 Demo 的主旋律，用**模进 + 倒影**各发展一遍
2. 检查强拍是否都在和声内音
3. 给副歌设计一个"比主歌高"的音区对比

## 六、本轮项目推荐：做「动机发展练习曲」

**推荐做什么**：取编曲 Demo 的一个 **3-4 音动机**，用六种技法（重复 / 模进 / 倒影 / 逆行 / 增值 / 组合）各发展出 2 小节，拼成一段 **8 小节旋律**——练会"一句变八句"。

**为什么值得做**：
- **动机发展是"写一首"的解药**——入门后最卡的就是这个；
- 做完这段直接替换进编曲 Demo 验证；
- 是旋律写作的**进阶落地**，对应[旋律写作入门](旋律写作入门.md)的下一步。

**具体怎么做**：
1. 取一个 3-4 音动机
2. 六种技法各发展 2 小节
3. 选顺耳的拼成 8 小节
4. 检查强拍在和声内音、音区设计

**产出**：一段「动机发展」的 8 小节旋律 → 直接进编曲 Demo，也是旋律写作进阶的第一份成稿。
