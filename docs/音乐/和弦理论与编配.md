# 和弦理论与编配

从"会用几个进行"到"**懂和弦怎么选、怎么让和声更好听**"。承接[配器实战入门](配器实战入门.md)的和弦部分，为[编曲 Demo](音乐创作推荐路线.md) 提供和声基础。

---

## 一、和弦构成

### 三和弦（地基）

| 和弦 | 构成 | C 大调例子 |
|------|------|-----------|
| 大三和弦 | 根音 + 大三度 + 小三度 | C（C-E-G） |
| 小三和弦 | 根音 + 小三度 + 大三度 | Am（A-C-E） |
| 减三和弦 | 根 + 小三 + 小三 | Bdim |

### 加料（让和弦更有色彩）

- **七和弦**：三和弦 + 七音（如 Cmaj7 = C-E-G-B，温暖）
- **挂留**：三音换二/四音（sus2/sus4），悬浮感
- **转位**：低音不是根音（C/E），让低音线条流动

## 二、调性与级数

每个大调内有 7 个和弦，用**级数**（罗马数字）表示，哪个调都一样：

| 级数 | C 大调 | 性质 | 功能 |
|------|--------|------|------|
| I | C | 大三 | 主（稳定） |
| ii | Dm | 小三 | 下属 |
| iii | Em | 小三 | - |
| IV | F | 大三 | 下属 |
| V | G | 大三 | **属**（最紧张、要解决） |
| vi | Am | 小三 | 相对主 |
| vii° | Bdim | 减 | 属 |

**关键**：级数比具体音重要——学会"级数思考"，任何调都能套。

## 三、常用进行与功能逻辑

### 终止式（和声回家的动力）

```
V → I   （最强烈，如 G → C）
IV → I  （教堂式，柔和）
```

### 流行万能进行（配器实战已列）

```
I–V–vi–IV（C–G–Am–F）  副歌常用
vi–IV–I–V（Am–F–C–G）  小调感
I–vi–IV–V（C–Am–F–G）  老派经典
```

**为什么顺耳**：这些进行都遵循"主-下属-属-主"的功能循环，回家感强。

## 四、让和弦更好听（进阶小招）

1. **加七音**：C → Cmaj7，立刻柔和；Am → Am7 同理
2. **替代和弦**：IV 用 ii 替代、V 用 vii° 替代，色彩变化
3. **副属和弦**：V/V（G 前加 D），制造短暂的紧张推进（如 C–D–G–C）
4. **低音进行**：用转位让低音走旋律线（C–C/E–F），比死站根音好听

## 五、在编曲里的用法（呼应配器实战）

- **柱式**：三音同按铺底，适合副歌力度
- **分解/琶音**：根-三-五-三，适合主歌抒情
- **音域注意**：和弦别全堆在中音区，低音交给贝斯、中高留旋律

## 六、练习推荐

1. **C 大调级数**：把 I–V–vi–IV 换成不同调弹一遍，练级数思考
2. **给编曲 Demo 换和声**：在[扒带](扒带实战教程.md)出的走向上，加一个七音/替代，对比听感
3. **写一首 4 和弦**：用 I–vi–IV–V 写一段，再改成 vi–IV–I–V，感受情绪差异
