# 每周训练模板

把[三分化动作要领](三分化动作要领.md)（力量）、[有氧恢复](有氧与恢复方案.md)、[核心训练](核心训练与体态.md)、[照片记录](成果照片记录技巧.md)、[复盘](训练数据复盘与进阶.md)整合成**一周执行模板**——照着走，不用每天想"今天练啥"。

---

## 一、周骨架（三分化 + 有氧 + 核心）

| 星期 | 内容 |
|------|------|
| 周一 | **A 日**（胸三头）+ 核心 10 分钟 |
| 周二 | 有氧 30 分钟 |
| 周三 | **B 日**（背二头）+ 核心 10 分钟 |
| 周四 | 休息 / 轻活动（散步） |
| 周五 | **C 日**（臀腿）+ 核心 10 分钟 |
| 周六 | 有氧 30 分钟 |
| 周日 | 休息 + 周复盘 |

> 有氧 2 次（配合[减重执行方案](减重执行方案.md)）、核心 3 次（每次 10 分钟）。

## 二、每次力量训练流程

```
热身（10分钟：全身激活 + 大项递增热身组）
  → 大项（卧推/深蹲/硬拉，先做）
  → 辅助动作
  → 核心（10分钟）
  → 静态拉伸
```

- 热身/拉伸见[热身与拉伸方案](热身与拉伸方案.md)
- 大项放最前（力气给最关键的动作，见[动作要领](三分化动作要领.md)）

## 三、每周固定事项

| 事项 | 时间 | 内容 |
|------|------|------|
| 称重 + 围度 | 周一晨起 | 空腹，固定条件 |
| 照片 | 每月 1 次 | 见[成果照片](成果照片记录技巧.md) |
| 周复盘 | 周日 | 容量/强度 + 体重/腰围趋势（见[数据复盘](训练数据复盘与进阶.md)） |

## 四、调整原则

- **状态差就减**：睡眠差/酸痛 3 天+ → 当天减量或改休息（见[有氧恢复](有氧与恢复方案.md)）
- 有氧可与力量日交换（但别一天两练）
- 连续 2 周下滑 → 安排 deload 周（见[周期化进阶](训练周期化进阶.md)）

> 模板是"默认路径"，**身体状态高于计划**——状态差时调整，别硬撑。
