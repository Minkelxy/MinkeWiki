## 🎯 快速开始

### 第一步: 了解训练计划

1. 阅读 [周训练计划](./健身计划/周训练计划.md)，了解三分化训练体系
2. 确认当前体重目标（74.8kg → 59.2kg，减重15.6kg）
3. 熟悉 A（胸+三头）/ B（背+二头）/ C（臀腿）三天循环安排

### 第二步: 开始训练

1. 按 [周训练计划](./健身计划/周训练计划.md) 中的动作、组数、RPE 执行
2. 根据身体状态（心率、睡眠、肌肉酸痛）判断是否休息
3. 每周保持有氧训练两次，每次30分钟

### 第三步: 记录数据

1. 每次训练后填写 [训练记录](./健身数据/训练记录.md)
2. 每周测量并记录 [身体指标](./健身数据/身体指标追踪.md)
3. 每月拍摄成果照片并归档

### 第四步: 定期复盘

1. 每周复盘训练完成情况
2. 每月对比数据和照片
3. 每季度调整训练计划
4. 年度总结并制定新目标

## 📊 数据记录指南

### 训练记录

**记录频率:** 每次训练后

**记录内容:**
- 训练日期和部位
- 动作名称、重量、组数、次数
- 训练感受(1-10分)
- 有氧训练数据

**使用建议:**
- 训练后立即记录,避免遗忘
- 定期回顾PR记录
- 分析训练趋势

### 身体指标追踪

**测量频率:** 每周1次(建议周一早晨)

**测量内容:**
- 体重、体脂率
- 围度(胸围、腰围、臀围、上臂围、大腿围等)
- 健康指标(心率、血压等)

**使用建议:**
- 固定测量时间(早晨空腹)
- 保持测量条件一致
- 关注长期趋势而非短期波动

## 📅 计划制定指南

### 三分化训练计划

当前采用三分化线性增长训练，分为三个训练日：

- **A日 - 胸、三头**：杠铃卧推、哑铃上斜卧推、双杠臂屈伸、仰卧臂屈伸、Y字侧平举
- **B日 - 背、三角肌后束、二头**：单手钢线下拉、对握下拉、单手器械划船、坐姿开肘划船、钢线弯举
- **C日 - 臀、股四头肌、腘绳肌**：单腿硬拉、保加利亚深蹲、颈前深蹲、罗马尼亚硬拉、山羊挺身

详细动作参数见 [周训练计划](./健身计划/周训练计划.md)。

### 饮食规划

采用 5:3:2 原则：碳水50%、蛋白质30%、脂肪20%。每日摄入约2273大卡。每15天一次放纵餐。具体见训练计划中的饮食规划部分。

### 拍摄要求

**拍摄频率:** 每月1次

- 相同光线
- 相同背景

## 🔄 使用流程

### 日常流程

```
每天   → 按三分化计划（A/B/C）循环训练 → 训练后记录数据
每周一 → 测量身体指标（体重、围度等）
每周   → 复盘减重进度（目标每周-0.561kg），按需调整碳水
每月1号 → 拍摄成果照片
每月末 → 月度复盘
```

### 数据追踪流程

```
训练 → 记录 → 测量 → 拍照 → 复盘 → 调整
```

## 💡 使用技巧

### 数据记录技巧

1. **及时记录**: 训练后立即记录,避免遗忘
2. **详细记录**: 不只记录重量,还要记录感受
3. **定期回顾**: 每周回顾数据,发现趋势
4. **对比分析**: 对比不同时期的数据变化

### 计划执行技巧

1. **灵活调整**: 根据身体状态调整计划
2. **循序渐进**: 不要急于求成
3. **保持一致**: 坚持比强度更重要
4. **适度休息**: 恢复是训练的一部分

### 照片管理技巧

1. **保持一致**: 相同的拍摄条件
2. **及时归档**: 拍摄后立即整理
3. **定期对比**: 制作对比图
4. **妥善保存**: 备份到云盘

## ⚠️ 注意事项

### 训练安全

- 动作质量 > 重量
- 热身和拉伸不能省
- 出现疼痛立即停止
- 必要时寻求专业指导

### 数据记录

- 保持记录的一致性
- 不要过度关注短期波动
- 关注长期趋势
- 数据是工具,不是目的

### 计划执行

- 计划是指导,不是教条
- 根据实际情况灵活调整
- 休息和恢复同样重要
- 坚持比完美更重要
