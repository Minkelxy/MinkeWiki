## 🎯 快速开始

### 第一步: 制定计划

1. 阅读 [年度健身计划](./健身计划/年度健身计划.md)
2. 设定年度目标(体重、体脂率、力量等)
3. 制定月度和阶段计划

### 第二步: 开始训练

1. 参考 [周训练计划](./健身计划/周训练计划.md)
2. 选择适合自己的训练模板
3. 每周日制定下周训练计划

### 第三步: 记录数据

1. 每次训练后填写 [健身记录表](./健身数据/健身记录表.md)
2. 每周测量并记录 [身体指标](./健身数据/身体指标追踪.md)
3. 每月拍摄成果照片并归档

### 第四步: 定期复盘

1. 每周复盘训练完成情况
2. 每月对比数据和照片
3. 每季度调整训练计划
4. 年度总结并制定新目标

## 📊 数据记录指南

### 健身记录表

**记录频率:** 每次训练后

**记录内容:**
- 训练日期和部位
- 动作名称、重量、组数、次数
- 训练感受(1-10分)
- 有氧训练数据

**使用建议:**
- 训练后立即记录,避免遗忘
- 定期回顾PR记录
- 分析训练趋势

### 身体指标追踪

**测量频率:** 每周1次(建议周一早晨)

**测量内容:**
- 体重、体脂率
- 围度(胸围、腰围、臀围、上臂围、大腿围等)
- 健康指标(心率、血压等)

**使用建议:**
- 固定测量时间(早晨空腹)
- 保持测量条件一致
- 关注长期趋势而非短期波动

## 📅 计划制定指南

### 年度计划

**制定时间:** 年初或开始健身时

**包含内容:**
- 年度总目标
- 阶段划分(基础期、强化期、巩固期、冲刺期)
- 月度计划概览
- 季度复盘模板

**使用建议:**
- 目标要具体、可衡量、可实现
- 分阶段推进,避免急于求成
- 定期复盘,灵活调整

### 周计划

**制定时间:** 每周日

**包含内容:**
- 本周训练目标
- 每日训练安排
- 训练详细计划(动作、组数、次数)
- 周复盘

**使用建议:**
- 根据身体状态调整强度
- 预留休息和恢复时间
- 记录实际执行情况

## 📸 照片管理指南

### 拍摄要求

**拍摄频率:** 每月1次

**拍摄条件:**
- 相同时间(早晨空腹)
- 相同光线
- 相同背景
- 相同姿势

**拍摄角度:**
- 正面
- 侧面
- 背面

### 文件管理

**命名规范:**
```
YYYY-MM-DD_部位_角度.jpg
例如: 2026-05-05_全身_正面.jpg
```

**文件夹结构:**
```
成果照片/

│   ├── 05/
│   ├── 06/
│   └── ...
├── 重点部位/
│   ├── 胸部/

│   └── ...
└── 特殊记录/
```

## 💡 使用技巧

### 数据记录技巧

1. **及时记录**: 训练后立即记录,避免遗忘
2. **详细记录**: 不只记录重量,还要记录感受
3. **定期回顾**: 每周回顾数据,发现趋势
4. **对比分析**: 对比不同时期的数据变化

### 计划执行技巧

1. **灵活调整**: 根据身体状态调整计划
2. **循序渐进**: 不要急于求成
3. **保持一致**: 坚持比强度更重要
4. **适度休息**: 恢复是训练的一部分

### 照片管理技巧

1. **保持一致**: 相同的拍摄条件
2. **及时归档**: 拍摄后立即整理
3. **定期对比**: 制作对比图
4. **妥善保存**: 备份到云盘

## ⚠️ 注意事项

### 训练安全

- 动作质量 > 重量
- 热身和拉伸不能省
- 出现疼痛立即停止
- 必要时寻求专业指导

### 数据记录

- 保持记录的一致性
- 不要过度关注短期波动
- 关注长期趋势
- 数据是工具,不是目的

### 计划执行

- 计划是指导,不是教条
- 根据实际情况灵活调整
- 休息和恢复同样重要
- 坚持比完美更重要
