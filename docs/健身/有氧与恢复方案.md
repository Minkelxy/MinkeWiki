# 有氧与恢复方案

减脂期的**有氧安排**与**恢复管理**——配合[减重执行方案](减重执行方案.md)，让减脂不掉力量、不崩状态。

---

## 一、有氧安排（配合减重）

| 项 | 建议 |
|----|------|
| 频率 | 每周 2-3 次 |
| 时长 | 每次 30 分钟 |
| 强度 | **中等**：能说话但微喘（约 60-70% 最大心率） |
| 类型 | 低冲击优先：快走、椭圆机、单车、爬楼梯 |

**时机选择**：
- 力量训练后（此时糖原低，减脂效率高）
- 或与力量日分开（别一天两练，除非恢复特别好）

> 减脂期有氧是**辅助**，不是主力——主力是饮食（见[饮食落地指南](饮食落地指南.md)）。

## 二、别过度有氧

- 有氧过多会**挤占恢复、掉力量**——减脂期本就难涨力，别雪上加霜
- 原则：**力量保持优先，有氧服务减脂，别让有氧压垮训练**
- 掉秤靠热量差，不靠有氧拼命

## 三、恢复三支柱

| 支柱 | 关键 |
|------|------|
| **睡眠** | 7-8 小时/天（最容易被忽略也最值钱） |
| 营养 | 蛋白够、碳水别砍光（已覆盖） |
| 压力 | 减脂本身是压力，别叠加过多生活压力 |

> 睡眠差 = 皮质醇高 = 减脂变慢 + 掉肌肉。**睡好觉是最便宜的增肌减脂补剂。**

## 四、睡眠优化

- **固定作息**：每天相近时间睡/起，比时长更稳
- 训练别太晚（睡前 2 小时内剧烈训练影响入睡）
- 睡前 1 小时少看屏幕；卧室温度略低助眠

## 五、deload 与休息日

- **每周至少 1 个休息日**（完全不练或只散步）
- 连续 2 周表现下滑 → 安排减量周（见[训练数据复盘与进阶](训练数据复盘与进阶.md)）
- 别用"累也要练"感动自己——恢复不足的训练是负效率

## 六、监测恢复（用数据说话）

| 信号 | 正常 | 警惕 |
|------|------|------|
| 静息心率 | 稳定 | 连续走高 5-7 次/分 |
| 睡眠质量 | 入睡快、醒得少 | 连续失眠 |
| 次日酸痛 | 1-2 天消退 | 持续 3 天+ |
| 训练表现 | 逐周稳定 | 连续下滑 |

> 把这些记进[训练记录](健身数据/训练记录.md)（feeling 字段），复盘时一目了然。
