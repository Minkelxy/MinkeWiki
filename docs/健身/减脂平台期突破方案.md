# 减脂平台期突破方案

掉秤停了怎么办——**系统排查，别慌着节食**。配合[减重执行方案](减重执行方案.md)，专门处理"体重连续几周不动"的情况。

---

## 一、先确认是不是真平台期

| 检查 | 方法 |
|------|------|
| 看趋势 | 看 **2-4 周**整体趋势，别被单日 ±1kg 骗 |
| 看围度 | 体重没掉但**腰围小了** → 可能减脂不减重，不算平台期 |
| 看照片 | 三个月对比照片，体型有变化就不是平台期 |

> 真平台期 = 体重 **2-4 周**没动 + 围度也没变化。

## 二、先排查（再谈应对）——按顺序查

| 顺序 | 查什么 | 典型坑 |
|------|--------|--------|
| 1 | 热量是否悄悄涨了 | 多吃了零食/酱料/饮料，或外食估少了 |
| 2 | 运动量是否悄悄少了 | NEAT（日常步数）下降，久坐变多 |
| 3 | 睡眠/压力 | 连续 <6.5h 睡眠、压力大 → 皮质醇高 → 掉秤慢 |
| 4 | 训练是否划水 | 重量/组数悄悄缩水，训练强度下滑 |

> **90% 的平台期是这几条之一**——先排查再改，别一上来就砍热量。

## 三、应对手段（按顺序试）

### 1. 减碳再观察
- 碳水再 -15g，观察 1-2 周（最温和的第一步）

### 2. Refeed（碳水上抬日）
- 减脂 3 周以上、状态差时，安排 1 天碳水+50%（约正常 1.5 倍）
- 作用：补糖原、恢复代谢感知，常能"重启"掉秤

### 3. 加 NEAT 而非加有氧
- 每天多走 2000-4000 步（通勤/走动），比加跑步更易坚持、不增食欲

### 4. 换训练刺激
- 换 1-2 个动作/调整动作顺序，给身体新刺激（见[三分化动作要领](三分化动作要领.md)）

### 5. 反向节食（减脂很久后）
- 减脂超过 3-4 个月卡死：**暂时回调热量**（+100-200 大卡）养几周代谢，再重新减
- 别无限减——长期赤字会让代谢适应，越减越难

## 四、别做的（平台期的坑）

| ❌ 别做 | 原因 |
|---------|------|
| 极端节食（<1200 大卡） | 掉肌肉、反弹，代谢更差 |
| 疯狂有氧 | 食欲暴增 + 掉力量，不可持续 |
| 每天称重焦虑 | 只看单日数字，自己吓自己 |
| 同时改所有变量 | 不知道哪个有效，出了问题难定位 |

## 五、监测（用数据判断）

- 记录体重趋势 + 腰围 + 静息心率（见[训练数据复盘与进阶](训练数据复盘与进阶.md)）
- 每次只改一个变量，记录 1-2 周再判断
