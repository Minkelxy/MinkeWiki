# 核心训练与体态

核心力量 + 体态改善——久坐人群最该补的一块。配合[三分化动作要领](三分化动作要领.md)的大项训练。

---

## 一、为什么练核心

- **护腰**：深蹲/硬拉时核心不稳 = 腰代偿受伤（见[动作要领](三分化动作要领.md)）
- **稳定**：核心是"力量的传输带"，稳了力量才传得出去
- **体态**：核心弱 → 腰腹松、体态垮

> 核心不是"练腹肌好看"，是**大项安全 + 力量的根基**。

## 二、核心是什么（别只练腹肌）

| 层次 | 功能 |
|------|------|
| 表浅（腹直肌/腹斜肌） | 卷腹、侧向 |
| **深层（腹横肌/多裂肌）** | 稳定、抗伸展 |
| 抗旋转 | 防扭转（负重单侧时） |

> 核心训练的本质：**抗伸展 + 抗旋转**（保持躯干稳定），不是单纯卷腹。

## 三、核心动作库（从易到难）

| 分级 | 动作 | 说明 |
|------|------|------|
| 入门 | 死虫式 | 仰卧四肢对抗，最简单安全 |
| 基础 | 平板支撑 | 30-60s，注意别塌腰 |
| 进阶 | 侧桥、鸟狗式 | 抗侧倾/抗旋转 |
| 高级 | 负重行走、悬垂举腿 | 稳定 + 力量 |

> 优先做**死虫/鸟狗**这类"抗伸展抗旋转"，比卷腹更护腰、更实用。

## 四、常见体态问题（久坐人群）

| 问题 | 表现 | 原因 |
|------|------|------|
| 圆肩 | 肩前扣、胸椎前倾 | 长期伏案、胸紧背弱 |
| 头前伸 | 脖子前探 | 低头看屏幕 |
| 骨盆前倾 | 腰部反弓、肚子前凸 | 久坐臀肌/核心弱 |

> 体态问题 90% 是**"前侧紧 + 后侧弱"**——练背后侧 + 拉伸前侧。

## 五、体态矫正动作

| 问题 | 矫正 |
|------|------|
| 圆肩/头前伸 | 练**背部**（划船/下拉，见动作要领 B 日）+ 拉伸胸大肌 |
| 骨盆前倾 | 练**臀/核心**（臀桥、鸟狗）+ 拉伸髋屈肌 |

> 矫正思路：**练弱的一侧 + 拉伸紧的一侧**，别只做拉伸。

## 六、怎么安排

- 每周 2-3 次，每次 5-10 分钟，**放在大项训练后或休息日**
- 每次挑 2-3 个动作：1 个抗伸展（死虫/平板）+ 1 个抗旋转（鸟狗/侧桥）
- 体态矫正动作可每天做（少量多次）
