# 动作退阶与进阶选择表（三分化）

承接[三分化动作要领](三分化动作要领.md)——要领文档告诉你**标准动作长什么样**，本文回答两个更实际的问题：**做不了标准动作怎么办（退阶）**、**练熟了怎么更难（进阶）**。给每个动作一条「退阶 → 标准 → 进阶」路线，保证减脂期力量不涨也能持续练对、练安全。

> 核心思想：**退阶不是放弃，是"换个方式练同一个肌肉"**。力量上来再回到标准，标准练透再加难度——引体向上就是你正在走的这条路。

---

## 一、为什么减脂期尤其需要退阶/进阶表

| 减脂期的现实 | 没有退阶表的后果 | 有退阶表的做法 |
|-------------|----------------|--------------|
| 力量增长慢（热量缺口下糖原/恢复受限） | 上不了重量就跳过动作 | 退一阶，练"做得动的版本" |
| 动作容易变形（疲劳） | 为了上重量牺牲质量 → 受伤 | 退阶保证动作标准 |
| 容易放弃（"练不了"） | 跳过 = 该部位缺刺激 | 每个动作都有"练得动"的版本 |

> 渐进超负荷不止"加重"：**加次数 → 加组数 → 减组间休息 → 进阶动作难度**都是手段（见[训练数据复盘与进阶](训练数据复盘与进阶.md)）。

## 二、通用进阶规则（所有动作通用）

1. **达标才升阶**：当前阶能"目标次数×组数、RPE≤7、动作不变形"**连续 2-3 次** → 升一阶
2. **升阶顺序**：先换更难的动作（角度/支撑/重量），再谈次数组数
3. **不达标就退阶**：做不到标准次数，主动退一阶练，别硬撑
4. **力量核心动作（卧推/深蹲/硬拉）不要跳级**：退阶 → 标准 → 负重，逐步来

## 三、A 日（胸 · 三头）退阶-进阶

### 卧推
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | **哑铃卧推** | 更稳定、轨迹自由，练胸基础力量；两手持铃稳定放下 |
| 标准 | **杠铃卧推** | 见[动作要领](三分化动作要领.md)，肩胛收拢、轨迹朝下胸 |
| 进阶 | 杠铃卧推 + 2.5-5kg / 底部暂停 1 秒 | 加难度后回落到标准次数再爬 |

### 双杠臂屈伸
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | **弹力带辅助** / **脚蹬地** | 用带子分担体重，或脚尖轻点地借力 |
| 标准 | 双臂屈伸 | 身体微前倾练胸，降到肩略低于肘 |
| 进阶 | 腿夹哑铃负重 | 先练透标准再负重，别急着加 |

## 四、B 日（背 · 后束 · 二头）——引体向上重点

### 引体向上路线（你的渐进方向，系统化）
| 阶 | 动作 | 怎么练 |
|----|------|--------|
| 退阶1 | **澳式引体**（斜身划船） | 手抓杠/低杠，身体斜着拉，**越接近水平越难**；目标 3×8-12 |
| 退阶2 | **弹力带辅助引体** | 带子从厚到薄，辅助力逐渐减小；目标 3×5-8 |
| 退阶3 | **离心引体**（慢放） | 凳上/跳起借力到顶，**控制 3-5 秒慢放**；目标 3×5-8 |
| 标准 | 标准引体 | 下巴过杠、慢起慢落；目标 3×5-8 |
| 进阶 | 负重引体 / 顶部停顿 | 加哑铃或停顿 1 秒，回落后再爬 |

> **建议**：每周 2-3 次，每次 3-5 组，组间休息 2-3 分钟。先攻"数量"，再攻"难度"——同一阶能轻松做满 8 次就升下一阶。

### 划船 / 下拉
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | 钢线下拉（低重量高次数） | 先学会"用背发力不是用手拉"（见[动作要领](三分化动作要领.md)） |
| 标准 | 单手钢线下拉 / 坐姿开肘划船 | 沉肩→夹背→拉到底停 1 秒 |
| 进阶 | 划船 + 暂停 1 秒 / 加大行程 | 加刺激不一定要加重量 |

## 五、C 日（臀 · 腿）退阶-进阶

### 深蹲
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | **高脚杯深蹲**（哑铃/壶铃胸前） | 重量前置，更容易保持躯干直立、蹲到位 |
| 标准 | 颈前深蹲 | 见[动作要领](三分化动作要领.md)，核心收紧、深度大腿平行 |
| 进阶 | 颈后深蹲 / 加重 | 颈前做不动就退杠铃片（要领原文）；标准练透再负重 |

### 罗马尼亚硬拉 RDL
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | **哑铃 RDL** | 双手持哑铃，更稳定、好找髋铰链感觉 |
| 标准 | 杠铃 RDL | 杠铃贴腿、腰背中立、髋主导顶起（见[动作要领](三分化动作要领.md)） |
| 进阶 | RDL + 底部停顿 / 加大行程 | 加强臀腿控制 |

### 保加利亚分腿蹲
| 阶 | 动作 | 说明 |
|----|------|------|
| 退阶 | 降低后凳高度 + **双手扶稳** | 先建立单腿稳定，重心在前腿 |
| 标准 | 标准保加利亚分腿蹲 | 前膝跟脚尖方向一致、不内扣 |
| 进阶 | 双手持铃负重 | 单腿力量够了再加 |

## 六、怎么落地（数据化）

1. **每个动作标"当前阶段"**：退阶 / 标准 / 负重——写进[训练记录](健身数据/训练记录.md)的备注
2. **周复盘核对升阶**：连续 2-3 次达标 → 升一阶（对应[训练数据复盘与进阶](训练数据复盘与进阶.md)的进阶规则）
3. **换动作/降阶也记录**：平台期想"换刺激"时，退阶换个练法是合规手段（见[减脂平台期突破方案](减脂平台期突破方案.md)）
4. 模板可放 [TrainingPlan](https://github.com/Minkelxy/TrainingPlan)（你的训练计划源码仓库）

---

## 七、本轮项目推荐：做一张「动作阶段路线卡」

**推荐做什么**：把上面 A/B/C 三天每个动作的「当前阶段 + 达标标准 + 升阶条件」整理成**一张路线卡**（1 页表格），每个动作标上你现在所处阶段，打印贴墙或做成 Markdown 放进健身目录；同时给[训练记录](健身数据/训练记录.md)加一列"阶段"字段。

**为什么值得做**：
- 减脂期最容易"练不了就跳过"，退阶表让每个动作都有**练得动的版本**——不跳过 = 不丢刺激，这是减脂期保肌肉的关键；
- 把你**已经开始的引体向上渐进**（README 里"一点一点进步喽"）系统化，推广到卧推/深蹲/硬拉所有动作；
- 1 页纸 + 一个字段，成本极低，马上能用，且直接喂给[周复盘](训练数据复盘与进阶.md)流程。

**具体怎么做**：
1. 按本文第三/四/五节，把 A/B/C 每个动作的退阶/标准/进阶填成一行
2. 给每个动作标"我现在的阶段"（如实填，做不了就是退阶）
3. 训练记录加"阶段"列，练前看一眼、练完记一笔
4. 每周复盘时核对：哪个动作连续达标 → 下周日升一阶

**产出**：1 页"动作阶段路线卡"（Markdown/打印版）+ 训练记录里的阶段标注 → 与[周训练计划](健身计划/周训练计划.md)、[数据复盘](训练数据复盘与进阶.md)直接配合。
