# 减脂坚持与习惯养成

饮食、训练、数据都有了，本文补**行为层**——减脂 15.6kg（74.8→59.2）是 **6 个月+ 的马拉松**，技术方案再好，坚持不住也白搭。核心一句话：**把减脂变成习惯，不靠意志力。**

> 减脂失败 90% 不是方案错，是坚持不住。意志力是消耗品，靠"每天自律"撑 6 个月不现实。

---

## 一、为什么坚持比方案重要

| 误区 | 正解 |
|------|------|
| "再自律一点" | 意志力会耗尽——**靠系统不靠意志** |
| "方案对了自然会瘦" | 方案只解决"吃什么练什么"，不解决"天天做" |
| "瘦不下来是身体问题" | 多数是**行为断档**：一两周破功 → 彻底放弃 |

> 目标：把"吃什么 / 练什么"变成**不用想的默认行为**，而不是每次都要做决定。

## 二、习惯养成三件套（对照你的三分化）

1. **习惯叠加**：把新行为绑在已有行为上——"周一到了，先热身再开练""饭前先喝一杯水"
2. **环境设计**：让好行为容易、坏行为麻烦——冰箱低层放蛋白、茶几不放零食、训练服提前摆好
3. **记录可见**：训练记录 / 体重趋势让进步可见——**你已经有自建数据系统**（见[训练数据复盘与进阶](训练数据复盘与进阶.md)），习惯养成正好用它

## 三、动机管理与低谷应对

- 减脂动机曲线是"**前高后平**"——别靠开头的热情，靠系统撑住中间 3-6 个月
- **低谷期**（2-3 周不掉秤）：回到[减脂平台期突破方案](减脂平台期突破方案.md)排查，别自暴自弃
- **心理陷阱：全或无思维**（"多吃一口 = 这周毁了"）→ 用"下一顿正常吃"替代，别补偿性节食
- **长期激励**：月度对比照 / 数据趋势，别盯单日体重（见[身体指标数据分析](身体指标数据分析.md)）

## 四、社交与场景（减脂最大的现实敌人）

| 场景 | 策略 |
|------|------|
| **聚餐** | 先吃蛋白 / 蔬菜垫底，主食留一部分；别空着肚子赴约 |
| **家人做饭** | 沟通目标，别自己偷偷不吃——有人支持坚持更久 |
| **出差 / 旅行** | 保证"蛋白够 + 走路多"，**别追求完美**，回来再回归节奏 |

## 五、每周复盘的行为清单（接[数据复盘](训练数据复盘与进阶.md)）

1. 这周**"坚持度"打几分**（1-10）？——比体重数字更早预警"要崩了"
2. 哪个环节最容易破功？（晚睡？加班吃零食？聚餐？）→ **针对性环境设计**
3. 记录 3 条"这周做得好的"，强化正反馈——别只盯着没做到的

---

## 六、本轮项目推荐：建「坚持日志 + 环境改造清单」

**推荐做什么**：在[训练记录](健身数据/训练记录.md)里加一个**"坚持度"字段**（每周 1-10 分 + 一句破功原因），并做一张**"环境改造清单"**——把 5 个最容易破功的场景改造成"好行为更容易"。

**为什么值得做**：
- 减脂 6 个月最缺的不是方案是**坚持**——坚持度自评比体重更早预警"要崩了"；
- **环境改造一次投入、长期受益**（改冰箱/茶几/加班场景，比每天自我斗争省力得多）；
- 结合你已有的自建数据系统，把"行为"也**数据化**，与[数据复盘](训练数据复盘与进阶.md)形成闭环。

**具体怎么做**：
1. 训练记录加"坚持度"字段，每周五记（1-10 分 + 一句破功原因）
2. 列出 5 个破功场景，逐个做环境改造（冰箱 / 茶几 / 加班 / 聚餐 / 旅行）
3. 月度回顾坚持度曲线，低谷前主动调整

**产出**：一张环境改造清单 + 坚持度记录（进现有数据系统）→ 与数据复盘配套，是减脂的"**行为保险**"。
