# 减重执行方案

基于你现有基础（74.8kg → 59.2kg、5:3:2 饮食、三分化 A/B/C、每周约 -0.56kg）的**具体执行推荐**。目标是把「计划」变成「可执行的每日动作」。

---

## 一、减重节奏：拆成 4 个阶段

总目标 15.6kg，建议分阶段，别盯着总数：

| 阶段 | 减重 | 周期 | 达标信号 |
|------|------|------|---------|
| 阶段一 | 74.8 → 70.8（-4kg） | 约 8 周 | 体重稳定下行 |
| 阶段二 | 70.8 → 66.8 | 约 8 周 | 腰围明显变化 |
| 阶段三 | 66.8 → 63 | 约 7 周 | 力量维持住 |
| 阶段四 | 63 → 59.2 | 约 7 周 | 平台期最多 |

**健康速率**：每周 0.4-0.7kg。若一周掉超 1kg，多半是水分/肌肉，反而要回调。

## 二、饮食执行推荐（比 5:3:2 更可落地）

1. **蛋白质优先**（30% 约 170g/天）：先吃够蛋白再谈碳水——减脂期保肌肉的关键
2. **训练日碳水略高、休息日略低**：同样总热量，把碳水往训练日堆
3. **放纵餐（每 15 天）放在训练后**：练后补充糖原，损失最小
4. **别靠饿**：每日 2273 大卡是基准，先减 10% 碳水（-15~30g），别直接砍总热量

**优先级**：先保证蛋白质 > 再管热量 > 最后管碳水比例。三样全抓容易崩。

## 三、训练调整推荐（减脂期）

| 原则 | 做法 |
|------|------|
| 力量以**保持**为主 | 维持重量，不追求每周期都加——减脂期本就难涨 |
| 容量可略降 | 组数 ×10-20%，强度（重量）别降 |
| 有氧 2-3 次/周 | 每次 30 分钟，低冲击（快走/椭圆机），别和有氧拼命 |
| 优先保大项 | 深蹲/硬拉/卧推的表现，其余可让路 |

> 减脂期力量掉 5-10% 正常；掉 15%+ 说明热量吃太狠，回调碳水。

## 四、平台期应对清单（掉秤停了就按顺序试）

1. 连续 2 周没动 → 碳水再 -15g，观察 1 周
2. 还不动 → 加 NEAT（日常步数/站立），别急着加有氧强度
3. 检查睡眠（<6.5h 会显著影响减脂）与蛋白是否吃够
4. 换 1-2 个动作/动作顺序，给身体新刺激
5. 最后才考虑加大有氧或再砍热量

## 五、数据监测推荐

- **每周一晨起空腹**称重 + 量腰围（固定条件，见[身体指标追踪](健身数据/身体指标追踪.md)）
- 用自建后端记录，按[训练数据复盘与进阶](训练数据复盘与进阶.md)每周复盘
- **看 4 周趋势，不看单日**：单日 ±1kg 都是水分

## 六、阶段一（前 8 周）每周节奏示例

| 每周 | 动作 |
|------|------|
| 训练 | A/B/C 三分化照常，有氧 2-3 次 |
| 饮食 | 蛋白 170g，训练日碳水中等、休息日低碳 |
| 记录 | 周一称重 + 腰围，存后端 |
| 复盘 | 每周看容量与体重趋势，按需调碳水 |
