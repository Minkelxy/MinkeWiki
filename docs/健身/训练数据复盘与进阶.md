# 训练数据复盘与进阶指南

配合[训练记录](健身数据/训练记录.md)和[身体指标追踪](健身数据/身体指标追踪.md)，用数据驱动训练决策。本指南回答两个问题：**看什么**、**怎么进阶**。

---

## 一、为什么复盘

三分化训练最怕「闷头练」——今天比昨天多做了几下，不一定代表在变强。复盘是把「感觉」变成「数据」，回答三个问题：

1. 我是不是真的在进步？（容量/强度趋势）
2. 训练是否均衡？（各部位分配）
3. 该加重了，还是该休息？（疲劳 vs 恢复）

## 二、复盘的核心指标

### 1. 训练容量（Volume）

> 容量 = Σ（重量 × 次数 × 组数）

- **周容量**是最直观的进步指标，趋势上升 = 有效
- 但容量上升若伴随**动作变形/伤痛**，说明强度虚高

### 2. 强度（Intensity）

- 用 **RPE**（自感用力程度 1-10）或 **%1RM** 衡量
- RPE 一致性：同重量、同次数，RPE 从 8 降到 6 → 进步信号
- 记录时 RPE 要诚实，别每组都写「力竭」

### 3. PR（Personal Record）追踪

- 每次刷新纪录（某重量×次数创新高）就标记
- 力量型项目（卧推/深蹲/硬拉）固定周期测 PR，别天天测

### 4. 疲劳与恢复

| 信号 | 正常 | 需警惕 |
|------|------|--------|
| 静息心率 | 稳定 | 连续走高 5-7 次/分 |
| 睡眠 | 7-8h | 连续 <6h |
| 次日酸痛 | 1-2 天消退 | 持续 3 天+ |
| 训练表现 | 逐周上升 | 连续 2 周下滑 |

### 5. 体重/围度趋势

- 看**周均/月度趋势**，别看单日波动（水分影响大）
- 目标减重：每周 -0.5kg 左右为健康速率（与现有 5:3:2 饮食配合）

## 三、进阶规则（何时加重）

**线性进阶（当前三分化采用）**：

```
某动作 3×8，当前用 60kg
→ 连续 2-3 次训练都能完成 3×8 且 RPE≤7
→ 下一轮加重 2.5-5kg（上肢2.5/下肢5），次数回落到 6-8 再往上爬
```

**两条铁律**：
1. **先达标再加**：目标次数×组数全部完成、动作标准，才加重量
2. **宁可轻不可变形**：为了上重量牺牲动作质量，是受伤的源头

## 四、何时 Deload（减量周）

出现以下任一情况，安排一周减量（容量/强度 × 40-60%）：

- 连续 2 周关键动作表现下滑
- 疲劳信号多项亮红灯（睡眠差 + 静息心率高 + 持续酸痛）
- 情绪抵触训练、频繁缺练

Deload 不是偷懒，是让超量恢复兑现的**计划内安排**。

## 五、周期化进阶方向（减脂期后可引入）

| 方式 | 做法 | 适用 |
|------|------|------|
| 线性 | 每周固定加量 | 新手/当前阶段 |
| 波浪（DUP） | 一周内重/中/轻循环 | 中期平台期 |
| 模块化（Block） | 力量块→肌肥大块→减脂块 | 长期规划 |

## 六、用自建数据做复盘（实操）

自建后端（`api_server.py`）已存训练记录与身体指标，可定期导出（`/fitness/export/training`）做周分析：

```bash
# 示例：导出训练数据 CSV
curl "http://localhost:8000/fitness/export/training?format=csv" > training.csv
```

**每周复盘清单**：
1. 本周总容量 vs 上周（同部位对比）
2. 每个动作的 PR / RPE 趋势
3. 体重、腰围周变化
4. 睡眠与静息心率是否正常
5. 决定：下周加重 / 维持 / 减量
