# 照片记录索引

记录健身成果照片,直观展示身体变化。

---

## 拍摄说明

### 拍摄要求

- **拍摄频率**: 每月1次(建议固定日期,如每月1号)
- **拍摄时间**: 早晨空腹,光线充足
- **拍摄角度**: 正面、侧面、背面
- **拍摄条件**: 
  - 相同光线条件
  - 相同背景
  - 相同姿势
  - 相同距离

### 拍摄姿势

**正面:**
- 双脚与肩同宽
- 双臂自然下垂或叉腰
- 目视前方
- 全身放松

**侧面:**
- 身体侧对镜头
- 双臂自然下垂
- 目视前方
- 展示身体轮廓

**背面:**
- 背对镜头
- 双臂自然下垂或叉腰
- 展示背部线条

### 文件命名规范

```
YYYY-MM-DD_部位_角度.jpg
例如: 2026-05-05_全身_正面.jpg
```
