# 减脂后塑形过渡

达到目标体重后，怎么从"减"平滑过渡到"塑形/增肌"——避免反弹，也避免"不知道下一步干嘛"。

---

## 一、何时过渡（别只看体重）

| 判断 | 说明 |
|------|------|
| 体重 | 达到 59.2kg 附近 |
| **体脂/围度** | 腰围、腹肌轮廓、镜子——**体脂比体重更准** |
| 持续时间 | 减脂 ≥ 3-4 个月，身体需要休整 |

> 过渡信号：减脂很久 + 状态疲惫 + 力量下滑 → 该转入"维持/增肌"阶段养一养，而不是硬减到底。

## 二、热量回调（反向节食，关键防反弹）

- **每周 +100-200 大卡**，分几周加回，别一下子吃回正常量
- 先加到**维持热量**（体重稳定），观察 1-2 周，再决定要不要进增肌
- 目的：让代谢"跟上来"，避免突然吃多 → 反弹

> 反向节食是减脂后的**必修课**——突然恢复饮食是反弹的主因。

## 三、训练切换（从"保持"到"增"）

| 阶段 | 减脂期 | 塑形期 |
|------|--------|--------|
| 容量 | 保持 | **加容量**（组数/次数上升） |
| 强度 | 维持 | 渐进超负荷（每周加一点） |
| 周期化 | 线性保持 | 上[波浪周期化](训练周期化进阶.md) |

- 塑形 = 渐进超负荷：容量/强度稳步往上走，肌肉才有生长刺激
- 有氧可从 2-3 次降到 1-2 次（给热量和恢复让路）

## 四、蛋白质（增肌的需求）

- 维持或**略升**：增肌期蛋白目标 ~1.6-2g/kg
- 把热量加回来的部分**优先给碳水**（训练表现 + 恢复），别全加脂肪

## 五、心态调整（很重要）

- **体重会回升**：肌肉 + 水分增加是正常的，别当成"减脂失败"
- 从"盯体重"转到"看体型/力量"——塑形期的进步是**围度和力量**，不是数字往下
- 用[身体指标数据分析](身体指标数据分析.md)的组合判断，别被体重绑架
