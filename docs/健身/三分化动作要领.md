# 三分化动作要领

针对[周训练计划](健身计划/周训练计划.md)里 A/B/C 三分化的主要动作，整理**标准要领、常见错误、安全提示**。复合动作（卧推/深蹲/硬拉）重点讲，辅助动作给快速要点。

> 通用原则：**重量宁轻勿变形**，动作质量 > 上重量。

---

## A 日（胸 · 三头）

### 🏋️ 杠铃卧推（重点）

| 项 | 要点 |
|----|------|
| 握距 | 略宽于肩，小臂垂直地面 |
| 肩胛 | **全程收拢、下沉**，贴在凳上（保护肩的关键） |
| 轨迹 | 杠铃下放时朝**下胸/中胸**，肘部约 45° 别外展平 |
| 双脚 | 踩实地面，别悬空 |
| 呼吸 | 下放吸气、推起呼气 |

**常见错误**：肩胛打开（肩前扣）、杠铃砸胸反弹、肘过度外展（伤肩）。
**安全**：大重量必须**保护/深蹲架安全销**。

### 辅助动作快速要点

| 动作 | 要点 |
|------|------|
| 哑铃上斜卧推 | 凳 30-45°，哑铃沿弧线下放，别砸胸口 |
| 双杠臂屈伸 | 身体微前倾练胸、直立练三头；降到肩略低于肘即可 |
| 仰卧臂屈伸 | 肘固定朝前，别外扩；下降到底肩部不难受为准 |
| Y字侧平举 | 轻重量，肩胛稳定，别耸肩代偿 |

## B 日（背 · 后束 · 二头）

### 🏋️ 划船类（重点）

| 动作 | 要点 |
|------|------|
| 单手钢线下拉 | 沉肩→拉向侧腹，**用背发力**不是用手臂拉 |
| 坐姿开肘划船 | 肘向两侧打开拉，夹背；控制离心（回放慢） |

**共同要点**：脊柱中立不弓腰、肩胛先下沉再收、**拉到底停 1 秒**。

### 下拉类

- **对握下拉**：握距与肩同宽，拉向锁骨，身体微后倾，别用惯性甩
- **要领**：想象"把肘往腰里拉"，而不是"把手往下压"

### 弯举

- **钢线弯举**：大臂固定、肘贴身，只动小臂；**别借力甩**，借力=白练

---

## C 日（臀 · 腿）

### 🏋️ 深蹲（颈前深蹲，重点）

| 项 | 要点 |
|----|------|
| 站距 | 与肩同宽或略宽，脚尖微外展 |
| 核心 | **全程收紧**，腰背挺直不弓不折 |
| 深度 | 蹲到大腿平行或更低，膝盖方向跟脚尖一致 |
| 重心 | 全脚掌受力，**别压脚尖** |

**常见错误**：膝盖内扣（伤膝）、弓腰（伤腰）、重量过深失去控制。
**颈前 vs 颈后**：颈前对核心要求高、更偏股四头；做不动就退杠铃片。

### 🏋️ 硬拉类（罗马尼亚硬拉 RDL，重点）

| 项 | 要点 |
|----|------|
| 起始 | 杠铃贴腿，髋向后推、膝微屈 |
| 下降 | 沿腿下放，**腰背始终中立**，杠铃到膝下 |
| 发力 | 髋主导顶起，**想象用屁股把杠顶上来** |
| 顶点 | 站直、夹臀，不后仰 |

**常见错误**：弓腰下放（大忌）、用手臂拉（不是拉）、起身过早屈膝变深蹲。

### 单腿类

- **保加利亚深蹲**：后脚搭凳，重心在前腿，前膝跟脚尖方向一致、别内扣
- **单腿硬拉**：支撑腿微屈，对侧腿后伸保持平衡，背部全程平

### 山羊挺身

- 幅度别过大：起来到身体与腿成直线即可，**别过度反弓腰**
- 慢起慢落，感受腘绳肌/臀发力

---

## 训练建议

1. **热身**：每次训练前 5-10 分钟——动态拉伸 + 轻重量递增热身组（大项做 2-3 组热身再上正式组）
2. **动作顺序**：大项（卧推/深蹲/硬拉）放前面，辅助放后面，力气给最关键的动作
3. **重量加不上去先查动作**：先确认要领，再考虑加重量
