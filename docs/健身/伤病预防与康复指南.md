# 伤病预防与康复指南

把[三分化动作要领](三分化动作要领.md)里分散的安全提示，汇总成一份**"训练中受伤怎么办"的完整指南**。核心一句：**酸痛是训练，疼痛是信号，伤是结果**——学会区分，才知道何时该停、何时该练、何时该就医。

> 三分化大量深蹲/硬拉/卧推，伤是最大的变量——它能把几个月的进度清零。这份指南是"止损阀"。

---

## 一、先分清：酸痛 vs 疼痛 vs 伤

| 类型 | 特征 | 处理 |
|------|------|------|
| **肌肉酸痛（DOMS）** | 24-48h 后出现、**两侧对称**、活动后缓解 | 正常，可继续练或轻练 |
| **疼痛（警示）** | **单侧**、关节处、尖锐、特定角度痛 | 停那个动作，先查姿势再考虑降重 |
| **伤（红旗）** | 剧痛、肿胀、变形、无法承重、麻木 | **停止 + 就医** |

> 黄金判断：**对称的酸痛可以练，单侧的 / 关节的 / 尖锐的疼痛要停**。疼到睡不着、影响走路，别硬扛。

## 二、常见训练伤速查（对应三分化动作）

| 部位 | 常见伤 | 症状 | 初步处理 |
|------|--------|------|---------|
| **膝** | 髌腱炎 / 半月板 | 蹲下、下楼时膝盖前/内侧痛，或"卡住" | 停深蹲，改高脚杯/箱式深蹲，冰敷 |
| **腰** | 腰肌拉伤 / 椎间盘 | 弯腰痛、久坐痛、放射到腿（麻木） | 停硬拉/深蹲，急性期冰敷后改热敷；**放射痛就医** |
| **肩** | 肩袖 / 肌腱炎 | 卧推、侧平举、肩外展痛 | 停推类动作，降重量，练肩胛稳定 |
| **腕/肘** | 肌腱炎（网球肘等） | 握持、弯举、俯卧撑痛 | 减轻负重，用护腕/护肘，别忍痛练 |

## 三、红旗信号（立刻就医，别拖）

- 剧痛 / 无法承重 / 关节变形 / 明显肿胀
- **麻木、放射痛**（麻到手指/脚趾）、无力
- 伤后 24-48h 肿痛不缓解，反而加重
- 任何"脱臼 / 断裂感 / 听到'啪'"的声音

> 别用"忍一忍就过去"安慰自己——**练废一周比停练一周贵得多**。该就医就就医。

## 四、恢复期怎么练（急性期过后）

1. **避开受伤部位**：膝伤练上肢/核心，肩伤练下肢——别让伤停掉整个训练
2. **受伤侧用退阶动作**保持活动（见[动作退阶与进阶选择表](动作退阶与进阶选择表.md)），别直接上标准动作
3. **恢复原则（PEACE & LOVE）**：保护 + 避免滥用消炎药 + 加压抬高 → 渐进负荷 + 乐观心态 + 血管活化 + 运动恢复
4. **恢复进度**：疼痛**完全消失**再加重——"感觉好了就冲"是复发率最高的坑

## 五、预防（比处理值钱十倍）

1. **热身/渐进**：见[热身与拉伸方案](热身与拉伸方案.md)，大项先做递增热身组
2. **动作质量 > 重量**：见[动作要领](三分化动作要领.md)铁律"重量宁轻勿变形"
3. **姿势自查**：深蹲膝盖别内扣、硬拉腰背中立、卧推肩胛收拢（见动作要领每节的常见错误）
4. **别连续两周加重量**：用[训练数据复盘与进阶](训练数据复盘与进阶.md)的 deload 安排保护关节
5. **睡够**：见[有氧与恢复方案](有氧与恢复方案.md)——睡眠是恢复三支柱之首

## 六、记录（用数据发现隐患）

- 训练记录加**"疼痛"标记**：部位 / 程度（1-5）/ 练前练后对比
- 疼痛**连续出现** → 先查动作，再考虑降重，别硬练到伤
- 每周复盘扫一眼疼痛记录（配合[训练数据复盘与进阶](训练数据复盘与进阶.md)）

---

## 七、本轮项目推荐：做一张「伤情自查与应急卡」

**推荐做什么**：把第二节速查表 + 第三节红旗信号做成**一页「伤情自查与应急卡」**（症状→判断→处理→何时就医），打印贴训练区或存手机备忘录；同时给[训练记录](健身数据/训练记录.md)加一个**"疼痛"字段**，每次训练顺手记。

**为什么值得做**：
- 三分化大量深蹲/硬拉/卧推，伤是最大变量——一张卡能在"该不该停"的犹豫瞬间给答案；
- 记录疼痛能**早发现隐患**，避免小伤拖大伤、大伤清零进度；
- 成本一张纸 + 一个字段，马上能用，直接配套[动作要领](三分化动作要领.md)/[退阶表](动作退阶与进阶选择表.md)/[复盘](训练数据复盘与进阶.md)。

**具体怎么做**：
1. 做卡片：酸痛/疼痛/伤三档判断 + 四部位速查表 + 红旗信号清单
2. 训练记录加"疼痛"字段（部位 / 程度 1-5 / 练前练后）
3. 每周复盘扫一眼疼痛记录，连续出现 → 安排退阶或 deload

**产出**：1 页伤情自查卡 + 训练记录里的疼痛字段 → 与动作要领/退阶表/复盘直接配套，是你的"止损阀"。
