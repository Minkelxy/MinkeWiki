# 补剂与恢复辅助

[饮食落地指南](饮食落地指南.md)讲"吃什么食物"，本文讲**"要不要补剂"**。减脂 / 训练期的补充剂判断——**大多数补剂是营销，少数有证据**。核心一句：**先食物后补剂，先睡眠后补剂**。

> 一句话结论：**蛋白粉 + 肌酸够了，别的先别买。**

---

## 一、先给结论（省心版）

| 补剂 | 值不值 | 说明 |
|------|--------|------|
| **蛋白粉** | ✅ 值得 | 凑不够蛋白时用（见[饮食落地指南](饮食落地指南.md)） |
| **肌酸** | ✅ 值得 | **证据最充分的训练补剂**，提高力量耐力 |
| **咖啡因** | ✅ 可 | 训练前提神，注意耐受和睡眠 |
| **维生素 D** | ✅ 看情况 | 日照少 / 室内多建议补 |
| BCAA / 燃脂丸 / 左旋肉碱 | ❌ 不值得 | 营销为主，证据弱 |

## 二、每个补剂怎么用

| 补剂 | 用法 |
|------|------|
| **蛋白粉** | 凑蛋白缺口（训练后 / 加餐），乳清即可，**别买贵的"水解"** |
| **肌酸** | 每天 3-5g，**无需"冲击期"**，长期吃；水要喝够 |
| **咖啡因** | 训练前 30-60 分钟，200mg 左右；**下午后别喝**（影响睡眠） |
| **维生素 D** | 测过缺再补，2000 IU 常见；不晒太阳就补 |

> 减脂期**蛋白优先**：补剂是补充、不是替代——先吃够食物，补剂只补缺口。

## 三、比补剂更值钱的"恢复辅助"（免费）

| 免费项 | 在哪 |
|--------|------|
| **睡眠**（恢复三支柱之首） | [有氧与恢复方案](有氧与恢复方案.md) |
| 蛋白质优先的饮食 | [饮食落地指南](饮食落地指南.md) |
| 训练后拉伸 / 放松 | [热身与拉伸方案](热身与拉伸方案.md) |
| 数据监控（静息心率 / HRV） | [训练数据复盘与进阶](训练数据复盘与进阶.md) |

> 这些**不花钱，效果远大于补剂**——先把免费的做完，再考虑花钱的。

## 四、避坑清单（别交智商税）

- ❌ 宣传"**快速燃脂 / 局部瘦**"的——都是营销
- ❌ 三无产品 / 来路不明——**只买正规品牌**
- ❌ 叠加太多——补剂不是药，不是越多越好
- 减脂期：**咖啡因可以，燃脂丸别碰**（伤心脏 / 失眠）

---

## 五、本轮项目推荐：做一张「补剂采购清单」

**推荐做什么**：做一张 1 页「补剂清单」：值得买的（蛋白粉 / 肌酸 / 咖啡因 / 维 D）+ 用法用量 + 避坑项，写清楚"**先补食物和睡眠，再考虑补剂**"。

**为什么值得做**：
- 健身人群**最容易在补剂上交智商税**——一张清单省几百上千；
- 蛋白粉 / 肌酸用法记下来不踩坑；
- 和[饮食落地指南](饮食落地指南.md)配套，是减脂期"该不该花钱"的决策表。

**具体怎么做**：
1. 按第一节表，标"要买 / 不买"
2. 记用法用量（蛋白粉几勺 / 肌酸 3-5g / 咖啡因时间）
3. 贴一张"**先免费后花钱**"的优先级提醒

**产出**：1 页补剂采购清单 → 与饮食落地指南配套，避免补剂智商税。
