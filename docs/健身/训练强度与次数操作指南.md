# 训练强度与次数操作指南（每组几次 / 休息多久 / 留几个余量）

[三分化动作要领](三分化动作要领.md)讲"动作怎么做"，[训练数据复盘与进阶](训练数据复盘与进阶.md)讲"何时加重"，本文补中间的**操作层**——次数区间、组间休息、RIR 实操、加量节奏。三分化执行时**每天都用得上**。

> 一句话：**次数区间选对目标，休息够再上重量，留余量别组组力竭**——参数对了训练才有效。

---

## 一、次数区间与目标（选对区间）

| 目标 | 次数 | 重量 | 适用 |
|------|------|------|------|
| **力量** | 3-6 次 | 重（85%+） | 三大项冲 PR |
| **肌肥大** | 8-12 次 | 中（70-80%） | **减脂保肌 / 塑形主力** |
| **耐力 / 线条** | 15+ 次 | 轻 | 辅助 / 热身 |

> 减脂期：**肌肥大区间（8-12）是保肌主力**——别全程小重量高次数。

## 二、组间休息（定好别拖）

| 动作 | 休息 |
|------|------|
| 复合（深蹲 / 卧推 / 硬拉） | **2-3 分钟** |
| 孤立（弯举 / 侧平举） | 60-90 秒 |
| 核心 / 高次数 | 45-60 秒 |

> 休息够了再上重量，**别赶时间**——恢复不足的组是负效率。

## 三、RIR / RPE 实操（留几个余量）

- **RIR**：还能再做几组的余量（RIR2 = 这组做完还能做 2 次）
- **RPE**：自感用力（10 = 力竭）；RPE8 ≈ RIR2
- 实操：**正式组一般留 RIR 1-2**（别每组都力竭），力竭留给最后一组
- 减脂期：训练表现波动大，**RIR 比 RPE 更实用**（见[数据复盘](训练数据复盘与进阶.md)的 RPE 记录）

## 四、加量节奏（接[数据复盘](训练数据复盘与进阶.md)）

- **连续 2-3 次达标**（次数全做完 + RIR 达标）→ 加重 2.5-5kg（上肢 2.5 / 下肢 5）
- **先涨次数再涨重量**：如 8 次做到 12 次，再加重量回到 8 次
- 停滞：查动作 / 恢复（见[伤病](伤病预防与康复指南.md) / [坚持](减脂坚持与习惯养成.md) / 数据复盘）

## 五、本周怎么排（示例）

- 大项：3-5 组 × 5-8 次，RIR 1-2，组间 2-3 分钟
- 辅助：3 组 × 8-12 次，组间 90 秒
- 有氧日不动力量

---

## 六、本轮项目推荐：做「训练变量速查卡」

**推荐做什么**：把本节**次数区间 / 组间休息 / RIR** 做成一张 **1 页速查卡**，贴训练区——练前扫一眼定组数 / 次数 / 休息。

**为什么值得做**：
- 三分化执行时最常问"这次做几组几次休息多久"——**一张卡免每次查**；
- **参数对了训练才有效**（次数区间错了 = 白练）；
- 和[动作要领](三分化动作要领.md) / [数据复盘](训练数据复盘与进阶.md)配套，是训练的"**参数底座**"。

**具体怎么做**：
1. 填次数区间表（力量 / 肌肥大 / 耐力）
2. 填组间休息表（复合 / 孤立 / 核心）
3. 记 RIR 用法（正式组留 RIR 1-2）

**产出**：1 页训练变量速查卡 → 贴训练区，三分化每次训练的执行参考。
