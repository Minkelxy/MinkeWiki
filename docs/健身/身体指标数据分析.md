# 身体指标数据分析

看懂你记录的身体指标（体重、腰围、围度、血压、力量），判断**进展对不对、有没有问题**。配合[身体指标追踪](健身数据/身体指标追踪.md)的数据。

---

## 一、看哪些指标（各看什么）

| 指标 | 反映 | 看什么 |
|------|------|--------|
| 体重 | 总量变化 | 长期趋势 |
| 腰围 | 腹部脂肪 | **减脂最直接** |
| 围度（臂/腿/胸） | 肌肉/脂肪 | 练对没练对 |
| 血压/心率 | 健康 | 异常预警 |
| 力量（卧推/深蹲） | 力量保持 | 减脂期别掉太多 |

## 二、趋势 vs 单日（核心方法）

- **看移动平均/周趋势**，不看单日——单日 ±1kg 都是水分
- 简单做法：每周一同一条件记录，看 4 周连起来
- 平台期判断也用趋势（见[减脂平台期突破方案](减脂平台期突破方案.md)）

## 三、指标间关系（组合判断才准）

| 组合 | 含义 | 行动 |
|------|------|------|
| 体重掉 + 腰围掉 | 减脂正常 | 继续 |
| 体重不动 + 腰围掉 | **减脂不减重**（好事） | 别焦虑体重 |
| 体重掉 + 力量狂掉 | 掉肌肉了 | 蛋白/热量加回来 |
| 腰围涨 + 体重涨 | 可能吃多了 | 回调饮食 |

> **单一指标会骗人，组合判断才可靠**——这正是为什么照片 + 围度 + 体重一起记。

## 四、异常识别

| 异常 | 可能原因 | 处理 |
|------|---------|------|
| 血压持续偏高 | 盐多/压力/恢复差 | 记录并留意，必要时就医 |
| 静息心率走高 | 训练过度/睡眠差 | 减量 + 补睡（见[有氧恢复](有氧与恢复方案.md)） |
| 围度无变化 2 月+ | 训练平台 | 见[周期化进阶](训练周期化进阶.md) |
| 体重平台 2-4 周 | 代谢适应 | 见[平台期方案](减脂平台期突破方案.md) |

## 五、用数据做决策

1. 每周复盘把[训练数据复盘与进阶](训练数据复盘与进阶.md)的容量/强度 + 身体指标放一起看
2. 记录存自建后端（`api_server.py`），可导出 CSV 分析
3. **数据是工具不是目的**——指标异常先看生活习惯，别只盯着数字焦虑
