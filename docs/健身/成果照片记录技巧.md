# 成果照片记录技巧

把每月健身照片拍得**能看出变化**——照片比体重秤更可靠地反映体型变化。配合你的[照片记录索引](成果照片/照片记录索引.md)系统。

---

## 一、为什么照片比体重可靠

- 体重受水分影响大（单日 ±1kg 正常）
- 照片记录的是**体型/体脂变化**——减脂期体重没掉但腰围小了，照片能看出来
- 三个月对比，照片是最直观的"成绩单"

## 二、标准化的关键（没有标准 = 白拍）

每次尽量**相同**：

| 维度 | 要求 |
|------|------|
| 时间 | 早晨空腹（固定） |
| 光线 | 同一光源、同方向 |
| 背景 | 同一面墙/同位置 |
| 服装 | 相同贴身衣物（背心/短裤） |
| 姿势 | 固定站姿、手放同处 |

> 标准化的意义：**只有控制变量，照片才反映真实变化**——换姿势/光线会骗人。

## 三、三个角度

| 角度 | 看什么 |
|------|--------|
| 正面 | 腰腹、胸、手臂轮廓 |
| 侧面 | 腹部平坦度、体态 |
| 背面 | 背阔肌、肩胛 |

> 每角度拍 1-2 张，选一张最好的存档（别贪多）。

## 四、拍摄技巧

1. **光线**：自然光（窗边）或固定灯位；避免顶光（显阴森）和背光
2. **距离构图**：全身入框，头顶留一点空间，别裁掉脚
3. **对焦**：拍自己时对准身体中段，别对着背景
4. **放松自然**：别憋气鼓劲，自然站姿才反映真实状态

## 五、对比方法（让变化显形）

- **并排对比**：把两个月同姿势照片并排，一眼看变化
- **加围度数字**：照片旁边标腰围/体重，数据 + 影像双印证（见[身体指标追踪](健身数据/身体指标追踪.md)）
- 每月对比，比每张单独看更有说服力

## 六、归档与索引

- 命名规范（已有）：`YYYY-MM-DD_部位_角度.jpg`
- 按 `成果照片/2026/MM/` 归档，更新[照片记录索引](成果照片/照片记录索引.md)
- 可配合[定时拍照装置](../制作/定时拍照装置.md)自动固定机位拍摄

## 七、检查清单

- [ ] 相同时间/光线/背景/服装/姿势？
- [ ] 正面 + 侧面 + 背面都拍了？
- [ ] 按规范命名并归档？
- [ ] 与上月并排对比，记录变化？
