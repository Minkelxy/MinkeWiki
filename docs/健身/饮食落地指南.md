# 饮食落地指南

把[减重执行方案](减重执行方案.md)里的框架（每日 2273 大卡、蛋白 ~170g、5:3:2 比例）变成**具体能吃的三餐**。核心：**蛋白先吃够，碳水往训练日堆。**

---

## 一、先定框架

| 项 | 目标 |
|----|------|
| 总热量 | 约 2273 大卡/天 |
| 蛋白质 | 约 170g/天（30%）→ **优先保证** |
| 碳水 | 约 50%——训练日略高、休息日略低 |
| 脂肪 | 约 20%——别压太低 |

> 优先级：蛋白 > 总热量 > 碳水比例。三样全抓容易崩，先保蛋白。

## 二、蛋白质来源（每餐 30-40g）

| 食物 | 每 100g 蛋白 | 备注 |
|------|-------------|------|
| 鸡胸肉 | ~31g | 减脂主力 |
| 瘦牛肉 | ~26g | 训练日/增味 |
| 鸡蛋 | ~13g/个 | 蛋黄胆固醇正常量没问题 |
| 鱼/虾 | ~20-25g | 脂肪低 |
| 豆腐/豆浆 | ~8-12g | 素食补位 |
| 乳清蛋白粉 | ~70-80g/100g | 不够时补差 |

**怎么凑 170g**：早餐 40g + 午 50g + 晚 50g + 训练后/加餐 30g，一天达标。

## 三、碳水怎么选

- **复杂碳水为主**：米饭、燕麦、红薯、全麦——饱腹感强
- **训练后快碳**：白米饭/香蕉，练后 1 小时补糖原
- 减脂期碳水**别砍光**：这是训练表现和心情的来源，砍光必反弹

## 四、脂肪别压太低

- 每公斤体重约 0.6-1g 脂肪，过低影响激素（睾酮/代谢）
- 优质来源：橄榄油、坚果（一小把）、鱼、蛋黄

## 五、三餐示例（约 2273 大卡）

| 餐 | 内容（示意） | 蛋白 |
|----|-------------|------|
| 早餐 | 燕麦 60g + 鸡蛋 3 个 + 牛奶/豆浆 | ~35g |
| 午餐 | 米饭 200g + 鸡胸 200g + 蔬菜 | ~55g |
| 训练后 | 乳清 1 勺 + 香蕉 1 根 | ~25g |
| 晚餐 | 米饭 150g + 鱼/牛肉 200g + 蔬菜 | ~50g |

> 这是**示意结构**，按你实际食物替换；重量用食物秤称两周就有手感。

## 六、放纵餐（每 15 天一次）

- 放在**训练日之后**，练后补糖原损失最小
- 放开吃一顿、别连吃一天，第二天正常

## 七、实践技巧（坚持比完美重要）

1. **先称后估**：头两周用食物秤，之后目测就能估
2. **预制备餐**：周末一次做 3-4 份鸡胸/米饭分装，工作日拿出来就吃
3. **外食怎么选**：优先"肉 + 饭 + 菜"的组合，避开油炸和甜饮料
4. **别为一顿崩盘放弃**：偶尔超了，下一顿正常吃就回来，别补偿性节食
