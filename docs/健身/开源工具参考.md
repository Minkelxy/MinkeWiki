# 健身开源工具参考

健身栏目已自建数据后端（`api_server.py` + `data/` 下的 JSON），这里整理可对照借鉴或补充的开源工具。**Star 数为 2026-08-05 抓取时的真实数据**，点击项目名直达仓库。

## 🏋️ 训练与数据追踪

| 开源项目 | Star | 技术栈 | 说明 |
|---------|------|--------|------|
| [wger-project/wger](https://github.com/wger-project/wger) | 6.6k | Python | 自托管健身/饮食/体重追踪器，功能模块完整，可对照自建后端的数据模型 |

## 💡 落地建议

- 自建后端已覆盖**训练记录 / 身体指标 / 成果照片**，若想加**营养摄入、饮食追踪、训练模板库**等模块，可直接参考 **wger** 的表结构与模块划分
- 训练计划部分，[周训练计划](../健身/健身计划/周训练计划.md) 的模板结构可借鉴 **workout-cool** 的计划组织方式
- 数据仍在本地 `data/` JSON + 自建 API 管着，与 wger 这类自托管方案互不影响，可作为功能对照清单
