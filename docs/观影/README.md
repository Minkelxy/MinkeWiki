# 观影记录

记录看过的电影 / 剧集 / 动画，附简评与评分。

## 记录约定

- 每部作品一个文件：`docs/观影/<作品名>.md`
- 看完再写，避免烂尾
- 新作品文件需在 `mkdocs.yml` 的「观影记录」栏目登记（nav 手工维护）

## 模板

按作品类型和想写的深度，选一个模板复制使用。
