# 娱乐区与展示墙设计

把[装修计划](index.md)里的**痛墙、动漫壁纸、榻榻米、钢制书柜、头盔架**等想法做成具体方案——这里是"住和玩"的核心区。

---

## 一、区域定位

| 区域 | 定位 |
|------|------|
| 主活动区（投影/游戏机/电脑/VR） | 娱乐中心，地面留空 |
| 榻榻米区（中间） | 休息/聚会/客卧，可升降 |
| 展示区（痛墙 + 书架 + 装备） | 视觉焦点，体现风格 |
| 床上方货架 | 储藏（疏解北京置物压力） |

> 原则：**展示区做焦点，其他区域别抢戏**——乱和挤是最破坏"整洁"的。

## 二、痛墙方案（重点）

按你的想法：**PVC 漫画板 + A4 背景 + 炸小人板，工业风**。

| 项 | 建议 |
|----|------|
| 结构 | 主面用 **PVC 漫画板**做底（耐脏、可擦写），配 A4 背景装饰 |
| 炸小人板 | 作为视觉中心，板面做棋盘/展示格 |
| 工业风 | 金属边框、黑色线缆走明装、铆钉细节 |
| 安装 | **免打孔**（3M 挂条/轨道），方便换内容 |
| 可替换 | 漫画板做成**可换插页**，想换风格随时换 |

## 三、动漫 / 游戏壁纸

- **两面墙不同风格**（动漫 + 游戏）：两面相对或相邻，避免视觉打架
- 配色建议：**一面深色主打 + 一面浅色**，别两面都深（显小、压抑）
- 与痛墙呼应：壁纸选同一作品宇宙，整体统一

## 四、榻榻米与换桌

| 项 | 建议 |
|----|------|
| 榻榻米 | 中间区域做成，收纳 + 休息一体；可选**升降桌**（麻将/聚会模式） |
| 换掉烂桌子 | 旧桌替换为与榻榻米配套的矮桌或工作桌 |
| 飘窗 | 利用飘窗做阅读/储物角，别浪费 |

## 五、展示与收纳

- **钢制书柜**（已确认现代风）：摆书 + 手办/谷子分层展示，层高可调
- **头盔架**：游戏装备/头盔做展示，放展示区墙面
- **床上方货架**：储藏为主，别堆装饰物（挡住光线）

## 六、灯光与氛围

- **游戏氛围灯**：RGB 灯带贴墙/桌沿，配合痛墙出效果（可接[智能家居](智能家居开源参考.md)用 WLED 类方案）
- **投影区遮光**：投影正对的墙避免强光，可加遮光帘
- **阅读/工作灯**：榻榻米区一盏暖色落地灯，和氛围灯分开控制

## 七、预算与执行顺序

| 顺序 | 项 | 优先级 |
|------|----|--------|
| 1 | 壁纸 + 榻榻米基础 | 硬装期做 |
| 2 | 书柜 + 换桌 | 软装 |
| 3 | 痛墙 + 展示板 | 软装 |
| 4 | 灯光/氛围 + 收纳货架 | 最后 |

> 痛墙和展示板**先定尺寸再施工**——书柜、投影、榻榻米的位置定了，墙上的东西才不会打架。
