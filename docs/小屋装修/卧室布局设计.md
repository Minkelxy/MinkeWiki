# 卧室布局设计

卧室的功能分区与布局规划——睡眠、储物（床顶货架）、梳妆兼顾，衔接[收纳设计](收纳设计.md)的床顶货架。

---

## 一、卧室功能分区

| 区 | 内容 | 优先级 |
|----|------|--------|
| 睡眠区 | 床（核心） | ⭐⭐⭐ |
| 储物区 | 床顶货架、衣柜 | ⭐⭐⭐（你的需求） |
| 梳妆/工作区 | 梳妆台、小书桌（可选） | ⭐ |

> 卧室第一是**好睡**：床的位置和光线比装饰重要。先定床，再定其他。

## 二、床与货架布局

- **床位置**：优先靠墙/不直对门；床头留床头柜位、避免空调直吹头
- **床顶货架**：靠床尾或侧墙上方（见[收纳设计](收纳设计.md)），**承重钢架 + 装稳固**，重物放下层
- **动线**：床两侧或至少一侧留 60cm 以上通行，别堵

## 三、衣柜与储物

- **衣柜位置**：床的对面或侧墙，留够开合空间（衣柜门/抽屉的拉开距离）
- 分区：挂区 > 叠区 > 抽屉（常穿的挂起来最好拿）
- 与床顶货架配合：**常用低、不常用高**（货架放不常用的）

## 四、灯光与窗帘

- **灯光**：暖光（2700K）+ 床头阅读灯/夜灯（见[灯光设计](灯光设计方案.md)）
- **窗帘**：**遮光帘**（睡眠关键）——比装饰窗帘重要
- 开关/插座在床头两侧都留（手机充电、床头灯）

## 五、小户型技巧

1. **垂直利用**：床顶货架 + 到顶衣柜，把墙做满
2. **床下收纳**：床架选带抽屉/箱体的，放换季衣物
3. **多功能床**：带储物箱体床，或可折叠（如客卧用）
4. 少摆装饰物——卧室越空越好睡（见[收纳](收纳设计.md)的"隐藏 vs 展示"）
