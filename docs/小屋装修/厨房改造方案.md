# 厨房改造方案（改鞋柜 + 洗衣/冰箱区）

对应[装修计划](index.md)里"**厨房不打算要，弄成鞋柜，放洗衣机冰箱**"。把"弃用厨房"变成"**玄关 + 洗衣 + 储物**"的多功能区——拆除、水电、排水、布局一次讲清。

> 一句话：原厨房的**水路/电路/地漏是资产**——改造的难点不是"拆掉厨房"，是"把水电改得顺"。

---

## 一、先定改造目标（你的需求）

| 区 | 说明 |
|----|------|
| **鞋柜区** | 厨房改玄关的鞋柜（见[收纳设计](收纳设计.md)的玄关分区） |
| **洗衣区** | 洗衣机（可能叠放烘干机）放这里，需进出水 |
| **冰箱位** | 冰箱留位 + 散热空间 |

> 三合一改造，动线顺起来：**进门 → 放鞋 → 放包 → 顺手洗 / 取物**。

## 二、拆除阶段（安全红线先讲）

- **燃气**：灶具 / 燃气管改接**必须燃气公司或有资质人员**，别自己动（见《城镇燃气管理条例》）
- **承重墙**：烟道 / 管井周边先确认不是承重——**承重墙不能拆**
- 水槽 / 橱柜拆除：**断水断电**；原水槽下水要么封堵要么改接洗衣机
- **烟道口要封**：弃用厨房记得封好烟道 / 通风口，防串味

## 三、水电改造（原厨房的水电是资产）

| 项 | 做法 |
|----|------|
| **进水 / 排水** | 原水槽位正好给洗衣机（上水 + 地漏排水）；烘干机也要电源 |
| **电路** | 原厨房插座位多，给冰箱 / 洗衣机 / 烘干机各规划一路 |
| **防水** | 洗衣区做**防水**（地面 + 返墙 30cm+），地漏保留——比原厨房要求高 |

> 水电是返工最贵的地方——**一次规划清楚，别等贴完砖再改**（见[装修公司沟通避坑](装修公司沟通避坑.md)）。

## 四、布局（三区动线）

```
进门 → 鞋柜（换鞋）→ 洗衣机 / 烘干机（顺手洗）→ 冰箱（取放）
```

- **鞋柜靠门侧**：进深 35-40cm 够普通鞋，见[收纳设计](收纳设计.md)的玄关分区
- **洗衣区预留**：洗衣机位宽 60cm+，留**排水 + 电源 + 操作台**；烘干机可叠放省地
- **冰箱位**：留散热空间，**别紧贴柜体**（两侧 / 背后留缝）

## 五、细节（鞋柜 + 灯 + 防潮）

- **鞋柜**：顶天立地 + 换鞋凳 + 底部灯带（进门感应），透气门板防潮
- **洗衣区防潮**：排风扇 / 留缝；地面坡度向好
- 配合[灯光设计方案](灯光设计方案.md)：玄关感应灯、洗衣区照明

## 六、预算与验收

- **预算**：拆除 + 水电改 + 鞋柜定制 + 防水，约 5k-1w（视面积，见[装修预算规划](装修预算规划.md)）
- **验收**（见[入住前检查清单](入住前检查清单.md)）：进出水无漏、洗衣机试机排水顺畅、冰箱散热空间够、鞋柜门开合顺

---

## 七、本轮项目推荐：做「厨房改造三区布局图」

**推荐做什么**：画一张"**厨房改鞋柜 + 洗衣 + 冰箱**"的三区平面图（含尺寸 / 水电点位 / 动线箭头），标注水电改造点（上水 / 排水 / 电源 / 防水范围），给装修公司直接照着施工和报价。

**为什么值得做**：
- 这是你计划里**明确要做的一步**（index 里"厨房弄成鞋柜放洗衣机冰箱"）；
- **有图才能让装修公司报价准确、施工不跑偏**——拆改和水电是返工最贵的地方，一次规划清楚省大钱；
- 三合一（鞋柜 + 洗衣 + 冰箱）动线规划好了，日常使用才顺。

**具体怎么做**：
1. 量厨房尺寸，画平面（进门 / 门侧 / 窗位）
2. 标三区：鞋柜区 / 洗衣区 / 冰箱位，各带尺寸
3. 标水电：上水、地漏排水、各设备电源、防水范围
4. 给装修公司报价 / 沟通（见[装修公司沟通避坑](装修公司沟通避坑.md)）

**产出**：一页「厨房改造三区布局图」→ 进装修施工图，是厨房改造的施工 + 报价依据。
