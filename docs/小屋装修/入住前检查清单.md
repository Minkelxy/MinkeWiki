# 入住前检查清单

搬家前**逐项验收**，别把问题带进门。承接[装修公司沟通避坑](装修公司沟通避坑.md)的完工验收，这是最后一遍总检查。

---

## 一、硬装验收（搬家前最后确认）

- [ ] 水电：插座逐个通电、开关、水压、地漏倒水看坡度
- [ ] 防水：闭水试验已过（见[避坑](装修公司沟通避坑.md)）
- [ ] 墙面/地面：平整无开裂、踢脚线贴实
- [ ] 门窗：开合顺、密封好、锁正常
- [ ] 马桶/洗手台：通水、无渗漏

> 硬装问题**入住前发现**最好修；住进去再发现，返工麻烦得多。

## 二、家电安装

- [ ] 冰箱/洗衣机/投影到位通电试机（见[家电选购](家电选购指南.md)）
- [ ] 以旧换新的旧机已处理，留好票据
- [ ] 安装产生的包装/垃圾清走

## 三、智能设备联调

- [ ] 指纹锁装好 + 设好指纹/密码
- [ ] 窗帘电机、灯具联调（见[灯光设计](灯光设计方案.md)）
- [ ] 智能家居中枢（HA）跑起来（见[智能家居](智能家居开源参考.md)）
- [ ] **网络设备上架**：软路由/交换机/NAS/服务器，全屋 Wi-Fi 测速（见[网络存储](网络与存储规划.md)）

## 四、软装与清洁

- [ ] 壁纸/榻榻米/书柜/床顶货架到位（见[收纳](收纳设计.md)）
- [ ] 痛墙/展示板安装（见[娱乐区](娱乐区与展示墙设计.md)）
- [ ] **深度清洁**：搬家前做一次全屋清洁，比搬完再打扫省力

## 五、安全

- [ ] 燃气/烟雾报警器（如有）测试
- [ ] 逃生路线、灭火器
- [ ] 热水器/燃气灶（如有）安全检查

## 六、入住 3 天后再复查

- 住 3 天后复查：漏水渗水、电器异常、Wi-Fi 死角
- 有问题的**立刻找施工方**（质保期内，别拖）
- 尾款/质保金在确认无问题后结清（见[避坑](装修公司沟通避坑.md)）
