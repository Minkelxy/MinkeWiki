# 装修公司沟通避坑指南

第一次装修，和装修公司打交道怎么不踩坑。配合[预算规划](装修预算规划.md)的三份报价对比，本文件讲**怎么谈、怎么签、怎么验收**。

---

## 一、选公司之前

| 项 | 建议 |
|----|------|
| 资质 | 看营业执照、施工资质、案例 |
| 口碑 | 问熟人/看工地，别只看广告和低价 |
| **别只看报价低** | 低价常是"漏项"——后面靠增项补回来 |

> 先看 2-3 家**分项报价**对比（见[预算规划](装修预算规划.md)），再谈细节。

## 二、谈的时候问清这几句

1. **"这个报价含什么、不含什么？"**——漏项提前曝光
2. **"增项怎么算？"**——问清增项单价，别让最后结算吓一跳
3. **"工期多久、延期怎么赔？"**——写进合同
4. **"水电/防水做多少？"**——这两项最容易被"省"掉

## 三、合同要点（白纸黑字）

| 要点 | 说明 |
|------|------|
| 材料清单 | 品牌/型号写清，别写"高档材料" |
| 付款节点 | 别一次付清，按节点（开工/水电/泥瓦/完工）分付 |
| 增项 | **任何增项先书面确认再施工** |
| 质保 | 水电/防水质保期（一般 2-5 年）写进合同 |

## 四、施工中（别全托管）

- **节点验收**：水电、防水做完先验收再覆盖（防水必须闭水试验）
- **拍照留证**：隐蔽工程（线管/防水）覆盖前拍照存档
- **常去工地**：发现问题当场说，别等完工一起算账
- 关键材料进场时**核对品牌型号**，别被偷换

## 五、验收（完工别急着签字）

- **闭水试验** 48h（防水）
- 插座逐个通电、开关、通水测水压、地漏倒水看坡度
- 墙面/地面平整、门开合、窗密封
- **尾款留一部分**：验收后几个月无问题再结清（质保金）

## 六、检查清单

- [ ] 看过 2-3 家分项报价，非一口价？
- [ ] 合同写了材料品牌 + 付款节点 + 增项规则？
- [ ] 水电/防水做完验收 + 拍照？
- [ ] 闭水试验 + 完工逐项验收？
- [ ] 尾款按质保期留了一部分？
