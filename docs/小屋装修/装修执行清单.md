# 装修执行清单

把你的[装修计划](index.md)笔记整理成**推荐执行顺序**——按「先硬装、后软装、再智能」的原则排优先级，避免返工和漏项。

---

## 一、整体顺序（推荐 4 个阶段）

```
阶段0 定方案 → 阶段1 硬装改造 → 阶段2 软装布置 → 阶段3 智能设备
```

**理由**：网线、电源、防水这些硬装改完就改不回来了，必须最优先；软装（壁纸/家具）在硬装基础上做；智能设备最后装，避免被施工弄坏。

## 二、阶段 0：定方案（先做）

| 事项 | 推荐动作 |
|------|---------|
| 联系装修公司 | 先谈**卫生间 + 厨房**两处改造，这是你最有想法的部分 |
| 确认卫生间方案 | 干湿分离 + 独立淋浴 + 浴缸 + 智能马桶 + 独立梳妆台 |
| 确认厨房方案 | 不保留厨房 → 改成鞋柜 + 洗衣机/冰箱区（或至少把洗衣机挪出来） |
| 预算与工期 | 让装修公司分项报价，再决定自装 vs 全包 |

## 三、阶段 1：硬装改造（动工期，错过后难补）

| 优先级 | 项目 | 说明 |
|--------|------|------|
| ⭐⭐ | 卫生间大改 | 防水/干湿分离/浴缸/智能马桶，工程最大、最该先做 |
| ⭐⭐ | 线路布置 | 网口/电源点位，见[网络与存储规划](网络与存储规划.md)——留网线比什么都重要 |
| ⭐ | 厨房改鞋柜 | 水电改造同步做，洗衣机进水/排水留好 |
| ⭐ | 飘窗/榻榻米基础 | 中间区域改榻榻米，地面找平先做 |

## 四、阶段 2：软装布置

| 项目 | 推荐方案 |
|------|---------|
| 壁纸 | 两面墙不同风格（动漫 + 游戏），施工完硬装再贴 |
| 书柜 | 已确认**钢制现代风**，按硬装尺寸定制/购买 |
| 榻榻米 + 换掉烂桌子 | 中间区域，收纳 + 休息一体 |
| 痛墙 | PVC 漫画板 + A4 背景 + 炸小人板，工业风（采购"谷子"配件） |
| 货架 | 床的上方，解决北京置物压力的储藏需求 |
| 头盔架/装饰 | 游戏装备展示，配合墙纸风格 |

## 五、阶段 3：智能设备（软装后装）

| 设备 | 推荐 | 备注 |
|------|------|------|
| 指纹锁 | ✅ 先装 | 用起来最值，出门不带钥匙 |
| 自动窗帘 | ✅ 装 | 电机选 Zigbee 版（见[智能家居开源参考](智能家居开源参考.md)） |
| 灯具 | ✅ 装 | 可换智能开关（Tasmota/米家） |
| 空调伴侣 | ✅ 装 | 配合小爱音箱语音控制 |
| 智能马桶 | ✅ 装 | 卫生间改造时预留电源 |
| 投影仪/冰箱 | 以旧换新 | 冰箱按原计划以旧换新，投影仪选好位再布线 |
| 地毯 | 最后 | 家具进场后根据空间定 |

## 六、网络与存储（贯穿全程）

- **阶段 1 必须预埋**：弱电箱 + 各房间网口 + 摄像头点位（详见[网络与存储规划](网络与存储规划.md)）
- 阶段 3 后搭建：软路由 + NAS + 服务器（为[银川创业计划](../创业/README.md)做准备）

## 七、下一步推荐（现在就做）

1. **约 1-2 家装修公司**现场量房，拿卫生间/厨房改造报价
2. 同时定下：钢制书柜尺寸、榻榻米区域尺寸、网口点位清单
3. 装修动工前，把「智能设备清单」交给施工方预留电源
