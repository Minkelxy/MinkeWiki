# 装修阶段时间表

从动工到入住的**整体时间规划**——知道每阶段多久、该并行做什么，避免"边装边乱"。

---

## 一、整体周期参考

| 阶段 | 周期 |
|------|------|
| 硬装（设计到完工） | 约 1.5-2.5 个月 |
| 软装（家具家电进场） | 1-2 周 |
| 通风散味 | 1-2 个月（新装至少 1 个月） |
| **从动工到入住** | **约 3-4 个月** |

> 给小户型/改动少的按 3 个月估，改动大（卫生间大改）按 4 个月。

## 二、阶段划分与内容

| 阶段 | 周期 | 内容 |
|------|------|------|
| ① 设计定稿 | 2-3 周 | 方案、分项报价、签合同（见[避坑](装修公司沟通避坑.md)） |
| ② 拆改水电 | 2-3 周 | 拆改、水电、防水（卫生间大改在这阶段） |
| ③ 泥瓦木工 | 2-3 周 | 贴砖、吊顶、定制柜体 |
| ④ 油漆收尾 | 1-2 周 | 墙面、灯具、洁具安装 |
| ⑤ 软装进场 | 1-2 周 | 家具、家电、智能设备 |
| ⑥ 通风入住 | 1-2 月 | 散味、检查、入住（见[入住清单](入住前检查清单.md)） |

## 三、并行安排（省时间的关键）

| 硬装阶段 | 同步做什么 |
|---------|-----------|
| 设计定稿时 | **定家电/软装清单**（尺寸先行，见[家电选购](家电选购指南.md)） |
| 水电阶段 | 确认网络点位（见[网络存储](网络与存储规划.md)） |
| 泥瓦阶段 | 定软装样式（壁纸/榻榻米/书柜） |
| 油漆阶段 | 采购家具家电（等硬装完进场） |
| 收尾时 | 预约智能设备安装（见[智能家居](智能家居开源参考.md)） |

## 四、延期缓冲（必须有）

- 装修**几乎一定延期**：预留 **20-30% 时间缓冲**（3 个月计划按 4 个月安排）
- 关键路径：卫生间改造最耗时，别排太紧
- 与装修公司约定**工期与延期责任**（见[避坑](装修公司沟通避坑.md)）

## 五、关键节点提醒

| 节点 | 注意 |
|------|------|
| 闭水试验 | 防水做完必须 48h 试验（见[卫生间](卫生间改造方案.md)） |
| 水电验收 | 覆盖前拍照留证（见[避坑](装修公司沟通避坑.md)） |
| 完工验收 | 逐项查，尾款留质保金 |
| 通风 | 别省，新装散味 1 个月+ 再入住 |
