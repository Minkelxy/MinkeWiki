# 家电选购指南

对应[装修计划](index.md)里要换的家电（冰箱、滚筒洗衣机、投影仪等）的选购建议。**原则：先定尺寸位置，再买家电——尺寸错了最冤。**

---

## 一、冰箱（以旧换新）

| 项 | 建议 |
|----|------|
| 容量 | 单人/双人 200-300L；留储物需求就 300L+ |
| 类型 | 多门 > 双门 > 对开门（对开门占地大、放小户型浪费） |
| 关键参数 | 能效（一级优先）、噪音 |
| 以旧换新 | 确认补贴规则与回收流程，别让旧机占着新位置 |

> **先量预留位**（宽×深×高，含散热缝），再按尺寸选型号。

## 二、洗衣机 + 烘干机

| 项 | 建议 |
|----|------|
| 类型 | **滚筒**（推荐，省水、不伤衣、可叠放） |
| 容量 | 8-10kg 起步 |
| 烘干 | 独立烘干机 > 洗烘一体（一体机烘干容量小、易藏污） |
| 摆放 | 叠放最省空间，配叠放架；进排水配合[卫生间改造](卫生间改造方案.md) |

> 若按你的想法把洗衣机放厨房改区，进排水点位要提前留好（见[装修执行清单](装修执行清单.md)）。

## 三、投影仪（娱乐核心）

| 参数 | 建议 |
|------|------|
| 亮度 | 室内 ≥1500 ANSI 流明（有环境光时） |
| 分辨率 | 1080P 起步，4K 看预算 |
| 投射比 | 短焦更省距离，按房间纵深算画面尺寸 |
| 幕布 vs 白墙 | 先试白墙，效果不够再上幕布 |

**配套**：投影正对墙面**遮光**（见[娱乐区与展示墙设计](娱乐区与展示墙设计.md)）、预埋 HDMI/电源线、留好吊装或支架位置。

## 四、其他家电

| 设备 | 建议 |
|------|------|
| 空调伴侣 + 小爱音箱 | 已有，配[智能家居](智能家居开源参考.md)接入 |
| 灯具 | 主灯 + 氛围灯分开控制，留灯带位（见娱乐区设计） |
| 智能马桶 | 见[卫生间改造方案](卫生间改造方案.md)（坑距/预留插座） |

## 五、购买时机与顺序

- **以旧换新 / 大促**：冰箱这类大件等补贴窗口；急用的先买
- **顺序**：硬装后、家电进场前**先量尺寸**；窗帘/灯光先装，家电最后进场避免施工碰伤
- 大件**保留发票与尺寸记录**，退换更方便
