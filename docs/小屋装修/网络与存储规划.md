# 网络与存储规划

对应[装修计划](index.md)里的「放置网络设备、服务器、NAS」需求——这是后续[银川创业计划](../创业/README.md)的硬件底座，也是整个[智能家居](智能家居开源参考.md)的中枢。建议装修时一次性把线路和点位规划好。

---

## 一、总体拓扑

```
入户光猫
   │
   ├── 软路由（OpenWrt：拨号/防火墙/科学上网/分流）
   │         │
   │         ├── 主交换机（8-16口千兆）
   │         │       ├── NAS（存储/备份/媒体）
   │         │       ├── 服务器/工控机（HA/Frigate/创业服务）
   │         │       ├── 各房间网口（电视、书桌、卧室）
   │         │       └── 摄像头（PoE 或 Wi-Fi）
   │         └── Wi-Fi AP（Mesh，覆盖全屋）
   └── 弱电箱（放光猫+软路由+交换机）
```

## 二、核心设备选型（开源）

| 设备 | 开源方案 | 说明 |
|------|---------|------|
| 软路由 | [openwrt/openwrt](https://github.com/openwrt/openwrt) ★27.9k | 开源路由器固件，软路由/硬路由都能刷，拨号+分流能力强 |
| NAS 系统 | [openmediavault/openmediavault](https://github.com/openmediavault/openmediavault) ★6.9k | 开源 NAS 系统，插件丰富（RAID/SMB/NFS/Docker） |

- 服务器应用另见[智能家居开源参考](智能家居开源参考.md)：Home Assistant（中枢）、Frigate（监控）、mediamtx（媒体/直播）

## 三、装修时要留的东西（关键！）

| 点位 | 数量建议 | 用途 |
|------|---------|------|
| 弱电箱 | 1 个（够大） | 放光猫/软路由/交换机 |
| 每个房间网口 | ≥1 个 | 电视、书桌、卧室电视 |
| 电视墙网口 | 2 个 | 电视 + 机顶盒/游戏机 |
| 书房/工作台 | 2-3 个 | 电脑 + NAS + 服务器 |
| 摄像头点位 | 门口 + 客厅/室外 | 网线（PoE）或电源 |
| 电源 | 弱电箱旁 1 组 + 各点位 | 网络设备、NAS 供电 |

**务必预留**：网线建议六类（Cat6），NAS/服务器旁留电源+散热空间，别塞在封闭柜里。

## 四、NAS 与备份策略

### 自建 vs 成品

| 方案 | 优点 | 缺点 |
|------|------|------|
| 自建（OMV + 旧电脑/工控机） | 成本低、可控、可扩 | 需自己折腾 |
| 成品（群晖/威联通） | 开箱即用 | 硬件贵 |

### 磁盘与备份（3-2-1 原则）

- **3 份副本**：原始 + 备份 + 异地
- **2 种介质**：磁盘 + 云/外置
- **1 份异地**：至少一份不在家里

已有基础：`scripts/auto_backup.sh` 每天自动 git 提交、周日打 tar 快照。可把 **NAS 作为第二份存档**，再考虑一份异地（云盘）。

### RAID 简表（家庭推荐）

| 级别 | 冗余 | 容量 | 适用 |
|------|------|------|------|
| RAID 1 | 1 盘冗余 | 一半 | 重要数据 |
| RAID 5（3盘+） | 1 盘冗余 | n-1 | 平衡 |
| 无 RAID | 无 | 全部 | 只做归档、另有备份 |

## 五、服务器跑什么（结合创业）

| 应用 | 用途 | 关联 |
|------|------|------|
| Home Assistant | 智能家居中枢 | [智能家居开源参考](智能家居开源参考.md) |
| Frigate | 摄像头本地检测 | 安防 |
| mediamtx | 流媒体/直播分发 | [无人直播技术方案](../创业/抖音直播/无人直播技术方案.md) |
| ThingsBoard | IoT 数据平台（LoRa 监测产品后台） | [创业工具与开源参考](../创业/工具与开源参考.md) |
| 个人文件/媒体库 | 照片、视频归档 | 家庭数据 |

## 六、功耗与散热建议

- 软路由 + 交换机 + NAS + 服务器：估算 **30-80W**（低负载）
- 建议预留独立回路 + UPS（停电保护 NAS/服务器）
- 设备集中放书房一角，留通风或装个小风扇
