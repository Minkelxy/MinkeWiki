# 装修预算规划

把装修花费拆成几块、按优先级分配，避免"边装边超"。配合[装修执行清单](装修执行清单.md)的阶段，先定预算再动工。

---

## 一、预算框架（先分类再算钱）

| 分类 | 占建议 | 内容 |
|------|--------|------|
| **硬装改造** | 40-50% | 卫生间、水电、防水、厨房改区 |
| **软装布置** | 20-30% | 壁纸、榻榻米、书柜、家具、窗帘 |
| **家电** | 20-25% | 冰箱、洗衣机、投影、智能马桶 |
| **智能家居** | 5-10% | 指纹锁、窗帘电机、灯具、传感器 |
| **预留** | **10%** | 意外支出（一定有） |

> 比例是建议不是铁律，但**预留 10% 是必须的**——装修几乎没有不超预算的。

## 二、按优先级分配（钱花在刀刃上）

| 优先级 | 项目 | 建议 |
|--------|------|------|
| ⭐⭐⭐ | 卫生间改造 + 水电防水 | **别省**，返工成本是双倍 |
| ⭐⭐⭐ | 网络布线 | 一次布好，后面省事 |
| ⭐⭐ | 智能马桶 + 玻璃隔断 | 提升感最强的两笔（见[卫生间方案](卫生间改造方案.md)） |
| ⭐⭐ | 床/柜/榻榻米 | 天天用的别将就 |
| ⭐ | 壁纸/装饰 | 可后补、可分期 |
| ⭐ | 氛围灯/展示 | 有钱再上 |

## 三、控制技巧

1. **三份报价对比**：找 2-3 家装修公司，对比**分项报价**（别只比总价）
2. **分项报价，别一口价**：一口价容易藏猫腻，分项才看得出哪贵
3. **硬装阶段超支最多**：预算大头先谈死，软装/家电可以后置
4. **家电等大促/以旧换新**：见[家电选购指南](家电选购指南.md)

## 五、执行建议

- **硬装花钱、软装花时间**：硬装一步到位，软装可以慢慢添（别一次买全）
- **先签硬装合同**，软装和家电等硬装完再定——避免开工后资金紧张
- 每笔大项超支 5% 以上，先砍一个"优先级⭐"的项目补回来
