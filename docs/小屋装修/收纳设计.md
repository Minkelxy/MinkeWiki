# 收纳设计

全屋收纳规划——对应[装修计划](index.md)里"储藏功能"和"整洁不拥挤"的核心诉求。

---

## 一、收纳三原则

1. **就近收纳**：东西放"用的地方"（钥匙放玄关、毛巾放卫生间）——否则会随手乱丢
2. **分类 + 分区**：按类归位，固定位置，用完放回
3. **隐藏 vs 展示**：乱的藏起来（柜/盒），好看的展示出来（痛墙/手办）——**比例控制住就不乱**

> 收纳的本质不是"塞进去"，而是**每个东西有固定去处**。

## 二、分区收纳方案

| 区 | 收纳重点 |
|----|---------|
| 玄关 | 鞋柜（厨房改区正好用）、钥匙/伞挂钩 |
| 客厅/娱乐区 | 游戏机/手柄收纳盒、线材收纳（游戏装备见[娱乐区设计](娱乐区与展示墙设计.md)） |
| 卧室/床顶 | **床顶货架**（见下）、衣柜分区 |
| 卫生间 | 浴室柜收纳瓶罐、镜柜（见[卫生间方案](卫生间改造方案.md)） |

## 三、床顶货架（你的核心需求）

疏解北京置物压力的关键——**床上方做货架**：

| 项 | 建议 |
|----|------|
| 位置 | 床上方、床尾或靠墙一侧，别挡主要活动区 |
| 承重 | 选**承重钢架**（你已选钢制书柜，同思路），膨胀螺栓固定 |
| 安全 | 床是睡觉区，货架**务必装稳固**（防坠落）；重物放下层 |
| 用途 | 不常用的大件/收纳箱放上面，常用物放低处 |

> 床顶货架 = 把"垂直空间"变成储藏——小户型最实用的扩容手段。

## 四、展示 vs 收纳的平衡

- **展示区**（痛墙、手办、游戏装备）：好看的上墙/上柜，见[娱乐区与展示墙设计](娱乐区与展示墙设计.md)
- **收纳区**（杂物、不常用的）：进柜进箱，**别摆出来**——乱感都来自"什么都摆着"
- 规则：**台面只留 2-3 件常用的**，其余进收纳

## 五、收纳工具清单

- 透明收纳盒（看得见才不会忘）、分格盒（抽屉内）
- 挂钩/挂架（门后、墙面垂直利用）
- 移动置物架（厨房/卫生间临时用）
- 真空压缩袋（被子/冬衣）
