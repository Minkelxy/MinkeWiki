# 窗帘与遮光设计

把你计划里的「自动窗帘 + 投影遮光」落地——**遮光分场景、面料怎么选、安装何时定、电动怎么接**。承接[智能家居开源参考](智能家居开源参考.md)的窗帘电机方案。

> 一句话：**遮光不是越厚越好**——投影要"白天看不见外面"，卧室要"早上不被亮醒"，采光窗要"透光不透人"，三个需求三种窗帘。

---

## 一、先按场景定"遮光需求"（别一刀切全遮光）

| 场景 | 需求 | 遮光率建议 |
|------|------|-----------|
| **投影区**（客厅主墙） | **全遮光**（白天也能投） | **≥95%**（遮光布 / 卷帘盒） |
| 卧室睡眠 | 高遮光（不影响睡眠） | 80-95% |
| 客厅日常 | 半透（采光 + 隐私） | 30-60%（纱帘 / 半透帘） |
| 浴室 / 卫生间 | 隐私为主 | 磨砂贴膜 / 百叶 |

> 投影清晰度 ≈ 屏幕亮度 ÷ 环境光——**投影区遮光是"免费升级画质"**，比加钱换投影仪还值。

## 二、面料与形式选择

| 方案 | 特点 | 适用 |
|------|------|------|
| **遮光布**（涂层 / 黑丝） | 遮光率 90%+ | 投影 / 卧室 |
| **双层帘**（纱帘 + 遮光帘） | 白天纱帘采光、晚上拉遮光帘 | 客厅一杆两轨最实用 |
| 卷帘 / 百叶 | 整洁、好清洁 | 投影区、小窗 |

> 关键词：**投影白天用要"遮光率 95% 以上"**——普通窗帘只有 70-80%，别用错了。

## 三、安装要点（硬装阶段决定，返工贵）

- **窗帘盒 / 卷帘盒**：吊顶前定好；投影区用**卷帘盒**遮光更好（顶部不漏光）
- **预留电源**：电动窗帘电机要电源（或电池版但常换电池）——**硬装时在窗帘位留插座**
- 轨道：窗帘盒内轨道 vs 明装罗马杆——投影区选**轨道**（严丝合缝，两侧/顶部少漏光）
- 宽度：轨道长度 ≈ 窗宽 × **1.5-2 倍**（遮光褶皱才够）

## 四、电动窗帘（接入 Home Assistant）

**电机选型**：
- ✅ **Zigbee 版**：可入 [zigbee2mqtt](https://github.com/Koenkk/zigbee2mqtt)，本地化、不绑厂商云
- ⚠️ 米家 WiFi 版：方便但绑生态（见[智能家居开源参考](智能家居开源参考.md)的取舍）

**接线**：电机电源 + 协议接入（Zigbee → zigbee2mqtt → Home Assistant）

**自动化（HA，最出彩的部分）**：
- **定时**：早晨自动开、晚上自动关
- **联动**：投影开 → 窗帘自动关；闹钟响 → 窗帘开一条缝（自然光唤醒）
- **场景**：一键"观影模式" = 投影 + 窗帘 + 灯光同时变暗

## 五、和灯光 / 投影的配合

- **投影区**：遮光 + 屏幕周围弱光（见[灯光设计方案](灯光设计方案.md)）——别让环境光直射屏幕
- **卧室**：遮光 + 床头灯；注意自动窗帘开合改变自然光，会影响灯光场景，场景里一起联动
- **窗帘 + 灯光 + 投影**做成一个"模式"，别各管各的（见[娱乐区与展示墙设计](娱乐区与展示墙设计.md)）

## 六、预算与执行（对齐现有清单）

- 遮光帘：普通 500-1000 / 窗；电动电机 300-600 / 窗（见[装修预算规划](装修预算规划.md)）
- 与[装修执行清单](装修执行清单.md)的"自动窗帘 ✅ 装"对齐：**硬装阶段先留电源 + 窗帘盒/卷帘盒轨道**
- 验收：白天拉上，投影区无明显漏光；电机无噪音、HA / APP 可控

---

## 七、本轮项目推荐：做「观影 / 睡眠双场景窗帘自动化」

**推荐做什么**：在 Home Assistant 里给窗帘做两个场景自动化——**「观影模式」**（投影开 → 窗帘自动关严 → 灯光暗）和 **「睡眠模式」**（晚上定时关 + 早晨开一条缝自然光唤醒），用一个 Zigbee 窗帘电机跑通。

**为什么值得做**：
- 窗帘是你计划里**明确要装的**（自动窗帘），但装完不接场景 = 只是"能用遥控的普通窗帘"；
- 双场景自动化把它变成**"会配合的智能家居"**，是向朋友展示智能家居最直观的入口之一；
- 和投影联动后观影体验提升明显（投影区遮光是免费画质升级），一次做成，天天用。

**具体怎么做**：
1. 硬装阶段：投影区留卷帘盒 + 电源，卧室留插座
2. 选 Zigbee 窗帘电机 → [zigbee2mqtt](https://github.com/Koenkk/zigbee2mqtt) → [Home Assistant](https://github.com/home-assistant/core) 接入
3. 建两个场景自动化（观影 / 睡眠）
4. 实测：投影时窗帘自动关严、亮度达标；早晨自动开缝

**产出**：一段「观影 / 睡眠模式」演示视频（窗帘 + 投影 + 灯光联动）+ HA 场景配置 → 进小屋智能家居清单，也是招待朋友时的体验亮点。
