# 床垫与睡眠环境

[卧室布局设计](卧室布局设计.md)说"卧室第一是好睡"但只讲布局，本文补**睡眠质量的核心决定项**——床垫、枕头、床品、卧室环境。床垫要用 5-10 年、买错难退，是最值得多花的一笔。

> 一句话：**床垫预算优先级 > 床架**——床架别花大钱，床垫值得多花。

---

## 一、床垫怎么选（预算内的关键决策）

| 项 | 建议 |
|----|------|
| **硬度** | 侧睡偏软 / 仰睡适中 / 俯睡偏硬；**别迷信"越硬越好"** |
| **材质** | 弹簧（耐用支撑）/ 乳胶（软弹）/ 记忆棉（贴合，注意透气） |
| **试睡** | 躺 10-15 分钟，重点看**腰 / 肩支撑** |
| **尺寸** | 单人 1.2m / 双人 1.5m 起步，留翻身空间 |
| **预算** | 预算优先级：**床垫 > 床架**（床架别花大钱） |

## 二、枕头与床品

- **枕头**：侧睡高枕 / 仰睡中低枕；材质按睡姿选
- **床品**：全棉 / 天丝透气，床单被套按季换
- **别忽略**：床笠 / 床垫保护罩，延长床垫寿命

## 三、卧室环境（睡眠质量）

| 项 | 建议 |
|----|------|
| **遮光** | 睡眠遮光率 80-95%（见[窗帘与遮光设计](窗帘与遮光设计.md)） |
| **温度** | 略低助眠（18-22℃） |
| **噪音** | 隔音 / 白噪音；手机充电**别放床头** |
| **空气** | 通风（见[环保与入住安全指南](环保与入住安全指南.md)）——卧室是长期待的地方 |

## 四、与你的床顶货架配合

- 床顶货架（见[收纳设计](收纳设计.md)）：注意**别影响睡眠区**——重物放下层、灯光避开睡区
- 床垫高度 + 货架高度协调，别挡视线

## 五、预算与执行

- 床垫预算占比：**睡眠是第一优先级，床垫值得多花**（见[装修预算规划](装修预算规划.md)）
- 与[装修阶段时间表](装修阶段时间表.md) / [入住前检查清单](入住前检查清单.md)配合：**床垫提前买晾味**（见环保指南）

---

## 六、本轮项目推荐：做一张「床垫选购清单」

**推荐做什么**：按本文做一张 **1 页床垫选购清单**（睡姿 → 硬度 / 材质 → 试睡要点 → 尺寸 → 预算区间），去店里试睡时照着打分。

**为什么值得做**：
- **床垫是卧室最大的睡眠决策**、用 5-10 年，买错返工贵（难退）；
- 试睡时容易"感觉都对"——**有清单才能客观比较**；
- 和[窗帘遮光](窗帘与遮光设计.md) / [卧室布局](卧室布局设计.md)合成"睡眠三件套"。

**具体怎么做**：
1. 定睡姿 → 定硬度 / 材质候选
2. 试睡打分表（腰 / 肩支撑、侧翻、透气）
3. 定尺寸 + 预算，比 2-3 款

**产出**：1 页床垫选购清单 → 进卧室采购，是睡眠质量的核心投资。
