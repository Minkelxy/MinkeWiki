# 小屋装修：智能家居开源方案

针对[装修计划](index.md)里列出的智能设备（指纹锁、自动窗帘、智能马桶、空调伴侣、小爱音箱、灯具、摄像头等），这里整理一套**开源本地化**的智能家居方案——核心思路是**不依赖单一厂商云**，用 Home Assistant 做本地中枢，把米家等生态的设备统一接入本地管理。**Star 数为 2026-08-05 抓取时的真实数据**。

---

## 🏠 中枢：Home Assistant

| 开源项目 | Star | 说明 |
|---------|------|------|
| [home-assistant/core](https://github.com/home-assistant/core) | 89.7k | 开源智能家居中枢，本地优先，可跑在树莓派/NAS/旧电脑上 |

**为什么选它**：你的需求里有小爱音箱（米家生态）+ 指纹锁 + 智能马桶等，米家设备默认走小米云。Home Assistant 可以**本地接管**这些设备，断网也能用，还能跨品牌联动（米家设备 + 普通 Wi-Fi 开关 + 摄像头统一到一个 App）。

## 💡 落地建议（对应你的设备清单）

1. **中枢**：用闲置电脑/旧笔记本或群晖 NAS 跑 Home Assistant（Docker），你本来就计划放 NAS。
2. **米家设备**：小爱音箱、智能马桶、指纹锁、空调伴侣 → 装 `hass-xiaomi-miot` 或 `XiaomiGateway3` 本地接入。
3. **自动窗帘**：若选 Zigbee 版窗帘电机 → 走 `zigbee2mqtt` 或小米多模网关。
4. **灯光**：普通灯用 Tasmota 固件的智能开关；氛围灯可后续加 ESPHome 自研。
5. **监控**：门口/室内摄像头 → Frigate 本地人形检测，联动 Home Assistant 触发告警。
6. **网络设备房**：货架 + NAS/服务器 + HA 一起放，走你规划的线路布置。

> 这套方案全部开源免费、本地优先，唯一要求是装修时**预留网线和电源**（网络设备房、窗帘电机、摄像头点位）。
