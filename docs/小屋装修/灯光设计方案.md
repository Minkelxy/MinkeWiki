# 灯光设计方案

全屋灯光怎么配——**基础 / 功能 / 氛围三层**。对应[装修计划](index.md)设备清单里的灯具，以及[娱乐区与展示墙设计](娱乐区与展示墙设计.md)的氛围灯。

---

## 一、灯光三层（先懂概念）

| 层 | 作用 | 例子 |
|----|------|------|
| 基础照明 | 全屋能看清 | 主灯、吸顶灯 |
| 功能照明 | 特定工作看得清 | 台灯、镜前灯、射灯 |
| 氛围照明 | 营造情绪 | 灯带、落地灯、洗墙灯 |

> 好灯光的秘诀：**别只靠一个大主灯**——三层叠加，空间才有层次。

## 二、分区灯光建议

| 区域 | 基础 | 功能 | 氛围 |
|------|------|------|------|
| 客厅/娱乐区 | 主灯（可调光） | 投影区遮光、屏幕周围弱光 | **游戏 RGB 灯带**（见娱乐区设计） |
| 榻榻米/休息区 | 主灯 | 阅读落地灯（暖色） | 灯带低位洗墙 |
| 卫生间 | 吸顶灯 | **镜前灯正面补光**（梳妆） | 夜灯（起夜不刺眼） |
| 工作/书桌 | 主灯 | 台灯（4000K 明亮） | - |

## 三、色温与亮度

| 色温 | 感觉 | 适合 |
|------|------|------|
| 2700K（暖） | 放松、温馨 | 卧室、榻榻米、氛围 |
| 4000K（中性） | 明亮、专注 | 书桌、厨房、卫生间 |
| 6000K（冷） | 冷清、提神 | 少用，只在需要高度集中处 |

> 卧室/休息区用**暖光**（2700K），工作区用**中性光**（4000K）；可调色温的灯一步到位。

## 四、智能控制（接入智能家居）

- **氛围灯带**：RGB/WLED 方案，可接[智能家居开源参考](智能家居开源参考.md)统一控制
- **智能开关**：主灯换智能开关（Tasmota/米家），语音/手机控制
- **场景预设**：一个"游戏"场景 = 主灯暗 + 灯带蓝 + 屏幕弱光；一个"阅读"场景 = 落地灯亮

## 五、预算与布线

- 灯具占总预算 5-8%（见[装修预算规划](装修预算规划.md)）
- **布线提前留**：灯带轨道、射灯位、窗帘灯都要在硬装时留线和电源
- 智能灯具的**零线**问题：部分开关要零线，提前跟水电工说

## 六、注意事项

- **防眩光**：灯具避免直射眼睛（射灯不要对着沙发/床头）
- 亮度宁亮勿暗：基础照明不够，眼睛累
- 色温全屋**统一基调**：别一个房间 2700K、隔壁 6000K，串起来突兀
