# 环保与入住安全指南

[装修阶段时间表](装修阶段时间表.md)只说"通风 1 个月+"，本文把「怎么散、散多久、怎么判断能住」补成**完整可执行方案**。核心原则：**源头控制 > 事后治理**——材料选对了，后面省一半事。

---

## 一、先分清"甲醛从哪来"（源头优先）

| 来源 | 说明 | 对应你的项目 |
|------|------|-------------|
| **板材** | 胶合板/密度板/生态板，甲醛最大来源 | 榻榻米、床顶货架、书柜、鞋柜 |
| **胶粘剂** | 贴壁纸、地板、踢脚线、家具安装用胶 | 动漫壁纸、厨房改鞋柜 |
| **涂料/漆** | 墙面漆、木器漆 | 卫生间改造、墙面重做 |
| 布艺 | 窗帘、地毯、沙发（含量低） | 窗帘、地毯（新买先洗） |

> 你的项目里用板用胶多的是**榻榻米、床顶货架、动漫壁纸**——这些是甲醛大头，选材料时重点盯。

## 二、材料环保等级怎么看（国标分级）

板材/柜体的环保等级看 **GB/T 39600-2021《人造板及其制品中甲醛释放量分级》**：

| 等级 | 甲醛释放限量 | 选购建议 |
|------|------------|---------|
| **E1** | ≤ 0.124 mg/m³ | 及格线，能买但不算优 |
| **E0** | ≤ 0.050 mg/m³ | **推荐**（定制柜/柜体选这个） |
| **ENF** | ≤ 0.025 mg/m³ | 无醛级，儿童房/密闭空间选 |

**四个判断技巧**：
1. **看检测报告**：买板材/柜体先要检测报告，看分级，别听销售口头说
2. **别信"零甲醛"**：没有零甲醛，只有限量低——宣称"零"的都是话术
3. **封边比板材更重要**：定制柜看封边是否完整（封边差 = 甲醛从断面持续释放）
4. **壁纸用环保胶**：动漫壁纸 + 胶水，选糯米胶/环保胶，别用劣质胶

## 三、治理方法：通风是唯一确定有效的

| 方法 | 效果 | 注意 |
|------|------|------|
| **通风（最有效）** | 唯一确定有效 | 新装连续通风 1-2 个月起步，每天 2 次以上 |
| 活性炭/矿晶 | 有一定吸附 | **会饱和回放**，1-2 个月必须换，量要够 |
| 空气净化器 | 看除醛 CADR | 靠活性炭滤网，别只靠它；定期换滤芯 |
| 光触媒/喷剂 | **证据不足、易复发** | 别当主力，别信"一次搞定" |
| 高温高湿闷放 | 加速释放 | 夏天/供暖期：闷 4-6h → 开窗 1h 反复，效率高 |

> 一句口诀：**通风是根治，活性炭是补位，喷剂是安慰剂。**

## 四、检测：怎么判断"能住了"

| 手段 | 可靠性 | 用法 |
|------|--------|------|
| 家用甲醛检测仪 | **低**（漂移大） | 只能看趋势，别信绝对值 |
| 甲醛测试盒 | 低-中（半定量） | 比色参考，同样别当数 |
| **CMA 检测机构** | **高**（采样送检） | 入住前做一次，几百元，最靠谱 |

**判断标准**：GB/T 18883-2022《室内空气质量标准》规定室内甲醛限值 **0.08 mg/m³**（密闭 12 小时后采样）。

**判断逻辑**：先闻（有刺激性 = 别住）→ 仪器看趋势 → **CMA 确认**。三者都过再搬，尤其你有储物需求，柜子里浓度更高。

## 五、银川气候的特别提醒

- **干燥 + 风大** → 通风条件其实好，夏天开窗效率高（比南方潮湿地区省事）
- **冬天寒冷** → 开窗受限制，用"焖放"短时通风 + 净化器 + 活性炭补位
- **供暖季** → 板材/胶在高温下释放加速，刚装完赶上供暖更要通风

> 你的 NAS/服务器会长期开机散热——**设备间也是"小热源"**，若和柜体/板材同室，等于给甲醛加热，注意该室通风。

## 六、入住前后节奏（时间线）

```
装修完 → 通风 1-2 个月（时间表已排）
  → 家具进场（柜子/床垫/沙发是后来源）→ 再通风 1-2 周
  → 入住前 CMA 检测一次（达标再搬）
  → 入住后 3 个月仍保持通风习惯
```

> 甲醛释放可持续 3-15 年，但**峰值在前 6-12 个月**——入住第一年最该坚持通风，别住进去就放松。

## 七、本轮项目推荐：做「空气质量监测 + 通风提醒」小项目

**推荐做什么**：在你现有的 Home Assistant 智能家居（见[智能家居开源参考](智能家居开源参考.md)）里，加一个**空气质量监测节点**（甲醛 + CO2 + 温湿度），配合**通风提醒自动化**——让"该不该通风、能不能关窗"有数据依据，而不是靠鼻子。

**为什么值得做**：
- 直接关系入住安全和你要常招待朋友的需求——空气质量是"看不见但最影响体验"的一项；
- 你的 NAS/服务器 + 智能家居本来就要上 HA，加一个传感器节点成本低（ESP32 + 甲醛传感器几十元）；
- 把"通风 1 个月+"从拍脑袋变成**数据说话**：甲醛浓度降到阈值再入住，住得安心、也能给朋友展示。

**具体怎么做**：
1. **一个传感器节点**：ESP32 + 甲醛传感器（如 Winsen ZE08-CH2O）+ 温湿度，参考 [aether](https://github.com/EnriqueNeyra/aether) / [aq-monitor](https://github.com/Verstreubulator/aq-monitor) 的结构（ESPHome 接入 HA）
2. **HA 仪表盘**：建"空气质量"卡片 + 历史曲线，标注甲醛/CO2 阈值线
3. **通风提醒自动化**：甲醛或 CO2 超阈值 → 推送"开窗通风"；开窗 30 分钟后自动提醒关窗（冬天配合保温）
4. **入住前实测**：装修完用它连续监测，记录"甲醛随通风下降"的过程，达标再搬

**产出**：一个 HA 空气质量卡片 + 通风提醒自动化 + 一段"甲醛浓度随通风下降"的记录 → 既保入住安全，也是小屋智能家居的第一块"会说话"的看板。
