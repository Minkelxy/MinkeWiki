# 大纲与场景清单

把[恒润疗养院创作路线](恒润疗养院创作路线.md)里定好的 Logline 和人物，变成**一页大纲**，再展开成**场景清单（Beat Sheet）**——这是正式动笔前的最后一步。

---

## 一、从 Logline 到一句话剧情

先有 Logline（一句话前提），再扩成**一句话剧情**（怎么起、怎么变、怎么收）：

> Logline：在疗养院，X 因为 Y 住进来，发现 Z。
> 一句话剧情：X 入院 → 发现病房的秘密 → 被迫在"装傻保平安"和"揭开真相"之间选择。

**一句话能说清因果链，故事骨架就立住了。**

## 二、一页大纲（One-Page Outline）

用**三幕各 2-3 句**写成一页：

| 幕 | 内容（示例结构） |
|----|-----------------|
| 第一幕 | 入院、认识环境、埋钩子（25%） |
| 第二幕 | 冲突升级、发现真相碎片、关系变化（50%） |
| 第三幕 | 抉择、高潮、主题点破（25%） |

> 一页写得完 = 结构清楚；写不完 = 还没想清楚，别急着动笔。

## 三、场景清单（Beat Sheet）

把每场戏列成一行，格式：

```
场景：病房夜
人物：护工、新病人
目标：护工要让病人签字
转折：病人发现签字单日期不对
```

**一个场景 = 目标 + 阻碍 + 转折**（套用[场景设计与冲突推进](场景设计与冲突推进.md)的三格）。

## 四、怎样排 beats（递增冲突）

- **冲突逐场递增**：每 2-3 场升级一次，别平铺
- **信息分批释放**：真相碎片一场露一点（见[悬疑写作](悬疑剧本写作.md)信息差）
- **主副线交错**：主线推进时，副线（人物关系）穿插，别让观众只看一条线
- 全程符合 **25/50/25** 节奏

## 五、工具

- 直接用 **Fountain** 写大纲（纯文本，语法见[Fountain语法速查](Fountain语法速查.md)）
- 一个文件一段一个 beat，方便后续扩成场景
- 用 git 存多版大纲，随时回退

## 六、写后检查

- [ ] 每场都有目标 + 阻碍 + 转折？
- [ ] 三幕占比接近 25/50/25？
- [ ] 冲突逐场递增、没有"废场"？
- [ ] 主角弧光在结尾兑现（开场 vs 结尾变了）？
