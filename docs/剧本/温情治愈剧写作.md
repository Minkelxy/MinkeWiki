# 温情治愈剧写作

温情/治愈类型剧本的写法——疗养院题材的另一个可选路线（对应[创作路线](恒润疗养院创作路线.md)的类型选项）。

---

## 一、温情剧的核心

| 要点 | 说明 |
|------|------|
| 情绪真实 > 情节曲折 | 观众被打动靠"真"，不靠"巧" |
| 治愈 | 不是没有苦难，而是**苦难里有暖** |
| 慢热 | 允许节奏慢，情感要一层层铺 |

> 温情剧的"剧情"往往平淡，**人物关系才是主线**。

## 二、结构特点（vs 悬疑）

| 维度 | 悬疑 | 温情 |
|------|------|------|
| 冲突 | 强、外部 | 温和、偏内在 |
| 推进 | 线索/反转 | 关系/情感递进 |
| 高潮 | 真相揭晓 | 情绪顶点（和解/告别） |
| 结尾 | 反转/悬 | **温情收**（不一定要圆满，但要暖） |

## 三、写作技法（细节见真情）

1. **细节 > 台词**：一个动作比一句"我爱你"有力——护工偷偷把病人爱吃的菜留出来
2. **留白**：情绪到顶点时**别说完**，留给观众自己感受（见[人物塑造对白](人物塑造与对白写作.md)的潜台词）
3. **避免硬煽情**：强行配乐式煽情会适得其反——**情绪要"压着写"**，让观众自己哭，别替观众哭

> 检验：观众哭是因为"人物打动了ta"，而不是"你硬要他哭"。

## 四、疗养院温情素材

| 场景 | 温情点 |
|------|--------|
| 病人与护工 | 从戒备到信任、日常陪伴 |
| 病人之间 | 互相关照、临时"家人" |
| 告别 | 体面的告别、和解 |
| 家属 | 迟来的理解与陪伴 |

## 五、练习推荐

1. 写一个**细节**：用"一个动作 + 一句普通的话"写护工对病人的关怀（不直说"关心"）
2. 写一场**告别戏**：压着写，情绪到顶点就停，不煽情
3. 对照[主题与结尾设计](主题与结尾设计.md)，想清楚这部温情剧的"暖"落在哪
