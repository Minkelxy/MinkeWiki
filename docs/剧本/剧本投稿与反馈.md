# 剧本投稿与反馈

作品**修改完成**后怎么投稿、怎么拿反馈——把恒润疗养院从"写完"推进到"被看见"。

---

## 一、投稿前准备（格式要专业）

| 项 | 要求 |
|----|------|
| 标准格式 | 用 Fountain + Textplay 导出**标准剧本排版 PDF**（见[Fountain速查](Fountain语法速查.md)） |
| 一页梗概 | Logline + 简介（人物/冲突/亮点），一页内 |
| 剧本信息 | 剧名、类型、时长、作者、联系方式（首页） |
| 校对 | 走一遍[修改打磨](剧本修改与打磨指南.md)清单，别带明显错漏投稿 |

> 投稿的门槛是"**让人 10 秒内看懂你的故事**"——梗概比剧本还重要。

## 二、反馈渠道（按层级）

| 渠道 | 特点 | 适合 |
|------|------|------|
| 朋友/同行 | 最直接、够意思 | 初稿阶段 |
| 编剧社群/论坛 | 有懂行的人 | 改过一两稿后 |
| 比赛/征集 | 专业评审 + 曝光 | 成品阶段 |

> **别拿第一稿去比赛**——先给朋友/社群改两轮，再投正式渠道。

## 三、比赛与征集注意

- 找**贴合类型/长度**的征集（短片、悬疑、疗养题材），别海投
- 看清截止日期、字数/页数上限、**版权约定**（有的征集要授权，先读条款）
- 一次投 1-2 个最匹配的，比海投有效

## 四、面对反馈（别全盘照收）

- **抓共性**：两个人以上提的 → 真要改
- 单个人的偏好 → 参考不照办
- 你的判断 > 读者意见（见[修改打磨](剧本修改与打磨指南.md)）
- 反馈是"哪里不舒服"，怎么改还是你决定

## 五、持续打磨

- 投稿被拒 ≠ 失败：收集评审意见，改完再投下一个
- 每轮修改都**记录版本**（git），保留成长轨迹
- 目标是"**够好 + 按时交**"，不是"完美"（见[修改打磨](剧本修改与打磨指南.md)的完成标准）
