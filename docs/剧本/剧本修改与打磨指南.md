# 剧本修改与打磨指南

初稿写完后的修改方法论，对应[恒润疗养院创作路线](恒润疗养院创作路线.md) 6 周计划的第 5-6 周。**初稿的价值是"写出来了"，修改的价值是"变成作品"。**

---

## 一、先冷静再改

- **放 2-3 天再读**：刚写完满眼都是好的，冷静后再读才发现问题
- 读的时候**只做标记不改**：标出读着别扭/存疑的地方，读完统一改

## 二、分两轮修改（别混着来）

### 第一轮：结构轮（看骨架）

- 三幕是否完整？高潮位置对不对？
- 每个场景有没有**转折**（套用[场景设计与冲突推进](场景设计与冲突推进.md)的检查）
- 人物弧光是否成立（开场 vs 结尾）
- **这轮大刀阔斧**：删场景、调顺序，别心疼

### 第二轮：细改轮（看血肉）

- 对白精简：每句能删就删（见[人物塑造与对白写作](人物塑造与对白写作.md)）
- 情绪用**动作/环境**表达，删直白情绪词
- 标点、格式（Fountain 语法）过一遍

> 顺序很重要：先骨架后血肉——结构没定就细改，改了也白改。

## 三、朗读与反馈

### 自己朗读
- **读出声**：拗口的对白、卡壳的地方立刻现形
- 一边读一边录，回听更客观

### 找 1-2 个读者
- 给**懂剧本的人**（能聊结构）或**普通观众**（能聊感受），各有用
- 听完问三个问题：你记得住哪个角色？哪里看懂了/没看懂？哪里无聊？

### 别全盘照收
- 抓**共性问题**（两个人都提的），单个人的偏好不必改
- 你的判断 > 读者意见：读者指出"哪里不舒服"，你决定"怎么改"

## 四、修改工具

| 工具 | 用法 |
|------|------|
| Fountain + git | 每稿一个 commit，随时回退对比 |
| 版本对比 | 两稿并排看，确认改对了地方 |
| 场景卡 | 删除/移动场景前，先把内容复制到卡片再排 |

## 五、何时算"完成"（别无限改）

满足这三条就收手：
1. **结构通**：三幕完整、高潮有力、每场有转折
2. **读着顺**：朗读不卡壳、不别扭
3. **反馈问题解决了**：共性问题已改，你认可的改动到位

> 记住：**没有完美的剧本，只有"够好 + 按时交"的剧本。** 一直改就是逃避完成。
