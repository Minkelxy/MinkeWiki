## 📝 Fountain 剧本格式（强烈推荐）

Fountain 是**纯文本剧本格式**，类似 Markdown 之于文档：纯 `.txt` 就能写，语法简单，可一键导出符合行业规范的剧本排版（场景标题、对话、过渡词自动格式化）。适合先在纯文本里起草，再导出 PDF 给剧组/平台。

| 开源项目 | Star | 技术栈 | 说明 |
|---------|------|--------|------|
| [nyousefi/Fountain](https://github.com/nyousefi/Fountain) | 670 | Objective-C | Fountain 格式的开源实现（参考规范与排版引擎） |
| [mattdaly/Fountain.js](https://github.com/mattdaly/Fountain.js) | 271 | JavaScript | Fountain 的 JS 解析器，可做 Web 剧本编辑器 |
| [overvale/Textplay](https://github.com/overvale/Textplay) | 107 | Ruby | 命令行工具，把 Fountain 纯文本转成标准剧本排版 PDF |
| [chuangcaleb/obsidian-fountain-editor](https://github.com/chuangcaleb/obsidian-fountain-editor) | 88 | TypeScript | Obsidian 的 Fountain 插件，写剧本时实时格式化预览 |

## 💡 落地建议

1. 「恒润疗养院」直接用 **Fountain 纯文本**起草（文件后缀 `.fountain`），随时在任意编辑器里写，不依赖付费软件
2. 用 **Textplay** 一键导出标准剧本排版；若用 Obsidian 做笔记，装 **fountain-editor** 插件即可边写边预览
3. 场景/大纲管理可参考 **kindling** 的侧栏大纲设计
