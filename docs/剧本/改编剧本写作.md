# 改编剧本写作

类型/手艺系列都齐了，本文补最后一环：**素材怎么变成剧本**。无论改一部小说、改编真人真事，还是把你对疗养院的观察/经历变成《恒润疗养院》，走的是同一条路——**先破后立**：先找到原作的"核"，再为你的媒介重建。

> 一句话：改编不是"抄"，是"翻译"——保核、换壳。

---

## 一、改编的本质：翻译，不是搬运

| 媒介 | 表达方式 |
|------|---------|
| 小说 | 叙述、内心独白、心理描写 |
| 剧本 | **画面、对白、动作**（剧本是给镜头看的） |

- 核心问题：**原作的"核"是什么**（主题 / 情绪 / 人物弧光）？改编 = 保核、换壳
- 常见错误：逐字逐景照搬 → 变成"念小说"，长台词流水账，镜头没东西可拍
- 翻译铁律：把"他内心很挣扎"变成**一场戏**（动作/对白/环境），把"多年以后"变成一个**转场**

## 二、改编四问（动笔前必答）

1. **原作的"核"是什么？** 一句话写出主题（如《恒润疗养院》："封闭空间里，人如何体面地老去"）
2. **为谁改？** 类型/受众决定取舍方向（商业短片 vs 文艺长片，取舍完全不同）
3. **保留什么？** 核心人物、关键情节、标志意象
4. **砍掉什么？** 内心独白、次要线索、旁枝人物——**剧本没时间全讲**

## 三、三步流程

1. **提炼**：读完原作用一句话写"我想讲什么"——这就是你改编的"核"
2. **结构**：把素材排进三幕（见[恒润疗养院创作路线](恒润疗养院创作路线.md)的三幕），核心事件放对位置
3. **转译**：叙述变画面、内心变动作、文字意象变视觉意象（灯光/物件/声音）

## 四、真人真事 / 亲身经历的改编（恒润疗养院最相关）

| 步骤 | 做法 |
|------|------|
| **建素材库** | 把观察/访谈记成卡片（人 / 事 / 细节 / 原话），别边写边翻回忆 |
| **提炼主题** | 素材是散点，主题是那条线——从素材里找"我到底想说啥" |
| **定边界** | 真人真事改编有隐私/法律边界（姓名/事件/肖像），**换名换细节**是最低要求，做虚构化处理 |
| **用真实细节** | 一个真实细节（病人半夜数路灯）比十个编造情节都真——这是改编独特性的来源 |

> 真实细节的威力：观众说不清哪里好，但就是觉得"真"。

## 五、改编的取舍原则

| ✅ 保 | ❌ 砍 |
|-------|-------|
| 主题 / 核心冲突 | 与主题无关的支线 |
| 标志性人物 / 意象 | 纯叙述 / 内心戏 |
| 关键转折 | 人物太多（**合并配角**） |

> 一句话：**为"核"服务的东西留，别的都让位**。取舍不清 = 剧本散、人物多、时长失控。

## 六、练习推荐（30 分钟量级）

1. **转译练习**：把一句心理描写（"她犹豫要不要敲门"）写成一场戏（敲门、停住、看表、转身、又回头）
2. **素材卡**：给恒润疗养院记 10 个真实细节，标出哪个能当"标志意象"（可反复出现的物件/动作）
3. **三幕排位**：把你的素材排进三幕，标出每个核心事件在第几幕、承担什么功能

## 七、本轮项目推荐：给恒润疗养院做「素材 → 剧本」转化练习

**推荐做什么**：从你对疗养院的观察/经历里整理 **10 张素材卡**（人/事/细节/原话），提炼一句话主题，选 3 个真实细节做"标志意象"，再排进三幕骨架——产出恒润疗养院的**改编施工图**。

**为什么值得做**：
- 恒润疗养院如果来自真实观察，这是把"素材"变"剧本"的**第一步**，也是最能出独特性的地方（真实细节别人编不出来）；
- 一页纸量级，可边做边校验方向，比写完整初稿再推倒成本低得多；
- 直接喂给[创作路线](恒润疗养院创作路线.md)的下一步（人物设定卡 / 大纲），也是[人物塑造与对白](人物塑造与对白写作.md)的素材来源。

**具体怎么做**：
1. 记 10 张素材卡（**不筛选**，想到就记）
2. 划掉 5 张——从留下的 5 张里提炼一句话主题
3. 选 3 个细节做"标志意象"（能反复出现的）
4. 排进三幕：核心冲突放第二幕中间，转折放第三幕前段

**产出**：10 张素材卡 + 一句话主题 + 三幕骨架 → 恒润疗养院的改编施工图，也是人物塑造与对白的素材库。
