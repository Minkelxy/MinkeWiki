# 视觉化写作与镜头语言

对白、结构、人物、类型都讲过了——本文补**"怎么写画面"**。剧本是给镜头看的，核心检验只有一句：**剧本的每一行都要能变成画面**。短片尤其如此：对白少、画面说话。

> 一句话：**写"能拍的"，不写"能读的"**。删掉所有对白，剧情还讲得通，才是好剧本。

---

## 一、为什么视觉化是剧本的灵魂

| 媒介 | 观众能看到 |
|------|-----------|
| 小说 | 内心、叙述、心理描写 |
| 剧本 | **只有画面和对白**（内心必须变成动作/环境/细节） |

- 剧本不是小说：观众看不到"他很挣扎"，只能看到"他做了什么"
- 所以剧本里的**每个情绪点，都要翻译成可拍的画面**

## 二、Show, don't tell 的三个落点

| 想说 | 别写 | 写 |
|------|------|-----|
| 他很难过 | "他很难过" | 他把烟按灭，盯着窗外出神 |
| 她很紧张 | "她很紧张" | 她反复整理衣角，声音发紧 |
| 关系破裂 | "他们关系坏了" | 两人中间隔着空位，谁也没坐过去 |

> 情绪 = 动作 + 环境 + 细节——**观众自己会读出来，不用你说**。

## 三、镜头语言基础（写场景时心里有镜头）

| 镜头 | 作用 | 剧本里怎么写 |
|------|------|-------------|
| **特写** | 强调细节 / 情绪 | 单独一行写关键物件（药瓶 / 照片 / 手） |
| **中景** | 人物关系 / 对白 | 默认景别，写清两人位置 |
| **全景** | 环境 / 孤独 / 封闭 | 先写环境再进人（疗养院走廊） |
| **蒙太奇** | 时间流逝 / 并列 | 连续短场景（每天同一时刻） |
| **转场** | 段落切换 | 用物件 / 声音 / 光线衔接，别硬切 |

## 四、一场戏的"视觉节奏"

1. **开头给环境**（景）→ **中间给动作/对白**（人）→ **结尾给"留下什么"**（情绪画面）
2. **长对白用动作打断**：让人边说边做事，画面不静止
3. **一场戏留一个"视觉钩子"**：观众记得住的那个画面（物件 / 动作 / 光线）

## 五、疗养院题材的视觉素材（复用[人物塑造](人物塑造与对白写作.md)的氛围工具箱）

- **时间感**：挂钟停摆 / 药片铝箔 / 换班铃
- **孤独**：空走廊 / 回音 / 单人病房门
- **生命感**：心电监护 / 窗外树 / 探视的花

> 这些视觉物件**反复出现 = 标志意象**（见[改编剧本写作](改编剧本写作.md)），让全片有"视觉记忆点"。

## 六、练习推荐

1. **无对白改写**：把一段独白改成纯动作 + 环境（逼你视觉化）
2. **镜头提示**：给一场戏写镜头安排（特写什么 / 全景哪里 / 怎么转场）
3. **删对白检查**：把剧本对白全删，还能看懂吗？——看不明白的地方就是没写"画面"

---

## 七、本轮项目推荐：给恒润疗养院写一页「无对白场景」

**推荐做什么**：挑一个关键情绪点（新病人入住第一晚 / 深夜走廊），写一页**完全无对白**的场景——只用动作 / 环境 / 物件 / 镜头提示，传达不安与孤独。

**为什么值得做**：
- **视觉化是短片剧本的核心竞争力**（短片对白少、画面说话），而恒润疗养院是短片定位（见[恒润疗养院创作路线](恒润疗养院创作路线.md)）；
- **无对白练习是"逼你视觉化"的最快方法**——不写对白，就只剩画面可写；
- 产出直接进恒润疗养院初稿，也是检验现有大纲"能不能拍"的标尺。

**具体怎么做**：
1. 选情绪点，定一个"视觉钩子"（物件 / 画面）
2. 用特写-中景-全景安排镜头（见第三节），**全程无对白**
3. 写完后删掉对白检查——还能看懂 = 成功

**产出**：1 页无对白场景 + 镜头提示 → 进恒润疗养院素材库，也是你视觉化写作的第一份成稿。
