# 悬疑剧本写作

悬疑类型剧本的技法与结构，对应[恒润疗养院创作路线](恒润疗养院创作路线.md)里推荐的悬疑路线。**核心：信息差就是一切。**

---

## 一、悬疑的核心：信息差

悬疑来自"观众知道的 ≠ 角色知道的 ≠ 作者知道的"：

| 三差 | 说明 |
|------|------|
| 观众 vs 角色 | 观众比角色知道得多 → 紧张（"别开门！"） |
| 角色 vs 观众 | 角色知道、观众猜 → 好奇 |
| 作者 vs 观众 | 作者藏、观众推 → 悬念 |

> 一场戏里先想清楚：**现在观众知道什么、角色知道什么**——这就是悬疑的开关。

## 二、三种悬念类型

| 类型 | 问题 | 例（疗养院） |
|------|------|--------------|
| Whodunit | 谁干的 | 病历是谁改的 |
| Why | 为什么这么做 | 为什么要隐瞒一个病人的死因 |
| How | 怎么做到 | 如何在封闭病房里进出不留痕 |

> 一部悬疑片通常**换着用**：先 Why，后 Whodunit，最后 How。

## 三、结构要点

### 1. 开场埋钩子
- 前 3 分钟给出一个"不对劲"的细节（护士查房时锁上了不该锁的门）

### 2. 线索铺设与误导（Red Herring）
- **每条线索都有用**：要么指向真相，要么是误导
- **误导要公平**：误导线索也要"合理"——回头想，观众会觉得被耍了而不是被骗

### 3. 反转（铺垫过的才叫反转）
- **反转 = 重新解读已有信息**，不是凭空冒出新信息
- 反转前要让观众"回头能看懂"（重看所有线索对得上）

## 四、疗养院题材的天然悬疑素材

| 素材 | 用法 |
|------|------|
| 封闭空间 | 凶手/秘密跑不掉，冲突压缩 |
| 病患身份 | 谁真的病、谁装的 |
| 药物 | 药是治疗还是控制 |
| 家属/护工 | 谁在隐瞒、谁在保护谁 |

## 五、写作技法（落地）

1. **别让观众比角色早知道太多**：信息一点一点漏（见[场景设计](场景设计与冲突推进.md)的信息释放）
2. **每场至少一条线索/一个疑点**：无信息的场景在悬疑片里等于废戏
3. **真相最后给**：高潮揭晓时，前面所有线索串成一条线

## 六、练习推荐（针对恒润疗养院）

1. **列 5 个疑点**：开场 5 分钟要埋 5 个"不对劲"，每个都指向后面
2. **设计一个反转**：选一个已知信息，设计"换个角度解读"成反转，检验铺垫是否够
3. **公平性自查**：反转揭晓后，回头检查每条线索是否都对得上
