# Fountain 剧本格式语法速查

Fountain 是**纯文本剧本格式**：用普通文本就能写出标准剧本排版，配工具一键导出 PDF。本速查覆盖全部核心语法，配合[剧本创作工具参考](剧本创作工具参考.md)里的 Textplay 等工具使用。适合直接用来写[恒润疗养院](恒润疗养院.md)。

---

## 一、标题页（元数据）

文件开头、第一个场景之前：

```
Title: 恒润疗养院
Credit: 编剧 Minke
Author: Minke
Draft date: 2026-08-05
Contact: minkeskl@qq.com
```

- 元数据键值对 `键: 值` 放在文件最前
- 遇到第一个场景标题（`INT./EXT.`）后，标题页结束

## 二、场景标题（Scene Heading）

**全大写 + 单独一行**即识别为场景标题：

```
INT. 疗养院大厅 - 夜
EXT. 医院门口 - 日
INT./EXT. 救护车内 - 黎明
```

- 变体：`EST.`（建立镜头）、`INT./EXT.`（内外切换）
- 需要强制时用 `!` 前缀：`!特殊场景`

## 三、动作描述（Action）

普通段落即动作，可大小写混用：

```
大厅里灯光昏暗，墙上挂着一排老照片。
护士推着轮椅缓缓经过。
```

- 动作与场景间建议用**空行**分隔

## 四、对话（Dialogue）

**大写角色名单独一行**，下一行是对话：

```
护士
    该吃药了。躺好，别动。

病人
    又是这间屋子。
```

- 角色可带**扩展**：`护士 (V.O.)`（画外音）、`(O.S.)`（画外）、`(CONT'D)`（接前）
- 需要强制识别为角色名时用 `@` 前缀：`@旁白`
- 同一角色连续说话，工具自动加 `(CONT'D)`

## 五、括号（Parenthetical）

对话中的表演/语气提示，用括号包裹：

```
病人
    (盯着天花板)
    我好像见过你。
```

## 六、双对话（Dual Dialogue）

两个角色同时说话，两段之间用 `^` 连接：

```
护士
    把他扶起来。
^
病人
    别碰我。
```

## 七、转场（Transition）

**全大写、以 `TO:` 结尾**的单行：

```
CUT TO:
FADE TO BLACK:
FADE IN:
```

- 强制转场用 `>` 前缀：`>直接显示`
- 转场默认右对齐

## 八、其他元素

| 语法 | 写法 | 效果 |
|------|------|------|
| 居中文本 | `> 居中 <` | 剧中标题/旁白 |
| 页断 | `===` | 强制分页 |
| 注释 | `/* 说明 */` | 不导出到成稿 |
| 便签 | `[[待补]]` | 屏显、不导出 |
| 强制换行 | `\` | 动作段内换行 |

## 九、排版要点

- **场景之间用两个空行**分隔，识别更稳
- 场景标题/角色名保持**全大写**，是识别的关键
- 对话前无需缩进，工具自动排版
- 任何编辑器都能写，`.fountain` 纯文本可放 git 版本管理

## 示例开头（可直接改）

```
Title: 恒润疗养院
Author: Minke

INT. 疗养院大厅 - 夜

大厅空旷，白炽灯嗡嗡作响。墙上挂钟指向十一点。

护士
    (低声)
    十二床又闹了，去看看。

病人从走廊尽头慢慢走来，脚步拖沓。
```
