# 群像剧写作

多角色"众生相"剧本的写作方法。疗养院的病人/护工/家属天然适合群像——与[悬疑剧本写作](悬疑剧本写作.md)是恒润疗养院的两种可选路线。

---

## 一、群像 vs 单一主角

| 类型 | 特点 | 难点 |
|------|------|------|
| 单一主角 | 一条主线、聚焦一人 | 配角易扁平 |
| **群像** | 多线、多人物 | **别让每个人都弱**——群像写砸=没有主角、也没有配角 |

> 群像不是"没有主角"，而是"多个有弧光的角色，围绕同一主题"。

## 二、核心：一个主题串起所有人

- 群像的黏合剂是**主题**，不是情节
- 每个角色体现主题的**一个侧面**（如"如何面对衰老"：有人抗拒、有人接受、有人逃避）
- 观众看完记住的是"这个主题下的众生相"，而不是某条线

> 先定主题，再分配角色——**所有角色都服务同一个主题**，群像才不散。

## 三、人物配置（4-6 个主要角色够用）

| 项 | 建议 |
|----|------|
| 主要角色 | 4-6 个（再多写不过来） |
| 功能分配 | 每人都要有戏、有弧光，别只当"配角" |
| 关系网交叉 | 角色两两之间要有关系（冲突/亏欠/秘密），构成网格 |

> 疗养院素材：病人（不同的病与心态）、护工（专业的 vs 冷漠的）、家属（关心的 vs 甩手的）——三类人交叉就是关系网。

## 四、多线结构

- **主线**：1-2 条（推进主题/核心事件）
- **副线**：2-3 条（人物关系），与主线**交错**推进
- 关键：**各线要有交集点**——在某场戏汇合，否则就是各自独立的故事

```
主线和副线交汇示例：A 病人的秘密，恰是被 B 护工查房时撞破
```

## 五、疗养院群像素材清单

| 人物类型 | 可写的冲突 |
|---------|-----------|
| 病人 | 抗拒治疗 / 想回家 / 隐瞒病情 |
| 护工 | 职业倦怠 / 私下同情 / 与制度冲突 |
| 家属 | 探望频率 / 遗产问题 / 良心愧疚 |

## 六、练习推荐

1. **列 5 个角色**：每个一句话目标 + 一个缺陷 + 一个主题侧面，检验是否都服务主题
2. **画关系网**：把角色连成图，标出每条线的冲突/秘密——缺线的补上
3. **一场群像戏**：写"食堂午饭"一场，让 4 个角色各带自己的心事同框，谁都没说出来但观众全懂
