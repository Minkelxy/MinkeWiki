## 项目概览

- **题材**：疗养院（封闭空间 + 众生相）
- **类型**：悬疑 / 温情治愈 / 黑色幽默（单选主打，避免混搭）
- **核心**：先写一句话前提（Logline），定调后再进入人物与大纲
