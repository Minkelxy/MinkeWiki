# 喜剧写作

类型写作系列的新一篇（与[悬疑](悬疑剧本写作.md)、[温情治愈](温情治愈剧写作.md)、[黑色幽默](黑色幽默写作.md)并列）。喜剧和黑色幽默是"明暗两兄弟"——黑色幽默是**用笑的壳装沉的核**，喜剧则先让你**放心笑**，再在笑点落地处留一点心酸。对恒润疗养院这种沉重题材，喜剧单元是最有效的节奏调节阀。

---

## 一、喜剧的本质：执念主角 × 不配合的世界

喜剧主角**不是"搞笑的人"**，而是：

> 一个坚信自己能达成目标的人，世界却总跟他作对——而他永不反省，越努力越糟。

| 误解 | 正解 |
|------|------|
| 主角要有趣、会抖包袱 | 主角**认真而执着**，笑点来自他的认真撞上荒谬的世界 |
| 笑点靠耍贫嘴 | 笑点靠**目标 → 障碍 → 用力反而更糟**的循环 |

> 关键分水岭：悲剧主角遇到障碍会反省成长；喜剧主角**一反省就不可笑了**。所以喜剧的弧光往往在最后才给——他终于承认"我错了"，这一刻既好笑又动人。

## 二、笑点结构三件套

### 1. 铺垫 + 笑点（Setup → Punchline）
先给观众一个预期，再用一个"更合理但没想到"的答案打破它。

> 铺垫：护工对着食谱教病人"养生"。
> 笑点：病人指着隔壁桌："他天天抽烟，活到 90。"
> （答案打破"养生=长寿"的预期，但完全符合人物逻辑）

### 2. 三法则（Rule of Three）
同一个梗讲三次：第一次铺垫、第二次强调、第三次**反预期**——第三次才最响。

> 例：病人三次问同一个问题，前两次护士耐心回答，第三次护士深吸一口气、把手里的表格叠好、抬头微笑："您刚才问过了。"

### 3. 升级（Escalation）
同一困境一层比一层糟，直到荒诞但**逻辑依然说得通**。这是喜剧的发动机，与黑色幽默共用。

> 例：护工想给病床轮子装锁防病人偷跑 → 锁被撬 → 病人给其他床也撬了 → 全院病床都"丢"了。

## 三、喜剧角色的逻辑（让"蠢"聪明起来）

| 原则 | 说明 |
|------|------|
| **逻辑自洽** | 角色是按自己的逻辑在认真做事，只是逻辑和世界不兼容。"蠢"是聪明人走错了路，不是智商低 |
| **认真** | 越认真越可笑——苦着脸讲最傻的事。喜剧角色从不觉得自己在搞笑 |
| **失势结构** | 让角色在自己不擅长的领域逞强（护士长去主持婚礼、老人在理疗室教按摩） |
| **不知情** | 观众知道、角色不知道（和[悬疑](悬疑剧本写作.md)共用"信息差"，方向相反——悬疑制造紧张，喜剧制造荒诞） |

## 四、对白层面的笑点

1. **答非所问**：问题很正经，答案岔到另一条逻辑线
2. **连珠炮节奏**：短句快接，停顿放在笑点前（**停顿是笑点的朋友**）
3. **自我拆台（自嘲）**：要克制，多了会油腻；配角用可以，主角最好别一直用
4. **重复变奏**：同一句台词换语境再说一遍，语境一换就出笑点

## 五、疗养院题材的喜剧分寸（最容易翻车）

喜剧是"明"，但疗养院的题材是"沉"——**笑点必须指对人**：

| ✅ 可以笑 | ❌ 不能笑 |
|----------|---------|
| 制度荒谬（体检排队、填不完的表） | 具体的病人/老人本身 |
| 处境荒谬（好人办坏事的循环） | 疾病/死亡的痛苦 |
| 人物性格（偏执、爱面子） | 弱势者的窘迫 |

**分寸自查表**：
- [ ] 观众笑完，嘲笑的对象是"处境/制度"，不是"人"？
- [ ] 荒诞背后逻辑说得通？（再荒诞也要可理解）
- [ ] 有没有一处"笑里带泪"的落点？（纯笑会轻浮）

> 疗养院喜剧的最高形态：**先笑，然后意识到笑声背后是孤独**——那一下"冷"，就是喜剧和黑色幽默的交界。

## 六、练习推荐（针对恒润疗养院）

1. **升级场景**：写"护工坚持让病人规律，病人偏要随心"的对抗，让同一困境升级 3 次
2. **三法则对白**：把一句普通对白改成"铺垫-强调-反预期"三段
3. **明暗转译**：把[黑色幽默写作](黑色幽默写作.md)里"葬礼上推销墓地会员卡"改写成纯喜剧版——对比两种写法

## 七、本轮项目推荐：给恒润疗养院写一页「喜剧单元」

**推荐做什么**：挑一个日常场景（早餐发药 / 体检排队 / 家属探望），用喜剧三件套（铺垫/三法则/升级）改写成**一页喜剧单元**（Fountain，约 1 页），结尾留一个"心酸"落点。

**为什么值得做**：
- 类型写作系列里喜剧是**最后一块拼图**，且和已有类型互补——悬疑给结构、黑色幽默给锋芒、喜剧给呼吸；
- 疗养院的沉重题材最需要"笑的杠杆"：一个喜剧单元能让全片节奏有起伏，也是检验你能否"用笑的壳装沉的核"；
- **篇幅小**（1 页），30 分钟能完成，正好当练习，失败零成本。

**具体怎么做**：
1. 选场景 + 定主角执念（护工要"规律"，病人要"随心"）
2. 套三件套：一个预期 → 三法则加强 → 升级到荒诞但可理解
3. 结尾落点：笑点结束后来一个安静瞬间（病人终于数完路灯、护工站了会儿才走）
4. 用 Fountain 写，配 [Textplay](剧本创作工具参考.md) 出排版

**产出**：1 页喜剧单元初稿 + 3 句"喜剧/黑色幽默改写对照" → 并入恒润疗养院素材库，也是你喜剧写作的第一份成稿。
