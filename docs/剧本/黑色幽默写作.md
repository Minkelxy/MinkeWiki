# 黑色幽默写作

黑色幽默类型剧本的写法——创作路线里第三个类型选项（与[悬疑](悬疑剧本写作.md)、[温情](温情治愈剧写作.md)并列）。

---

## 一、黑色幽默是什么

| 误解 | 正解 |
|------|------|
| 讲个笑话 | **用荒诞/反讽处理严肃题材** |
| 搞笑就行 | **笑里带刺**——荒诞之下是真实的人性 |

> 黑色幽默的"黑色"是题材（生死/衰老/制度），"幽默"是处理方式（荒诞/反讽）——**用笑的壳装沉的核**。

## 二、核心技法（三件套）

### 1. 反差
- 严肃题材 + 荒诞处理：比如疗养院里"葬礼上有人推销墓地会员卡"
- 反差是黑色幽默的发动机

### 2. 反讽
- **期待 vs 现实**：观众以为要怎样，结果偏偏不是
- 语言反讽：嘴上说的和实际做的相反

### 3. 冷静旁观
- **作者不评判、不煽情**——用旁观者口吻讲最荒诞的事
- 越冷静越"冷"；一煽情就破功

## 三、疗养院黑色幽默素材

| 题材 | 荒诞点 |
|------|--------|
| 衰老/生死 | 排"死亡名额"、给过世病人办"好评返现" |
| 制度/官僚 | 填不完的表格、形式主义的巡查 |
| 家属 | 抢遗产比哭丧积极 |

> 疗养院的"封闭 + 生死"场景天然适合黑色幽默——荒诞就藏在日常里。

## 四、分寸把握（黑色幽默最容易翻车）

- **别冒犯到"人"**：可以讽刺制度/现象，别嘲笑具体的人（病人/家属）
- **荒诞但要可理解**：再荒诞，逻辑要说得通（观众能懂为什么）
- **有"人味"**：纯荒诞会空洞，黑色幽默底下要有真情——**笑完有点心酸，才是好的黑色幽默**

## 五、练习推荐

1. 写一个**反差场景**：把一件严肃的事（如病情告知）用荒诞方式处理，但不失体面
2. 写一句**反讽对白**：嘴上说的和实际做的相反，观众听得懂
3. 对照[主题与结尾设计](主题与结尾设计.md)：想清楚这部黑色幽默的"核"是什么
