## 计划

这次出行可以说是今年最重要的。计划必须尽善尽美，没有机会提前踩点，也要评估到位，做到胸有成竹。实际上是七月四日计划的改良，需要考虑对方的体力，一个人和两个人是不一样的。

预估中午接触，可以先去射箭，然后西夏万达吃饭。吃完玩一个简单的项目，去按摩。按完卡丁车，卡丁车玩完了去稍微逛逛，去吃饭。吃完去看电影吧，或者密室。

所以应该是，西夏区 → 金凤区 → 兴庆区 → 金凤区 → 西夏区。这样看，我应该住在西夏区，先会合去射箭，然后中午吃完饭应该去书店买一些书，然后打车去按摩。按摩完就可以去玩卡丁车，然后去奥莱观察观察。吃饭，吃完去密室逃脱。我觉得这样的安排是相对合理了。

前面的计划被谷哥批评了，没有考虑体力和休息，基本上一直在移动和运动，只安排了吃，没安排喝东西，指望我随机应变是不现实的。细节的地方要注意。吃什么现在基本上是确认的，晚上去吃奥莱的，中午就在西夏万达吃，要去选一个合适的。娱乐项目也是确认的，射箭和卡丁车是必选，密室是机动项目。然后就是考虑这里面的填充物，需不需要在街头走走。在哪里休息，在哪里闲逛。

核心的三个项目是：射箭、卡丁车、吃饭。其他项目都应该是可替换的。

出发的位置在他们学校或者新城，首先抵达贺兰山体育场射箭，预估玩一小时。然后前往西夏万达吃饭。或许可以去科技馆玩玩，绝对是不错的选择。或者这会可以考虑逛逛那天的展会，需要考察一下，总之尽量在新城和金凤区找一些玩的。因为下一站一定是会去按摩，这个店有分店，在金凤区比较方便去。避免这个过程在户外，降低晒太阳时间。

按摩应该在4点后，按完最好早于6点。下一步去卡丁车，位于兴庆区，稍微偏僻。去了后应该在一小时内结束战斗，希望不要排队。然后再切换到吃饭，去奥莱，mbf说有好吃的，就去那家，顺便逛逛。吃完恐怕接近9点了，送回去，计划通。

先问姐姐看看她喜欢吃什么，然后规划一下路线，路线原则上应该要顺行，不能太有冲突，另外要安排充足的休息时间。合理的补水时间，适当的休息，随时准备好变更计划。

备选的项目：浆板、网球、羽毛球，猜测浆板会好，如果科技馆不喜欢，那就浆板。补水应该在所有的大项目后，目测她喜欢喝奶茶，但夏天还是考虑其他饮料好一些。
