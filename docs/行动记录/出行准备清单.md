# 出行准备清单

> 任意时刻出行都要准备的事情。

## 常备（每次都带）

### 电子

- 背包（装下面这些东西）
- 充电宝，随身携带，带 lightning 转接线
- 充电器 / 数据线
- 耳机

### 证件与随身

- 身份证
- 钥匙
- 少量现金（停车、无网络时用）
- 驾照（骑车必带）

### 卫生

- 纸巾、湿巾
- 口罩
- 唇膏、护手霜

### 药物

- 止痛药
- 感冒药
- 外伤：创可贴、碘伏棉签、纱布
- 肠胃药（外出吃饭更稳妥）

### 防晒（宁夏日照强，常年备）

- 伞
- 防晒霜、防晒喷雾
- 墨镜
- 防晒袖套 / 面罩（骑车用）

### 降温（夏季）

- 冰贴
- 小风扇 / 扇子
- 水 / 功能饮料

## 按需（看场景）

### 骑行（摩托）

- 头盔、手套、护具
- 雨衣
- 手机支架

### 过夜 / 远途

- 洗漱用品、换洗衣物
- 拖鞋
- 充电器多带一根

### 户外（爬山 / 徒步）

- 充足的水、能量补充（能量棒 / 零食）
- 防蚊液、止痒膏
- 头灯 / 手电（可能晚归）

### 约会 / 记录

- 相机 / 拍立得
- 小礼物、惊喜
- 湿巾多带一点（户外用餐）

## 出发前检查

- 按清单过一遍，别漏证件和充电宝
- 看当天天气：雨天带伞，高温加强防晒补水
- 手机充满电，确认目的地路线
