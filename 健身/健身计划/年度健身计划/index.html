    年度健身计划¶

    年度健身纲领,明确量化目标,指导训练方向。

    年度核心指标¶

    体能指标¶

    指标 当前值 目标值 优先级
    体重 83 kg 72 kg 高
    体脂率 待测量 % 12-15 % 高
    BMI 25.3 22.0 中

    力量指标¶

    指标 当前值 目标值 优先级
    深蹲 kg kg
    卧推 kg kg
    硬拉 kg kg
    三大项总和 kg kg
    引体向上 个 个

    有氧指标¶

    指标 当前值 目标值 优先级
    5公里跑 分秒 分秒
    静息心率 次/分 次/分

    围度指标¶

    指标 当前值 目标值 优先级
    胸围 cm cm
    上臂围 cm cm
    腰围 cm cm
    大腿围 cm cm

    阶段规划¶

    基础期 (1-3月)¶

    核心任务: 建立习惯,打磨动作

    训练导向: - 频率: 每周3-4次 - 强度: 中等(60%-70% 1RM) - 重点: 动作质量 > 重量 - 容量: 每个部位每周10-12组

    阶段检查点: - [ ] 训练习惯稳定(连续4周达标) - [ ] 三大项动作标准 - [ ] 基础力量提升10%-15%

    强化期 (4-6月)¶

    核心任务: 提升强度,突破瓶颈

    训练导向: - 频率: 每周4-5次 - 强度: 较高(70%-85% 1RM) - 重点: 渐进式超负荷 - 容量: 每个部位每周12-16组

    阶段检查点: - [ ] 三大项达到年度目标的60% - [ ] 体重向目标靠近 - [ ] 围度开始增长

    巩固期 (7-9月)¶

    核心任务: 巩固成果,优化体态

    训练导向: - 频率: 每周4-5次 - 强度: 中高(65%-80% 1RM) - 重点: 弱项强化 - 容量: 根据弱项调整

    阶段检查点: - [ ] 三大项达到年度目标的80% - [ ] 体脂率接近目标 - [ ] 体态明显改善

    冲刺期 (10-12月)¶

    核心任务: 冲击目标,年度收官

    训练导向: - 频率: 每周4-5次 - 强度: 高(75%-90% 1RM) - 重点: 目标导向 - 容量: 根据目标调整

    阶段检查点: - [ ] 三大项达到年度目标 - [ ] 体脂率达标 - [ ] 完成年度测试

    训练频率指导¶

    周计划分配原则¶

    阶段 无氧次数 有氧次数 休息天数 说明
    基础期 3-4次 1-2次 2-3天 适应为主
    强化期 4-5次 1-2次 1-2天 强度提升
    巩固期 4-5次 1-2次 1-2天 弱项强化
    冲刺期 4-5次 1-2次 1-2天 冲击目标

    分化方式建议¶

    训练天数 推荐分化 适用阶段
    3天 全身训练 基础期
    4天 三分化(推/拉/腿循环) 强化期/巩固期
    5天 三分化+弱项加练 冲刺期
    6天 推拉腿各2次 进阶期

    月度检查¶

    每月必测指标¶

    指标 测量频率 记录位置
    体重 每周 身体指标追踪
    体脂率 每月 身体指标追踪
    围度 每月 身体指标追踪
    三大项 每2月 健身记录表
    引体向上 每月 健身记录表
    5公里跑 每季度 健身记录表

    月度复盘要点¶

    1. 数据对比: 与上月、年初对比
    2. 进度评估: 是否按计划推进
    3. 问题识别: 瓶颈和不足
    4. 下月调整: 训练重点和计划微调

    季度复盘¶

    Q1 (1-3月)¶

    检查清单: - [ ] 训练习惯建立 - [ ] 动作标准掌握 - [ ] 基础力量提升10%+ - [ ] 体重趋势正确

    调整方向: - 习惯不稳 → 降低强度,保证频率 - 动作不标准 → 减少重量,增加练习 - 进步过快 → 可适当增加强度

    Q2 (4-6月)¶

    检查清单: - [ ] 三大项达到年度目标60% - [ ] 围度开始增长 - [ ] 体脂率趋势正确 - [ ] 无疲劳积累

    调整方向: - 力量停滞 → 增加容量或改变计划 - 体脂偏高 → 增加有氧或调整饮食 - 恢复不足 → 增加休息或减少容量

    Q3 (7-9月)¶

    检查清单: - [ ] 三大项达到年度目标80% - [ ] 弱项有所改善 - [ ] 体态明显变化 - [ ] 体能指标提升

    调整方向: - 弱项明显 → 增加弱项训练频率 - 体脂不达标 → 加强有氧和饮食控制 - 力量瓶颈 → 尝试新训练方法

    Q4 (10-12月)¶

    检查清单: - [ ] 三大项冲击年度目标 - [ ] 体脂率达标 - [ ] 完成年度测试 - [ ] 总结全年经验

    调整方向: - 目标接近 → 全力冲刺 - 目标差距大 → 调整预期,避免受伤 - 提前达成 → 维持或设定新目标

    年度测试¶

    测试时间¶

    测试 时间 说明
    基础测试 1月第1周 记录初始数据
    中期测试 6月最后1周 评估半年进度
    年度测试 12月最后1周 评估全年成果

    测试内容¶

    力量测试: - 深蹲 1RM - 卧推 1RM - 硬拉 1RM - 引体向上 最大次数

    体能测试: - 5公里跑 最快速度 - 静息心率

    身体成分: - 体重 - 体脂率 - 胸围/腰围/上臂围/大腿围

    调整原则¶

    何时调整¶

    • 连续2周无法完成计划
    • 出现关节疼痛或不适
    • 持续疲劳,恢复缓慢
    • 目标提前达成或明显无法达成

    如何调整¶

    频率调整: - 恢复不足 → 减少1次训练 - 进步缓慢 → 增加1次训练

    强度调整: - 动作变形 → 降低重量 - 轻松完成 → 增加重量

    容量调整: - 时间不足 → 减少组数 - 恢复良好 → 增加组数

    分化调整: - 某部位薄弱 → 增加该部位频率 - 整体疲劳 → 改为全身训练
