    周训练计划¶

    三分化训练安排,每周4次无氧,循环执行。

    使用说明¶

    • 每周日制定下周训练计划
    • 根据身体状态灵活调整
    • 记录实际执行情况
    • 每周复盘,持续优化

    三分化训练体系¶

    训练分化说明¶

    训练日 训练内容 主要肌群
    推日 胸+肩+三头 胸大肌、三角肌、肱三头肌
    拉日 背+二头+后束 背阔肌、肱二头肌、三角肌后束
    腿日 腿+臀+核心 股四头肌、腘绳肌、臀大肌、核心肌群

    每周训练安排¶

    采用 4天无氧 + 3天休息 的模式,三分化循环:

    第一周: 推 → 拉 → 休息 → 腿 → 推 → 休息 → 休息
    第二周: 拉 → 腿 → 休息 → 推 → 拉 → 休息 → 休息
    第三周: 腿 → 推 → 休息 → 拉 → 腿 → 休息 → 休息
    第四周: 推 → 拉 → 休息 → 腿 → 推 → 休息 → 休息

    每3周完成一个完整循环,确保每个部位每周训练1-2次

    进阶调整方案¶

    当某个部位需要加强时¶

    加强胸部: - 增加推日训练频率(每周2次推,1次拉,1次腿) - 在拉日增加1个胸部动作

    加强背部: - 增加拉日训练频率(每周2次拉,1次推,1次腿) - 在推日增加1个背部动作

    加强腿部: - 增加腿日训练频率(每周2次腿,1次推,1次拉) - 将腿日分为股四头肌日和腘绳肌/臀日

    日期 训练内容 时长
    周一 推日 75分钟
    周三 拉日 75分钟

    注意事项¶

    训练原则¶

    • 渐进超负荷: 每次训练尽量比上次多1-2次,或多2.5kg
    • 动作质量优先: 宁轻勿假,感受目标肌肉发力
    • 充分休息: 同一部位至少休息48小时
    • 记录数据: 每次训练后记录重量和次数

    常见误区¶

    误区 正确做法
    每天训练同一部位 给肌肉48-72小时恢复时间
    跳过腿部训练 腿部训练促进全身肌肉生长
    忽视热身和拉伸 热身10-15分钟,拉伸10分钟
    训练时间过长 无氧训练控制在75-90分钟内
    频繁更换计划 坚持一个计划至少8-12周

    调整信号¶

    需要增加强度的情况: - 连续2周可以轻松完成所有组数和次数 - 训练后没有肌肉酸痛感 - 力量增长停滞

    需要降低强度的情况: - 关节疼痛或不适 - 持续疲劳,恢复缓慢 - 睡眠质量下降 - 训练热情降低
