    抖音直播辅助工具 - 功能规划文档¶

    版本: v1.0
    更新日期: 2026-04-28
    状态: 规划中

    📋 文档说明¶

    目标用户¶

    • 颜值主播 / 歌势主播 / 虚拟主播
    • 需要自动化直播辅助的个人主播
    • 希望通过弹幕互动提升观众参与度的主播

    核心目标¶

    1. 降低直播运营成本 - 自动化处理重复性工作
    2. 提升观众互动 - 弹幕游戏、点歌、投票等功能
    3. 数据驱动优化 - 统计分析帮助改进直播内容
    4. 支持虚拟主播 - 符合抖音规范的数字人直播辅助

    📦 功能模块详细规划¶

    模块一：弹幕获取与连接¶

    1.1 弹幕获取方式¶

    方式 优先级 说明
    模拟模式 P0 用于测试开发，生成随机弹幕数据
    WebSocket直连 P1 连接抖音WebSocket（需逆向）
    第三方工具 P2 通过BarrageGrab等工具中转
    官方API P3 等待抖音开放官方接口

    1.2 连接管理¶

    • [ ] 自动重连机制（断线后3秒重试）
    • [ ] 心跳保活检测
    • [ ] 多房间支持（同时监控多个直播间）
    • [ ] Cookie管理（支持登录态）

    1.3 消息类型支持¶

    • [x] 弹幕消息（文本内容）
    • [x] 礼物消息（名称、价值、数量）
    • [x] 点赞消息（点赞数）
    • [x] 进入房间消息（用户进入提示）
    • [ ] 关注消息（新关注用户）
    • [ ] 分享消息（直播间被分享）

    模块二：自动回复系统¶

    2.1 关键词回复¶

    功能描述: 根据弹幕关键词自动回复
优先级: P0
触发方式:
  - 精确匹配: "你好" → "你好呀！"
  - 正则匹配: "主播.*美" → "谢谢夸奖~"
  - 模糊匹配: 包含关键词即可触发
配置项:
  - 回复概率: 0.3 (30%概率回复，避免刷屏)
  - 冷却时间: 5秒 (同一用户冷却)
  - 随机回复: 支持多条回复随机选择

    2.2 智能回复¶

    • [ ] AI对话 - 接入ChatGPT/文心一言等
    • [ ] 情感分析 - 识别弹幕情感倾向，智能回应
    • [ ] 上下文记忆 - 记住对话上下文，连续交流

    2.3 欢迎语系统¶

    • [ ] 新用户进入欢迎
    • [ ] 老用户回归欢迎（根据历史记录）
    • [ ] 等级区分（高等级用户特殊欢迎）
    • [ ] 粉丝团用户特殊标识

    模块三：点歌系统 ⭐ 核心功能¶

    3.1 基础点歌¶

    功能描述: 观众通过弹幕点歌，主播按顺序播放
优先级: P0
指令格式:
  - "点歌 歌名"           # 基础点歌
  - "点歌 歌名-歌手"      # 指定歌手
  - "切歌"               # 主播/管理切歌
  - "取消点歌"           # 取消自己的点歌
限制条件:
  - 每人最多同时点3首歌
  - 同一首歌在队列中不能重复
  - 支持设置禁止点的歌曲黑名单

    3.2 点歌队列管理¶

    • [ ] 可视化点歌列表（Web界面/OBS插件）
    • [ ] 当前播放显示（歌曲名、点歌人）
    • [ ] 预计等待时长计算
    • [ ] 历史点歌记录
    • [ ] 点歌统计（今日点歌数、热门歌曲Top10）

    3.3 音乐平台对接¶

    平台 优先级 说明
    网易云音乐 P0 API完善，曲库丰富
    QQ音乐 P1 用户基数大
    酷狗音乐 P2 部分歌曲独家
    本地音乐 P1 支持播放本地MP3

    3.4 高级功能¶

    • [ ] 自动播放 - 点歌后自动在播放器中播放
    • [ ] 歌词显示 - 同步显示歌词到OBS
    • [ ] 付费点歌 - 礼物达到一定价值可插队
    • [ ] 点歌冷却 - 每人每分钟限点1首

    模块四：投票系统¶

    4.1 弹幕投票¶

    功能描述: 主播发起投票，观众通过弹幕参与
优先级: P0
指令格式:
  主播: "开始投票 选项A 选项B 选项C"
  观众: "投票A" / "投票B" / "投票C"
  主播: "结束投票" / "查看结果"
配置项:
  - 投票时长: 默认60秒
  - 每人限投: 1票
  - 实时显示: 投票进度实时更新

    4.2 投票类型¶

    • [ ] 单选投票 - 只能选一个选项
    • [ ] 多选投票 - 可选多个选项
    • [ ] 评分投票 - 1-10分评分
    • [ ] PK投票 - 两队PK模式（红蓝对决）

    4.3 投票展示¶

    • [ ] 实时票数柱状图
    • [ ] 百分比显示
    • [ ] 投票结果导出

    模块五：弹幕游戏¶

    5.1 互动游戏¶

    游戏 说明 优先级
    弹幕狼人杀 观众通过弹幕参与狼人杀 P2
    弹幕海龟汤 猜谜游戏，主播给出情境 P2
    弹幕抽奖 随机抽取幸运观众 P1
    弹幕红包 虚拟红包，抢红包游戏 P2
    弹幕PK 两队观众弹幕数量PK P1

    5.2 礼物游戏¶

    • [ ] 礼物抽奖 - 送特定礼物参与抽奖
    • [ ] 礼物榜PK - 礼物价值排行榜
    • [ ] 盲盒礼物 - 随机礼物奖励

    模块六：礼物答谢系统¶

    6.1 自动答谢¶

    功能描述: 自动感谢送礼物的观众
优先级: P0
触发条件:
  - 任意礼物都答谢
  - 超过一定价值才答谢（如10钻石）
  - 首次送礼特别感谢
答谢方式:
  - 文字答谢: "感谢XXX送出的火箭！"
  - 语音答谢: TTS语音播报
  - 特殊效果: 触发屏幕特效
配置项:
  - 答谢冷却: 避免连续送礼刷屏
  - 合并答谢: 连续送礼合并为一条

    6.2 礼物统计¶

    • [ ] 实时礼物收入统计
    • [ ] 礼物排行榜（日榜/周榜/总榜）
    • [ ] 金主分析（消费最多的观众）
    • [ ] 礼物趋势图

    模块八：虚拟主播支持 ⭐ 特色功能¶

    8.1 合规检测¶

    功能描述: 确保虚拟主播直播符合抖音规范
检测项:
  - 实时互动检测: 确保有真人互动
  - 内容重复检测: 避免话术重复像录播
  - 画面质量检测: 卡顿、声画不同步检测
提醒机制:
  - 长时间无互动提醒
  - 内容重复度过高提醒

    8.2 虚拟主播专属功能¶

    • [ ] 动作触发 - 特定弹幕触发虚拟人动作
    • [ ] 表情切换 - 根据情绪自动切换表情
    • [ ] 语音合成 - TTS播报弹幕/回复
    • [ ] 多形象切换 - 支持多套虚拟形象

    后端: Python + asyncio + aiohttp
数据库: SQLite (本地) / MySQL (服务器)
前端: Vue.js + Element UI (Web界面)
通信: WebSocket
部署: Docker / Systemd

    ⚠️ 风险提示¶

    平台风险¶

    • 抖音政策变化可能影响功能可用性
    • 非官方API可能被封禁
    • 需要持续关注平台规范更新

    技术风险¶

    • WebSocket连接稳定性
    • 大流量下的性能问题
    • 数据安全问题

    合规风险¶

    • 自动回复可能违反平台规则
    • 需要避免过度自动化（虚拟主播规范）
    • 用户隐私数据处理合规
