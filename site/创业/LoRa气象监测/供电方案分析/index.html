LoRa气象监测节点供电方案分析¶

方案概述¶

供电方案组合¶

采用 太阳能板 + 锂电池 + 超级电容(SPC) 的混合供电方案，充分发挥各组件优势，实现高效、稳定、长期的供电保障。

方案优势¶

  • 太阳能板：持续能源输入，可再生能源
  • 锂电池：可充电，高能量密度，成熟技术
  • 超级电容(SPC)：高功率密度，瞬时大电流放电，长循环寿命

应用场景¶

  • 户外气象监测节点
  • 无人值守长期运行
  • 恶劣环境（高温、低温）
  • 低功耗间歇工作模式

组件特性分析¶

1. 太阳能板¶

技术参数¶

选型建议¶

  • 5W方案：适合低功耗节点，日均功耗<50mAh
  • 10W方案：适合多传感器节点，日均功耗<100mAh
  • 安装方式：倾斜30-45度，朝南（北半球）

成本¶

  • 5W太阳能板：约30元
  • 10W太阳能板：约50元

2. 锂电池¶

技术特点¶

  • 高能量密度：150-250Wh/kg
  • 可充电：可重复充放电500-1000次
  • 宽温域：-20℃ ~ +60℃
  • 高电压：3.7V标称电压
  • 低自放电：月自放电率约5-10%
  • 安全稳定：成熟技术，安全性高
  • 成本优势：价格相对较低

放电特性¶

  • 连续放电：0.2C - 1C（推荐0.5C）
  • 脉冲放电：最大2C，持续时间<10s
  • 截止电压：2.5V

充电特性¶

  • 可充电：锂电池为二次电池，可重复充放电
  • 充电方式：恒流恒压充电（CC-CV）
  • 充电电流：0.5C - 1C
  • 充电电压：4.2V
  • 太阳能作用：太阳能给锂电池和超级电容同时充电

3. 超级电容(SPC)¶

技术特点¶

  • 高功率密度：10-100kW/kg，远高于电池
  • 长循环寿命：100万次以上
  • 快速充放电：秒级充放电
  • 宽温域：-40℃ ~ +70℃
  • 低内阻：毫欧级内阻
  • 高效率：充放电效率>95%

  • 并联：提高容量，降低内阻
  • 推荐配置：2个2.7V电容串联（5.4V）或直接使用5.5V电容

工作模式¶

1. 太阳能充足模式（白天）¶

  • 太阳能板产生电能
  • 通过MPPT充电管理给锂电池和超级电容充电
  • 锂电池电压上升至4.2V
  • 超级电容电压上升至5.5V
  • 超级电容通过LDO稳压给节点供电
  • 锂电池处于充电状态

2. 太阳能不足模式（阴天/夜晚）¶

  • 太阳能板输出不足
  • 超级电容放电给节点供电
  • 当超级电容电压降至3.6V时
  • 锂电池开始工作，通过LDO稳压给节点供电

3. 瞬时大电流模式（LoRa发送）¶

  • 节点需要瞬时大电流（100-200mA）
  • 超级电容提供瞬时大电流
  • 锂电池提供持续小电流
  • 确保LoRa模块稳定发送

4. 长期无光照模式（连续阴雨天）¶

  • 太阳能板无输出
  • 超级电容电量耗尽
  • 锂电池单独供电
  • 可持续供电7-15天（取决于容量）

充放电管理¶

充电管理芯片选择¶

方案一：CN3791（推荐）¶

  • 特点：太阳能专用，MPPT追踪，支持锂电池充电
  • 输入电压：6V - 26V
  • 输出电压：可调（4.2V - 8.4V）
  • 充电电流：2A
  • 充电效率：>95%
  • 价格：约8元

方案二：BQ25504¶

  • 特点：超低功耗，MPPT充电，冷启动
  • 输入电压：0.1V - 5.5V
  • 输出电压：可调（2.5V - 5.3V）
  • 静态电流：330nA
  • 充电效率：>90%
  • 价格：约15元

方案三：LTC3105¶

  • 特点：低电压启动，高效率
  • 输入电压：0.225V - 5V
  • 输出电压：可调（1.8V - 5V）
  • 静态电流：6µA
  • 充电效率：>85%
  • 价格：约20元

充电策略¶

1. MPPT最大功率点追踪¶

  • 实时追踪太阳能板最大功率点
  • 提高太阳能利用率15-20%
  • 适应光照强度变化

2. 分阶段充电¶

  • 恒流充电：快速充电阶段（0.5C - 1C）
  • 恒压充电：电压稳定阶段（4.2V）
  • 浮充充电：维持电压阶段

3. 过压保护¶

  • 锂电池电压上限：4.2V
  • 超级电容电压上限：5.5V
  • 超过上限自动停止充电
  • 防止过充损坏

4. 欠压保护¶

  • 锂电池电压下限：2.5V
  • 超级电容电压下限：3.0V
  • 低于下限停止放电
  • 防止深度放电

放电管理¶

1. 电源切换逻辑¶

void power_management_task() {
    // 读取电压
    float solar_cap_voltage = read_solar_cap_voltage();
    float lithium_battery_voltage = read_lithium_battery_voltage();

    // 电源切换逻辑
    if (solar_cap_voltage > 3.6V) {
        // 超级电容供电
        use_solar_cap();
        log_power_source("Solar Cap");
    } else if (lithium_battery_voltage > 2.5V) {
        // 锂电池供电
        use_lithium_battery();
        log_power_source("Lithium Battery");
    } else {
        // 低电量告警
        low_battery_alert();
        enter_deep_sleep();
    }

    // LoRa发送前预充电
    if (lora_send_pending) {
        precharge_solar_cap();
    }
}

2. 瞬时大电流管理¶

  • LoRa发送前：预充电超级电容
  • LoRa发送中：超级电容+锂电池并联供电
  • LoRa发送后：超级电容快速充电

3. 低功耗策略¶

  • 休眠时：仅锂电池供电，超级电容待机
  • 唤醒时：超级电容+锂电池并联供电
  • 采集时：超级电容提供瞬时大电流

组件续航能力¶

超级电容续航¶

  • 容量：5.5V × 20F = 110J = 30.6Wh
  • 可用容量：3.6V - 5.5V区间，约15Wh
  • 续航时间：15Wh / (3.3V × 1mA) = 4545小时 ≈ 189天（理论值）
  • 实际续航：考虑效率，约30-60天

锂电池续航¶

  • 18650×2容量：3.7V × 5000mAh = 18.5Wh
  • 可用容量：4.2V - 2.5V区间，约15Wh
  • 续航时间：15Wh / (3.3V × 1mA) = 4545小时 ≈ 189天（理论值）
  • 实际续航：考虑效率，约7-15天

混合供电续航¶

  • 晴天：太阳能供电，锂电池和超级电容储能
  • 阴天：超级电容供电，锂电池备用
  • 连续阴雨天：锂电池供电，可持续7-15天

优缺点分析¶

优点¶

1. 成本适中¶

  • 锂电池价格相对较低
  • 超级电容价格适中
  • 整体成本比锂亚电池方案低47元

2. 可充电¶

  • 锂电池可重复充放电
  • 太阳能可持续充电
  • 减少更换频率

3. 技术成熟¶

  • 锂电池技术成熟
  • 充电管理芯片丰富
  • 供应链完善

4. 瞬时大电流¶

  • 超级电容提供瞬时大电流
  • 支持LoRa模块稳定发送
  • 避免电压跌落

5. 高效率¶

  • MPPT充电管理
  • 超级电容充放电效率>95%
  • 太阳能利用率高

缺点¶

1. 寿命相对较短¶

  • 锂电池寿命500-1000次循环
  • 约2-3年需要更换
  • 比锂亚电池寿命短

2. 温域较窄¶

  • 锂电池：-20℃ ~ +60℃
  • 超级电容：-40℃ ~ +70℃
  • 不适合极寒环境

3. 自放电较高¶

  • 锂电池月自放电率约5-10%
  • 长期不使用会自放电
  • 需要定期充电维护

4. 设计复杂¶

  • 需要充放电管理电路
  • 需要电源切换逻辑
  • 需要保护电路

电源管理算法¶

void power_management_task() {
    // 读取电压
    float solar_cap_voltage = read_solar_cap_voltage();
    float lithium_battery_voltage = read_lithium_battery_voltage();

    // 电源切换逻辑
    if (solar_cap_voltage > 3.6V) {
        // 超级电容供电
        switch_to_solar_cap();
        log_power_source("Solar Cap");
    } else if (lithium_battery_voltage > 2.5V) {
        // 锂电池供电
        switch_to_lithium_battery();
        log_power_source("Lithium Battery");
    } else {
        // 低电量告警
        low_battery_alert();
        enter_deep_sleep();
    }

    // LoRa发送前预充电
    if (lora_send_pending) {
        precharge_solar_cap();
    }
}

  • 太阳能板：5W单晶硅
  • 锂电池：18650×1 (3.7V/2500mAh)
  • 超级电容：5.5V 4.7F
  • 充电管理：CN3791
  • 适用场景：温湿度监测，日均功耗<0.5mAh
  • 成本：约83元
  • 续航：晴天无限，阴雨天7-15天

标准节点配置¶

  • 太阳能板：10W单晶硅
  • 锂电池：18650×2 并联 (3.7V/5000mAh)
  • 超级电容：5.5V 10F × 2 并联
  • 充电管理：CN3791
  • 适用场景：多传感器监测，日均功耗<1.0mAh
  • 成本：约130元
  • 续航：晴天无限，阴雨天10-20天
